# 验收标准确认：弱网注入：传输层损伤注入与可视化

> 运行 weaknet-injection · 创建于 2026-10-24

## 验收标准

| 编号 | 验收内容（用户可判断） | 判定方式 |
|---|---|---|
| AC1 | 同一 profile + 种子、固定调用序列下，两次运行的注入决策一致；换种子结果不同；真实对跑可重复跑（不要求逐决策一致） | L3 内核用例（假传输 + 固定时钟） |
| AC2 | 关闭注入时与原传输行为完全一致（不排队、不消耗随机数、统计为零） | L3 用例断言 `RollCount=0` |
| AC3 | 延迟/抖动/丢包/重复/乱序按参数生效；可靠信令（Join/StartGame）不被丢/重复/乱序，且严格保序；队列溢出只影响不可靠包 | L3 用例 + 对跑 Join/StartGame 断言 |
| AC4 | 只在编辑器/开发包/开发宏内装配，且只包真 KCP（本地测试房不包）；release/测试者包不编译注入面 | 装配用例 + 源码/宏守卫 |
| AC5 | HUD 联机段显示当前注入配置与统计；RTT/丢包曲线用 240 样本（≈60s@4Hz）降采样显示并标注真实窗口；无对局时整段隐藏 | App 层文本/曲线用例 + Play 冒烟 |
| AC6 | 预设切换走可审计命令；数值可运行中调；不新增 public static 可变状态 | 命令审计用例 + 反射守卫 |
| AC7 | 固定种子弱网 L3 对跑通过；可定向跑；夜间门禁新增该步骤并可回读 | `test.py --lane L3 --filter ...` + nightly 日志 |
| AC8 | BuildHash 不变；L1、EditMode 定向、L3 定向、doc-lint、toolchain-check 全绿 | 各门禁 |
