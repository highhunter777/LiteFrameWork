# 项目文档与待办总览

> 本文件是当前工作入口。详细历史施工记录已归档到 `Docs/Archive/2026-09-20/`；客户端商业化优先级以《商业级通用客户端框架总设计》C0～C5 为准，服务端优先级以《商业级通用服务端框架总设计》R0～R4 为准。

## 1. 当前基线

- **框架**：LiteFramework 的事件、时钟、StageMachine/HSM、DI、Lua 注册表、资源/UI 壳已形成基础。
- **战斗**：LiteSim.Core 已有 60Hz Sim、固定槽位、hitscan、命令/帧事件、快照/回滚基础；RoomServer 已有权威循环、AOI、回溯、重连骨架。
- **网络**：LiteNet 使用 KCP 双通道 + protobuf；非战斗服务统一规划为 HTTPS/JSON + WebSocket。
- **配置**：Luban 客户端 binary、服务端 JSON、buildHash 链路已存在；当前玩法表仍以 `tbcombatnum` 为主。
- **缺口**：武器、Action/技能、局内/局外背包、聊天、公会尚无正式业务实现；正式战斗场景和 Meta 服务仍需落地。

## 3. 当前优先级

### P0：先修同步契约

1. 补齐 `MatchStateSnapshot`、`PublicCombatState`、`PrivateStateSnapshot`，不能把武器/技能/局内包只放进当前未完整承载的 `CustomData/Globals`。
2. 同步更新 `CopyTo`、`SimChecksum`、`SnapshotDiffer`、`SnapshotCodec`、`SnapshotReassembler`、重连路径和布局测试。
3. 扩展 `InputFrame`/`InputGate`：Reload、Switch、Skill、Pickup、UseItem、`action_seq`；只增 protobuf 字段，不重编号。

### P1：战斗可玩闭环

- 8 人目标，先用 2–4 人无头对跑。
- 步枪/霰弹、弹药/换弹/切枪、死亡/复活、KDA、回溯命中。
- 冲刺、AOE、护盾三项 Action；整数帧时间轴和中断规则。
- 远端插值、本地和解、重连、HUD。

### P2：经济与社交

- 局内 12 格临时背包、拾取/使用/丢弃、`RewardDelta`。
- ProfileService、40 格局外背包、Loadout、Reservation、Mongo 幂等结算。
- Guild CRUD/权限/公告、公会频道、ChatService WebSocket/过滤/补推。

## 4. 验收闸门

- 8 人 3 分钟对局无 tick stall；150ms RTT、10% 丢包可收敛。
- 重连 5 秒内恢复公共状态、本人弹药/CD/局内背包；不重复伤害或结算。
- 所有非战斗写操作带 `requestId`；库存带 revision CAS；公会带 version CAS。
- `dotnet test`、协议 round-trip、无头房间、Mongo 幂等、Unity L2 门禁均纳入 CI。
