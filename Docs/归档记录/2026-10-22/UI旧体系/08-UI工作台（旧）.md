# 08-UI 制作与预览

> **本文定位**：回答“怎么选页/新建页、怎么命名/绑定、怎么校验生成、怎么单页预览”。
> **不做的事**：不裁决设计（归 [UI编辑器工具专项设计](UI编辑器工具专项设计.md) §8）、不记批次证据（归 [施工进度/UI线.md](../../../施工进度/UI线.md)）、不覆盖门禁全表（归 [05-验证与门禁](../../../说明/10-测试与门禁.md)）、不解释 UI 框架机制（归 [03-技术细节-客户端](../../../说明/03-客户端框架与运行时.md) 与 [UI框架总设计](UI框架总设计.md)）。
> **冲突裁决**：与代码不一致以代码为准并顺手修本文。命令中的 `unity command ...` = Unity Pipeline CLI（见 [Unity 操作规范](../../../说明/15-工具链手册.md)）。

## 0. 它是什么

UI 制作主线：**新建/打开页面 → Prefab Stage 布局 → 主窗口就地命名/绑定/控价 → 校验/生成 → 布局预览**。

| 用它 | 别用它 |
|---|---|
| 新建标准页面、维护 BindNode、插控件模板、校验/生成 | 断言 UI 行为——那是 L2 EditMode/PlayMode |
| 看单页布局、保存 prefab 即时热重载 | 验证玩法/网络/房间流程——走 [07-本地联测](../../../说明/11-构建与本地联测.md) |
| 在 Prefab Stage 内改 prefab、选页预览 | 整场景运行时保存——**不做** |

**唯一编辑面是 Unity Prefab Stage**；工具窗口不造第二套画布，不接管几何/锚点/层级。旧 UI 工作台场景/面板已退役；运行内目检收敛为布局预览（§4）。

## 1. 入口与就绪

| 入口 | 操作 |
|---|---|
| **UI 制作** | Hub `LiteGame/工具链` → **UI 制作**；等价 `python scripts/toolchain.py open ui.compose` |
| **新建页** | UI 制作窗口顶部「新建页」，或 Hub → **新建 UI 页面**（`ui.page-new`） |

- **选页**：UI 制作窗口顶部「已登记页面」下拉直接读 tbuiform；选页即打开对应 Prefab Stage 并绑定目标——**不需要去 Project 搜 prefab**。Project/Prefab Stage 手动选择仍可跟随。
- **目标页**：Prefab Stage 打开即绑定；未开 Stage 时只读展示。**改名/绑定/插控件前先开 Stage**（插入控件要求 Stage）。
- 生成绑定代码会触发脚本重编译（窗口状态丢失）；生成后重开窗口并回到目标页。

## 2. 新建页

> **角色边界**：本向导会写 Lua 与 `tbuiform`，属**工程接入**动作；美术起页只复制 `Screens` 视觉基线，不执行登记步骤（角色拆分见 [UI美术角色与交接专项设计 §7](UI美术角色与交接专项设计.md)）。

### 2.1 输入

| 字段 | 说明 |
|---|---|
| 页面名 | `Page_<PascalCase>`，如 `Page_Shop`；根名与文件名同文 |
| tbuiform id | 建议取现有最大业务 id + 1；**201–203 系统反馈面、204–206 静态先例保留区不得复用** |
| layer | 0 全屏页 / 1 覆盖页 / 3 系统面 |
| full_screen | 常规页面为开 |

### 2.2 产物

1. `Assets/ShareResource/UI/Screens/<Page>.prefab`——复制编辑器脚手架 `Tmp_Page` 后改根名，**自包含 prefab**（不是模板 variant）。
2. `Assets/LiteGame/Lua/UI/<Page>.lua`——最小页面骨架（`class` / `_viewName` / `OnShow` / `OnHide`）。
3. `Luban/Data/#uiform.xlsx` 追加一行（`id` / `lua_path` / `prefab` / `layer` / `full_screen`），随后跑 Luban。

脚手架根契约：`Canvas` + `CanvasScaler`（1920×1080，Match 0.5）+ `GraphicRaycaster` + `CanvasGroup`；子件 `Cot_SafeArea` + `SafeAreaReceiver`；不预置 `BindName` / `BindRoot`。

### 2.3 安全与失败

- 写表前备份到 `Temp/uiform-backups/`；id / lua_path / prefab 查重；非法名/保留 id 被挡。
- 表行写入失败：删除本次新建的 prefab/Lua（只删本次产物），报错。
- Luban 失败：回滚表行；本次 prefab/Lua 保留并显式提示“未登记”，按日志修复后重试或手动清理。
- 成功后向导直接打开新页的 Prefab Stage；无 `BindRoot` 时不自动生成绑定代码。

## 3. UI 制作主窗口

### 3.1 分区

| 分区 | 作用 |
|---|---|
| **顶部** | 已登记页面选择器（读 tbuiform，选页开 Stage 并绑定目标）+ 刷新页面 / 新建页 / 预览 |
| **绑定暴露** | 树/勾选/选中；前缀预设（选前缀 + 只填语义名）；批量换前缀 / 同文修复；预览先行；应用直写 Stage 或资产；引用点清单；生成物 hash |
| **受控属性** | 只显示标了 `UiWidgetProperty` 的控件成员；未标注成员没有绘制入口；几何/锚点仍在 Prefab Stage 编辑 |
| **校验·生成** | 窄档（本 prefab）/ 全量档；问题可定位节点；生成路径 B 绑定代码并记录 hash |
| **控件库** | 扫描 `Assets/ShareResource/UI/Widgets` 的 `Tmp_*`；插入到 Stage 当前选中节点（无选中 = Stage 根）；插入后不改名 |

### 3.2 绑定改名闭环

1. 在树中选节点（可勾选批量）→ 前缀/语义自动回显。
2. `预览所选` / `预览批量` → 检查计划与引用点（Lua/C# 字符串字面量）。
3. `应用` → Stage 内走 Unity Undo；无 Stage 时写资产文件（预览先行，应用即落盘）。
4. 改名后按引用点清单同批同步 Lua/C#；工具只提示，不代改。

### 3.3 生成

- 有 `BindRoot` 的 prefab 才显示生成入口；生成确认后触发重编译。
- 生成成功同一步记录绑定面 hash；`ui.binding-hash` 规则只判漂移，不代记录。
- 无 `BindRoot`：路径 B 未启用，只提示，不伪造 hash。

## 4. 单页布局预览

1. 在 UI 制作窗口选中目标页 → 顶部「预览」。
2. 编辑器保存当前场景后打开预览场景并进 Play；页面由 `UiPreviewDriver` 直接实例化。
3. 改 prefab → **保存资产**即热重载（只监听目标 prefab 的导入）。
4. 退出 Play → 自动回到进入预览前的场景；预览中 DevHUD 隐藏，避免遮挡页面。

**是布局档**：不跑 Boot/Lua/数据，文案与数据为 prefab 默认值；按钮回调、列表数据、语言服务不在这档验证。
**需要本地化/真实数据**：走 Boot → Preload → Main 的正常启动与联调，或 L2 PlayMode；本工具不再造第二套运行内目录/注入/HUD 预览。

## 5. prefab 回写（已退役）

专用回写窗口（`ui.writeback` / 菜单 `LiteGame/快捷/Prefab 回写`）已退役：在 UI 制作主线里，Prefab Stage 的原生编辑与 Overrides 已覆盖“改 prefab”需求，Play 内调参不再额外维护一套实例→资产窗口。

- 需要改 prefab：在 Prefab Stage 直接改，保存即落资产。
- 需要 Play 中改实例：用 Unity 原生 Overrides；要把改动固化回 prefab，用 Inspector 的 **Apply**（结构面/引用面按 Unity 原生规则处理）。
- 如果后续出现“必须逐属性挑选、且原生 Overrides 不够”的真实消费者，再按 `ToolInteractionSession` 契约恢复专用回写工具；不靠菜单存在维持。

## 6. 排障速查

| 现象 | 原因/处置 |
|---|---|
| 主窗口显示“未绑定目标” | 从顶部「已登记页面」选页；或在 Project/Prefab Stage 选择 prefab |
| 页面下拉为空/没有新页 | 点「刷新页面」；检查 `Luban/Data/#uiform.xlsx` 与 Python/openpyxl |
| 找不到 Prefab 回写 | 已退役；用 Prefab Stage 与 Unity 原生 Overrides（§5） |
| 插入控件置灰/提示“未在 Prefab Stage” | 打开目标 prefab 的 Stage；无选中时插到 Stage 根 |
| 新建页报 id 已存在/保留 id | 点「建议」取最大业务 id + 1；不要复用 201–206 |
| 新建页报 Python/openpyxl/表源 | 检查 `python --version`、`pip install openpyxl`、`Luban/Data/#uiform.xlsx` |
| Luban 失败 | 看窗口结果与 Console；表行已回滚，prefab/Lua 保留并标记“未登记” |
| 生成后窗口状态没了 | 生成触发域重载，属预期；重新打开 UI 制作并选回目标页 |
| 预览没画面/目标不存在 | 检查目标 prefab 路径；预览只接受已保存的 prefab 资产 |
| 改 prefab 预览不刷新 | 保存**资产**（不是场景）；确认导入完成；点预览横幅「重载」 |
| 预览里看不到 DevHUD | 预览主动隐藏 DevHUD，属预期 |
| 想找旧 UI 工作台入口 | 已退役；用 UI 制作主窗口与布局预览（§1/§4） |

Console 自查：`[UiPreview]` = 预览加载；`[UI 制作]` = 绑定应用；`[UI]`/`[Nav]` = UI 服务与导航。

## 7. 边界与纪律

- **dev/editor-only**：预览场景、脚手架模板、预览驱动都住 `Assets/LiteGame/Editor/`（或编辑器条件编译件），不进收集组、不进构建。
- **不旁路生产校验**：布局预览只做目检；断言、取消/超时、租约清理归 L2；真链路验收走 Boot/联调。
- **不做第二套画布/运行时面板**：布局由 Prefab Stage；不恢复工作台式页面目录、状态注入、HUD 预览。
- **真机验证纪律**：任何“能点/能操作”的结论走真实操作路径（可点性 → 模拟操作 → 副作用断言），不以直调 API 冒充操作过。
