# 服务端宿主结构拆分专项设计

> 版本 1.0 · 2026-10-17 · 状态：归档稿（原现行专项设计）——6A/6B/6C/7A 切分边界即当前实现；批次证据见 [施工进度/服务端装配与结构线](../../施工进度/服务端装配与结构线.md)；退役原因与现行权威见[同目录归档说明](README.md)
> 来源：代码质量审计-服务端 §五 [高]（ServerHost god class 余部）＋ [中]（MetaHost.Build god 方法）；切分边界由 P4 余部判据评估批（2026-10-12 §9.1"块内互调 grep"判据表）预先裁决，本设计只做排期与落形。

## 1 · 目标与总红线

把 `ServerHost`（~2290 行，房间表触点 49 处散布 8 个方法族）按**已裁决的刀**拆到 ~1300 行量级、`MetaHost.Build`（~170 行）收为 ~30 行编排。**行为零变化**是总红线：公共 API 一个不动（ServerHost 公共面被 20+ 测试构造消费）、ACK 四道闸与 P0 红线不触碰、每批全量 LiteNet ＋ L1 门禁收口；新组件一律 `internal` ＋ 批3"单源构造公式"先例（容器注入与缺省自建同一方法）。

## 2 · 切分边界

| 批 | 组件 | 持有 | 宿主保留 | 关键语义 |
|---|---|---|---|---|
| 6A | `RoomRegistry`（Server/RoomServer，internal） | 房间表双结构（字典＋插入序 List）、容量判定、查询、**身份校验**增删、catch-快照读（心跳线程面） | 房间**构造工厂**（模板/多图/数值/Worker 驱动绑定）与**销毁清理**（会话路由复位、邮箱 Complete）——清完经 registry 落表 | 快照读的竞态兜底（扩容撕裂 catch）收进 registry 单点；遍历中增删的 `i--` 补偿语义保持 |
| 6B | `InboundHandlers`（分发＋Heartbeat/Input/Mismatch/RestoreComplete/Leave/StartMatch）＋ `InboundJoinHandlers`/`InboundReconnectHandlers`（Join/重连两族；端口阈值触发的拆分形态） | 入站 `OnData` 分发 switch ＋ 九族处理器 | 传输事件线接线（OnConnected/Disconnected——会话记账＋限流属宿主身份面）、SendToSession/Reject 诊断单点、房间构造/销毁/提交/排空 | **构造器注入协作者**（非每调用端口，`IRoomWorkerHost` 8 成员先例）；注入协作者 **>12 即停刀重切**（拆 InboundJoin/InboundReconnect）；宿主私有 `InboundHostAdapter` 实现端口（6B 实测 8/6/9 成员） |
| 6C | （门控评估，**结论：不切**） | Mailbox 路由族（Submit/Drain\*） | —— | 6C 评估（2026-10-17）：外部触点跨传输回调/宿主节拍/Worker Tick/入站端口，且互锁 Apply 族与 PendingDisconnect——不做，保持宿主现形态；记录见 `施工进度/结构批6C路由族评估.md` |
| 7A | `MetaHostOptions` ＋ `MetaServiceRegistration`（static） | Options/配置/日志接线段；Auth/Lobby/Persistence/Sample 模块注册（功能门随块走） | `Build` 收约 30 行编排；中间件/端点挂载序；优雅关闭与 CLI 解析 | **Meta 源集在 META_TARGETS 闭包内**：批尾必重录 meta BuildHash ＋ `--check`（落形见 `施工进度/结构批7A宿主装配分段.md`） |

## 3 · 明确不切（P4 判例，除非出现新消费者）

Ops 周期打印（无独立状态可搬）、**回传应用族**（Apply\*——P4 已按线程归属裁决留宿主）、**Mailbox 路由族**（Submit/Drain\*——6C 评估：外部触点跨传输/节拍/Worker/入站端口，且互锁 Apply 族与 PendingDisconnect）、排空（对外协调职责）、Pump 骨架。判例依据：外提＝把耦合搬进参数表，收益递减（同 P2 HttpWorker 判例）。

## 4 · 批表与验收

| 批 | 前置 | 验收 |
|---|---|---|
| 6A RoomRegistry | 在途批已收口（工作树干净） | 全量 LiteNet（Release 车道）＋ L1 门禁 ＋ `--check` 双 OK；`RoomDestructionTests` 上报面用例天然钉快照读语义 |
| 6B InboundHandlers | 6A | 同上；Handle 族全链用例已在册，零新用例回归 |
| 6C 路由族评估 | 6A/6B | 裁决记录（预期不做） |
| 7A MetaHost | 无（可插队） | MetaServer.Tests ＋ L1 门禁 ＋ L3（Mongo 可用时）＋ **meta hash 重录** |

每批收尾一律走 batch-wrapup 流程（纪律扫描含注释零施工痕迹、登记表/施工进度回写、独立 commit）。

## 5 · 风险与缓解

| 风险 | 缓解 |
|---|---|
| 6B 端口膨胀 | 协作者 >12 停刀裁决；分发 switch 可留宿主只搬 handler |
| `_currentRoom` 流转时序（ApplySignal 族定位） | 6A/6B 不改写序；全量用例护 |
| 心跳读面竞态语义漂移 | catch/last-good 语义搬进 registry 由既有上报面用例钉 |
| 7A meta hash 漂移 | build-hash-sync 流程强制进批验收 |
