# 爆头带调带工具：双模式视觉调带 + 比例单源化（2026-10-07 同日续）

**用户裁决**：爆头带"过大"的收值不拍脑袋——**人为视觉调整、工具导出**，且**编辑器模式与测试模式都要能调**。

## 落地

| 面 | 落点 |
|---|---|
| 比例单源化 | 新生成件 `HeadBake.g.cs`（`Ratio`，初始 0.775=原值——本批**不改判定值**）；`CombatConfig.HeadHitLine` 改 `HitscanHeight × HeadBake.Ratio`（仍 const，随烘焙身高自动缩放） |
| 编辑器调带器 | `Assets/LiteGame/Editor/HeadHitLineTuner.cs`（菜单 `LiteGame/调整爆头带`）：Scene 视图画命中柱/顶圈/模型锚点参考线（颈 1.277/面顶 1.545/帽顶 1.669/发冠 1.866——`ProbeHeadBand` 实测），**拖黄圈或滑杆**调下沿 → 导出 `HeadBake.g.cs` |
| 测试模式实时预调 | `CombatConfig.HeadHitLineDevOverride`（开发三宏 `UNITY_EDITOR‖DEVELOPMENT_BUILD‖LITEFRAMEWORK_DEBUG` 内，release 编译剥离）+ `HeadHitLineLive`；判定（`ShootingSystem`）与 F11 绘制（`BattleHeadshotDebugDrawer`）同读 Live——**本地服与预测同进程同值，滑杆一动实弹即见 Crit 档变化**；测试面板加滑杆+复位+导出按钮（与调带器共用 `HeadHitLineTuner.Export`） |
| 锚点实测 | 新诊断件 `AgentScripts/ProbeHeadBand.cs`（AimIdle t=0 humanoid 骨骼+renderer 竖直范围）：可见面部 [1.26,1.545]、帽 [1.351,1.669]、发冠 1.866——收带取值的对照系 |
| 过期文案修复 | GmPanel F11 标签"爆头线1.7m/头顶2.0m"（旧文漂移）改动态读常量 |

**沙箱语义**：覆写不落盘、不进 digest/快照（与免死/缩放同性质）；对局中改动后回滚重放按当帧值重判（测试沙箱可接受）；导出触发重编译（对局中导出会中断对局——面板有提示）。

# 枪口烘焙（2026-10-07）

**用户裁决**：逻辑枪口三常量不再手调——**烘焙 prefab 的 `Weapon_Rifle/Muzzle` 锚点位置**；产物形态＝编辑器工具 + 生成文件；参考姿态经复核动画机后改判为**单套 AimIdle**（腰射开火窗 FireIdle 亦以 AimIdle 循环填窗——射弹时刻视觉姿态单族；Idle/Walk/Run 低持姿态不开火、无弹道意义）。

## 交付

| 面 | 落点 |
|---|---|
| 烘焙工具 | `Assets/LiteGame/Editor/MuzzleOffsetBaker.cs`（菜单 `LiteGame/烘焙枪口偏移` + run_script 入口）——采样 prefab 锚点 @ AimIdle t=0，`R` 格式输出，幂等重跑；**美术调锚点/换枪后重跑即重烘** |
| 生成文件 | `Assets/LiteSim/Core/Scripts/MuzzleBake.g.cs`（`Forward=0.7739859` / `Right=0.0829204246` / `Height=1.29482734`；含仓路径与坐标系说明，无日期戳） |
| 常量接线 | `CombatConfig.MuzzleOffsetForward/Right/Height` 改为引用 `MuzzleBake`（值：0.35/0.2/1.0 → 0.774/0.083/1.295）；`CombatConfigDigest` 注释同步（三字段进联机身份不变） |
| 注释同步 | `ProcedureBattle`（删"闭环自激/锚点解耦"过期段——点口径后锚点问题消亡）、`ShootingSystem`（擦顶区间语义例）、`SimRaycast`（"眼高"→"弹道出射高度"）、`HeadshotTests`/`ShootingObstacleTests` 几何注释 |

## 数值影响（如实）

- **枪口高 1.0 → 1.2948**：水平弹道原点抬高；"高差位擦顶"类几何随动（爆头判定不受影响——判据走 `AimPoint.Y`）。
- `ShootingObstacleTests`：偏移平移/镜像用例目标位随新偏移重校（±0.55 替代 ±0.7）；矮盒挡弹用例盒顶改取 `MuzzleOffsetHeight`（端点语义随常量自跟随）。
- 锚点在前低持 bind 姿态下与旧常量差异极大（0.028/0.918/0.566）——不作为参考（已排除并登记）。

## 验收证据

| 项 | 结果 |
|---|---|
| L1 全量 | **1289/1289 全绿**（含改造后的 `ShootingObstacleTests` 几何与 `HeadshotTests` 注释面） |
| SimChecksum 基线 | **重录**（枪口高度变 → 脚本场景馈送几何变；算法零改动） |
| buildHash | 重录 **`f1817648b9c412d3`**（60 文件——新增 `MuzzleBake.g.cs`） |
| Unity 编译 | `completed`、`failed:false`、0 错误（含新 Editor 工具与生成文件） |
| 纪律扫描 | 绿 |

# 身位烘焙（2026-10-07，同日续）

**用户裁决**：服务端身位圆柱以 prefab 的 **CharacterController 为单源**——烘焙生成常量给服务端用（与枪口烘焙同构）；**同批把 CC 调成贴视觉模特**。

## 交付

| 面 | 落点 |
|---|---|
| prefab CC（pipeline 改） | `Player(Rifle).prefab`：r 0.5→**0.32**、h 2.0→**1.80**、center (0,0.90,0)（探针复核实测；贴模特：模型高 1.84 含帽、肩半宽 ≈0.2） |
| 烘焙工具 | `Assets/LiteGame/Editor/BodyCylinderBaker.cs`（菜单 `LiteGame/烘焙身位圆柱`）——读 CC、**校验 center.y == height/2**（圆柱底=脚底）后生成常量 |
| 生成文件 | `Assets/LiteSim/Core/Scripts/BodyBake.g.cs`（`Radius=0.32` / `Height=1.8`） |
| 常量接线 | `CombatConfig.HitscanRadius/HitscanHeight` 改 **const 引用 BodyBake**（从 `LoadFrom` 移除，8→6 参）；`HeadHitLine` 改 **`HitscanHeight × 0.775` 比例派生**（1.55 → 1.395，头带 [1.395,1.8] = 0.405m） |
| 表退役 | `#combatnum.xlsx` 删 `hitscan_radius/hitscan_height` 两列 → `gen.bat` 全链重生成（cs/bin/lua）；消费面同步：`ConfigService`/`CombatNumbers`（日志改 `body=…(烘焙)`）/`FixedCombatConfig`（装载面 6 字段）/L1+EditMode 用例 |

## 数值影响（如实）

- 判定柱贴模特：直径 1.0→0.64m、高 2.0→1.8m——"打空气也命中/无头的头带"收窄（头带上段虚空从 0.33m → 0.12m）。
- 贴墙距离 / 命中判定 / 视图 CC 三方同值联动；爆头带随身高比例缩放（1.395 下沿，零成本可再调）。
- 测试几何随新常量重算：`MovementCollisionTests`（全量符号化到 `CombatConfig.HitscanRadius`）、`ShootingObstacleTests`（偏移用例按 r/R 符号重构）、`SimRaycastTests`（并列切线用 R）、`HeadshotTests` 高差位（柱顶 1.8 后瞄点 2.0 落空 → 改 1.7）、`BattleLaserEditModeTests`（近弧/收敛端点按新常量重算）。
