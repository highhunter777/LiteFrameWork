- [中] `Server/RoomServer/Modules/ServerLoop.cs:77` + `ServerHost.cs:2072` — 命名空间环：Application 层便捷构造 `ServerLoop(ServerHost,…)` 直依赖根目录类型，宿主又持可写属性 `public ServerLoop.LoopStats LoopStats { get; set; }` 反向依赖；同文件通用构造（:86）与 `Ops.BindRoomsGauge` 委托反转（`Ops.cs:569-574`）是既有正形。修法：便捷构造移组合根或改收 `Action pump`；`LoopStats` 改注入只读。
