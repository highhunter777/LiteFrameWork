## 4. 收敛纪律

- **搬目录 = 改结构**：`Assets/` 下文件搬动走 unity-pipeline CLI，并同步 `ScanTargets.cs`、YooAsset 收集组、`Tests.slnx`/csproj（[02 §1.10](../../../规范/02-代码与修改规范.md)）。
- **不改类型、不并类**：只搬文件与改命名空间；顺带合并/改名视为独立批次。
- **每批收口必收紧基线**：`python scripts/gate/dir-flat-lint.py --update`，登记表同步删行；清零后本文件改「已清零」并留归档。
- **新增代码不受豁免**：新目录从一开始就按 ≤5 组织，不进基线。
- **共享包搬动会改 BuildHash**：`com.litegame.{sim,net}` 内文件路径参与源集摘要，P4 批末必须跑 `python scripts/codegen/toolbox.py build-hash` 并同步两端。
