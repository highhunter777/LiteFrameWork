## TakeContainer 消费清单

`GameEntry.TakeContainer()` 是**唯一**允许从外部取"已装配根容器"的口（容器语义不进业务流程）。消费面封闭，新增一行即等于放行一处运行期服务定位——须在评审里说明它为什么不是流程代码：

| 消费点 | 性质 | 说明 |
|---|---|---|
| `LiteGame/Editor/Gm/GMEditorResolve.cs` | 编辑器工具 | GM 工具箱页件的运行态取件单源 |
| `Assets/Tests/UI/PlayMode/BattleSmokePlayModeTests.cs` | PlayMode 冒烟 | 流程机/工厂/服务观测（A12）——测试面允许 |

约束：**产品运行期与流程阶段不得调用**（`Modules/**` 的段与阶段只消费构造注入的能力）；`GameEntry` 的 XML 注释与本表同源维护。
