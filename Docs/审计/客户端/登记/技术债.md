- [中] `LiteGame/App/Bootstrap/ContentModule.cs:102-112` — `PlayerCapabilities` 五项版本全 0、AppVersion/Channel 为空，而 `LiteFramework/Scripts/Core/Content/ReleaseManifestValidator.cs:217-231` 仍逐轴比较；兼容检查实际半关闭，任何非 0 下限清单会被拒。修法：由 `BuildIdentity` 生成真实能力，或显式 `CompatibilityMode.Off` 并加“现有清单接受/拒绝结果不变”对照测试。
- [中] `LiteFramework/Scripts/Core/Logging/Log.cs:35-37,150-162` — 静态环形缓冲 `_ring/_start/_count` 无锁；`LiteClient/Runtime/Battle/BattleContext.cs:174` 订阅 `Application.logMessageReceivedThreaded` 后经 `LiteClient/Runtime/Diagnostics/ClientDiagnosticsBundle.cs:49-52` 读 `Log.Recent`，与主线程写入并发。修法：加锁/原子快照，或回调只投递到主线程后再取日志。
- [低] `LiteGame/Editor/UiTools/Widgets/UiWidgetManifestGenerator.cs` — WidgetSpec 只校验结构，"声明状态/尺寸与实现不匹配"无机制。2026-10-27 探测：30 个模板根均无 LayoutElement/ContentSizeFitter/LayoutGroup，SizeBehavior 是"放置意图"而非模板内实现；模板级机械校验会误报 19/30，须先裁布局契约或改在页面使用点校验。
