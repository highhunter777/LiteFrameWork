## 4. 生命周期与操作协议

### 4.1 两层状态

目标实例阶段为 `Loading → Ready → Open → Closing → Cached → Disposed`。加载/初始化失败进入统一释放终态；缓存打开从 Cached 进入同一打开管线。阶段命名是目标模型，迁移时可映射旧枚举，不强制一次改完所有调用方。

展示状态独立记录 Visible、Covered、Paused、InputEnabled。Covered/Paused 可同时成立；暂停解除不自动解除遮盖；遮盖不自动清除暂停。转场仍是表现阶段，不能成为唯一的清理依据。

- 所有 Open 页面均可关闭，含 Covered/Paused。尚在 Loading 的页面可取消；已 Closing 的调用共享收尾；Cached 的 Close 幂等返回已关闭。
- Show/Close/覆盖重算只能由 UIService 调度，不允许业务任意修改状态或 Logic。
- 初始化失败不得以 Active + NullLogic 伪装成功；只有明确声明无逻辑的静态页可使用空逻辑。
- 回调异常必须有 formId、阶段和内容版本。OnInit/首次 OnShow 失败执行打开回滚；低频交互错误可隔离；持续 OnUpdate 错误停止该更新通道并上报。
- 统一清理先撤销当前显示代次，随后调用受保护的 OnHide，再释放订阅和临时对象；任一清理异常不得阻断后续释放。

### 4.2 首次与复用合流

统一流程：`校验请求/预留操作 → 获取或创建实例 → 持有租约 → 校验版本与初始化 → 建立展示作用域 → 复位视觉 → 排序/遮盖/输入 → OnShow(data) → 入场/替换 → 返回结果`。

- 获取或创建之后只有一条路径；复用只省略仍有效的实例初始化。
- 复位 alpha、位置/缩放基线及动画残留；输入状态由当前层级和输入锁重新计算，不能无条件设 true。
- 同组全屏替换、模态层序等策略对新建和复用一致；旧页保留到新页初始化可提交。打开失败先清新页并恢复旧页。
- 显示请求的数据属于一次打开。已经打开时同请求幂等返回；更新数据使用显式刷新操作，不暗中再次 OnShow。
- 生命周期回调中提出的新操作进入服务队列，安全调度点执行；不得在枚举表/栈时直接改集合。这是重入正确性要求，不以性能占比决定。

### 4.3 并发、取消与失败结果

目标操作结果区分成功/已打开/已关闭/被拦截/忙/取消/失败，并携带 requestId、formId、错误码与诊断信息。兼容期现有 `ShowAsync` 可包装为成功返回 UIForm、失败抛类型化异常；不返回 null 表示进行中。

- 同一 form、同一语义的并发 Show 共享一个实际加载/打开操作。等待者应使用可多订阅完成源或保留后的任务，不能对只能单次消费的 UniTask 盲目重复 await。
- 数据冲突不静默覆盖：默认第一个请求持有数据，后续不同请求返回 Busy；需要替换由显式 Replace/Update 发起。
- 调用方 token 取消仅取消该等待者；无等待者且操作尚未提交时可撤销工作。Close、父 Scope 退出和 Shutdown 对页面操作发出权威取消。
- 取消贯穿加载、实例化后检查、初始化、转场和提交；不能只把 token 传到 loader。
- 每次打开有递增展示代次；异步图片/网络结果/动画回调在写入前验证代次。旧结果必须释放自己的临时资源，不能覆盖复用后的新页面。
- 队列有上限、等待超时和可观测拒绝结果。首版导航操作单写者串行，候选配置 QueueCapacity=8、OpenTimeout=10s、TransitionTimeout=2s；均需目标设备和真实包验证后调整。
- 队列满在创建/入栈/OnShow 之前拒绝；已经接受的操作必须完成、失败或取消。不得丢动画请求后假装页面操作成功。
- UI 操作在主线程执行。取消失败仍需完成所有权清理，不遗留 loading/closing 标记。

### 4.4 作用域、关闭与 Shutdown

| 作用域 | 生命周期 | 所持资源 | 退出动作 |
| --- | --- | --- | --- |
| 实例作用域 | 创建至真正销毁，缓存期间仍在 | GameObject、逻辑实例、绑定元数据、Prefab/字体等长期租约 | 停止表现、释放逻辑/绑定、销毁对象、释放租约 |
| 展示作用域 | 每次打开到关闭 | CTS、按钮和事件订阅、请求等待、临时图标/对象 | 取消、失效代次、OnHide、退订、释放临时资源 |
| 父级 UI Scope | Root/Account/Match/Scene 所属期 | 属于该上下文的实例和导航记录 | 全部强制关闭并按策略销毁；禁止跨账号残留 |

`CloseAsync(reason)` 区分 User/Back/Replace/ScopeExit/Reload/Shutdown。用户关闭可经异步关闭守卫确认；系统清理不受业务“未保存拦截”无限阻挡，必要保存由上层流程提前完成。系统关闭不必播放离场，但必须完成 OnHide 与释放。

`CloseAll` 从全部打开和进行中的操作清理，不只抓 Active 快照；清理期间停止接受会逃出当前 Scope 的新请求。`ShutdownAsync` 幂等：停止接入 → 取消进行中与排队操作 → 关闭全部页面 → 销毁缓存/释放租约和 Lua 引用 → 销毁 DDoL Root → 完成所有等待者。逐项异常汇总上报，不中断后续清理。

## 5. Lua、绑定与资源所有权

### 5.1 Lua 实例与回调

- 注册表保存模块/工厂，由实例工厂执行 `module.new()` 或约定的创建函数；每个页面实例持独立 Lua 对象。先验证返回类型和生命周期方法，再发布为可用实例。
- `self.ui` 绑定在实例上；调用冒号定义的生命周期时显式传 `self`：`OnInit(self, formContext, data)`、`OnShow(self, data)`、`OnUpdate(self, dt)`，无参回调也传 self。
- 所有权分开：注册表拥有模块引用，页面拥有实例和回调引用。页面销毁不得 Dispose 共享模块引用；工厂初始化失败也要释放已经创建的引用。
- 目标扩展回调为 `OnResume`、`OnNavigationResult(result)`、`OnLocaleChanged(locale)`、`OnDispose`；通过可选能力/适配层迁移，不把旧七回调数量设成不可更改限制。OnShow 仅表示一次新打开。
- 按钮、事件、binder 进入展示作用域；OnHide 自动清理。C# 与 Lua 使用同一语义；只移除框架持有的监听，避免 RemoveAllListeners 误删其他合法监听。
- 高频 HUD 不跨 Lua；Lua 心跳先检测方法存在，再构造参数；采用生成的强类型委托/非分配调用，不能只复用 object[] 却保留 float 装箱。
- `IUIData` 保留为边界类型。Lua 数据引用的借用或持有须显式，异步操作持有期间不能由调用方提前释放。
- 白名单继续保留；不向 Lua 暴露容器、任意 GameObject 查找、Transport 或 SimWorld。

### 5.2 资源租约与缓存

与客户端 `IContentService` 对齐，UI loader 返回 `AssetLease<T>` 或等价可释放句柄；Unity 对象引用不能代替包引用计数。

- Prefab 租约从加载完成持有至最后一个依赖实例销毁。缓存实例也算使用者；销毁已安排但 Unity 尚未完成销毁时不得提前卸载依赖。
- 可共享 Prefab 租约，但必须有实例引用计数；关闭缓存页只释放展示期资源，不能把实例依赖提前释放。
- 缓存键至少包含 formId 与内容版本。配置可声明 Singleton/Transient；首版默认单实例，多实例页通过独立 instanceId 定位，不用 formId 覆盖字典。
- 缓存策略为 Resident、LRU、DestroyOnClose；首版实现预算与销毁路径，Resident 也必须计入总预算并有配置上限。记录数量、估算/测量内存、最后使用时间、版本和所属 Scope。
- LRU 只淘汰未打开、未被操作引用的缓存实例。支持低内存、账号切换、内容版本切换和 Scope 退出清理。
- 异步图标/头像采用临时租约 + 展示/列表绑定代次，替换时对称释放。
- UI 前置：实际目标平台 Offline/Host 模式至少一条贯通；模拟模式可加载不代表 Player 可发布。包签名、下载和回滚由内容服务承担，UI 消费其结果。

## 6. 导航、排序、模态与转场

### 6.1 导航与产品流程

显示栈决定当前层序；独立导航记录保存页面、caller、数据/恢复状态与返回结果，不能让每页维护一套返回栈。

- 目标 `GoAsync` Push 当前页到导航历史；`ReplaceAsync` 显式替换当前记录；`BackAsync` 返回上一条有效记录。旧的“同组全屏即 Replace”仅作兼容映射，新导航不得因此丢掉返回历史。
- 本轮即实现基本多步 Back；URI 深链、复杂路由匹配和任意外部直达留待真实消费者。
- Back 优先级：当前模态/确认 → 当前导航页 → 页面关闭守卫 → 平台/产品退出策略。Loading 阻断期间按操作取消规则处理返回，不能悄悄穿透到下层。
- 返回结果经 `OnNavigationResult` 或类型化等待任务交付一次；不调用 OnShow 代替结果。历史页面可缓存或销毁重建，恢复数据和滚动位置由导航记录/页面模型保存。
- `ShowDialogAsync<T>` 返回确认/取消/关闭原因，支持有界队列、优先级、互斥组和 Scope 取消。重复断线/错误弹窗按键合并，不无限堆叠。
- Loading、空状态、错误/重试、Toast 有统一入口；请求失败的反馈可观察，关键错误界面必须可从内置资源启动。统一入口指的是**语义**统一——视觉仍取控件模板并落在 System 层（第 6.2、7 节），不得由服务自建；同一反馈语义不得存在第二条并行实现（如服务内自建 Toast 与控件模板 Toast 并存）。
- **Toast 多条并存（2026-09-25 裁决）**：多条提示同时存在、按序堆叠，每条各自计时长独立消失，不彼此替换、不重置他人计时。堆叠顺序与间距由承载控件定义（承载容器提供纵向排布，不由服务逐条摆位）；提示条数量设上限，超出按最旧淘汰并计数（§6.1"反馈可观察"）。
- 关闭守卫只读状态并返回允许/拒绝/等待确认，不在 CanClose 内无约束地递归发起关闭。

### 6.2 层序、遮盖与焦点

保留语义层 Bottom/Window/Top，可增 Modal/Loading/System；层配置集中定义。排序按当前打开顺序计算，每次入栈、移除、BringToFront、复用后统一更新。

**反馈面归 System 层（2026-09-25 裁决）**：Toast/Loading/错误重试等统一反馈面占 System 语义层，经统一排序器与其余层一并分配 order——不得自建 Canvas、不得使用私有 sortingOrder 跨越层区间。“压过一切 UI”是层序结论，不是可以用魔数预支的权利；私有排序通道与第 7 节视觉单一来源同源，是同一类越权的两种表现。

每页占一个可配置排序区间，页内装饰/特效占受限偏移；层间区间互不重叠。旧的 100 槽位回卷和固定 150/250/350 特效插槽废止。容量不足拒绝并诊断，禁止悄悄复用正在使用的 order。

遮盖从“仍逻辑打开且有遮盖能力”的全部页面推导，不能只看当前 Active。关闭最高全屏时先确定下一遮盖源，再一次性更新各页目标状态；测试至少包含三层全屏、暂停与遮盖重叠、低层新页在高层全屏后打开。

输入由单一协调者综合模态栈、转场锁、暂停和产品策略计算。模态有真实射线遮罩；禁用页面交互不等于停止阻挡下层射线。焦点保存/恢复、键盘/手柄 Submit/Cancel 和平台返回统一处理；自定义 UIWidget 必须遵守上层输入锁，不能仅信赖自身 interactable。

### 6.3 转场生命周期

保留 Push/Pop/Replace 表现策略与 Runner。导航操作决定模式；动画策略不决定页面是否存在。

播放 Handle、Owner 代次、UIClock 驱动和后端清理遵循[动画模块专项设计](../animation/动画模块专项设计.md)；本文继续裁决 UI 操作结果与输入恢复。SetUpdate(true) 不等于接入项目 UIClock，UI Tween 和序列帧须共同落实分域时钟规则。

- 策略增加 CancellationToken 和复位契约。超时/关闭/Scope 退出必须停止其 Tween/异步工作，再恢复目标视觉和输入；迟到回调受操作代次保护。
- 输入锁在接受转场时生效，不能等一帧后策略开始才关。恢复为协调者计算值，不无条件写 blocksRaycasts=true。
- 结果区分 Completed、Skipped、TimedOut、Cancelled、Failed。允许动效失败降级为立即完成页面操作，但必须先复位；页面取消则清理/回滚，不能按成功处理。
- 缩短/关闭动画是质量档和可访问性配置；也要经过相同完成流程。
- Begin/End 只对已接受并开始的事务配对；拒绝有独立结果。事件订阅者异常不允许卡死 Runner。

## 7. 渲染、适配与制作边界

- 默认保留 ScreenSpaceOverlay。统一根 Canvas/CanvasScaler、参考分辨率和 Match 策略；横屏初始参考 1920×1080、Match=0.5，产品可覆盖。页面为子 Canvas 时由根缩放；独立根 Canvas 则需自己的缩放配置，禁止两边重复缩放。
- SafeArea 作用于可交互内容容器，背景可铺满；处理分辨率、方向和安全区变化。测试至少覆盖常规横屏、超宽屏、刘海、窗口缩放；竖屏产品增加相应组合。
- 只有实际世界空间粒子/3D 夹层消费者才启用 ScreenSpaceCamera；独立 RenderTexture 预览可继续显示在 Overlay。多相机、排序和遮罩必须在目标渲染管线验证。
- Canvas 按更新频率、同时可见范围和批次代价划分；不强制每个动态元素一个 Canvas。非交互 Graphic 默认关闭 raycastTarget，只保留必要 Raycaster。
- 图集按页面共享关系和加载/卸载边界组织，不能把所有 UI 强制放进一个大图集；不以旧 packingTag 是否存在作为唯一验收。
- shader 校验实际的 alpha、Stencil Mask、RectMask2D、裁剪和目标平台兼容性，不要求字符串意义上的“继承 UI/Default”。
- 目录继续使用 `Assets/UI/Screens|Widgets|Patches`，字体继续在 `Assets/Fonts`；YooAsset Screens/Widgets 收集路径不互相包含，tag `ui`。具体规则由制作规范与校验器维护。
- 世界 VFX 归表现服务；UiFx 管 UI 动效，UI 内帧动画和粒子由页面/控件持有。跨页预算与降级出现时提取管理器；没有必要先建独立 UI 特效服务。所有播放都进入展示作用域，不携带玩法判定。

**视觉单一来源（2026-09-25 裁决）**：用户可见的 UI 视觉一律来自 `Assets/UI/Screens|Widgets` 的模板；运行时代码不得构建视觉结构——不 `new GameObject` 造 Canvas/Graphic/Text/Button，不 `AddComponent` 挂视觉组件。服务层只持有实例并驱动其状态，不参与外观搭建。层容器节点（`UIRoot` 与各层节点）是层级骨架不是视觉，不在此限。**测试夹具同样适用**：夹具从测试专用 prefab 加载，不拼装，见[UI 测试开发专项设计 §7.2](../../quality/UI测试开发专项设计.md)。

**引导期错误界面——唯一例外**：`ProcedureError` 的兜底界面可在资源系统不可用时以代码构建，须同时满足：

1. **仅限初始化不变量的兜底路径**——触发条件是宿主引导失败或内容不可用，不是任何常规流程分支；
2. **必须绑定冒烟标记作为存在证据**——`BootstrapError` 标记进 `scripts/player-smoke.ps1`，无证据的"兜底界面"不成立；
3. **不得被常规运行路径复用**——一旦某界面在正常流程中也会出现，即失去例外资格，必须回到模板。

第 3 条是例外不被稀释的关键：判据是“资源包可能加载不出来时仍要能显示”，不是“这个界面比较重要”。

## 8. 数据更新与控件

### 8.1 更新分级

| 类别 | 输入与所有者 | 更新时机 |
| --- | --- | --- |
| 静态 | 页面初始化数据 | 初始化/资源或样式版本变更 |
| 离散事件 | ViewModel、语言和红点变化 | 值变化后刷新，重复值跳过 |
| 高频 HUD 数据 | C# HudModel 聚合同帧/同快照变化，DirtySet | 逻辑输入/快照提交后记录脏位，渲染帧 flush 一次 |
| 视觉连续变化 | C# ticker + UIClock | 渲染帧；血条插值、飘字和倒计时 |
| Lua 低频编排 | 可选 OnUpdate | 默认关闭；声明需要时默认 10Hz，可配置预算 |

逻辑输入频率不能绑死视觉动画频率；网络无新快照时血条/转场仍可平滑推进。事件不能先逐条过 Lua 再在 C# 合并。

控件支持 AutoTick 与外部 Tick，任一时刻只有一个驱动者；HUD 挂统一 ticker，独立模板可自驱。倒计时只在显示秒变化时格式化；血条收敛后停止写入；飘字集中更新并有容量；Tween 使用 UIClock 语义。稳定无变化帧不构造闭包、日志串或 Lua 参数数组。

保留单向 UIDataBinder 与命令式 API；同一属性只有一个数据驱动所有者，动效作用属性需要显式协调。暂不引入跨 Lua 双向绑定框架。

### 8.2 虚拟列表

保留 `IVirtualListSource.Bind(index, item)` 的兼容适配，重写内部为窗口复用。

- 节点数由可见容量 + overscan 决定，不随数据总量线性创建；原 HardCap 不能作为“虚拟化”替代或静默截断业务数据。
- 根据 Content 偏移、viewport 尺寸、方向、item 尺寸和 spacing 计算首末索引；维护 Content 总尺寸，水平路径不能使用垂直尺寸。
- 节点重绑先解除旧回调/租约，绑定代次失效，再写新数据；异步头像结果必须核对稳定 key 与代次。
- ScrollRect 监听一次绑定，禁用/销毁对称解绑；重复 Refresh 不增长监听。
- 数据增删保留锚定项或按声明策略重置；减少到 0、短列表、尺寸变化、滚到末尾再缩容都要正确。
- 首版固定尺寸单轴；Grid/变高列表按真实消费者扩展。SimpleListView 用于小列表，不冒充虚拟列表。
- Lua 首版采用 `SetList(name, rows)` 行数据协议，C# 适配数据源，行点击回传稳定 key；禁止每个滚动帧跨 Lua 调 Bind。

## 9. 本地化、文本与可访问性

目标文本链为 `#text.xlsx → 生成 key/语言数据 → LText 服务 → LTextLabel/页面模型`。首版 zh-CN + en；缺 key 开发期报告并显示 `[key]`，发布期先回退源语言，再显示可诊断占位。`Get/Format/Raw` 为目标接口，尚未实现。

- key 命名 `UI.<页面>.<语义>` / `Common.<语义>`；模板参数按编号/语义验证，英文 one/other 显式选取；新增复杂语言时评估复数规则和 RTL，不承诺“加列即可零代码支持”。
- 语言变更刷新本地化组件或 `OnLocaleChanged`，不重跑 OnShow、不重新订阅按钮、不重发业务请求。缓存页重新打开前应用最新语言；Covered 页也更新或记录脏版本。
- 字体作为字体族和 fallback 链配置，检查缺字、图集容量和共享材质；首版可统一 NotoSansSC SDF，但不得以“唯一字体”禁止必要 fallback。
- 作者文本走允许的富文本标签；玩家/外部文本默认禁富文本或经验证的转义路径插入。`<size>` 限范围，sprite/link 有名册与处理器，不开放任意材质/字体标签。
- 长文本用中英真实内容及伪本地化验证；不把“英文固定长 30–50%”当通用事实。关键按钮/结果信息不能依赖截断；正文必须有明确的换行、扩展或滚动边界。
- HUD 数字/计时可使用约定的 Invariant 格式；商店/地区化数字与日期按产品 locale 策略。分清实际倒计时与显示格式，不用 UI 文本决定玩法。
- 支持焦点可见、键盘/手柄导航、字体缩放与减少动效策略；目标平台需要的屏幕阅读/语音接入作为平台适配项明确验收。
- `LTextLabel` 打字机为表现行为，关闭/语言变化取消旧任务；不改变业务数据。

## 10. 热更、环境重建与调试补丁

### 10.1 正式内容更新与同环境扩展

正式发布遵循[热更与内容发布专项设计](../content/热更与内容发布专项设计.md)：首版在冷启动或安全窗口激活同一 Release 的脚本、配置、Prefab 与依赖，受控重建 Lua 环境。先完整校验候选，失败保留旧版本；页面清理沿用本文实例/展示作用域和操作终态，不复用已销毁 env 的对象。

MarkLogicStale/ApplyStaleLogic 保留为迁移/开发接缝，不代表已有生产事务。同环境局部更新仅在模块纯度、候选 require/cache 隔离、完整依赖闭包与恢复测试通过后开放。已打开页若保留旧逻辑，也必须持有其配置、共享模块和资源版本；新页面按新 generation 创建，不能混用依赖。

禁止先清当前脚本/注册表再填充、或将部分失败结果发布为成功。候选执行不打开页面、不订阅正式事件、不写存档；无法保证隔离时采用整套环境重建。ContentGeneration、Lua generation 和显示代次各自承担失效职责。

### 10.2 DevReload / env 重建

停止新请求 → 取消加载/转场/等待 → 全关并销毁该 env 关联实例（含缓存、Covered、Paused）→ 释放所有 Lua 回调、实例、Bridge 缓存和注册表引用 → 销毁 env → 预载/新 env/填表 → 恢复可接入状态。失败进入可重试错误态，不复用旧环境对象。调试重建与正式热更新途径分开。

### 10.3 UIPatch

保留调试补丁设计：既有节点的 RectTransform/TMP/Image/CanvasGroup 属性与文本 key 可记录到 `Assets/UI/Patches/<Form>.uipatch.json`；仅 Editor/dev 宏允许，不进入生产内容包。真机调试写 persistentDataPath 后人工取回。

补丁记录目标稳定标识、Prefab 基版本和旧值；应用在初始化前，应用到资产经 Unity 工具预览差异、Undo/保存，版本冲突不能静默覆盖。生产 Prefab 是发布真相，补丁仅暂存；结构增删归 Prefab Stage，不能形成第二套运行时布局格式。

## 11. 流程边界与生产工具

UI 通过 UseCase/ViewModel 消费业务，不直接碰 Transport、protobuf 或 SimWorld。流程发领域事件，展示协调者决定页面；需要阻塞的业务前置由 UseCase/流程明确等待，动画本身不承载业务成功条件。Scope 退出必须等待清理终态，不能以“流程不等表现”为由跳过资源回收。

Match/Battle/Result 流程、ProcedureArgs 的必要上下文和安全窗口属于客户端/玩法主线的依赖，不计作 UI 已实现。UI 核心 U0/U1 可用 fake loader/model 验证，不等待 M11 成品。

工具顺序：绑定/资产校验 → 生成一致性 → 样式和多语言预览 → 控件编排面板。Timeline 判定轨和导出由 [动作与特效设计](../../gameplay/动作与特效专项设计.md) 负责；不是 UI 核心修复前置。不承诺以行数估计工具成本。

## 12. 验收、预算与观测

### 12.1 分层用例

测试分类和执行仍以 [测试总设计](../../quality/测试开发框架总设计.md) 与 `scripts/test.ps1` 为准；本节只定义 UI 覆盖，不虚构已存在的测试命令。

| 层级 | 必测场景 | 判定 |
| --- | --- | --- |
| L1 | 可抽取纯逻辑：请求合并、队列拒绝、导航历史、深度分配、缓存淘汰、代次与取消 | 一个请求一个终态；排序不重叠；所有权对称 |
| L2 EditMode | 绑定/缺脚本/资源引用/本地化/样式；转场 fake clock/异常/超时 | 正例绿且违规负例红；结果可定位资产 |
| L2 PlayMode | 真 UIService + 真 Lua 页面开关复用；取消加载；三层遮盖；Modal 输入；列表滚动；语言变更；DevReload/Shutdown | 可见可点且数据正确；无迟到写入；清理后无悬挂订阅/对象 |

**L2 PlayMode 现状（2026-09-25）**：`Assets/Tests/UI/PlayMode` 已建并接入 `scripts/l2-unity-gate.ps1` 同一门禁（真 UIService + 真 LuaEnv + 真 prefab，YooAsset EditorSimulateMode）。已覆盖：冷开/关闭后复用（同一实例）/Shutdown 释放/*在途取消（类型化 `UIOpenException{Canceled}` + 租约对称）/暂停（OnPause 且 OnUpdate 停派发）/跨层覆盖（Covered→OnCover、关源→OnReveal）/动画资源组合（按包可用性分流）/反馈面真 prefab。**未覆盖**：列表滚动、语言变更、DevReload 环境重建、Modal 输入；语义 Locator/Driver/Wait/Evidence 分层未建立。
| L4 Player/真机 | 实际 AB/目标加载模式、低内存、前后台、内容更新/失败恢复、长文本/安全区、长时操作与性能 | 达到已记录设备预算并保留构建/日志/Profiler 证据 |

建议回归序列：同页开关 100 次；并发 Show 与中途 Close；首开失败后重试；页面 A/B/A 返回；三层全屏逐层关闭；列表 0/1/500/5000 条首尾往返且反复 Refresh；复用项异步图标乱序；新逻辑语法错误；环境重建后重新打开。只验证最终状态不够，需断言回调次数、引用/订阅数量与峰值。

### 12.2 预算口径

下表为首轮目标，不是已达成成绩。每次测量记录设备、平台、分辨率、质量档、构建类型、页面/数据规模和采样区间；Editor 数字不能代替 Player。

| 指标 | 初始目标/约束 |
| --- | --- |
| 稳定帧 UI CPU | 参考场景 p95 ≤2ms；记录 p99 与尖峰，并纳入整帧预算 |
| 稳定无变化帧分配 | UI 自有热路径 0 B/帧；输入/打开/文本变更分配单独统计 |
| 打开主线程工作 | 单帧实例化+初始化目标 ≤16ms；结算页总工作可另记 ≤32ms，但不得默认允许单帧卡顿 32ms |
| 冷/热打开体验 | 分别统计资源等待、主线程工作、首个可用帧、转场完成时间，不与 CPU 工作混为一项 |
| 单页绘制 | 初始参考 ≤25 drawcall；结合同时可见页面总量和 GPU 时间验收 |
| Overdraw | 热点截图和 GPU 指标确认；旧“全屏一律 ≤2 层”取消 |
| 列表/缓存/特效 | 数量与内存有配置上限；列表节点随视口容量；预算拒绝/降级可观测 |
| UI 粒子 | Demo 首版同时可见系统参考 ≤3，按质量档限制；超限返回降级结果 |

观测点：Show/Init/Commit/Close/Dispose、Lua 回调、转场、列表 Bind/滚动、HUD flush 的 ProfilerMarker；打开/加载/缓存数、租约/订阅/动画数、队列长度/拒绝/超时、列表节点数、内容版本与最近失败。诊断采样避免每帧分配。

### 13.1 暂不做与升级触发

- 不替换 UGUI、不自研 batcher；只有真实平台测量证明现有路线无法满足预算，才立独立选型任务。
- 不构建跨语言双向 MVVM；多个页面需要同模型展示时先扩 C# ViewModel 和单向绑定。
- 不泛化任意 Prefab 分帧实例化；先减少同步工作、预热与分块。仍超预算才设计子块异步加载及其取消/半成品状态。
- UIClock/ticker 优先复用现有时钟；集中调度服务按实际消费者接入，不因已有接口而强制启用。
- 字体特效、材质预设、第二字体按实际内容需求扩，不以旧“空集不造机器”禁止必要本地化。
- 历史环境问题（Luban regen 删除 asmdef、启动场景误用、个人本地 package 路径）归客户端构建/环境任务；UI 验收必须记录所用场景与包模式，不能靠手工恢复掩盖不可复制性。
