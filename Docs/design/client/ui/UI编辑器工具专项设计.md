# UI 编辑器工具专项设计

> 状态：现行专项设计
> 版本：1.0
> 更新日期：2026-09-21
> 适用范围：UI 标记、编排、时间轴和样式编辑器
> 维护责任：客户端工具
> 类别：**工具/编辑器**——编辑器侧能力设计：共性纪律、UI 编辑器两阶段、时间轴编辑器、样式编辑器。制作红线见《UI 制作规范》；排期与批次见《UI 演进路线图》；选型对比与论证见 `Docs/Archive/2026-09-20/`。

## 0. 总则与共性纪律

- 编辑器服务**内容与界面生产**，不替运行时做决定；**产物必须过运行时纪律**——绑定索引可生成、时序为整数帧、模板/表内无裸引用、不引业务依赖。
- 产物全走既有生成链（Luban / gen.bat / 绑定索引），不做编辑器私有运行时格式；产物与手工产物受同样校验；编辑器不引入新运行时依赖（纯 Editor 程序集）。
- **Odin 只进 `LiteGame.Editor`**：运行时组件零 Sirenix 依赖，受控面用自有 attribute 表达、Editor 侧写 Odin drawer 认它——摘除 Odin 只换绘制层，不倒架构。校验展示可用 Odin Validator（独立付费项，未购则自研 ~200 行）。
- 序列化内容（prefab/asset/meta）一律经 Unity/Pipeline，禁手改（UNITY-GUIDE 红线）。

## 1. UI 编辑器（两阶段）

**技术栈定案**：四面板用 **Odin Inspector**（授权已有）。

### 1.1 阶段一：标记工具（随控件模板落地实施）

- 能力：树形视图（BindRoot/BindNode 结构 + 缺失检测）；Inspector 增强（类型下拉/批量改名/复制标记）；场景视图标记叠加；一键校验（重名绑定/缺失组件/重复标记/类型不符/疑似未标控件）；一键生成（`UIBindIndex` + 路径 B 绑定类，多 prefab 批量 + 全局名冲突检查）；校验进 CI 前置。
- 落点：`LiteGame.Editor`（在 `BindIndexBuilder`/`UIBindBase` 之上扩展，不新增 asmdef）。
- 验收：控件库 20 余件模板全量校验通过；生成物与运行时索引一致（Play 断言）；改名/删除标记后一键重生成无残留。

### 1.2 阶段二：编排器（控件模板库就绪后实施）

**分工定案**：几何/层级归 Unity 原生（**画布 = Prefab Stage 原生编辑**，拖拽/锚点/吸附/撤销免费）；自研只做四件面板——①控件库面板（缩略素材架）②标记面板（一键标记 + 暴露清单树）③属性面板（**只显示壳允许的面**，把纪律变物理边界）④校验与生成面板。

- 工作流：Prefab Stage 打开界面 → 控件库拖入 → 原生调布局 → 标记命名 → 属性面板调受控面 → 校验生成 → Play 经 Lua 验证。
- **产物 = 标准 prefab**（原生保存到 `Assets/UI/` 约定目录），无"生成 prefab"步骤。
- 价值不均衡：③④ 是独有价值，①在控件 20+ 才明显；**范围允许按体感收缩**，不凑齐四件。
- 阶段一是阶段二的基础设施（顺序不可颠倒）；控件模板库（25 件，见《UI 制作规范》§6）是素材。

## 2. 时间轴编辑器（技能 + 动画/表现共用）

**定案**：编排层直接用 **Unity Timeline**（内置 1.7.6，零引入成本）；曲线层/状态机层保留 Animator。**自研收窄为三件**（一次性 ≈650–950 行）：自定义轨（判定/表现语义，≈300–500 行）+ 导出器（TimelineAsset → 表，≈200–300）+ 导出校验（≈150）。

### 2.1 轨道映射

| 需求 | 承载 | 自研 |
|---|---|---|
| 判定轨（前摇/判定窗/位移/冷却，Sim 消费） | 自定义 Track + Clip（判定类型/半径/伤害系数/时长帧） | 是（与表现轨共用框架） |
| 表现轨（特效/音效/震屏/飘字） | 自定义 Track + Clip（引用名下拉选，禁手填） | 是 |
| 动画轨 / 属性动画 | 内置 Animation Track | 无 |
| 事件轨 | 内置 Signal Track | 少量接线 |

🔴 **秒→帧硬规则**：Timeline 以秒记录 clip；导出时 `帧 = round(秒 × 60)` 并校验 `|秒×60 − 帧| < 1e-4`，不满足即拒（否则两端判定帧可能不一致）。

### 2.2 数据流（真相方向）

**Timeline 管时序，表管数值**——分层单源，不构成影子真相：时序只来自 TimelineAsset（程序/TA 编辑），数值只来自 `tb_action_num`（策划可改可 diff 可热更）；一键导出（菜单 + TimelineAsset 保存时自动触发）产出 `tb_timeline.tracks` 时序列（紧凑串 `帧:轨类型:参数;…`，产物勿手改）。判定与表现在同一条时间轴对齐。

### 2.3 运行时形态

| 场景 | 形态 |
|---|---|
| 联机技能表现 | **走导出数据 + 序列执行器（M4b），不跑 PlayableDirector**（快照/和解重对齐/`silenceUntilFrame` 与 Timeline 播放模型摩擦） |
| 非对局演出 | 可直接跑 PlayableDirector（白拿） |
| 骨骼/属性动画 | Animator / Animation Track，随 YooAsset 热更 |

### 2.4 导出校验（七类，各配负例）

秒→帧对齐；判定点整数帧且 ≤ 总帧长；引用完整性（特效/AnimationClip/状态名/表 id 存在）；必填参数缺失；语义规则（冷却 ≥ 前摇 + 最短判定窗）；同帧同类冲突；**引用对账**（Timeline 引用的数值键必须在 `tb_action_num` 存在）。

### 2.5 热生效与硬约束

- 非对局态：`IConfigService.ReloadAsync()` 立即生效（Lua 侧消费顺带 DevReload）；**对局中禁止热重载**（技能表参与 Sim 判定，换表破坏确定性与两端一致），提示"下一局生效"。
- 必须落地的纪律：技能表消费点不缓存 `Tables` 跨对局（统一经 `IConfigService.Tables`，对局中快照到上下文）；`ReloadAsync` 清理顺序钉死（清缓存 → 重建 → 通知消费点 → 放行新对局）；对局态守卫；与 DevReload 分工 = DevReload 管 Lua 侧、导出重载管 C# 表侧。

## 3. 样式编辑器（设计稿待实施，批次见《UI 演进路线图》）

> 定位：颜色 token 升级 + 文本样式档收纳（表现层工具，不参与判定）。预算 ~800–1000 行 / 2–3 天。

### 3.1 定位边界

- 无玩法状态、不进运行时包 → **仅编辑器工具语义**；呈现层为 Odin 窗口（`OdinMenuEditorWindow`，只进 `LiteGame.Editor`）。
- **不塞进编排器**：编排器管"某个界面怎么排"，本编辑器管"全工程样式单源与纪律"；接缝 = 编排器属性面板只暴露"选档位"。
- **职责分层定案（2026-09-19）**：编辑器管**静态基准**（出厂默认）；运行时管**动态观感**（按状态/数据/交互改观感）。接缝契约：运行时**只改实例、禁回写 prefab 资产**；对账只读盘上资产、不把运行时表现当漂移；"回基准"是显式动作；性能纪律约束的是**改法**（别每帧标脏 mesh），不是"能不能改"。

### 3.2 档位设计

三层形态：① 单源 = `Editor/Style/UiStyle.cs`（12 色 token，已有）+ `UiTextStyle.cs`（档位表，新）；② 批处理 = `UiStyleTool` 双轴扩展；③ 呈现 = `UiStyleEditorWindow`；④ 纪律 = 校验项进 L2 + 面板展示。

- **两层不混**：档位管"语义角色"（固定一组属性），阶梯 =《UI 制作规范》§2 的合法字号集合 {12,14,16,20,24,32,40}（校验用，不是档位集合）；**颜色不进档位**（仍由 12 token 管，避免双源）。
- 档位最小集（由 25 件模板 30 个 TMP 实测推导）：

| 档 | 字号 | 对齐 | 换行 | 溢出 | 字重 |
|---|---|---|---|---|---|
| `Title` | 24 | Center | 关 | Truncate | 常规 |
| `Body` | 20 | Center | 开 | Overflow | 常规 |
| `Caption` | 14 | Left | 开 | Overflow | 常规 |
| `LabelSingle` | 20 | Center | 关 | Truncate | 常规 |
| `Emphasis` | 20 | Center | 开 | Overflow | 加粗 |

- 垂直对齐统一 Middle、字距/行距统一 0（写进所有档位）；阶梯外档位不预建（YAGNI）。
- 收敛清单：现状 1 处字号 22 不在阶梯上 → 收敛到 24（就近；若该处是"正文"语义则改 20，实施前看实际界面）；其余值直接映射档位，无观感变化。

### 3.3 三个轴的定案

- **标记机制 = 方案 A**：`UiTextStyleRef`（MonoBehaviour + enum，运行时零 Odin）挂在每个 TMP 上选档。可枚举可校验、对账可定位；未标记 = 不动（渐进迁移），对账报告"未标记清单"（后升级为校验失败）。
- **Shader = 只校验、不管理**（2026-09-19 定）：不做 shader 库/变体面板——shader 是工程级基础设施且换 shader = 断批。只做两条：S1 UI 件 shader 必须继承 `UI/Default`；S2 TMP 必用 SDF 变体。
- **字体特效 = 设计暂缓**（2026-09-19 定）：现状 30/30 默认材质无预设，建机制 = 给空集造机器。允许形态：共享 TMP 材质预设资产 + `TextFx` 枚举（初始只 None，非 None 预设 ≤2/页）+ 效果色取自 12 token。硬限制：彩色描边与 `<color>` 同乘顶点色会连带染字面，零自研 shader 下做不到"每文本独立彩色描边"。触发条件 = 模板里第一次出现"确实需要描边"的文本。

### 3.4 批处理与作用域

- **双轴语义不同**：颜色轴 = 最近 token 匹配 + 1e-4 阈值（吸收离散变体）；文本轴 = 按标记档位**精确应用**（整数字号/枚举不用阈值）。改 token/档位值 → 重跑刷新即全量传播，幂等。
- 作用域：`Assets/UI/Widgets/**` + `Assets/UI/Screens/**`。只改已标记组件的文本属性与颜色；不改结构、不动锚点/尺寸、不碰 shader（批①挂标记除外）；全部经 `PrefabUtility`（禁手改 prefab/meta）。
- **纳入**：帧动画资产引用（`AnimatedImage` 的 `Sprite[]`，只校验引用与名册一致，不重排帧序）。
- **不纳入**：tween 参数、粒子参数、`Animator` 参数（归各自规范；"不纳入"= 不进校验，不是禁用）；UI 特效调度主体（已定案不建服务、经 `UiFx` 口，运行时机制见《UI 运行时专项设计》“动效与特效运行时”节——本编辑器只管资产引用，播放归运行时）。

**候选轴（同判据筛选，全部待触发、不占已定批次）**——判据：prefab 上可判定 + 单源值/名册 + 不与池化/合批对冲：

| 候选轴 | 内容 | 性质 |
|---|---|---|
| 尺寸/间距阶梯校验 | 间距 8 的倍数、图标 24/32/48/64/96、安全边距 32（数值化《UI 制作规范》§2 的 ⚪ 建议） | 校验型（整数精确判定，同文本轴性质） |
| Image.Type 用法 | 图标 = Sliced（九宫格）、进度 = Filled、装饰 = Simple | 校验型 |
| TMP Sprite Asset 名册 | `<sprite name=…>` 内联图标引用与名册一致 | 校验型（同帧动画资产引用性质；前置：TMP Sprite Asset 先建，当前 0） |
| 层次深度 | prefab 层级 ≤5 | 校验型（结构类，只报不改） |

❌ 时长/缓动阶梯（0.15/0.25/0.35s、`OutQuad`/`InQuad`）长得最像"样式"但**不纳入**：tween 参数不是 prefab 静态值（生成端在策略件/`UiFx`），归动效与运行时。候选轴全部等各自触发（如尺寸阶梯校验想随批③ 进 L2 时点名确认）；样式编辑器对自身同款纪律：**空集不造机器、加轴等触发**。

### 3.5 校验纪律（进 L2 EditMode 用例 + 面板展示）

| # | 规则 | 强度 |
|---|---|---|
| 1 | 字号落在阶梯 {12,14,16,20,24,32,40} | 🔴（现状 1 处违规：22） |
| 2 | `enableAutoSizing` 必须关 | 🔴 |
| 3 | 字体资产唯一（全 UI 同一 SDF 字体） | 🔴 |
| 4 | `characterSpacing`/`lineSpacing` = 0 | 🔴 |
| 5 | 垂直对齐 = Middle | 🟡 |
| 6 | 每个 TMP 有档位标记 | 🟡 报告 → 后转 🔴 |
| 7 | 文本只放 key 或留空 | 🔴 |
| 8 | 档位值 ↔ 实际属性一致（刷新幂等） | 🟡 |
| 9 | `fontMaterial` 无实例化（全走 `fontSharedMaterial`） | 🟡 报告 → 后转 🔴 |
| 10 | 非 None 材质预设 ≤ 2/页 | 🔴（每多一个 = 拆一批） |
| 12/13 | shader 继承 `UI/Default`；TMP 用 SDF 变体 | 🔴 |
| 11 | 动效/粒子不进校验（运行时行为，扫描器看不见） | 明确排除 |

校验只对**盘上资产**生效（规则 9/10 校验基准引用；运行时换材质受批次数约束、不受这两条约束）。落点：EditMode 用例进 L2，**不给 DisciplineScanner 加规则**（要读的是 prefab 序列化数据 + 组件语义，文本正则做不了）。

### 3.6 其余决策定案

档位就这 5 个（不加 Small/Display）；`UiTextStyleRef` 编辑器侧不允许逐组件覆盖（运行时改实例不受此限）；作用域含 `Screens/`；运行时**给色不给字号**（改字号 = 重排版 + 字体图集重建；改色走 `CanvasGroup`/顶点色批改，`UiFx.Pulse/Flash` 禁对 TMP_Text 调用）；图集 packingTag 不纳入；艺术字/第二字体不纳入（撞字体资产唯一 + 中文 SDF 无 fallback）。
