## 0. 为什么重构（问题登记）

2026-09-27~28 的动画线连续批改暴露了驱动层的**结构性问题**：开火形态配对被实现成散布在 `CharacterLocomotionDriver.Tick/SubmitFire/OnFrameEvent` 里的布尔规则集——`s.IsAim` 合成（瞄准位 OR 射击驻留窗 OR 片段在途）、`AimMoving` 迟滞锁存（两分支手动刷新防陈旧）、移动门控（`if (s.AimMoving) return;`）、起跑终止叠加（moving && inFlight → Stop）、`FireStanceHoldSeconds` 驻留计时。每条规则都对，但**它们是同一件事的碎片**：一个隐式的、没有名字的状态机。

枚举登记面（`CharacterAnimationIds` + `AnimationProfile` + `FrameEventAnimationMap` 三处手工同步）在每加一个语义时都要动三个文件——"现在的枚举太麻烦了"（用户原话，2026-09-29）。三表一致性靠测试钉（映射表↔Profile 交叉校验），不靠结构。

**结论**：把隐式状态机升成显式层次状态机，用框架现成的 `HierarchicalStageMachine`（LiteFramework/Fsm，UnityLib 同步件——不是新造轮子）。

## 1. 分层（上层战斗层 / 下层移动层）——互斥覆盖，单机双根

```
Combat（复合态，根①）               ← 战斗层（上层）：决定"正在干什么"——激活即覆盖移动层
 ├── FireIdle（开火·静止：站姿射击片段按事件重播 / 播完持 AimIdle 循环）
 ├── FireWalk（开火·移动：AimWalk 四向循环——限速走路档）
 ├── AimIdle（瞄准·静止）
 ├── AimWalk（瞄准·移动：4 向 strafe + 步频倍率）
 ├── Reloading（随消费者接入再启用，批C）
 └── Hit / Death / Evade（后续消费者接入时启用，批C）
Locomotion（复合态，根②）            ← 移动层（下层）：默认移动——战斗根不活动时主导
 ├── Idle（速度≈0）
 └── Moving（速度轴 1D 混合 {Idle,Walk,Run}）
```

- **单机双根，互斥覆盖（v0.3 核心语义）**：每槽**一台** `HierarchicalStageMachine`、两棵根树。在战斗根任一态上=覆盖中（移动根整体不活动）；退回移动根=覆盖解除。框架多根=互斥平级根：单活动路径、跨根迁移=全退全进（LCA=0）——正是"覆盖/解除"的语义。**为什么双根成立**：取消半身后同时活动需求不复存在，任何时刻只有一层驱动身体。
- **战斗层不可被移动层打断（v0.5 核心不变量）**：战斗根→移动根**只有两条退根路**——`Fire*`：窗尽 ∧ !IsAiming（开火态自然结束）；`Aim*`：!IsAiming（ADS 解除）。**移动事实（速度/锁存）永不触发退根**——只驱动战斗根内的 idle↔walk 轴（FireIdle↔FireWalk、AimIdle↔AimWalk）与退根时的叶选择。打断只来自战斗层家族自身（批C 死亡/受击/换弹——权威事件），不是移动层。
- **覆盖的机制面=通道接管（§8 纪律扩展）**：战斗动作全走 **FullBody 通道**（无 Mask 整身覆盖）。**各根自管本根通道**：移动根 OnLeave 收 Locomotion 通道（停 MoveBlend 句柄）、战斗根 OnEnter 播 FullBody；反向同构（战斗根 OnLeave 收 FullBody、移动根 OnEnter 重提交 MoveBlend 按当前速度权重）。HSM 事务序（LCA 下先深→浅退出、再浅→深进入）**结构性保证先停旧通道再开新通道**——同帧无两层写身体，§6 单一写入责任成立。
- **战斗根状态 → 通道映射**（全部 FullBody）：
  - `FireIdle` → `AimIdle_Shoot`（2× 速——Fire 事件**按重播**：在播吞/已完重起；**播完窗内持 `AimIdle` 循环**——窗内保持 clip；停步进态同持站姿）
  - `FireWalk` → `AimMoveBlend`（4 向混合**循环** + 倍率；**不播站姿射击**——无移动射击资产，债 #5，反馈枪口特效）
  - `AimIdle` → `AimIdle` 单片段循环；`AimWalk` → `AimMoveBlend`（4 向 + 播放倍率 1×..2× 钳制——限速下恒≈1）
  - 批C：`Reloading`→`Reload`、`Hit/Death/Evade`→`Hit1/Die1/Evade`
- **移动根状态 → 通道映射**：`Idle`/`Moving` 同形态 `MoveBlend`（Locomotion 通道，权重就地连续；态界只服务诊断直读与转换表，跨越不重提交）。
- **半身机构（UpperBody 通道）**：**保留不拆**（后端分层混合/AvatarMask/能力位与契约用例零改动），当前生产消费者为 0——未来需要半身叠加时按消费者重新启用。
- **Profile 仍是绑定单源**：HSM 只持有**状态 ID**，不持有片段名——`AnimationProfile` 的 id→binding/loop/speed 登记面保留。枚举 `CharacterAnimationIds` 从"三处手工同步的词汇表"降为"Profile 登记用的 id 常量"，`FrameEventAnimationMap` 整个废弃（映射=状态机的转换条件）。批B-② 随通道改绑重新登记（Fire/AimIdle/AimMoveBlend → FullBody；登记数据变、机制不变）。

## 2. 状态事实与转换（谁驱动状态机）

**输入事实**（每渲染帧采集，沿用现驱动器来源，零新数据面；**单机单上下文**）：
- `IsAiming`（SimView.IsAiming，Sim 权威）
- `Speed` / `MoveDir` / `Rotation`（视图帧间位移与朝向）
- **`IsMoving` 锁存**——迟滞公式单源在 `LocomotionBlendMath`（进 0.6 / 出 0.3 m/s）；**原始速度的纯函数**，由驱动器每帧算并喂入——战斗根 idle↔walk 轴（两族共用）与退根叶选择**同吃这一个锁存**，机内无迟滞散字段
- 帧事件（Fire——经 SimView.EventSink 静默门，§8 接缝纪律不变）
- 片段完成终态（backend Tick 返回的 done mask）

**开火窗（战斗根复合态持有，Sim 权威+View 同源镜像；六次裁决）**：**开火态＝FireIdle/FireWalk 状态族所在的射击窗语境**——自开火判定起、最后一次开火后窗长内的整段。窗长**单源** `CombatConfig.FireStanceFrames = 60`（**1s @60Hz**——开火动画 ≈0.48s **小于窗**，窗与动画时长解耦；**不变式：窗长 ≥ 开火片段播放时长**（`60 ≥ ⌈0.967×2×…⌉=29`），否则事件后窗先于 clip 尽会截断在播射击片段——一致性校验随批；影响模拟行为 ⇒ 进 `CombatConfigDigest`）。Sim 侧 `EntitySlot.FireStanceFrames`（帧计数，**私有面**——只进全量 checksum，远端开火输入不可重建）在 `ShootingSystem` 开火判定点置窗（与 `FrameEventKind.Fire` 事件**同点**⇒ 两层窗同触发同长度）、每逻辑帧统一递减（整数计数 ⇒ 确定性；缺席/空输入帧与死亡实体照常推进）；**事件刷新＝重置到满窗**（上限即窗长 1s，不累加）。View 侧 `FiringHoldSeconds = FireStanceFrames / TickRate` 派生——**改窗长只动一处**。

**窗内保持 clip（六次裁决核心）**：Fire 状态族持续整窗、**窗内永远有 clip 在播**——
- `FireIdle`：Fire 事件 → 播一轮 `AimIdle_Shoot`（2×，在播吞/已完重起）；**clip 播完 ∧ 窗在 → 态内切 `AimIdle` 循环**（不迁移——"开火动画播完进入 aim 动画循环播放"）；新事件 → 重播射击片段 + 窗重置满窗。
- `FireWalk`：`AimMoveBlend` 四向循环（同窗规则——"firewalk 也一样"）；新事件只续窗（不播站姿 clip，反馈枪口特效）。
- **窗尽＝保持 clip 的终点**：根单点裁决转移——Fire 状态的通道所有权终止、移交次态：**同形态次态就地续播**（AimIdle/AimWalk 的循环与 Fire 态持的是同一 clip——续播保相位，不重提交不闪动）；**异形态由次态提交替换**（移动根 MoveBlend 提交替换、淡出收尾；Death 等打断态同理）。离场不做无条件 Stop。
- **离开开火态即取消限速**（`InputSystem`：瞄准 ∨ 开火态 → `AimMoveSpeed` 走路档——**限速时间＝开火态时间＝射击窗 1s**）：自然结束＝窗尽，被打断＝打断态落地时在其建立点清窗（死亡不特判——输入已丢弃、窗自然衰减；换弹/回避随批C 落地时**双端同批**补清窗纪律）。

**退根/降级裁决单点（v0.5）**：窗递减与退根/降级目标选择**收在战斗根复合态 OnUpdate 单点**——窗尽时按 `IsAiming × 锁存` 选目标：IsAiming → Aim 叶（AimIdle/AimWalk），否则 → 移动根叶（Idle/Moving）。叶只发**层内** idle↔walk 轴请求，且**先判语境解除**（根已挂退根请求时叶放弃一切层内请求——防 last-wins 覆盖与一帧闪现）。

## 3. 不动的东西（明确边界）

- `AnimatorAnimationBackend` / `AnimationLayerGraph` / `ChannelNode` / `ChannelBlendAdvance` / 遮罩机构 / `UpperBodyMaskFactory` 排除面——**引擎机构零改动**（UpperBody 通道当前零消费者，机构与契约用例保留）。
- `AnimationProfile`/`AnimationDefinition`/Blend 数学（`LocomotionBlendMath`）——绑定与权重数学不动（批B-② 只改登记的通道列）。
- 通道语义（Locomotion/UpperBody/FullBody）与淡化时长、截断策略、节点稳定用例。
- `IFrameEventAnimationConsumer` 接缝与 §8 静默门、合并规则——只换消费者内部实现。
- `[Anim][diag]` 诊断面升级为 HSM 状态直读（单机 `Current` 活动路径——"Combat/FireWalk"、"Locomotion/Moving"），IModuleStats 聚合照旧。

## 4. 迁移路径（不推倒）

## 5. 风险与对策

- **HSM 是事务式（一帧一事务）**：全部转换为单跳 Request（跨根全退全进=覆盖切换）；FireIdle 连发重起走态内合并口（不迁移、不触发 LCA）——批B-① 先例保持；退根/降级由根单点裁决，叶先判语境——无 last-wins 竞速。
- **战斗层不可被打断的边界**：移动事实只在层内用——FireWalk 中窗尽 ∧ 仍在移动 → 退根选 Moving 叶，保持 clip 由 MoveBlend 替换、限速同帧解除；反向（移动中开火）随时可进战斗根——**单向可进、退出只走战斗层自己的条件**，正是"上层覆盖下层"的语义。
- **窗长＝1s 独立常量的结构属性（六次裁决）**：开火动画（≈0.48s）小于窗（1s）——**播完由 aim 系循环填满窗口**（窗内保持 clip），这正是"窗与动画解耦"的落点；单发点射后走路档与持枪语境持续 1s；**不变式：窗长 ≥ 开火片段播放时长**（`FireStanceFrames ≥ ⌈片段时长×倍率×TickRate⌉`——否则事件后窗先尽会截断在播射击 clip，一致性校验随批：资产改长/倍率改值 ⇒ 常量必须跟改）；改窗长只动 `CombatConfig.FireStanceFrames` 一处。
- **窗尽移交不闪动**：Fire* 持的 aim 循环与 Aim 叶是**同一 clip**——窗尽转移走"同 ID 在播即续播"（保相位、零淡化、零重提交）；异形态（移动根/打断态）由次态提交替换（后端 0.12s 淡出收尾）。对拍用例钉死"窗尽无 Interrupted、无句柄重建"。
- **跨根切换频率**：ADS/开火窗每次翻转=全退全进+Stop/重提交 Locomotion——与今日"瞄准形态切换"**同频同本**（有界尾部/节点稳定用例已覆盖）；切换接缝的 0.12s 淡化观感归真机手测。
- **站定开火的视觉等价假设**：今日上半身叠加只在站定时出现（移动门控），`AimIdle_Shoot` 整身播与"AimIdle 基础+上半身叠加"预期近等价（同包瞄准姿态族）；真机验收归手测，不等价再议腰射专用片段（债 #5）。
- **同形态跨越不重提交**：Idle↔Moving 同 `MoveBlend`、AimIdle↔AimWalk 同瞄准语境内、**AimWalk↔FireWalk 同 `AimMoveBlend`（跨态同形态——进开火族就地续播）**——跨越只走 `UpdateBlendWeights` 就地调权重（重提交会刷 `Interrupted` + 0.12s 淡化接缝），对拍用例钉死。
- **确定性边界**：HSM 全在 View 侧、不碰 Sim 事实；唯一例外是**开火窗的 Sim 侧镜像**（`FireStanceFrames`）——由开火判定（输入驱动）派生、回放可重建，只进全量 checksum；View 侧动画仍被静默门挡在门外（不播双份）。
- **和解 churn 边界（如实登记）**：`FireStanceFrames` 私有 ⇒ 和解基线早于开火帧时，窗内公共 `Vel` 逐快照纠偏至窗尽（有界 churn ≤ 窗长 1s/次点射；远端视图走快照插值不受影响）。**根治＝协议加列**（`SlotDelta` 带窗计数、只增字段号），首版不做，登记在《角色状态与动作专项设计》§7。
- **步频倍率缩放恒≈1**：窗内与瞄准中均被限到走路档 ⇒ `speed/AimMoveSpeed ≈ 1`——倍率缩放成为恒等路径；机制保留，确认无第二用途后随批退役。
- 平面机对拍用例已有（框架 §HSM 文档"flat 机 = 退化形态，两者有对拍用例"）——复用该测试基建。
