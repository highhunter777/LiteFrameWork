# 联机同步策略选型

> 状态：已决策，持续复核
> 版本：1.0
> 更新日期：2026-09-21
> 适用范围：联机模式、同步范式和切换触发条件
> 维护责任：网络同步

## 1. 两根策略轴

| 轴 | 当前选择 | 切换粒度 |
|---|---|---|
| 模式轴 | TopDown 3D 射击（后置 FPS） | 构建级/启动配置 |
| 范式轴 | 状态同步（服务器权威） | 构建级/启动配置 |

一个构建只包含一种 `(模式, 范式)` 组合；不做房间级混跑。

## 2. 共享底座

传输与协议、RoomServer 流程、Join/buildHash、UI/Lua、镜像/插值机制、重连接口都共享。战斗协议只有 LiteNet/protobuf 一份，不引入第二套消息定义。

## 3. 范式差异

| 面 | 状态同步 | 帧同步预案 |
|---|---|---|
| 权威循环 | 服务器跑 Sim、广播快照 | 服务器中继输入，影子 Sim 校验 |
| 数值 | float/IEEE | 定点数整层替换 |
| 客户端 | 预测、回滚、快照和解 | 全体输入重放 |
| 重连 | 权威快照 + 输入历史 | 关键帧/输入追帧 |
| 当前状态 | **正在实施** | 未启动、显式失败 |

## 4. 装配纪律

- 启动配置选择策略，未实现组合必须明确报错，不能静默回落。
- 当前 Sim/Core/LiteNet 不写模式分支；差异只放策略实现和装配点。
- 帧同步触发判据和成本见《帧同步备选方案》；当前开发只按《状态同步专项设计》执行。
