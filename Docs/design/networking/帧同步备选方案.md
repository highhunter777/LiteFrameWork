# 帧同步备选方案

> 当前不启动。主路线是《状态同步专项设计》的服务器权威状态同步。
> 状态：备选，未启动
> 版本：1.0
> 更新日期：2026-09-21
> 适用范围：状态同步无法满足产品目标时的备选评估
> 维护责任：网络同步

## 1. 触发条件

仅在以下情况之一持续成立时评估启动：

- 状态同步带宽无法满足目标人数/地图规模。
- 服务器权威迭代成本成为主要瓶颈。
- 必须支持低带宽、大人数、强复查的锁步玩法。

## 2. 与当前路线的差异

| 面 | 状态同步 | 帧同步 |
|---|---|---|
| 数值 | float | Q16.16 等定点数整层替换 |
| 服务器 | 权威 Sim + 快照 | 中继输入 + 校验 |
| 客户端 | 预测/和解/插值 | 确定性重放/回滚 |
| 重连 | 快照恢复 | 关键帧/输入追帧 |
| 反作弊 | 服务端事实 | 逐帧校验/分歧定位 |

## 3. 启动成本

需要新增 M7′ 数值层、M10′ 网络层、全量 determinism/回放验收；预计 3–5 周，不得在当前 Sim 内预写空分支。

## 4. 启动检查

确认带宽数据、目标人数、作弊模型和复查需求；新建独立策略程序集；通过全量输入重放、跨平台 checksum、断线追帧和分歧定位测试后，才允许切换构建策略。
