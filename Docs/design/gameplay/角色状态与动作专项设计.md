# 角色状态与动作专项设计

> 状态：现行专项设计
> 版本：1.2
> 更新日期：2026-09-27
> 适用范围：角色 Sim 状态、输入控制、网络映射和表现状态
> 维护责任：角色与表现

## 1. 三层边界

| 层 | 职责 | 禁止 |
|---|---|---|
| Sim | 移动、朝向、动作阶段、状态效果、战斗判定 | Unity/Lua/框架引用 |
| 控制器/网络 | 采集设备意图、帧对齐、输入校验、发送 | 直接改 Transform 或权威状态 |
| View | 镜像、动画、特效、音效、相机、HUD | 回写 Sim 判定 |

## 2. 状态模型

- `ActionState`：`ActionId/StartFrame/Phase/SourceId`，阶段为 `None/Windup/Active/Recovery`。
- 每实体一个主动作槽；技能、冲刺、交互、死亡/复活可进入；移动、瞄准、连发射击不进入。
- **瞄准态**（右键举枪）：**权威公开状态**——`EntitySlot.Flags` 的 `Aiming` 位（该位集随公共快照/差分/checksum 下发，远端可见），不进主动作槽；链路口径、限速与朝向规则见 §7（**主体已交付 2026-09-27**，余项登记在 §7 末）。
- `StatusSlot`：固定数量的 `EffectId/EndFrame/Param`；眩晕、护盾、无敌等限时状态住 Sim。
- 仲裁优先级：死亡 → 状态压制 → 主动作 → 移动/瞄准 → 表现过渡。

## 3. 输入三件

1. `IIntentSource`：键鼠和触屏输出相同的 Move/Aim/Buttons。
2. 上下文门：UI/菜单打开时输出零战斗意图。
3. 帧边界门：渲染帧只刷新待用意图，逻辑帧消费一次；追帧不产生额外输入。

服务器重新绑定 EntityId，并校验移动/瞄准向量、帧号、按钮白名单、动作频率和 `action_seq`。

## 4. 动作和武器的协作

- 连发 Fire 每帧由 `WeaponSystem` 处理，不占主动作槽。
- Reload/Switch 若有前后摇，使用 `category=reload/equip` 的 ActionState 参与仲裁。
- `ActionSlots.TryOccupy/Release` 统一处理冲刺、技能、交互和换弹冲突；同帧按优先级和 EntityId 决定。

## 5. View 驱动

角色动画的 Profile、CharacterAnimationDriver、播放器与后端按[动画模块专项设计](../client/animation/动画模块专项设计.md)实施。本文负责角色事实与输入边界；播放时钟、打断结果、资源和池化契约由动画专项维护。

- Animator 参数只由 Sim 快照/事件推导，单向写入；值不变不重复写。
- 本地相机跟预测位置，和解期间跟表现位置；远端插值。
- 开火枪口反馈可立即播；命中、受击、死亡和技能结果只由权威事件触发。
- `silenceUntilFrame` 防回滚重放重复特效、音效和震屏。

## 6. 验收

- UI 打开时角色不动；追帧输入次数准确；非法按钮被拒绝。
- 动作前摇/判定/后摇、状态持续、回滚重放两端一致。
- 本地移动无明显延迟，远端不抖，和解不重复播事件。

## 7. 瞄准态（右键）实施口径（**主体已交付**，2026-09-27；余项见表末）

瞄准是**权威状态**而非纯表现（它改变移速/动画/相机）：任一段缺席要么表现为"客户端按了没效果"（白名单/预测清零），要么表现为"远端永远不举枪"（没落 Sim 状态）。自下而上逐段落点与状态（✅ = 已交付，⏳ = 待做）：

| 段 | 落点 | 要点 | 状态 |
|---|---|---|---|
| 输入资产 | `Player.inputactions` 的 `GamePlay/Aim`（Button 型，绑 `<Mouse>/rightButton`） | 资产已存在，无需新增 | ✅ |
| 设备源 | 输入三件第 1 件（`NewInputIntentSource.Sample`） | `Aim.IsPressed()` 拼进 `Buttons`；**连续意图**，不带 `action_seq` | ✅ |
| 输入面 | `SimInputFrame.ButtonAim`（位 9，**不进**离散意图位集） | 位定义见[业务总设计 §3.2](游戏业务系统总设计.md#32-输入位和边沿) | ✅ |
| 预测/回放 | `SimInputFrame.PredictedButtons` + `RollbackSim.PrepareNext` | 预测帧只保留**连续意图位**（开火/离散位不进预测）——否则本地举枪会在缺真实输入的帧闪断；新增连续位时改这个常量，别在回滚代码里散写位 | ✅ |
| 服务器准入 | `InputGate.AllowedButtons` | 白名单加位；未登记位会让**整条输入**被丢弃（客户端正常、服务器判非法） | ✅ |
| Sim 状态 | `EntityFlags.Aiming`（`EntitySlot.Flags` 位 0），由 `InputSystem` 每帧从输入位覆写 | **输入位与实体标志位是两个位空间**（各自命名常量，值可相同）；`Flags` 已在 checksum / 公共快照 / 差分器 / `SlotDelta.flags` 内 ⇒ **协议零改动**、远端可见 | ✅ |
| **限速** | `CombatConfig.AimMoveSpeed` = `MoveSpeed × AimMoveSpeedFactor(0.5)`，由 `InputSystem` 应用到移动速度 | 0.5 = 乘 2 的幂（**位级精确**、不引舍入）；= 2.5 m/s 恰为视图 Walk 档上界 ⇒ 瞄准移动只需一套 `AimWalk_*`，不需要 AimJog。值已进 `CombatConfigDigest`（联机身份） | ✅（表化待补 ⏳） |
| **朝向派生** | `InputSystem` 的 `Yaw` | 瞄准中**或开火帧** → 朝准星（腰射的射击方向来自 `Aim`，身位必须跟枪口一致，否则子弹像从侧面飞出）；否则有移动 → 朝移动方向；都没有 → **保持上一帧**（不拿零向量退化，且回放/重放可重建） | ✅ |
| 表现读取 | `SimView.IsAiming(slotIndex)` | 本地取预测态（**按实体 Id 解析槽位**，不能把带版本的 Id 当下标）、远端取最新权威快照的位（离散位"取新不取插值"；槽位已死/首快照未到 → false） | ✅ |
| 动画 | `CharacterLocomotionDriver`：非瞄准 = `MoveBlend{Idle,Walk,Run}` 速度轴混合；瞄准+静止 = `AimIdle`；瞄准+移动 = `AimMoveBlend{AimWalk_F/R/B/L}` 四向插值 | **权重由 Driver 给**，经 `UpdateBlendWeights` **就地调参**（不换句柄/不重建节点/不产生终态）；唯一迟滞在"瞄准静止 ↔ 瞄准移动"（进 0.6 / 出 0.3 m/s），两轴权重本身连续故无需迟滞 | ✅ |
| 相机 | `ProcedureBattle` 已留缝（`SimView.LocalAimPointPosition` + 场景 `/Aim Camera`） | 瞄准位为真时抬 Aim Camera priority；是否同时切换瞄准解算相机需手测手感 | ⏳ |
| 散布/后坐 | `ShootingSystem` + 玩法表 | 瞄准降低散布（腰射反之） | ⏳ |

**余项与边界（登记在案）**：① 瞄准的**散布/后坐**数值差异（需表列 + digest + buildHash）；② **瞄准相机** priority 与解算切换（手测项）；③ 限速数值**表化**（加列 `aim_move_speed`，当前是代码常量）；④ 混合的**步幅对齐**未做（片段按 1× 播，观感校准留 G2 手测）；⑤ 腰射**专用动画**未做（开火绑定仍是 `AimIdle_Shoot`，非瞄准腰射复用同一片段——真实开火消费归 G2）。
**门禁口径**：L1（位定义 / 预测保留 / 限速 / 朝向 / `Flags` 读写 / 混合权重就地更新）、L2 EditMode（驱动速度轴与瞄准四向权重、迟滞、Profile 混合槽位命中片段表）、L3（服务器白名单接受 + 快照携带该位）、手测（相机与手感）。
