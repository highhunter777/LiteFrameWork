# 动作与特效专项设计

> 状态：现行专项设计
> 版本：1.0
> 更新日期：2026-09-21
> 适用范围：ActionSystem、动作表现、世界空间 VFX 和预算
> 维护责任：战斗表现

## 1. ActionSystem

动作系统覆盖有前摇/持续/后摇的离散动作：技能、冲刺、蓄力、交互、死亡/复活；移动、瞄准、连发射击属于连续系统，不直接进入动作时序。

- 每实体一个主动作槽。
- `ActionState` 记录 id、起始帧、阶段和来源。
- 中断规则、优先级、消耗和效果由 Luban 表驱动。
- Timeline 只负责编辑和导出；Sim 只执行有限效果指令，不执行任意 Lua/MonoBehaviour。
- 联机判定走 Sim；表现轨由 View 序列执行器消费。

## 2. VFX 服务

VFX 是表现服务，不是玩法系统：不保存判定状态、不修改 Sim、不调用音频服务。

```csharp
IVFXService.Play(defId, attach, follow, scale)
IVFXService.Stop(handle)
IVFXService.StopAll(attach)
```

内部负责 YooAsset 加载、Prefab 池化、挂点跟随、自动回收和基础预算；触发时机由 View 观察状态差分/帧事件决定。

## 3. 联机规则

- 回滚期间由 `silenceUntilFrame` 防重复播放。
- 特效不能携带命中、伤害、碰撞等事实。
- UI 动效走 `UiFx`，音频走独立 AudioService。
- 首版只做同屏数量上限和低端机降级；跨特效优先级/抢占后置。

## 4. 验收

播放/停止/跟随/回收正确；池化无异常实例增长；超预算按配置降级；回滚和重连不重复播关键事件。
