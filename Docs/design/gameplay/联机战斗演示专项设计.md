# 联机战斗演示专项设计

> 状态：现行专项设计
> 版本：1.0
> 更新日期：2026-09-21
> 适用范围：联机战斗垂直切片、灰盒验收与演示内容
> 维护责任：联机玩法

## 1. 首版规格

| 项 | 规格 |
|---|---|
| 视角 | 3D 俯视角，自由瞄准 |
| 房间 | 8 人目标，先 2–4 人灰盒验收 |
| 操作 | PC 键鼠；触屏沿用同一 Move/Aim/Buttons 输入面 |
| 战斗 | hitscan、伤害、死亡、延迟复活、KDA、比分 |
| 武器 | 步枪 + 霰弹枪，弹药/换弹/切枪 |
| Action | 冲刺、AOE、护盾 |
| 局长 | 3 分钟或击杀目标先到 |
| 地图 | 单张灰盒地图，视觉与 Sim 判定数据分离 |

## 2. Sim 清单

移动/瞄准、武器运行态、ActionState、状态效果、命中/伤害、死亡/复活、比分、局内背包和结算触发全部住 Sim。客户端只预测移动/朝向；开火、技能和拾取结果等待服务器事实。

## 3. 表现和 UI

- `SimView` 负责槽位镜像、远端插值、本地和解衰减和事件静默。
- 相机跟本地预测位置；和解期间跟衰减后的表现位置；震屏由 View 观察事件触发。
- HUD：HP、护盾、弹药、换弹、技能 CD、比分、击杀提示、延迟/丢包。
- UI 逻辑走 Lua/C# Bridge；高频 HUD 由 C# 脏位更新，避免 Lua 每帧调用。

## 4. 时间轴和技能

Unity Timeline 是编辑入口，自定义判定/表现轨，导出 `tb_action`/`tb_action_num`。秒转帧使用 `round(seconds*60)`，误差必须 `<1e-4`；对局中禁止重载。

## 5. 联调顺序

`地图提取/角色动画 → 输入和三个门 → SimView/相机 → 武器表现 → Action/VFX → HUD → RoomServer/重连 → 8 人验收`。

## 6. 完成判定

- 8 人目标局跑通，远端平滑、本地和解不抖。
- 150ms RTT、10% 丢包下可收敛；重连恢复公共/私有状态。
- 技能判定、冷却、消耗和表现同轴；AOI 不影响判定结果。
