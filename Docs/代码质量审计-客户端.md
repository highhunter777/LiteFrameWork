## 总评

单文件质量高于平均水平：注释即契约、fail-fast、有界队列、端口分离、常量集中、全库无 TODO 标记、Security 无硬编码密钥。真正的结构性问题不在"烂代码"，而在三个系统性模式：

1. **"单源"承诺靠人肉同步而非机制**——FSM 双内核互抄、SimChecksum 字段清单手抄两份、动效默认值三份副本、SimTrig 表长双写。守卫测试钉不住"改一处漏一处"。
2. **能力先行、接线缺位**——KcpNetworkService/AudioService/UIBindBase 路径 B/CommandCenter 批3 功能/主流程不开 UI，全部无消费者或断链，编译器与测试都不拦，属静默半成品。
3. **临时手段沉淀成常态**——`[Diag]` 哨位进了热路径、反射取容器断链、静态可变全局进了确定性判定路径。"排查完即删"的债从没人删，已反向塑造代码结构。
