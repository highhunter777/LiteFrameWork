# 测试开发方案（精简版）

## 1. 测试分层

| 层 | 内容 | 工具 |
|---|---|---|
| L1 | 纯 C# 规则、协议、Sim、库存/公会/聊天纯逻辑 | `dotnet test` |
| L2 | Unity 编译、资源/meta、EditMode、Prefab/UI 自检 | Unity Pipeline |
| L3 | RoomServer + 无头客户端 + 网络损伤 | PowerShell/测试 harness |
| L4 | 真实设备、性能、灰度和运营回归 | Unity/部署环境 |

L1 是主回路；L2 检查引擎资产；L3 检查联机行为；L4 不替代前面三层。

## 2. 必测规则

### 框架和配置

- DI 注册/解析/循环依赖/Seal。
- 事件订阅注销、池化双归还、时钟分域、FileSys 原子写。
- Luban 三端产物、缺表 fail-fast、buildHash 不一致拒绝。

### Sim 和网络

- 固定布局深拷贝、checksum、输入排序、命令轮次、帧事件清理。
- 移动/朝向预测、回滚、快照差分/重组、AOI 等价性。
- 回溯命中窗口、无效输入、伪造 EntityId、超频 Fire、重连恢复。

### 六大系统

- 武器射速/弹药/换弹/多弹丸/重复包去重。
- Action 前摇/判定/后摇/冷却/中断/资源。
- 局内背包堆叠/拾取/使用/掉落/回滚 checksum。
- 局外库存 revision CAS、幂等、结算 ledger。
- Chat UTF-8 限长、敏感词、限频、频道权限、seq 补推。
- Guild 角色矩阵、并发 CAS、审计日志、邀请过期。

## 3. 联机验收

- 2–4 人先行，最终 8 人房 3–5 分钟无 tick stall。
- 150ms RTT、10% 丢包/乱序下最终收敛，和解率目标 ≥99%。
- 重连 5 秒内恢复公共状态、本人私有状态和局内背包。
- 同一可靠命令重试 100 次只执行一次；不重复伤害、扣物品或发奖励。

## 4. CI 门禁

《CI门禁（L1-L2）》是 Unity 门禁唯一入口；本文不重复 CI 操作细节。每个新增状态字段必须同时增加快照、checksum、重连和测试用例。

## 5. 不自动化的内容

不把肉眼观感、复杂美术质量、网络运营策略和第三方账号验证伪装成 L1 单测；它们进入 L2/L3/L4 验收清单。
