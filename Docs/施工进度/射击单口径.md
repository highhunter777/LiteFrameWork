# 缺陷修复：擦边命中（"准心在圆柱上却射不中"，2026-10-07 同日续）

**用户报告**：准心在圆柱内/轮廓上却射不中；疑与水平（枪口）偏移有关。

## 复现与根因（实测）

- 新增全几何扫描（相机 rig (0,10,−8) → AimPoint → 逻辑枪口弹道；距离 1.2–24m × 6 方位 × 可见弧/顶盖采样）：
  **1566 例 12 例失败（0.77%）**，全部为"瞄在柱轮廓边（擦边几何）"，全部由**命中圆闸**拒绝；
- **根因 = 圆闸数值消减**：旧式 `c2 = |m|² − b²` 是两个 ~D² 量级大数相减——float32 消减误差随距离放大
  （实测虚假 `c2−r²` = **+1.7e-5 ~ +7.8e-5**，18–24m）。AimPoint 由相机射线 ∩ 同一圆柱解出、**落在表面上**，
  命中线数学上必经表面；只有擦边时真实 c2−r² ≈ 0 ⇒ 误差符号一翻即"整发拒掉"。
  **修复 = 垂距直接分量计算（`p = m − b·D̂`）+ `SimRaycast.TouchEpsilon = 1e-5` 接触容差（切线视为命中）**。
- "水平偏移"的角色（回答）：不是根因，但是**放大器**——枪口前向 0.774m 偏移让"子弹切线锥"与"相机切线锥"
  错位，擦边带恰好落在玩家可视轮廓边缘；F11 画出圆柱后玩家精确瞄圈 ⇒ 体感集中爆发。

# 命中柱拆分：判定宽容 / 物理体宽解耦（2026-10-07 同日再续）

**用户报告**：准心只瞄角色**下半身**才能中，瞄**上半身**射不中。

## 复现与根因（实测，推翻上一轮取值）

- 探针（BakeMesh 真变形、旋转不变"离轴最大半径"）量战斗姿态视觉轮廓：
  **Idle：下 0.27~0.29 / 上（武器 0.59、长发 0.37）**；**AimIdle：下 0.40~0.43 / 上（长发 0.64、武器 0.77）**。

  （手臂/持枪/长发/站姿）远超躯干 ⇒ **上半身绝大多数可见部位落在命中柱外**：准心压上去时相机射线

# 缺陷修复：自瞄下激光"瞄地"（瞄准点事实源绑错，2026-10-07 同日三续）

**用户报告**：自瞄爆头（`AutoHeadshotRig`）开启时，瞄准激光不指角色头部而是**瞄地**；疑参数有错。

## 根因（接线错误，非参数）

`ProcedureBattle.AimPointOf` 曾把激光端点/相机构图/传送的瞄准点**绑定在"鼠标源实例"上**
（`input.Source is NewInputIntentSource`，开局装配时抓取具体实例）：
- 开局后换源（自瞄件 `SetSource`）⇒ 闭包仍调**旧鼠标源**的 `TryGetAimPoint`——鼠标停在地面 ⇒ 激光/构图追鼠标
  ⇒ **"瞄地"**，与真实弹道（走 `Pending` 意图帧，自瞄点是对的）脱节；
- 开局前已换源 ⇒ 判定失败返回 null ⇒ 激光落**枪管模式**（枪口朝下自然扎地）⇒ 同症状。
**结论**：子弹一直是对的，是激光在说谎；任何"换意图源"的验证件（自瞄/触屏/测试替身）都会踩。

## 修复

`AimPointOf` 改绑 **待上行输入帧**（`IInputService.Pending` 的 AimPoint 三分量；零值 = 无点 → null）——
准心/激光/相机构图/传送与开火**同吃一份事实**；任何意图源（含 `AutoHeadshotRig`）下"激光=准心=弹道"同源不失效。
消费点（激光注入/`SetAimPoint` 构图/传送）无需改动，语义自动统一。

## 验收证据

| 项 | 结果 |
|---|---|
| Unity 编译 | 0 错误（客户端表现件，不进 buildHash/L1） |
| 实机复核项（待用户） | F12 自瞄：激光端点应压在目标头部带内并与弹道同终点；换源开关前后不脱节 |
