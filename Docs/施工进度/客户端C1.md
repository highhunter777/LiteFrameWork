### 2026-09-23 · C1-①②③ ClientHost/AppLifetime 交付（已完成，待提交）

**代码位置**：

- `Assets/LiteFramework/Scripts/Core/Hosting/ClientScope.cs`——作用域原语：命名 + 链接父级 CTS（父子取消级联；父/外部令牌互斥）+ IDisposable LIFO 登记（逆序释放、单项异常隔离聚合、幂等）+ 登记进已死作用域就地释放并显性失败。`Core/Hosting/ClientModule.cs`——`IClientModule`（InitializeAsync/ShutdownAsync 契约：ct 穿透不吞、关闭可重入不抛）与 `ClientContext`（根 Scope + 按类型产物袋：同型重复登记即装配错误；Require fail-fast）。
- `Core/Hosting/ClientHost.cs`——注册顺序 = 初始化顺序 = 关闭逆序（依赖图由调用序表达，Host 不推断）；初始化失败**只逆序关闭已成功模块**后原异常上抛（确定错误态）；ShutdownAsync = 刷新钩子（登记序，失败聚合）→ 逆序模块关闭（单模块失败不阻断，OperationCanceledException 区分主动放弃）→ 根 Scope 释放；幂等；平台事件订阅口（Pause/Focus/LowMemory/QuitIntent，订阅者异常吞并聚合）；`Product<T>()` 只读产物透传（引导适配器驱动容器/流程机用）；**无静态可变状态**，`ResetForEditorReload()` 为未来静态门面唯一清理入口。
- `Assets/LiteFramework/Scripts/Unity/App/AppLifetime.cs`——Unity 平台桥：OnApplicationPause/Focus/OnLowMemory/OnApplicationQuit → Host 转发；退出序列 = QuitIntent 收集 → 刷新钩子 → ShutdownAsync（有界等待 `GracefulShutdownMaxMs=3000`，挂死模块不放行成僵尸）；`RuntimeInitializeOnLoadMethod(SubsystemRegistration)` 转发静态清理（Domain Reload 关闭场景）；OnDestroy 走同一完整关闭（非 Quit 销毁路径不泄漏）。生命周期消息为 public——编辑态 SendMessage 不派发引擎消息（ShouldRunBehaviour 断言，L2 实测），直调 public 是 EditMode 可测的唯一形态。
- `Assets/LiteGame/Runtime/Main/Hosting/GameModules.cs`——GameEntry 装配步骤全量模块化（9 模块）：PlatformInfrastructure（FileSys/Log）→ Settings（Load；退出 Save）→ Clocks（双轨时钟/事件/墙钟）→ Schedulers（逻辑/UI/时间轴）→ LuaHost（组件；退出 Shutdown）→ Config → UiShell（注册表+红点+UIService；退出红点清空）→ Presentation（Entity/Audio/VFX）→ Container（容器注册 + CreateMachine 流程机平移）。产物经 ClientContext 传递（同型唯一、Require fail-fast）；每模块 Shutdown 只调已存在能力，缺口（UIService Shutdown/租约/VFX 释放）登记归 U1/M11。

**实施口径偏离与登记**：

1. **IClientModule 契约为 UniTask**（§6.1 设计原文）；为此 LiteFramework.Core 双轨引入 UniTask（Unity 内嵌源码 + dotnet NuGet 同版本 2.5.11）。Core 的"零依赖"属性从"零第三方"放宽为"零引擎 + UniTask 客户端异步单源"——LiteSim/LiteNet 纯度红线不受影响。
2. **AppLifetime 生命周期消息改 public**：编辑态 SendMessage 不派发引擎消息（ShouldRunBehaviour 断言，L2 实测）；直调 public 方法绕开编辑态限制，引擎运行时行为不变。
3. **模块 Shutdown 只调已存在能力**：Settings 退出 Save、Lua Host Shutdown、红点 Clear；VFX/Entity/Audio/FSM 无关闭面 = no-op 并登记（实例/租约释放归 U1/M11）——本批交付 Host 编排与逆序保证，不虚构尚未存在的释放语义。
4. **GameEntry 静态收敛幅度**：仅删 RegisterInstance 死入口与 M0SelfTestRunner 注入（吸收客户端线清理）；`s_booted` 幂等标记保留静态（跨场景重载防重复引导，不持真实生命周期）。
5. **BuiltinBundleBuildInvoker 为本批新增**：C0-③ 的 Offline 冒烟走的是双标记中"错误 UI"分支（内置包从未真实构建——`Bundles/` 只有 Simulate 产物）；本批补齐"AssetService 就绪"健康分支的可重复生产方式，并纳入冒烟必验。
