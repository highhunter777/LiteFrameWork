### 5. 接缝 3：IUiOperationQueue（已完成）

- **契约与实现**：`Assets/LiteClient/UI/UiOperationQueue.cs`——`IUiOperationQueue<T>` + `UiOperationQueue<T>`（FIFO／容量／拒绝计数／取队／清空），**唯一允许 `Queue<T>` 作为 UI 调度器的地方**。
- **共用面**：`UINavigationController` 的 `Queue<NavOp>` 与 `UITransitionRunner` 的单槽待办都改为该原语（容量 8 / 1、丢弃计数读数不变；导航超时清扫逻辑保留在导航侧）。

- **验证**：Unity 重编译 0 错；`UiTransitionEditModeTests` + `UiNavModalEditModeTests` + `FeedbackServiceEditModeTests` + `PageFlowBattleMenuEditModeTests` **41/41 PASS**。
