# 注释标准化

《AGENTS 代码规范 6》全局落地：第一方代码注释只描述现有设计与实现——施工过程、批次、迁移叙述一律进本目录，代码里只留契约、约束与"为什么"。

## 标准（2026-10-02 用户确认口径）

- **保留**：类型职责（1-3 行）、参数/返回值、不变量、线程与性能约束、当前禁止事项、必要的"为什么"（只看现在）。
- **删除**：日期戳、批次号、"此前/原先/后来/改为/已收/回退/迁移/翻红/裁决"等过程叙述、口径变更史、旧路径与旧类名示例。
- **压缩**：类型头大段（ASCII 图/表格/多段引用）→ 1-3 行；签名自释的成员注释直接删。
- **断言消息/日志文案**同标准：只删历史叙述，不改断言逻辑与阈值。
