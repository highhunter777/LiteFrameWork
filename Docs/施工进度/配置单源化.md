## 实现

| 位置 | 实际变更 |
| --- | --- |
| `Luban/Data/#combatnum.xlsx` | 移除 gravity、entity_hp，保留移速/射程/伤害原值 |
| `#movementconfig.xlsx` | 保留现有 gravity，成为重力唯一表源；此文件未修改 |
| `#entityconfig.xlsx`、`__tables__.xlsx` | 新增实体定义表 id/initial_hp；默认角色 id=1、HP=100，双端分组登记 |
| `Assets/LiteClient/Adapters/Serialization.Luban/SimConfigMapper.cs` | 共用三表校验/投影；RoomServer 只源链接同一无 Unity/UniTask 依赖文件，不引用客户端程序集 |
| `ConfigService.cs`、`Server/RoomServer/CombatNumbers.cs` | 客户端预取新增实体表；两端重力/生命均由共用映射装配，双列对账退役 |
| `CombatValues/MovementValues/MovementConfig/CombatConfig/EntityValues` | 标明表归属；默认重力由 MovementValues 提供，默认生命由 EntityValues 提供 |
| `Assets/GameData/{Generated,Config}`、`Assets/LiteGame/Lua/Cfg` | Luban 重生成 C#/binary/Lua：combatnum 退列、Tables 增实体表、实体三份产物新增 |
| `Luban/gen.bat`、`scripts/codegen/gen-luban.ps1`、`Luban/gen_lua_keys.py` | 去个人绝对输出路径；C#/binary/Lua/LuaKeys 先在 Assets 外生成，全部生成成功后发布；保留原行尾、跳过相同文件，不删除或恢复 asmdef/meta |
| `Tests/LiteNet.Tests/ConfigurationSourceTests.cs` | 新增 14 项回归；既有 CombatNumbersTests 与客户端 EditMode 对账面同步适配 |

`CombatValues.Gravity/EntityHp` 保留为对局固定快照字段，是所属表的投影，不构成第二套可编辑表源。机制仍只接收 primitive 实例；没有扩大为整条移动/实体系统接口重构。当前数值保持 move=5、gravity=-20、range=100、damage=25±1、hp=100；同值摘要与 Sim 行为保持一致。

工作开始时已有武器/散布/切枪等未提交改动，本批基于其继续施工并保留它们；全量测试数量不能全部归于本批。
