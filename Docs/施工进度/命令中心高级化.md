## 施工记录（2026-10-03，批1–3 一次工作面交付——同文件/同装配链交叠，代码两笔提交【批1+2 随 GM 样例 / 批3 高级形态】、本节分批记录）

### 批1 命令核心

- 契约件（`Assets/LiteFramework/Scripts/Core/Command/`，一类一文件）：`ICommand`/`ICommandHandler<T>`/`CommandResult`（readonly struct——设计草图的可变字段写法与 readonly struct 语义冲突，改 readonly 字段 + 构造；CS8340 实测）/`CommandReject` 归因面（None/GmBlocked/HandlerRejected/HandlerFault/InterceptorRejected）/`CommandOptions`/`ICommandCenter`/`CommandCenter`。
- `CommandCenter`：Register（唯一处理器 fail-fast；`IDisposable` 幂等注销——**首版 Dispose 里 `_center=null` 画蛇添足破坏幂等，实测 NRE 后去除**）；Send（权限门→处理器；无处理器=编程错误直接抛；处理器异常隔离为 Failed + 日志 + 审计；处理器拒绝 Reason 缺省归一 HandlerRejected）；命令对象生命周期归调用方；审计环 32 条无条件记录（预分配环形）；IModuleStats 四键。
- **权限门可测接缝**：`gmEnabled` 构造注入（Core 不含宏判定）；L1 用例两态实测（三宏内放行 / 传 false 模拟 release 得 GmBlocked 且 GmBlocked 与 Failed 不混）；生产接线=ContainerModule 按三宏并集传入。

### 批3 高级执行形态（设计 §4——"地基完整性优先于当前无调用方"四形态全入契约）

- **排队执行** `SendQueued(cmd, delayFrames=0)`：入队即移交（fire-and-forget）；Tick 到期按入队序执行（快照量 + 出队回队相对序保持——同事件中心延迟模式）；执行时同样过权限门与拦截器链（经 Send 同一核心）；有界 `MaxQueued` 256 + `_queuedDropped`（Snapshot 增量键）+ 溢出与执行完回收池化命令；无处理器入队时早暴露（编程错误）；Tick 内缺处理器边缘隔离不炸泵。
- **异步处理器** `IAsyncCommandHandler`（ValueTask——Core 零第三方不引 UniTask）+ `RegisterAsync`/`SendAsync`（同键互斥两向 fail-fast；OCE 透传取消语义归调用方）；**Send/SendAsync 双向形态检查**（打错面 = 编程错误直接抛——首版 Send 缺守卫直接强转炸 InvalidCastException，实测补上）。
- **拦截器管线** `ICommandInterceptor` + `RegisterInterceptor`（登记序；任一拒绝 = InterceptorRejected 短路不执行处理器；异常 fail-open 同事件拦截口径）。
- **撤销重做**（opt-in）：`RegisterUndoable`（`IUndoableCommandHandler : ICommandHandler` 追加 Undo；Registration.Undoable 位）；仅同步 Send 成功入撤销栈（容量 64 淘汰最旧——List 队尾弹出/队首淘汰）；**入栈即移交撤销所有权（"生命周期归调用方"的可撤销例外——契约例外写入设计 §4 与接口注释）**；新成功命令使重做线失效；Undo 异常不回塞防死循环；Redo = 经注册期定型的 adapter 走 Send 同一核心重新 Execute（**首版 adapter 只有 SendQueued 建并且 Redo 依赖它，实测失败后把 adapter 建造移到注册期——治本**）。

### 过程实测（踩坑登记）

- readonly struct 的实例字段必须 readonly（CS8340×2 轮）——设计草图的 field-initializer 写法两侧都编不过，统一改 readonly + 构造函数；内部可变结构（PendingCommand/UndoEntry）用普通 struct。
- `Math.Min(long,int)` 返回 long——审计读取面的容量换算要显式 cast（CS0266）。
- **同类型 vs 异类型注册的双测陷阱**：TCommand 由处理器类型推断——想测"不可撤销不进栈"必得**另立命令类型**，同类型双注册会被唯一处理器契约当场拦（实测红后改 Plain 类型）。
- adapter（`Func<object, CommandResult>` 闭包）建造时机：**注册期定型**，勿在排队/重做等调用点惰性建——Redo 不经 SendQueued 时表为空（实测红根因）。
- Unix 泛用惯用句（`||` 语句分隔符）在 PS 5.1 不可用——bash/sed 调用改 .NET API 行手术（`ReadAllLines`+`WriteAllLines` UTF8 无 BOM）。
