# 命令中心高级化：施工进度

> 依据：[《命令中心专项设计》](../设计文档/architecture/命令中心专项设计.md)（目标契约与验收以设计为准，本文件只记录施工状态与证据，不在此重复定义）。
> 背景（2026-10-03 规划）：全仓无任何命令面基建（无 `ICommand`/命令注册/GM 命令清单）；`DebugTuner` GM 面板是公有字段旋钮 + `Inject` 直调服务（连续状态直调），离散调试动作散落无统一入口。定位裁定：**统一命令中心**——类型化命令总线（注册/执行/结果）+ GM 权限门（三宏分流），GM 面板为第一消费端，G3 业务命令后续接入。

## 批次规划

| 批 | 范围 | 状态 |
|---|---|---|
| 批1 命令核心 | `Core/Command/` 契约类型（`ICommand`/`ICommandHandler<T>`/`CommandResult`/`CommandOptions`/`ICommandCenter`）+ `CommandCenter`（Register 生命周期/Send 执行序〔权限门→处理器〕/重复注册 fail-fast/处理器异常隔离/审计环 32 条/`IModuleStats`）；`CommandCenterTests`（L1：权限门两态、无处理器 fail-fast、审计与统计口径等） | **规划中** |
| 批2 GM 发现面与诊断 | `GetRegisteredInfos`/`GetAuditLog`（Debug 三宏读取面）；`DebugTuner` 示范接入 1 个 GM 命令（消费端闭环验证，旋钮不动）；测试 | **规划中** |

## 边界（登记，非本专项范围）

- 排队/延迟执行（延迟通知归事件中心 `PublishQueued`）；撤销/重做（客户端撤销无权威语义）；异步处理器（`Send` 保持同步，真实异步命令出现再加 `SendAsync`）；拦截器管线（校验归处理器）；网络转发（`RoomCommand`/协议层职责——命令中心不做权威不发网络）。
- `DebugTuner` 连续旋钮（时间缩放/暂停）保持直调形态，不强行命令化。
