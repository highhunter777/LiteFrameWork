## 裁决与边界

- **后坐 = 准心冲量**（用户裁决）：每发上跳 + 指数回弹并入屏位写入——非相机 kick（固定斜视角下相机后坐归另一战场，未裁决不预建）。
- **表化落点 = 新表现域表 tbcrosshair**（用户裁决）：tb_weapon 是判定面表（bytes 进 digest），纯表现列入内会造成"表现调参强制两端表同步"的摘要漂移——落 UI 域（同 tbanimationprofile 先例：单端热更不换联机身份）。
- **Luban 登记坑（新）**：`__tables__.xlsx` 登记行 **A 列标记必须 `'##'`**（留空会让该行按另一形态解析出同名第二类型，报"类名小写重复"假撞车——win 大小写敏感）——与数据表 xlsx"数据行 A 列留空"纪律相反。
- **驱动/测试件整文件入库携带批C 同流段**：`BattleCrosshairDriver`/`BattleCrosshairEditModeTests` 的**静态散布张开段**（MaxSpreadScale→表行化的前身、缩放用例）是击杀提示批（批C，在途未提交）先写的同流基础——本批机制在其上重写，两段已绞合不可 hunk 分离，随本批一并入库（提交信息注明）。批C 其余面（击杀播报/ping）仍在工作区由其收口。
- 两用例期望修正（EditMode 首轮红）：屏幕零点在画布中心系 = (−960,−540) 非原点（后坐断言改相对基准）；`WeaponConfig.Loaded` 在 EditMode 为回落表（霰弹行不可解析——per-weapon 用例改"book 行值≠Default"证行驱动 + 缺行回落）。
