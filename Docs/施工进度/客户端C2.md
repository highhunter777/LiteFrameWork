**DOTween 版本裁决（本仓 DOTween 为闭源 DLL，反射实证）**：

原实现按 `SetUpdate(UpdateType.Custom)` 接线——**该枚举值在本仓 DOTween 中不存在**（`UpdateType` 仅含 `Normal/Late/Fixed/Manual`），编译期即失败。实测确定 Manual 轨语义后改接：

- `Manual` 轨**不受引擎自动更新**，只由 `DOTween.ManualUpdate(dt, unscaled)` 推进；不调用即完全冻结 → 暂停语义天然成立；
- `independent=true` 时取 `unscaled` 参数（实测 `ManualUpdate(0.1, 0.4)` 推进 0.4）；
- `ManualUpdate` **只推进 Manual 轨**，Normal/Late/Fixed 轨的既有 Tween 不受影响（用例钉死）——这是 UIClock 接管"只动 UI 轨"的前提。
- `Shell/UI/Anim/UiAnimationClock.cs`（新）——`UiAnimationClock`（静态 UI 时钟绑定点，域重载静态清理）+ `DotweenUiClockDriver`（按 `UIClock.ScaledDelta` 派发 Manual 轨；步进为零即不调用 = 暂停即停）。`UiFx` 四原语与转场策略 `BuildBase` 改 Manual 轨；`AnimatedImage` 序列帧改走 `UiAnimationClock.Delta`；`GameEntry.ResetForEditorReload` 补清绑。落实《动画模块专项设计》§1 裁决"当前 SetUpdate(true) 不等价 UIClock：必须由 UI 动效适配层明确接入项目 UIClock"。
