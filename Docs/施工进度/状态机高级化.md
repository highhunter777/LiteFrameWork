# 状态机高级化：施工进度

> 依据：[《状态机专项设计》](../设计文档/architecture/状态机专项设计.md)（目标契约与验收以设计为准，本文件只记录施工状态与证据，不在此重复定义）。
> 背景（2026-10-03 规划）：`Core/Fsm` 已有平面/抢占平面/层级三机体与表驱动（`StageSpec`+`TableStage`）、异步流程（`ProcedureStageBase`）配套，L1 测试 1,241 行；Procedure/`UITransitionRunner`/LiteSim 角色驱动消费中。能力差：层级机无抢占/恢复、无迁移表与守卫（事件驱动迁移只能业务手写）、无快照恢复（帧同步回滚/存档恢复无机制可依）、诊断面只有 `IModuleStats` 快照与 `Interrupted` 标记。定位裁定：**地基完整性优先于当前调用方**——按专项设计补齐迁移表/强制迁移/看门狗/层级机抢占对齐/快照恢复/诊断面，覆盖 AI 决策、回滚恢复、GM 跳态等暂无消费者的场景；空配置时行为与现状逐位一致。

## 边界（登记，非本专项范围）

- 并行区域/正交态（表现分层归动画层通道接管，实体组合归实体分型表）；行为树/效用 AI（再立专项）；运行期改图（状态集/边 = 配置，变更重建机器）；祖先作用域事件边（Any 边 + Guard 读 `ActivePath` 表达）；跨线程；编辑器图编辑工具；协程/UniTask 状态体（异步阶段走 `ProcedureStageBase`）——设计 §3.6 非目标登记。
- 角色驱动层状态树内容（战斗/移动双根、通道接管）归《层次动画机设计》；连段/取消窗/霸体玩法判定归《角色状态与动作专项设计》；本专项只交付机制。
- `UITransitionRunner` 编排级超时兜底（2s 强制收尾）保持现状，与机器级驻留看门狗正交。

## 施工记录

### 批1 迁移表与守卫（完成）

- `TransitionTable<TId,TReq>`：三种边（事件边 `AddEdge<TEvt>`/条件边 `AddEdge`/任意态边 `AddAnyEdge`）声明序链表评估；Start 封板（`Lock`），封板后加边抛；`To == From` 加边即抛；`Validate` 由两机构造转调（From/To 未注册抛，Any 免 From）。
- 平面机集成：构造重载挂表；`Tick` = OnUpdate → 条件边（仅本帧无挂起，显式请求永不被覆盖）→ Advance；`Raise` 先评估事件边（命中经 `RequestCore` 入队并消费返回 true），未命中回退问当前态 sink。
- 层级机集成：构造可选参挂表；`Tick` 同序（条件边以最深活动态匹配）；`Raise` 先边后冒泡。
- Debug 三宏深校验（`StageGraphDiagnostics`）：Start 时一次 BFS——可达集 = 迁移边（含 Any）∪ 复合树（树上任一点可达 ⇒ 祖先链与全部子态可达）∪ 时长→NextId 链；不可达阶段 Log.Warning 不抛；`DurationFrames > 0` 而无出口（NextId/AutoResumeOnEnd 均无）死底告警。dotnet 侧 `LITEFRAMEWORK_DEBUG` 全量激活。
- 测试（`TransitionTableTests`，14 用例）：事件边先于 sink、声明序首中、守卫短路回退、条件边当帧生效/不覆盖手动请求、Any 边、封板、构造期 fail-fast、层级机同判例（事件边消费/条件边让位/封板/跨根父链不误报）、死底与不可达告警（`Log.Recent` 按机器名过滤，CoreStatic 串行）。
- 门禁：L1 全量 620/620 通过（含既有 `StageMachineTests`/`StageMachineArpgTests`/`HierarchicalStageMachineTests` 回归不翻红）。

### 批2 强制迁移与看门狗（完成）

- `ForceState(TId, in TReq)`：平面机公开强制通道——绕准入（`CanAccept`）入队，编程错误检查照常（重入/未注册/Start 前/OnLeave 窗口抛）；基础机与 `Request` 等价，差异在抢占型子类。
- `IStageTimeout<TId>`（StageSpec.cs，与既有可选接口同文件）+ `StageSpec.TimeoutFrames/TimeoutTarget` 列 + `TableStage` 代为实现。
- 看门狗统一裁决：两机 `Tick` 内、条件边之后、`Advance` 之前——当前阶段（层级机为最深活动态）驻留帧数 ≥ 上限且本帧无挂起 → `ForceState(TimeoutTarget)`，`TimeoutCount` 计数；同帧条件边命中或已有挂起请求则让位。层级机同步补 `ForceState`（校验 + 绕准入入队）。
- 深校验死底判据补看门狗出口：`DurationFrames > 0` 而无 NextId/AutoResumeOnEnd/看门狗 → 告警。
- `Reset` 清 `TimeoutCount`（两机）。
- 测试（`ForceStateWatchdogTests`，9 用例）：基础机等价 Request、抢占机绕准入对照 Request 被拒、四类编程错误照抛、超限触发与计数/复位清零、抢占机低优先级目标仍强制、条件边让位、挂起让位、未启用零行为、层级机最深活动态裁决。
- 门禁：L1 全量 629/629 通过。

### 批3 层级机抢占对齐（完成）

- `PreemptionCore<TId,TReq>`（internal 共用件）：准入纯函数 `CanAdmit`（中断规则 → 优先级，自身推进放行，拒绝回报 `RejectReason`）+ 恢复栈（深 4 丢最老计数）+ `TryPopResume`（栈空/已在目标语义）+ `Reset`。
- `PreemptiveStageMachine` 改转调 core（公开签名与语义逐位不变，`MaxResumeDepth` 常量转引）；补带迁移表构造。
- `HierarchicalStageMachine` un-seal 并加子类扩展点（默认行为逐位不变）：`RequestCore`（校验 → virtual `CanAcceptRequest` 准入 → 入队）、`ForceState`（绕准入）、`EnqueueRequest`/`EnqueueTransition`（恢复通道）、`OnDeepestPreempted`（事务退出段前的被抢占通知）、`InStageCallback` 窗口（OnUpdate 循环与进入段）、`LastReject`/`MarkRejected`、`DeepestStage`/`GetStage`；`Reset`/`Snapshot` 改 virtual；看门狗改走 `ForceState`。
- 新增 `PreemptiveHierarchicalStageMachine<TId,TReq>`：抢占裁决问最深活动态（优先级/中断/恢复意愿读其可选接口）；被抢占最深态按 `ResumeMode` 入恢复栈（栈存 id，`TryResume` 经 `EnqueueRequest` 走层级机原生展开管线，无需路径快照）；带优先级覆盖 `Request` 重载；`Snapshot` 追加恢复栈统计。
- `IStageHost.Request` 文档口径更新（抢占型层级子类可能返回 false）。
- 测试（`PreemptiveHierarchicalStageMachineTests`，9 用例）：优先级抢占/霸体拒绝与强制绕过、自身推进放行、恢复栈入栈与 TryResume 绕准入回原路径、栈空/已在目标、深度上限丢最老、事件边命中准入拒绝仍消费不冒泡、sink 消费不迁移、看门狗强制绕霸体。既有 ARPG 475 行判例与层级机判例回归不翻红。
- 门禁：L1 全量 638/638 通过。

### 批4 快照恢复（完成）

- `FsmCapture.cs`：`FsmRestoreMode`（Hooks/Silent）+ `FsmCapture<TId>`（活动路径（平面机单点）/复合历史/恢复栈/驻留秒帧/迁移与看门狗计数）——Capture 一次性分配，浮点按位置回。
- 平面机：`Capture()`/`Restore(capture, mode)`——Hooks 复用迁移事务（旧 `OnLeave` → 新 `OnEnter`(default)，同态零分歧零回调）；Silent 纯置换零回调；两模式清挂起（结构性裁决）；`CaptureCore`/`RestoreCore` 虚扩展点（子类补恢复栈）。
- 层级机：快照含活动路径与复合历史；Hooks 按快照**精确路径**（不重展开）走 LCA 事务序（分歧尾深→浅退、目标尾浅→深进）；Silent 直灌 `_active`/`_history`；快照路径/历史 id 未注册（结构已变）→ 抛。
- `PreemptionCore` 补 `CaptureInto`/`RestoreFrom`（恢复栈随快照往返，栈内 id 注册校验）；`PreemptiveStageMachine`/`PreemptiveHierarchicalStageMachine` 覆写接线；两机补 `IsRegistered` 查询。
- 测试（`FsmCaptureRestoreTests`，11 用例）：平面机 Hooks 回调序/Silent 零回调与浮点按位/两模式清挂起、抢占机恢复栈往返、层级机 Hooks 深浅回调序/精确路径不重展开/历史随快照置回/Silent 零回调、Start 前/回调内/OnLeave 窗口抛、结构已变抛、**Silent 确定性重放**（回滚后同输入重放与连续运行逐位一致——Current/StageTime/StageFrames/TransitionCount）。
- 门禁：L1 全量 649/649 通过。
