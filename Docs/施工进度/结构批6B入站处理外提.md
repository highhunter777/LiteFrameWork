# 结构批 6B：入站处理外提（InboundHandlers）

> **来源**：《服务端宿主结构拆分专项设计》§2 批 6B。
> **状态**：**已完成（工作区未提交；附验证证据）**。

## 交付

| 面 | 落点 |
| --- | --- |
| 分发与短处理器 | 新 `InboundHandlers`（internal）：`OnData` 包体硬边界/包速率/会话触碰/解码分发 switch；Heartbeat/Input/Mismatch/RestoreComplete/Leave/StartMatch 六个短处理器；入站输入复用缓冲随族持有 |
| Join 族 | 新 `InboundJoinHandlers`（internal）：准入链 → 房间解析/创建 → 命令投递；票据拒绝分类计数随族持有（宿主公开 `TicketRejections` 转发） |
| 重连族 | 新 `InboundReconnectHandlers`（internal）：一次性票据消费/绑定校验 → 邮箱 admission（Worker/宿主 owner 两形态）→ 席位移交 → 版本确认＋权威快照＋输入历史；`ReconnectTicketRaceException` 归族内 |
| 端口 | 新 `InboundPorts.cs`：`IInboundCoreHost` 8 成员 / `IInboundJoinHost` 6 成员 / `IInboundReconnectHost` 9 成员（均 ≤12 拆分阈值）；`IRoomGateway`（房间编排）＋ `IInboundDiagnostics`（发送/进房拒绝/邮箱计数） |
| 宿主边界 | 宿主私有 `InboundHostAdapter` 单实例实现五端口并构造器注入处理器；传输 `OnConnected/Disconnected`、`SendToSession`/`RejectJoin`、房间构造/销毁/提交/排空仍留 `ServerHost`；`_nowMs` 由 `BeginInbound` 单点刷新 |
| 状态迁移 | `_inputBatch`/`_batchFrames`、`_ticketRejections`、`ReconnectTicketRaceException` 随族迁出；入站首包时钟语义保持 |
| 行为零变化 | 入站 switch 顺序、限流/会话触碰、Join/重连 admission、命令路由、重连响应时序逐条保持；公共 API 零变化 |
