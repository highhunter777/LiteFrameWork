## 5. 结论与下一步

**当前判定：框架准入仍未达成**（五包在"进行中"或"未开始"，五个样例无一成链）。但主动作变了：**PlayMode 执行能力已从"不存在"变成"已接入 L2 门禁"**——这是"样例验证取代接口存在性验收"（§2）此前唯一缺失的执行层。

剩余结构性阻塞收窄为一条：

1. **包②端到端装配 fail-closed**——阻塞准入项「可构建与真实启动」「更新与配置可靠」及样例①的验签/下载段。

**下一步**：
- 包③余部——动画资源组合段与暂停段；样例②余部（列表段、DevReload 环境重建段、输入锁恢复）。
- **包④多房间隔离样例**可并行（纯运行时，不依赖 PlayMode），是样例④"至少两个独立房间验证隔离"的唯一缺口。
- 包⑤需等待①②④，且依赖 Meta 的 M0-c/M0-d。

### 2026-09-25 · 包③余部（真 Lua 生命周期段）

补齐包③退出条件里的"**真 Lua**…复用…卸载可验证"：

- `Assets/Tests/UI/PlayMode/LuaPagePlayModeTests.cs`（4 例）——链路为真 LuaEnv（loader 读磁盘
  `LiteGame/Lua/**.lua`）→ `LuaBehaviourAdapter`（真 ui-API 派发表）→ 真模块 `UI.UIMain`
  → 真 prefab → `UIService` 真转场。断言口径取 UI测试专项 §4.3：
  **实例 Created/Reused**（复用返回**同一实例**）、**租约 Acquired/Released 对称**、
  **页面状态**（关后 IsOpen 为假）、OnShow 计数（首开 1 / 复用 2）。
- 取消段：在途打开被 `CloseAsync` 权威取消 → 断言**类型化** `UIOpenException{Canceled}`
  （不是悬挂、不是静默）、页面无残留、租约获取与回归**对称**、OnShow **未执行**。

**三条实测教训**（均与"测试要测的就是它声称测的那件事"有关）：

1. **在途窗口必须由测试自己制造**：`LoadRealPrefabAsync` 原先直接 await 真实 IO，加载若同帧完成，
   `CloseAsync` 走的是"已打开"的转场关闭路径，**测不到取消语义**——用例绿/红取决于未定义的时序。
   改为加载口显式 `await UniTask.Yield(ct)`，窗口确定性存在。
2. **取消的终态必须显式观测**：`ShowAsync` 的取消交付为 faulted task，未观测时 UniTask 记 unhandled
   异常并打 error 日志——**会踩 UI 门禁"Console 新增 Error 即判失败"**。用例须 `Assert.Throws` 取用。
3. **诊断用例先写再删**：先用 `CancelDiagnosticPlayModeTests` 打点确认取消路径本身正确
   （`open.Status=Faulted` / `IsOpen=False`），再改断言——避免"改测试迁就实现"掩盖真缺陷。

### 2026-09-25 · 包③余部（暂停/覆盖段 + 动画资源组合段）

补齐包③退出条件里最后两段：

  关闭遮盖源 → OnReveal，且 **Covered 态不派发 OnUpdate**。
- `AnimationResourcePlayModeTests`（2 例）——**动画资源组合段**：真角色经真加载链路 → 真控制器
  → `AnimatorAnimationBackend` 提交 Locomotion 状态 → 循环状态不自然结束 → 卸载释放幂等。
- 新增资产：`Widgets/Baseline.prefab`（基准页控件，纯底+文案）+ `Screens/BaselineA/B.prefab`
  （**A/B 位置语义**——同层全屏走 Replace，必须跨层才是 Covered，故 A=layer0、B=layer2）。
  A/B 是**层级与状态语义的最小真实页面**，不是业务页模板。

**两处实测结论**：

1. **`Pause`/`Resume` 是同步派发**：`UIForm.EnterPaused` 直接 `SafeCall(OnPause)`，不等帧末
   （帧末只用于转场推进 `UIService.Tick → _transitions`）。按实测改断言——**不按假设写**。
2. **资源条件用例按可用性分流，不用 `Assert.Ignore`**：`CombatGirlsCharacterPack` 未入库
   （176MB，用户选择不入 VCS），干净检出上真角色不可用。两条分支**各自断言**——无包时验证
   "驱动层明确跳过、不建播放器、不报错"（《动画专项》§4 灰盒降级契约），而非让用例消失。
   `Assert.Ignore` 会让降级行为**永远没人验**。

**门禁噪声修正**：L2 的 `eval_file` 未传命令级 `--timeout`，落 `CodeEvalCommand` 的 5000ms 默认——
编辑器忙时报 "Main thread operation timed out after 5000ms" 并落 Console **error** 级条目，
被"Console 无新增 error"检查记成噪声。已补 `--timeout 30000`。
