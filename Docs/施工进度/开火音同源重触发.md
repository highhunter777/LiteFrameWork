## 交付

| 面 | 落点 |
| --- | --- |
| 服务口 | `AudioService.PlayRetrigger(组, voiceKey, clip, volume, priority, spatialBlend, position)`：按 (组, `voiceKey`) **恒占同一代理**——重复调用**重启**该代理当前 clip（`AudioSource.Play()` 对在播源即从头重播）；首次/绑定被抢占后按既有"空闲轮转 → 优先级抢占 → 丢弃"规则取代理；空闲期不占并发。诊断读数 `VoiceCount` / `RetriggerCount` |
| 驱动 | `BattleAudioDriver` 开火音改走重触发——本地 `gun_fire_local`（2D；`LocalFirePriority = 1` 高于他人/命中档 0，**自己的枪不被抢**）、他人开火逐槽位 `gun_fire_remote_{slot}`（3D；键域 = 槽位数，有界）；槽位未解析回落一次性 `Play3D` |
| 日志 | 丢弃**限频**：首条即报，其后每 100 条汇总一条（`DropLogEvery`）；累计读数 `DroppedCount`（**读数不受限频影响**，日志只压输出） |

## 如实说明（边界）

| 项 | 说明 |
| --- | --- |
| 命中/爆头/死亡音 | 仍走一次性 `Play3D`（与开火音共享 Effect 组预算）——重火力交火下命中音仍可能丢（有限频日志与 `DroppedCount` 可观测）；是否也收成"逐声源重触发 voice"**待裁决** |
| 火音 clip 形态 | 仍是"1.5s 整段含长尾"；重触发下每发只播前 ~100ms 即被下一发重启（节奏正确、不堆叠、不糊）——要"带尾枪声"需接**尾音层**（仓库已有 `sfx_gun_tail_rifle_*.wav`，当前零引用） |
| 离群计数 | 一次 44 重触发 / 30 发未复现（其余均在 1:1 ±2），登记备查（疑似和解回放期的重复投递） |
| 编辑器输入注入 | 电平型（开火）单次注入即可；**沿型（换弹 `WasPressedThisFrame`）单次注入必被采样错帧错过**——须按下/松开交替泵；管道 `simulate_key` 编辑器侧同受此限（dev Player 的 Runtime 侧不受限）。已留痕于 [HUD 弹药读出接线](HUD弹药备弹读出接线.md) |
