### 2026-09-22 · C0-③ Offline Player 与最小错误 UI（已完成）

**交付件**：

3. scripts/player-smoke.ps1——启动冒烟：清场（杀旧实例/删 Player.log）→ 拉起构建产物 → 轮询日志断言定义态标记（BootstrapError 错误 UI 或 AssetService Offline 就绪，任一即通过）→ 进程清场。阻塞项：产物缺失/进程早退/超时无标记。

**验证证据（Player 实测）**：

- 构建：增量完成，产物 Builds/StandaloneWindows64/Test.exe（含 Offline 分支与错误 UI）。
- 冒烟：Test.exe 拉起 → **Player.log 命中 AssetService（Offline 初始化成功、"AssetService 就绪" 入日志）→ 进程存活 → C0-3 player smoke PASSED（exit 0）**。Player 实际到达的健康态优于 C0 最低要求（错误 UI 路径作为初始化失败兜底同时就位）。
