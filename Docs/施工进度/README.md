# 施工进度

本目录记录施工进度与批次执行状态。全项目先后、并行关系和关口见 [总体施工路径](../待办总览.md)，本目录保存其引用的实施证据，与设计文档严格分离：

- 设计、契约、验收标准只写入 `Docs/design/`，本目录不裁决任何设计问题。
- 每条进度记录必须可验证：代码路径、测试命令、产物位置；不得以文档描述代替实现证据。
- 批次状态只用：`未开始 / 进行中 / 已完成（附验证证据）/ 阻塞（附原因）`。
