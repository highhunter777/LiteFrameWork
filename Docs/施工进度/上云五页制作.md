## 结构与命名（镜 UIMain 先例 + 制作规范 §9）

- 页面根 = Canvas(ScreenSpaceOverlay) + CanvasScaler(1920×1080, match 0.5) + CanvasGroup + RectTransform；根名 = 文件名。
- 结构：`Bg_*`（全屏出血，raycast off）+ `Cot_SafeArea`（SafeAreaReceiver）为根下两件；内容/交互全入 SafeArea。
- 暴露 = `BindNode.BindName`（与节点名同文，BIndIndexBuilder 运行期按名解析）：文案/按钮/控件节点全暴露、`Bg_`/`Cot_` 不设。
- 标签约定：按钮标签子节点 `Txt_<按钮语义>`（如 `Button_GuestLogin` → `Txt_GuestLogin`）——"文案节点同样暴露（SetTextKey 需寻址）"的落法。
- 控件节点 = **嵌套模板实例**（复用模板根空名暴露位写 BindName）：`VirtualList_Rooms/Records`、`SimpleList_Players`、`Slider_Volume`、`Toggle_Sound`、`Dropdown_Quality/Language`。
- 占位文案：灰盒中文占位已登记待整改（文案键 `#text.xlsx` 随本地化装配批登；`SetTextKey` 现必抛）。

## 边界与备注（如实）

- **美术资源接入（2026-10-10 同日第二段）**：五页改用 Synty `InterfaceMilitaryCombatHUD` 素材（`Sprites/HUD`，Sliced 复用其既有九宫格边框）——按钮=`Bar_Angled_01_Gradient/02_Clean`、面板=`Background_DogEar_02_Gradient`、头部=`Frame_Angled_01`、全屏底纹=`Background_Crosses_01`（α0.05）、暗角=`Vignette_Box_Large_01`；色相仍走 UiStyle token tint。重跑 BuildAll/VerifyAll：暴露面与结构不变（装饰件不设 BindName）；sprite 接线探针：5 页 25 处 Image 全非空（每页 Backdrop/Vignette + 页面板/按钮）。**观感（tint 深浅/暗角强度/边框密度）需人眼过目**——改构建器常量重跑即可迭代。
- **场景纪律**：全程 Prefab Stage 隔离（`LoadPrefabContents`）构造；临时预览场景用毕关闭；执行中发现并还原了 NewScene 默认置激活的副作用（激活场景回 Test）。用户场景内容零写入。
- **视觉目检限制（工具结论）**：本仓管线在 **edit 模式**的 `screenshot`/`capture_scene_view`/专用相机 RenderTexture 均**不含 UGUI Canvas 内容**（像素采样实证：整图仅清屏色；连训练场自带 HUD 也不出现在 game view 截图中）——`CaptureAll` 的 PNG 出图路径因此不可用（保留为工具，供未来 play 模式/修复后复用）。**视觉目检走：编辑器双击 prefab（Prefab Stage 预览）/ Play / 后续 UI 工作台（W0）**。
- **未做（挂账）**：MetaClient 等接线（批C）；列表行数据（G6 SetList）；语言/长文本实机目检；按钮标签寻址若接线批另立口径（如直接以 Button 名寻址）需同批对齐本命名。
- 布局观感 = 灰盒基准 + Synty 素材首版（色值取 UiStyle token、字号阶梯 12/14/16/20/24/32/40、边距 32）——观感迭代归制作线（改 prefab 序列化为准，不依赖构建器；构建器仅首版铺设）。
