## 状态

**代码与文档已交付，工具实跑验证完成；luban/proto 两工具的重生成实跑随下次真实触发表/协议改动执行**（见文末遗留）。

## 背景

五件 CLI 生成器（`gen-build-hash.py`/`gen-proto.ps1`/`gen-luban.ps1`/`gen-sync-code.ps1`/`refresh-hash.ps1`）是"两端同源"红线的执行面，但形态分散：Python/PowerShell 混用且约定不一、仓库根推导手写 ×4、失败口径三套（`throw` 带栈 / `exit 1` / 异常冒泡）、输出无统一前缀、`gen-proto` 缺参触发交互式提示、操作知识散落 scripts/README + 修改指南 + 脚本头注释三处、`scripts/README` 索引漏登记两件工具。本批按《生成器工具箱专项设计》统一。

## 交付

| 面 | 落点 |
|---|---|
| 共享单源 | 新增 `scripts/codegen/_common.ps1`：`Get-CodegenRepoRoot`（仓库根推导，机制化 scripts/README 约定）+ `Write-Tool`/`Write-ToolWarn`/`Write-ToolFail`（统一前缀 `[codegen/<tool>]` 三档输出）+ `Get-FileSha256Base64`（内容哈希，原 gen-luban 内联收口） |
| 统一入口 | 新增 `scripts/codegen/toolbox.ps1`：无参列工具索引；`<tool> [args...]` 转发参数与退出码（python 走 `python`，ps1 走 `pwsh -NoProfile -File` 子进程）；未知工具列索引 + exit 1 |
| 形态统一 | 五工具统一为 `Invoke-<Xxx>` 主函数 + 尾部 `try/catch → Write-ToolFail + exit 1`；头注释五段式（用途/入口/输出/重跑时机/消费点）；.ps1 全部 ASCII-only |
| gen-proto | 交互式提示疣点消灭（`Mandatory` 参数 → 显式校验 + 用法报错）；protoc 前置校验（路径不存在/命令不可用给干净 ABORT）；中文头注释 ASCII 化（知识吸收进专项设计，原文归档） |
| gen-build-hash.py | 输出统一 `[codegen/build-hash]` 前缀；尾部重复 `__main__` 守卫疣点清理；规则本体（源集/排序/归一化/算法）零改动 |
| gen-luban / gen-sync-code / refresh-hash | 输出统一前缀；暂存/发布、解析/生成、编排四步逻辑逐行保留；refresh-hash 头注释 why 全保留 |
| 消费面兼容 | `build-player.ps1` 直调 `gen-build-hash.py --check` 不动；`Luban/gen.bat` → `gen-luban.ps1` 委托不动；CI 不直调生成器（核对过） |
