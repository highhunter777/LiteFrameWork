## 状态

**已完成（2026-10-07，验证证据见下）**：火光与命中特效全链接线（事件 → 驱动 → VfxService → fx_* 资源）。

## 交付

| 面 | 落点 |
|---|---|
| 资源归置 | `BuildCombatFxAssets` 构建器（CopyAsset 新 GUID，依赖留原包；与 fx_lazer_sight 同例）→ `Assets/FX/fx_muzzle_flash.prefab`（MuzzleFlash1）、`Assets/FX/fx_impact_enemy.prefab`（DirtImpact）；YooAsset「FX」组按文件夹收集自动入包；**URP 补丁无需导入**（既有实测登记） |

| 装配 | `ProcedureBattle.AttachCombatFx`（`_hitFeedback` 注册两消费者；VFX 服务缺注入 → 如实警告降级；清理段消费者先于分发器拆） |

## 遗留（如实）

- **远端开火火光**：Fire 帧事件只来自本地预测世界；公开面开火驻留窗**瞄准也会置窗**、无法区分开火 → 远端火光归 **CombatEvent 批**（可靠战斗事件留 P1）；
- 命中特效**表面分流**（Brick/Concrete/Metal/… 与贴花）归 **批D ObstacleHit**（目前敌人命中用单一件 DirtImpact；枪口件为 MuzzleFlash1——**换件 = 改构建器源路径重跑**，美术可调）；
- 音效（开火/命中）未接（AudioService 面在后批）；特效缩放（火光 1.0 / 爆头 1.35）为本地常量，观感微调单点。
