# 武器表与武器系统（G2-P1 首段）

《游戏业务系统总设计》§5 武器系统方案；tb_weapon 数据面 + Sim `WeaponSystem` 消费链。**步枪全链落地**；霰弹枪/散布/切枪表现/自动换弹后置。

## 状态

**已完成（2026-10-07，验证证据见下）**：步枪表 → 装载 → Sim 武器系统 → 输入（Reload/seq）整链。

## 交付

| 面 | 落点 |
|---|---|

| Sim 系统 | `WeaponSystem`（新增，SimStep 序：Input → Movement → **Weapon** → Shooting）：**懒装备**（活动存活且未装备 → 默认步枪满弹——首生/复活同规则，Despawn 清行后自动重装）、**换弹推进**（整数帧到帧转移弹药）、**换弹请求**（`ButtonReload` 边沿）；**开火消费** `TryConsumeShot`（节拍=ceil(TickRate×60/rpm)=6 帧 ∧ Ready ∧ 有弹；扣弹/推进 NextFireFrame/ShotSeq++） |
| 射击门 | `ShootingSystem`：已装备实体经武器门（**拦截在一切副作用之前**——不开火则无 Fire 事件/无开窗/无 RngState 消费）；伤害/射程随表（`wdef.Damage`/`wdef.Range`）；**未装备实体**（测试/沙盒直调形态）维持旧路径（逐帧 + `tb_combat_num.base_damage` 兜底） |
| 输入链 | `Reload` = R 键（资产已备）→ 设备源产 `ButtonReload`（**按下沿**）；**`action_seq` 产生点落在 `InputService` 帧边界门**（仅离散位帧递增，不随 Reset 归零——连接内单调防服务器判回退） |

## 数值（首轮手感裁决）

600 RPM / 16±1 / 弹匣 30 / 备弹 90 / 换弹 2.2s → **身杀 7 发 ≈0.60s、爆头 4 发 ≈0.30s**（HP100、爆头×2；"TTK 长一组"用户裁决）。弹匣一梭 ≈4 杀。表可调、digest/hash 随表自动联动。
