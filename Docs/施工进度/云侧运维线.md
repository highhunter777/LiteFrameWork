### 4. 过程踩坑（留痕）

1. **改了 C# 但云上没重新发布** → 配置里开了端点、日志里没有端点。云上跑的是自包含产物，**改代码必须 `dotnet publish -r win-x64 --self-contained` 后上传 `room/`**。

4. **本机转发失败（已定位并解决）**：`ssh -N -L 9101:…` 报 `bind [127.0.0.1]:9101: Permission denied` —— **不是云上问题**（`AllowTcpForwarding` 为默认 `yes`、`sshd` 在跑、`10.8.0.1:9101` 正常监听），而是**本机端口 9101 落在 Windows TCP 排除端口区间 9014-9113**（`netsh int ipv4 show excludedportrange protocol=tcp`，Hyper-V/WinNAT 预留）。改用本机端口 `19101` 转发即通。已固化进 `scripts/deploy/gm.ps1`。
5. **POST 必须带 body**：无 `Content-Length` 的请求被 `HttpListener` 直接 `411 Length Required`（实测 curl 不带 `-d` 时）。脚本对所有动作统一带 `{}` / 具体 JSON。
