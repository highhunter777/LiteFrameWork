# 客户端开发能力地图

> **定位**：回答“客户端开发每类改动，用什么工具、在哪个环验证、最终形态还补什么”。这是一张**操作视角的索引**，把散在平台、路线图、调试手册里的能力按“改什么”串起来。
> **不做的事**：不裁决工具形态与契约（归[开发工具链平台专项设计](../设计文档/架构/开发工具链平台专项设计.md) §1.1 与各专项）；不排能力优先级（归[调试与开发工具链演进路线图](../设计文档/测试与性能/调试与开发工具链演进路线图.md)）；不记批次与完成状态（归 `Docs/施工进度/`）；不列每个工具的参数（归[工具索引](../工具链/工具索引.md)）。
> **冲突裁决**：工具形态与收敛判据以平台专项为准；能力目标以路线图 T0～T3 为准；操作步骤以 [13-调试手册](13-调试手册.md)、[08-UI 制作与调试](08-UI工作台.md)、[07-本地联测](07-本地联测.md) 为准；UI 设计以 [UI 系统总设计](../设计文档/客户端/UI系统/UI系统总设计.md) 为唯一入口。
> **关联**：[05-验证与门禁](05-验证与门禁.md)、[06-环境与协作纪律](06-环境与协作纪律.md)、[修改指南 §2](../修改指南.md)。

## 1. 先选环

| 环 | 载体 | 目标反馈时间 | 适用改动 |
|---|---|---|---|
| 内环 | Editor Play + 进程内服/本地 Room + 热重载 | 秒级～1 分钟 | 表现、手感、UI、纯逻辑、表/Lua |
| 中环 | 可调试 Player + 远端内容 + 本地/云端 Room | 小于 5 分钟 | 联机行为、内容/配置、Lua、网络路径 |
| 外环 | release IL2CPP + 云部署 + 真人对局验收 | 按批次 | AOT/IL2CPP 差异、真网络、跨机、发布验收 |

能用内环/中环回答的问题，不要进外环；进了外环就要给出理由（真网络、AOT、跨机）。

## 2. 按改动类型查能力

| 你要改 | 现役能力 | 最终形态补齐 | 入口 |
|---|---|---|---|
| prefab / material / 动画 / 手感参数 | 六页烘焙（身位/枪口/持枪/爆头带/根位移/地图）、`write-if-changed`、本地测试模式实时滑杆 | 资产写盘 dry-run 差异 + Undo 全量覆盖 | Hub → 烘焙工具箱；GM → 本地测试模式 |
| UI prefab / 页面 / Lua 页面 | UI 工作台（起页/布局/命名/契约/校验/预览）、页面流 `UINavigationController` | 样式/文案“预览→应用→回滚”，契约 diff、设备档矩阵 | Hub → UI 工作台 / 起页 / 页面登记；见 08 手册与 [UI 编辑器工具链专项设计](../设计文档/客户端/UI系统/UI编辑器工具链专项设计.md) |
| 纯客户端 C# | Editor 重编译 + L1（秒级） | 不变（内环继续最快） | `scripts/gate/test.py --suite L1` |
| 表源 / 表值 / 配置 | Luban 双端生成、表值数据面摘要（`CombatConfigDigest`） | 中环开发 Player 热更表值，不重打 IL2CPP | Hub → 生成器；`Luban/gen.bat` |
| Lua 逻辑 | Reload Env / Refill Registries | 中环 Player 内热更 | Hub → 生成器动作 |
| 协议 / 共享源 / 生成读码面 | `build-hash` / `proto` / `sync-code` / `refresh-hash`；出包门禁 `--check` | 构建 preflight：告诉你“必须重打哪几个产物” | Hub → 生成器；`python scripts/codegen/toolbox.py` |
| 联机行为 | A 本地测试模式（进程内）/ B 本地全链（Meta+Room）/ C 云上（普通房/测试房）；云端测试房模板、bot、重连 | 可调试 Player + 弱网注入 + 关联日志 | 本地联测页；[07-本地联测](07-本地联测.md)；[11-联机测试流程](11-联机测试流程.md) |
| 对局异常 / desync | 房间记录、`ReplayTool` 首分歧与字段 diff、客户端现场包、崩溃件、符号归档、GM 取回、**结构化 JSONL（`logs.query` 可查）** | 现场包语料化；日志按 match/frame 过滤 | 13 手册 §8；`Server/ReplayTool`；`/gm/diag-*`；`scripts/logs/query.py` |
| AOT / 真网络 / 跨机 | release 通道 + 云上真人对局 | 不变（永远外环） | [11-联机测试流程](11-联机测试流程.md) |

| 联机本地链 | Hub → 本地联测页；`scripts/local/local-chain.py` | 两端起停、探针、日志尾随 |
| GM（本地测试模式 / 云端测试房） | Hub → GM 七页（云端测试房创建/选图在「本地测试模式」页；功能调参在「调试参数」页） | 本地测试模式/调试参数/命令与审计/场景/配置诊断/本地联测/联机诊断 |
| 运行期读数 | DevHUD（F1） | 只读；七段可折叠、按行着色（白/灰/黄/红）；模块 stats/联机/性能（p50/p95/p99、GC、Draw/Batches、HUD 自耗时）/日志尾/错误/DiagTrace/日志 sink；联机含 60s RTT/丢包 sparkline 与回滚/输入领先/快照年龄；**UI Toolkit 渲染（IMGUI 自动回退）**；F4 复制、F5 级别、F6 仅本局、F7 现场包、F8 JSON、F9 `@tag` 过滤；拖动/缩放/折叠/过滤持久化；日志带 `[m/f/p]` 上下文；六段读数经 `DebugKernel`；见 13 手册 §2 |

## 4. 典型场景

**调手感**：Hub → 烘焙页 → 预览差异 → 应用（不对手感就回滚）；对局内用 F9 滑杆实时试，定型后导出常量 → 出包前 `--check`。

**改一个 UI 页**：UI 工作台选页 → Prefab Stage 布局 → 命名/暴露 → 契约 → 增量校验 → 布局/设备档预览；工程登记/绑定生成后，需要真实数据/本地化走 Boot 联调、F8/深检或 L2。

**查联机问题**：云上房间终态记录 → `/gm/diag-fetch` 取回 → `ReplayTool` 定位首分歧帧与字段 diff → 现场包 + 构建身份/配置摘要进单。

**加一个表字段**：改 `Luban/Data` → `Luban/gen.bat` → 跑 `gen-build-hash.py`（生成读码面在闭包内）→ 按 07 手册三端各自动作 → 出包门禁复算。

## 5. 最终形态的客户端增量

| 能力 | 目标 | 退出条件 | 归属 |
|---|---|---|---|
| 中环内容通路 | 表值/Lua/Prefab/场景/美术改动在开发 Player 上“发布→接受→激活→回滚”，不重打 IL2CPP | 四类改动各走通一次且不重打 Player | 路线图 T1；热更专项 |
| 可调试 Player | attach、控制台、运行时调参；与发布包分离 | 开发包可 attach、可控制台；release 不含调试面 | 路线图 T1 |
| 弱网注入 | 延迟/抖动/丢包/重复/乱序，固定种子；HUD 曲线 | 固定种子场景可复现，进夜间 | 路线图 T1 |
| 关联日志 | session/match/frame/player 过滤；错误现场附最近日志 | 任一错误可按 match/frame 过滤 | 路线图 T1 |
| 资产写盘 | `ToolWriteScope` 资产模式：dry-run/备份/Undo | 样式/样例预览不改盘、Undo 可恢复 | 平台专项；写盘契约 §8 |
| 构建 preflight | 按 diff 输出最小重建集 | 任一改动的构建计划可解释 | 路线图 T1 |
| 性能与回归 | ProfilerMarker、夜间阈值、CI 生成物漂移 | 超预算变红；漂移 CI 变红 | 路线图 T2 |
| 度量 | 构建/测试耗时、flaky、变化到验证时间 | 关键指标有趋势 | 路线图 T3 |

## 6. 硬边界

- **判定逻辑与共享源不能热更**：改两端常量必须重打包（BuildHash 红线）。
- **release 包不可调试**：控制台、GM、DevHUD 只活在开发载体，随三宏剥离。
- **内环绿不等于可发布**：AOT 差异、真网络、跨机必须走外环。
- **不做第二个 Hub/CLI、不做全量遥测平台**：入口与形态见平台专项 §1.1 的六条收敛判据。
