# 08-UI 制作与调试

> **文件名说明**：路径沿用历史编号 `08-UI工作台.md`，现行名称以本标题为准；旧版手册快照见 [归档记录/2026-10-22/UI旧体系/08-UI工作台（旧）.md](../归档记录/2026-10-22/UI旧体系/08-UI工作台（旧）.md)。
> **本文定位**：回答“美术/工程怎么起页、布局、命名、绑定、生成契约、校验、预览，以及怎么在真包/编辑器里调试 UI”。
> **不做的事**：不裁决设计（归 [UI 系统总设计](../设计文档/客户端/UI系统/UI系统总设计.md) 与 [UI 编辑器工具链专项设计](../设计文档/客户端/UI系统/UI编辑器工具链专项设计.md)）；不记批次证据（归 [施工进度](../施工进度/README.md)）；不覆盖门禁全表（归 [05-验证与门禁](05-验证与门禁.md)）。
> **冲突裁决**：与代码不一致以代码为准并顺手修本文。命令中的 `unity command ...` = Unity Pipeline CLI（见 [Unity 操作规范](../工具链/Unity操作规范.md)）。
> **现行形态**：唯一制作入口＝Hub `ui.workbench`（页面/控件库/绑定/契约/校验五透视 + 角色 Lane + 共享上下文）。`ui.compose` 与 `ui.page-new` 已于 P2-1 退役；起页/登记归 P2-2（`ui.page-scaffold`/`ui.page-register`），工作台内按钮暂置灰并显示原因。

## 0. 它是什么

```text
起页（美术） → Prefab Stage 布局 → 命名/暴露 → 样式/文案
→ 生成契约 → 增量校验 → 布局预览/截图
→ 页面登记（工程） → 绑定生成/接线 → 全量校验
→ 运行时调试/真机验收 → 契约基线
```

| 用它 | 别用它 |
|---|---|
| 起页、布局、控件插入、命名/暴露、契约、校验、预览 | 断言 UI 行为——那是 L2 EditMode/PlayMode |
| 单页布局/设备档/语言/安全区目检 | 验证玩法/网络/房间流程——走 [07-本地联测](07-本地联测.md) |
| 运行时页面/绑定/布局/输入/性能诊断 | 在编辑器里替代真机验收 |

**唯一编辑面是 Unity Prefab Stage**；工具窗口不造第二套画布，不接管几何/锚点/层级。

## 1. 入口与就绪

| 入口 | 操作 |
|---|---|
| **UI 工作台**（现行） | Hub `LiteGame/工具链` → **UI 工作台**；等价 `python scripts/toolchain.py open ui.workbench` |
| **起页（美术）** | **P2-2 提供**（工作台页面透视的起页按钮现置灰并显示原因）；目标形态＝`ui.page-scaffold`（仅 prefab） |
| **页面登记（工程）** | **P2-2 提供**；目标形态＝`ui.page-register`（表/Lua/Luban/hash） |
| **校验** | 工作台校验透视（窄档＝本 prefab；全量档＝全部资产）；或 `ui.validate` |
| **预览** | 工作台上下文条「预览」（`UiPagePreview`）；P2-3 升级为预览透视（设备档/语言/截图矩阵） |
| **运行时调试** | 编辑器 Play：Hub `ui.runtime-debug`；Player：F8 |
| **CLI** | `python scripts/toolchain.py list` / `open <id>` |

**就绪检查**：

- Unity 2022.3 LTS 已打开工程；`Assets/LiteGame/Editor/UiTools/` 无编译错误。
- `Luban/Data/#uiform.xlsx` 可读；`python -c "import openpyxl"` 通过。
- 目标 prefab 的 Prefab Stage 已打开（插入控件/改名要求 Stage）。
- 生成绑定会触发脚本重编译；窗口状态会丢，生成后重开并回到目标页。

## 2. 角色与 Lane

| Lane | 你能做 | 你不能做 |
| --- | --- | --- |
| **美术** | 起页（仅 prefab）、布局、控件库、令牌、静态 key、暴露标记、契约生成、增量校验、预览/截图 | 页面登记、Lua/表写入、绑定生成、逻辑接线 |
| **TA** | 令牌/字体/图集/材质/控件模板、控件规范、性能预算、全量校验 | 业务逻辑、页面导航 |
| **工程** | 页面登记、绑定生成、契约评审/消费、逻辑接线、全量校验、运行时调试 | 未经美术评审改视觉/字号/间距/切图 |

- 一个 prefab 同一时间一个 Owner；Lane 是动作集，不是权限系统。
- 角色/交接细则见 [UI 美术协作与交接规范](../设计文档/客户端/UI系统/UI美术协作与交接规范.md)。

## 3. 起页（美术）

### 3.1 输入

| 字段 | 说明 |
|---|---|
| 页面名 | `Page_<Semantic>`，如 `Page_Shop`；根名与文件名同文 |
| 页面类型 | 全屏 / 浮层 / HUD |
| 视觉基线 | `Tmp_BaselineA` / `Tmp_BaselineB` / `Tmp_ListScreen` |
| 目标模块 | 资源收集组/归属 |

### 3.2 产物

1. `Assets/ShareResource/UI/Screens/Page_<Semantic>.prefab`：从基线**复制**为自包含 prefab（不是 Variant）。
2. `UiPageManifest` 草稿条目（Owner=美术、状态=草案）。
3. **不写** Lua、不写 `tbuiform`、不生成绑定类。

根契约：`Canvas` + `CanvasScaler`（1920×1080，Match 0.5）+ `GraphicRaycaster` + `CanvasGroup`；`SafeAreaReceiver` 在内容容器；不预置 `BindName`/`BindRoot`。

### 3.3 布局

- 在 Prefab Stage 完成；控件库插入 `Tmp_*` 嵌套 prefab。
- 插入后**不自动改名**；焦点落到命名输入，由作者确认。
- 选中 `Tmp_*` 时看影响面（只读），实例更新走 Unity 原生 Overrides。
- 布局规则见 [UI 制作规范 §布局](../设计文档/客户端/UI系统/UI制作规范.md#ch-layout)。

### 3.4 命名与暴露

- 节点名 `Role_Semantic`；词表见 [UI 命名与控件词表参考](../设计文档/客户端/UI系统/UI命名与控件词表参考.md)。
- 需要工程接线的节点挂 `BindNode`，`BindName` 同名、页面内唯一。
- 只暴露逻辑要操作的控件；装饰件/模板内部件不暴露。
- 静态文案挂 `LTextKeyRef` 或填 key；动态数值不挂静态 key。
- 批量改名先预览，列出 Lua/C# 引用点；工具只提示，不代改。

### 3.5 样式与文案

- 颜色/字号/间距/圆角/动效优先令牌引用；裸值会被校验报告。
- 文字角色 Title/Body/Caption/Label/Emphasis 来自令牌。
- key 必须存在；中/英/长文本/伪本地化预览。

## 4. 契约与校验

### 4.1 生成契约（美术触发）

1. 工作台契约透视 → 生成/刷新。
2. 检查 `sourceHash`、`controls[]`、`text[]`、`templates[]`。
3. 契约 diff = UI API 变更；破坏性变更双方评审。
4. 生成后跑增量校验。

### 4.2 增量校验（美术）

- 入口：工作台校验透视（窄档）；`ui.validate-art` 随 P2-3 提供（本批未建）。
- 范围：本次改动 prefab + 直接依赖；目标 <10s。
- 判据：结构/命名/绑定/样式/文本/布局/资源；Error 必须修，Warning 解释或登记例外。
- 增量不替代全量；全量在工程/CI。

### 4.3 全量校验（工程）

- 入口：`ui.validate` 或 CI。
- 规则族与报告见 [UI 编辑器工具链专项设计 §校验](../设计文档/客户端/UI系统/UI编辑器工具链专项设计.md#ch-validation)。
- 契约漂移、hash、越界引用、资源/收集组、debug 入包都会拦。

## 5. 页面登记（工程）

### 5.1 输入

| 字段 | 说明 |
|---|---|
| 页面名 | 与 prefab 根名一致 |
| id | 业务段推荐现有最大业务 id + 1；不复用系统面 201–203、静态先例 204–206 |
| layer | 0 Bottom / 1 Window / 2 Top / 3 System |
| full_screen | 常驻全屏页为开 |
| 逻辑语言 | Lua（路径 A）或 C#（路径 B） |
| 缓存策略 | Resident / Lru / DestroyOnClose |

### 5.2 产物

1. `Luban/Data/#uiform.xlsx` 追加一行（`id`/`lua_path`/`prefab`/`layer`/`full_screen`）→ 跑 Luban。
2. Lua：`Assets/LiteGame/Lua/UI/<Page>.lua` 最小骨架；C#：`UIBindBase` 派生类 + Designer。
3. 绑定 hash 清单条目。
4. `UiPageManifest` 状态更新（草案→已登记/已接线）。

### 5.3 安全

- 写表前备份；id/路径查重；非法名/保留 id 被挡。
- 表行失败：只删本次产物，报错；Luban 失败：回滚表行，保留 prefab/Lua 并标记“未登记”。
- 不静默成功；失败给恢复/回滚路径。

### 5.4 接线

- 只用契约 `controls[]` 内的 `bindName`；越界引用被校验拦。
- 数据流按 [UI 系统总设计 §数据流](../设计文档/客户端/UI系统/UI系统总设计.md#ch-data-flow)。
- 页面关闭清订阅/异步；列表整表替换；高频数据不跨 Lua。
- API 见 [UI 逻辑 API 参考](../设计文档/客户端/UI系统/UI逻辑API参考.md)。

## 6. 绑定生成

### 6.1 路径选择

| 路径 | 适用 | 产物 |
| --- | --- | --- |
| A 运行时标记 | Lua/轻量页 | `BindNode.BindName` → `UIBindIndex`；无生成类 |
| B 生成类 | C#/高频/复杂 | `BindRoot` → `Xxx.cs` + `Xxx.Designer.cs` |

- 同一页面只选一种主逻辑语言。
- 生成文件禁手改；主类可手写 partial。
- 生成成功同一步记录绑定面 hash；hash 规则只判漂移，不代记录。

### 6.2 生成后

- 触发脚本重编译；窗口状态丢失属预期。
- 重新打开工作台并回到目标页。
- 若 `BindRoot` 缺失：路径 B 未启用，只提示，不伪造 hash。

## 7. 预览

### 7.1 布局档

1. 工作台选中目标页 → 预览。
2. 编辑器保存场景后打开预览场景并进 Play；页面由预览驱动直接实例化。
3. 改 prefab → 保存资产即热重载（只监听目标 prefab 导入）。
4. 退出 Play → 回到进入前场景；预览中隐藏 DevHUD/F8。

**是布局档**：不跑 Boot/Lua/数据；按钮回调/列表数据/语言服务不在这档验证。

### 7.2 设备档/语言/截图

- 工具栏切换分辨率/安全区/DPI/横竖屏。
- 语言：中/英/伪本地化；长文本；字体缩放。
- 截图矩阵：中/英/长文本/安全区/设备档；作为交接证据。

### 7.3 数据档/真链路

- 需要空/大列表/错误/加载等状态：走运行时调试 `ui.inject` 或 Boot → 目标页。
- 需要真实数据/行为：Boot → 登录 → 目标页 / PlayMode；不在预览工具里复制第二套面板。

## 8. 运行时调试速查

> 完整设计见 [UI 运行时调试工具链专项设计](../设计文档/客户端/UI系统/UI运行时调试工具链专项设计.md)；本文只给最短路径。

| 我要 | 入口 |
| --- | --- |
| 打开/返回/替换/重开任意页 | F8 面板目录，或 `ui.list/open/back/close/reopen` |
| 复现空/大/长文本/错误/加载 | `ui.inject <id> --state=Empty/Large/LongText/Error/Loading` |
| 看某个控件能不能点/被谁挡 | `ui.raycast` / F8 可点性摘要 / 编辑器深检 |
| 看页面状态/层序/焦点/缓存 | 编辑器深检 `ui.runtime-debug` / `ui.dump` |
| 看绑定被谁消费/契约漂移 | 深检「绑定与契约」页签 |
| 看布局/安全区/Canvas | 深检「布局与安全区」页签 |
| 看性能（rebuild/批次/GC） | 深检「性能」页签 |
| 把实例调整落回 prefab | 编辑器深检写回模式（属性级 diff） |
| 留证据 | `ui.capture` / `ui.dump` / `ui.bundle` |

**纪律**：默认只读；写回必须显式选目标 prefab、看 diff、逐属性确认；Player 只采集 patch，不写资产；面板自身要可点。

## 9. 排障速查

| 现象 | 原因/处置 |
|---|---|
| 工作台显示“未绑定目标” | 从页面选择器选页；或在 Project/Prefab Stage 选择 prefab |
| 页面下拉为空/没有新页 | 刷新页面；检查 `#uiform.xlsx` 与 openpyxl |
| 插入控件置灰/提示“未在 Prefab Stage” | 打开目标 prefab 的 Stage；无选中时插到 Stage 根 |
| 起页报 id 已存在/保留 id | 取最大业务 id + 1；不要复用 201–206 |
| 页面登记报 Python/openpyxl/表源 | 检查 `python --version`、`pip install openpyxl`、`#uiform.xlsx` |
| Luban 失败 | 看结果与 Console；表行已回滚，prefab/Lua 保留并标记“未登记” |
| 生成后窗口状态没了 | 生成触发域重载，属预期；重开工作台并选回目标页 |
| 预览没画面/目标不存在 | 检查目标 prefab 路径；预览只接受已保存资产 |
| 改 prefab 预览不刷新 | 保存**资产**（不是场景）；确认导入完成；点重载 |
| 预览里看不到 DevHUD | 预览主动隐藏，属预期 |
| 绑定未命中/类型不符 | 核对 `BindName`/节点类型；看深检「绑定与契约」 |
| 点了没反应 | 先看可点性（遮挡/interactable/blocksRaycasts），再看回调是否绑定 |
| 页面复用后状态残留 | 检查 `OnShow` 是否重推数据、`UnbindAll` 是否清旧回调、异步代次 |
| 契约漂移 | 重新生成契约并跑校验；不要手改契约 |
| 真机安全区不对 | 用设备档预览 + 真机包；检查 `SafeAreaReceiver` 是否在内容容器 |

Console 自查：`[UI]` = UI 服务/导航；`[ui/workbench]` = 工作台动作结果（契约/清单/门控原因）；`[UiPreview]` = 预览；`[UI 编排]` = 绑定应用（存量日志）；`[UiDebug]` = 调试面（dev-only）。

## 10. 边界与纪律

- **dev/editor-only**：预览场景、脚手架模板、预览驱动、深检窗口、F8 面板都不得进收集组/构建。
- **不旁路生产校验**：布局预览只做目检；断言/取消/超时/租约清理归 L2；真链路走 Boot/联调。
- **不做第二套画布/运行时面板**：布局由 Prefab Stage；调试面只读/显式写回，不替代制作。
- **真机验证纪律**：任何“能点/能操作”的结论走真实操作路径（可点性 → 模拟操作 → 副作用断言），不以直调 API 冒充操作过。
- **不手改生成物**：契约/清单/Designer 由工具生成；改动走源 prefab + 重生成。
