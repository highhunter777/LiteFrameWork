# 08-UI 工作台操作手册

> **本文定位**：回答"UI 工作台（dev-only 手测台）怎么打开、怎么开/关页面、怎么切语言、怎么注入边界态、怎么看 HUD、怎么把 Play 里调好的 prefab 改动固化成资产、出问题怎么排"。
> **不做的事**：不裁决设计（归 [UI工作台设计](../设计文档/client/ui/UI工作台设计.md)）、不记批次证据（归 [施工进度/UI工作台W2.md](../施工进度/UI工作台W2.md)）、不覆盖门禁全表（归 [05-验证与门禁](05-验证与门禁.md)）、不解释 UI 框架机制（归 [03-技术细节-客户端](03-技术细节-客户端.md) 与 [UI框架总设计](../设计文档/client/ui/UI框架总设计.md)）。
> **冲突裁决**：与代码不一致以代码为准并顺手修本文。命令中的 `unity command ...` = Unity Pipeline CLI（见 [UNITY-GUIDE](../UNITY-GUIDE.md)）。

---

## 0. 它是什么、什么时候用

dev-only 的人工目检台：**不跑完整业务流程**也能开/关任意已登记页面、驱动反馈面（Loading/错误/Toast）、目检多语言与边界布局、静态看战斗 HUD、把 Play 里调好的属性固化回 prefab 资产。

| 用它 | 别用它 |
|---|---|
| 看某页长什么样（含边界态、英文文案） | 断言 UI 行为是否正确——那是 L2 EditMode/PlayMode（夜间门禁） |
| 触发动效/反馈面看手感 | 验证玩法逻辑、网络、房间流程——走 [07-本地联测](07-本地联测.md) |
| UI 效果调参 → 固化进 prefab | 整场景运行时保存——**不做**（真装配链的生成物不得烤进场景） |

**不旁路装配**：工作台跑**真装配根**（`GameEntry` → 全模块 → 流程机 `Launch→Patch→Preload→Main`），只换"落点"——面板替代玩法首屏。所以你在里面看到的都是生产线上的东西。

## 1. 打开与就绪

1. 编辑器打开 `Assets/Scenes/UiWorkbench.unity`（**不在 Build Settings**，编辑器打开该场景按 Play 即可；与 `Boot.unity` 同款最小件：`GameEntry` + 主相机）。
2. Play。真启动链照跑：Patch（本地通道，无 CDN）→ Preload（配置/内容/Lua）→ Main（`Rig`+地图场景叠加作背景，无害）。
3. **就绪判据**＝面板状态行出现 `就绪:True`（＝`ConfigService.Loaded` ∧ 阶段 `Main`）。在此之前：交互钮**置灰**、状态行提示 `配置未发布（Preload 中）`。

> 说明：配了 Meta 基址时，Main 之后**入口页会自动打开**（登录页）——这是产品链路行为，不是工作台干的；面板一键可关（ESC 或目录行 `关`）。

**工作台模式开关（两个入口）**：`GameEntry` 上的 `DebugTuner.WorkbenchMode` 勾上后——①Main **不加载对局场景组**（没有 `BattleRig`/`Arena01` 背景，启动更干净）②**把工作台面板自建出来**（dev 预制体 `Assets/LiteGame/DevHUD/WorkbenchUI.prefab`，编辑器形态）。于是有两种进法：

| 入口 | 操作 | 效果 |
|---|---|---|
| **正常启动 + 开关** | 打开 `Boot.unity` → `GameEntry` 的 `DebugTuner` 勾 **`WorkbenchMode`** → Play | Main 起来后**加性加载工作台场景**（不加载登录页） |
| **运行中从大厅进** | 正常 Play → 屏幕左上「开发」→ **UI 工作台** | 同上（置开关 → 加性加载工作台场景）——开发页在大厅/任意页面在场时都可点 |

> **工作台场景不支持直接 Play 了**：`Assets/Scenes/UiWorkbench.unity` 已收敛为**纯叠加 UI 场景**（只有面板预制体实例；无引导件、无相机、无场景入口）——入口统一走 **Boot**（上面两行）。退出＝「开发 → 设置菜单 → 退出工作台（确认）」→ **场景被真正卸载**（`Scenes` 只剩 Boot）＋落回大厅页。

`Boot.unity` 上该开关**默认关**（正常游戏流程行为不变）；想在"工作台场景"里手测带战斗场景背景的形态，就把该场景的开关取消勾选再 Play。

**开发页**（dev 覆盖件，`DevMenu` 字段默认开；编辑器形态）：左上「开发」钮 → ①**测试模式：训练场**（本地服 Room-Test，**真进训练场**：加载 `TrainingGround` 场景 + 取训练场地图行 `map_id=2`）②**UI 工作台** ③**直连对局**（真 KCP 到本机 RoomServer；房间地图行键由**房间模板 `map_id`/宿主默认图**定——原型形态无票据，见 [07-本地联测](07-本地联测.md) §5.1）④设置菜单 ⑤关闭。已取代先前的 **F9/F10 热键**（入口全走 UI；对局内退出＝ESC → 设置页 → 退出对局）。另有 `DebugTuner` 直入开关：**直入训练场**（优先级高于直入工作台）与**直入工作台**——直入形态**不加载登录页**，退出按 UI 回大厅页。

**训练场布点调整**（多图批；布点＝内容，判定数据永远由重烘产生）：①手工调（首选）——在场景里拖/增删 `spawn_NN`、改掩体代理；布点工具 `TrainingGroundLayout.EnsureSeed()`（菜单 `LiteGame/地图/训练场布点：补齐缺失件` 或**烘焙工具箱「地图」页**）**只补缺失件、不删已有**，手工布点不会被重跑抹掉；②回种子——同页「全量重建种子」清旧 `MapCollision` 重建（**会覆盖手工调整**）。两条路改完都走发布链：**烘焙工具箱「地图」页 → 训练场烘焙** → `Luban/gen.bat` → `python scripts/codegen/gen-build-hash.py`。约束（≤16 出生点、正缩放、yaw 仅 90° 倍数、**不落障碍内/不越边界**）在烘焙器里 fail-fast 点名，细则见《[地图数据专项设计](../设计文档/gameplay/地图数据专项设计.md)》§8.5。

## 2. 界面总览（两块画布）

| 画布 | 排序 | 位置 | 什么时候看得见 |
|---|---|---|---|
| `WorkbenchPanel`（面板） | -100 | 左列目录 / 右列演示组 / 顶部状态行 | 页面**之下**（页面上浮）——页面背景接近不透明时会看不清它，但**射线不被页面挡**（实测可点） |
| `WorkbenchOverlay`（工具条） | 5000 | 屏幕左下窄条（两行，宽 ≤400px） | 页面**之上**——页面打开时也可见可点；实测不压 HUD 底栏血条与弹药 |

| 控件 | 作用 |
|---|---|
| `Cot_Forms` 每行 = 一条 tbuiform 登记：`Txt_FormId`（id + Lua 路径）、`开`、`关` | `开` = 真导航打开（`UINavigationController.GoAsync`）；`关` = `UIService.CloseAsync`。状态行回显"开 12 完成" |
| `Cot_Demos`：`Loading 开` / `进度上报` / `Loading 收场` / `Error 弹窗` / `Toast` | 反馈面演示：先开 Loading → `进度上报` 每次 +0.25（看进度条与文案）→ `Loading 收场`；Error/Toast 各一发 |
| `Txt_Status`（顶行） | 全量读数：`阶段 / 就绪 / 语言 / HUD / Loading(加载文案) / 最近操作` |

**工具条控件**（页面打开时也点得到）

| 控件 | 作用 |
|---|---|
| `中` / `EN` / 当前语言读数 | 切语言（**真语言服务**：已开页面文案 + 列表行立即重刷，与设置页同一条链） |

| `HUD 预览:关` | 战斗 HUD 静态预览开关（见 §5） |
| `回写工具` | 打开 prefab 改动回写窗口（见 §6；仅编辑器可用——开发版 Player 里置灰并显示"回写（仅编辑器）"） |
| 窄读数 | `HUD:开/关 + 最近操作`（全量读数在面板状态行） |

**页面 id 参考**（tbuiform 登记；目录行按表自动生成，新登记页面零改码出现）

| id | 页面 | 备注 |
|---|---|---|

## 3. 日常流程：开/关页面目检

1. 面板左列找到目标行（如 `12 UI.Page_Lobby`）→ 点 `开`。
2. 状态行出现 `最近:开 12 完成`，页面出现在屏幕上；页面按导航语义**压栈**（可叠多层）。
3. 收场三选一：面板该行 `关` / **ESC**（平台 Back，走导航器 Back 链） / 打开别页（Push）。
4. 快速目检建议：先开 `204/205/206`（静态页）看控件与动效；再看 `11/12/15`（真业务页）。

---

## 4. 日常流程：语言切换与边界态注入

**切语言**：工具条点 `中` 或 `EN` → 当前语言读数与状态行 `语言:` 同步；已开页面文案立即重刷（含列表行的本地化列）。

**边界态注入**（查布局健壮性）：

1. **先在目录开一个页**——注入只作用于"**本工作台目录打开过的最近页**"（不新增产品 API 换取的边界）；上云入口自动开的登录页不在作用域，此时点注入钮会提示 `状态注入需先经目录打开一个页面`。
2. `空列表` → 把该页所有列表内核（`VirtualList`/`SimpleListView`）换成零行源：看**空态**排版（提示语/占位图）。
3. `长文本` → 给该页所有文本追加长样本（`（长文本溢出检验 LongText-Overflow-Check 0123456789）`）：看**溢出/换行/省略号**。
4. `复位注入` → 还原注入前的文本；若列表被清过，走"关 + 开"真链路**重开该页**复位数据（状态行：`页面重开 14 完成（列表已复位）`）。

> **预览性质**：注入不算产品态——页面自己的数据推送或切语言会覆盖注入文本；重开页面即彻底复位。状态行会回报注入数量（如 `空列表注入:1 个列表（14）`）。

---

## 5. 日常流程：HUD 静态目检

1. （建议）先关掉所有页面——**HUD 在页面之下**（根画布 sortingOrder 0 < 页面层 100+，与对局内层级一致），页面开着会盖住它。
2. 工具条点 `HUD 预览:关` → 变 `HUD 预览:开`，实例化 `Hud_Battle.prefab`。
3. 看准心/弹药/血条/面板摆放与配色。**这是静态默认画面**：无对局数据源（数值不跳、准心不跟鼠标、设置钮无响应，默认隐藏的面板保持隐藏）。
4. 再点关闭：销毁实例并归还内容租约（随面板销毁也会自动归还）。

## 6. 日常流程：prefab 改动回写（调参固化的最后一步）

**闭环**：验收＝Game 视图 → 编辑＝Inspector（Play 中改实例属性） → 固化＝回写窗口勾选直写。

1. 场景里**放置一个 prefab 实例**（选中实例内任意子对象即可）；在 Play 中实时改属性看手感。
   - **必须是有 prefab 关联的实例**（场景里放置的实例 / Prefab 模式下编辑的对象）。运行时 `Instantiate` 出来的副本（**包括工作台打开的那些页面**）没有 prefab 关联——工具会显式拒绝并说明，这是 Unity 机制，不是配置问题。
2. 打开窗口：工具条 `回写工具`，或菜单 `LiteGame/UI/回写/Prefab 改动回写`（菜单名与工具条跳转路径单源，由守卫用例钉住）。
3. `取当前选择`（也可把对象拖进字段）→ `重新扫描`。
4. 清单按"对象 · 组件"分组，每条显示 `属性  实例值 → 资产值  [标签]`：

| 标签 | 含义 | 默认 |
|---|---|---|
| `显式记录` | Unity 记在案的改动（如 Inspector 改过的颜色/文本等组件属性） | **勾选** |
| `数值差异` | 其余当前值差异——含脚本/驱动每帧写出的数据文本与动态位置，也含 Unity 只维护"默认记录"的路径（**RectTransform 位置/尺寸/锚点**即属此类） | 不勾，**核对「实例值 → 资产值」后再勾** |
| `✗ 不可回写` | 实例新增组件 / 实例新增子对象 / 指向场景对象的引用 / 不支持的类型 | 显式列出、拒绝落地 |

5. 顶部按钮：`全选显式记录` / `全选数值差异` / `全不选` / `显示不可回写项`（结构面说明单独一栏列出）。
6. `回写选中项` → 逐属性直写**源 prefab 资产**（有 Undo、**不需退 Play**）→ 自动复扫：**已固化项不再出现在清单里**（等值即无差异）＝自带自校验；状态区显示写入条数与目标资产路径。

**边界（工具不做）**：

- **结构面**（新增组件/子对象、层级差异）不回写——归 Prefab Stage 与 Unity 原生 Overrides；
- **场景对象引用**不落盘（写进资产会成坏引用）；
- **不回滚实例 override**：固化后实例上仍留着已等值的记录（视觉无差）；要实例回归干净态用 Unity 原生 Overrides ▸ **Revert**；
- **不做整场景运行时保存**。

不要固化"运行时值"：数据文本（血量/时间/进度）、被动画/布局驱动的动态位置属驱动或表，**归驱动常量或表**，固化会污染 prefab——这也是「数值差异」默认不勾的原因。

## 7. 改动与扩展（改布局、复跑验证）

| 想做什么 | 怎么做 |
|---|---|
| 改面板/工具条布局或补控件 | 改 `AgentScripts/BuildWorkbenchPanel.cs` → `unity command run_script --file AgentScripts/BuildWorkbenchPanel.cs --entry BuildWorkbenchPanel.All`（**幂等**：重建 dev 预制体 + 场景瘦身；接线驱动 20 字段）；驱动字段改动同步改接线段。资产守卫用例（`WorkbenchUiAssetEditModeTests`）会钉"预制体存在 + 驱动引用齐备 + 场景不含面板件" |
| 复跑"可点性自检" | Play 中 `run_script --file AgentScripts/WorkbenchW2Probe.cs --entry WorkbenchW2Probe.Env`（全部按钮射线命中统计，未命中会列出名字与顶面） |
| 复跑操作模拟（射线定目标 → 点击 → 读数） | `--entry WorkbenchW2Probe.ClickNamed --args '["Button_HudPreview"]'`；目录行 `--entry WorkbenchW2Probe.ClickRow --args '["12", true]'`；组合步 `ClickThenState` / `ClickRowThenState`（点击后等待并读状态） |
| 读状态（页面栈/列表行数/长文本计数/编辑器窗口） | `--entry WorkbenchW2Probe.State`；场景加载证据 `--entry WorkbenchW2Probe.Scenes` |
| 给列表灌几行造"有数据"前提 | 先开页 → `--entry WorkbenchW2Probe.StuffRows --args '[3]'`（再点 `空列表` 即可看到 3→0 的可见变化） |
| 新增页面全流程 | 登记 tbuiform → 页面自动出现在目录（零改码）；面板布局无需动 |

## 8. 排障速查

| 现象 | 原因 | 处置 |
|---|---|---|
| 所有按钮点不动/灰 | 未就绪（配置未发布、阶段不是 Main） | 看状态行 `就绪:False` 与 `阶段:`；等 Preload/Main 完成；Console 搜 `[Config]`/`[Lua]` |
| 注入钮提示"需先经目录打开一个页面" | 当前页不是工作台目录打开的（如入口自动开的登录页） | 先在目录点一次 `开` |
| 回写窗口报"选中对象不是 prefab 实例" | 选中的是运行时副本（无 prefab 关联） | 在场景中放置实例后重选；或改用 Unity Prefab 模式调整 |
| HUD 预览开了但看不见 | 页面盖住了它（HUD 在页面之下，与局内一致） | 先关页；或看工具条窄读数确认 `HUD:开` |
| 面板左列被挡住 | `DevHUD` 的 F1 统计窗盖住了它 | 按 **F1** 收起 DevHUD |
| 页面文案显示 `[key]` 字样 | LText 缺 key（开发期缺 key 策略） | 属正常开发期显示；补 `tbltext` 行后重开页 |
| 想复现"某页开不了/开页报错" | 数据/服务依赖（如房间页需要房间数据） | 该页是真的要数据；工作台只保证开页与布局，不造数据 |
| 工作台里没有战斗场景背景 | `DebugTuner.WorkbenchMode` 默认开（本场景刻意跳过对局场景组加载） | 需要背景就把该开关取消勾选；正常游戏流程（Boot）该开关默认关、行为不变 |
| 工作台场景启动慢 | 启动链 Patch→Preload→Main 本身要跑（内容/Lua/配置装载） | 属正常启动成本；纯 UI 迭代用 `204/205/206` 静态页 |

Console 自查：`[Workbench]` = 工作台就绪日志；`[UI]`/`[Nav]` = UI 服务装配与导航；`[Lua]` = 页面逻辑装载。

## 9. 边界与纪律（别越界）

- **dev-only**：不担产品职责；**不进正式包**——驱动件整件套三宏（release 剥净）、工作台场景被 `LiteGameIgnoreRule` 的 dev 资产排除挡在收集组之外；守卫用例钉住这两条口径。
- **不做自动断言、不进 `scripts/gate`**：断言、取消/超时、租约清理归 L2（夜间）。
- **真机验证纪律**：任何"能点/能操作"的结论必须走真实操作路径（可点性射线自检 → 模拟点击 → 副作用断言 → 截图存证），禁以直调 API 冒充"操作过"（[修改指南 §2.3](../修改指南.md)）。
- 工作台**不做整场景运行时保存**；场景与 prefab 的分工：场景不承载可调视觉，prefab 承载（要固化走 §6）。
