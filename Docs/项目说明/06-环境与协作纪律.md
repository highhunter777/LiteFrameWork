## 1. 环境要求与恢复

| 项 | 要求 |
|---|---|
| Unity | **2022.3.55f1c1**（Unity 中国版）；L2 按 `--unity-exe` → `UNITY_EXE` → `LocalNotes/unity-editor.txt` → Unity Hub/标准安装/注册表解析，`restore-check` 输出实际路径 |
| .NET | **.NET 8 SDK**（L1/L3 与服务端宿主） |
| Python | `python` + `openpyxl`（`scripts/codegen/gen-build-hash.py` 等） |
| Unity CLI | `unity` 命令在 PATH（Pipeline/门禁/构建脚本都走它）；工具链单源：`scripts/gate/toolchain.json` |
| 一键校验 | `python scripts/gate/restore-check.py`——缺 BLOCKING 项直接 exit 1 |

**随库分发 vs 需自备**（**清单权威＝[环境恢复指南](../环境/环境恢复指南.md)**）：`Packages/`（含 YooAsset、Luban wrapper、`com.unity.pipeline`）、**`ProjectSettings/`（已入库，含 `HIDE_REFLECTION` 等宏）**、`scripts/`、`Tests/`、**TMP 中文字体 `Assets/ShareResource/Fonts/`（2026-10-13 起入库）** 都在库里；而 **Odin（按席位付费）、部分美术资源、XLua Tools、`MCPForUnity` 等本机工具**需按《环境恢复指南》说明自备（实际检查项以 `scripts/gate/restore-check.py` 为准）。第三方素材包（如 `Assets/CombatGirlsCharacterPack`）按政策**不入 VCS**——缺包时角色无视图（不造占位替身），Console 有明确告警。

## 4. Unity 操作纪律（摘要）

- 与运行中的 Unity 交互统一走 **Unity CLI / Pipeline**；连接命令**必须带** `--project-path "E:\unityProject\Test"`（本机注册表有大小写重复条目，不带会连错实例）。
- 禁止手动创建/修改/删除 `.meta`，不得复用其中的 GUID（历史事故见 [05 §3](05-验证与门禁.md)）。
- 编辑器开着也能跑门禁（`l2-unity-gate.py` 的 A 路径），无需关闭工程。
- 改完代码**区分本轮与历史日志**：先 `clear_console` 再观察，避免把上一轮失败编译的残留当成本轮结果。
- 编辑器关闭 Domain Reload 时，静态状态靠 `RuntimeInitializeOnLoadMethod` 复位点清理（如 `GameEntry.ResetForEditorReload`）——新增静态状态时要一并登记。

## 6. 常见坑（都踩过）

| 坑 | 现象 | 处置 |
|---|---|---|
| 忘了重跑 buildHash | 两端握手失败、拒绝进房 | 跑 `gen-build-hash.py`；出包前 `--check` 会拦下（开发期不设测试守卫） |
| 外部改 `.cs` 后 Unity 没导入 | `recompile_status` 报 up_to_date，用例跑旧程序集（**L2 假绿**） | 用 `l2-unity-gate.py`（内含强制 Refresh + 新鲜度守卫），不要只看 `recompile_status` |
| 改动落在点目录 | `Assets/<模块>/.dotnet/obj/**` 的 `.cs` 被误当源码 | 新鲜度守卫已排除点目录；`.dotnet/` 与 `.gitignore` 同源 |
| 拿"启动中"的日志当完成证据 | 冒烟假通过（裸标识符标记） | 只用**完成态标记**（`[Asset] ready` 等），见 05 §4 |
| 判定层混入非确定性 API | 两端行为分叉，握手/重放对不上 | R1～R3 扫描 + L1 的 IEEE/确定性用例 |
| 表数据（`.bytes`）只更了一端 | 客户端进房后 `StartGame` 即被拒（`玩法数据身份不符` Error + 回主菜单） | 按发布顺序**同批**：服务端换 `.bytes` 重启 + 客户端内容候选；两端装载后摘要（`CombatConfigDigest`）复算比对，不等拒局 |
| 在 `RoomServer/Runtime` 里打日志 | R11 打红 | 输出只走 `RoomOutput` 事件，宿主侧再落日志 |
| 缺第三方素材包 | 角色无视图（不造占位替身）；其余表现件静默降级 | 缺件有告警；正式验收留真机/G2 |
