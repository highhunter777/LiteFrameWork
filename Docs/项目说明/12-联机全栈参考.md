### 2.2 会话相位机（`ClientSessionPhase`）

| 相位 | 语义 | 迁移入口 |
|---|---|---|
| `Idle` | 未进房（构造后、JoinAck 前） | 构造初值；`SendJoin` 不迁移 |
| `Connected` | 在房，输入/快照正常 | `JoinAck` 到达（`RoomClient.cs:516`）；`CompleteRestore` 成功 |
| `SuspectedLost` | 传输断开，席位仍在重连窗内 | `HandleTransportDisconnected`（`:498-499`，仅 `Connected`/`Restoring` 且无终局） |
| `Reconnecting` | 已重拨 + 已发 `ReconnectRequest`，等响应 | `BeginReconnect`（`:294`） |
| `Restoring` | 验票+版本确认通过，快照/历史已交应用层 | `HandleReconnectResponse`（`:405-406`） |
| `Failed` | 终态：票据空/耗尽/版本不符/超时 | `BeginReconnect` 无票据（`:290`）、响应不符（`:408`）、超时（`:429`） |

- 超时预算 `ReconnectTimeoutMs = 10_000`（`:48`）；`Reconnecting` 期间**连接建立后重置**该预算（`:392`）。
- **不自动重试**：进入 `Failed` 后由应用层裁决（本产品 = `BattleContext.OnPhaseChanged` → `End(SessionFailed)`，`BattleContext.cs:400-402`）。
- 版本确认三项：`Seed`、`ConfigHash`（仅当已收 `StartGame` 时）、`BuildHash`（`RoomClient.cs:417-422`）。

### 4.5 比赛生命周期状态机

`Created(0) → WaitingForPlayers(1) → Starting(2) → Running(3) → Finishing(4) → Settling(5) → Closed(6)`，另 `Aborted(7)`（`MatchStateMachine.cs:8-19`）。

| From → To | 触发 | 位置 |
|---|---|---|
| Created → WaitingForPlayers | 首个 `AuthenticatedJoin` | `RoomRuntime.cs:275-276` |
| WaitingForPlayers → Starting | 房主 `StartEarly`（**唯一开局入口**） | `:307-322` |
| WaitingForPlayers → Aborted | 等待超时（`WaitingTimeoutMs > 0`） | `:456-461` |
| Starting → Running | `StartMatch` 内 | `:549,566` |
| Running → Finishing | 时限到 / 玩法结束 / 全员离场 / `Shutdown` | `:464-476,378-379,488-489` |
| Finishing → Settling → Closed | `Finish` 内连续迁移 | `:509-512` |
| 任意 → Aborted | `Abort`（幂等，只成功迁移才产 `RoomAbortedOutput`） | `:517-523` |

配套语义：

- 迁移表 `IsAllowed` 是唯一真值来源；非法迁移输出 `Reason="Rejected:"+reason`，**不改状态不抛**（`:526-535`）。
- 进房相位闸：`Starting/Running/Finishing/Settling` 一律拒（`:257-262`）。
- 空位分配取**最低空位**；满员拒；`NextPlayerId` 高水位只升不降（`:266-283`）。
- **未开局断线即释放席位**（空位可复用）；**对局中断线保留席位**（重连窗内可重绑）（`:359-396`）。
- owner = 首个入座者；离席迁给**最低在线**其余席位，旧房主重连**不夺回**（`:403-417`）。
- 满员**不自动开局**（`:288-289`）。
