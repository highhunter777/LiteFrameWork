## 1. 分层与入口

### 1.1 四类载体

| 载体 | 是什么 | 在哪 |
|---|---|---|
| **编辑器 GM 页** | Hub 内页件（`IGmPage`），不进包 | `LiteGame/工具链` → 调试分类；`Assets/LiteGame/Editor/Gm/` |
| **运行期投影** | DevHUD（F1）/ F2 / F3 | `Assets/LiteGame/Adapters/Dev/Projection/` |
| **工具与日志指标** | 门禁、IEEE 对账、`SimWorldDiff`/`SimReplayRunner`、回放；`Log`/`HostLog`/`Ops`/`/metrics` | `scripts/gate/`、`Server/ReplayTool`，见 §8 |

### 1.2 剥离边界与热键

调试件几乎全部**随开发三宏剥离**（`UNITY_EDITOR || DEVELOPMENT_BUILD || LITEFRAMEWORK_DEBUG`）：release 包里这些类型**不存在**（编译不进，不是"关着"）；例外是产品日志门面 `Log`（release 保留，输出 `Warning` 起）。判定路径**禁读静态可变值（含 dev 宏内）**，GM 开关一律是显式注入的规则实例。

| 键 | 作用 | 生效形态 |
|---|---|---|
| **F1 / F2 / F3** | DevHUD（只读）/ 常用调试面板 / 开发控制台 | 编辑器 + 开发包 |
| **F4–F9** | HUD 内部键：复制 / 级别 / 仅本局 / 现场包 / 导出 JSON / 过滤 | HUD 可见时 |
| **T / ESC** | 传送到准心（本地测试模式且 `TeleportEnabled`）/ 设置页退出对局 | 对局内 |

`F10` 预留给 UI 运行时调试面板（目标形态，未落地），`DevHotkey` 目前只绑 F1–F9。文本输入所有权互斥：控制台打开占输入，HUD F9 过滤开着时先退出。

### 1.3 按改动选环

| 环 | 载体 | 适用 |
|---|---|---|
| 内环 | Editor Play + 进程内本地服 + 热重载 | 表现、手感、UI、纯逻辑、表/Lua（秒级） |
| 中环 | 可调试 Player + 本地/云端 Room | 联机行为、内容、网络路径（分钟级） |
| 外环 | release IL2CPP + 云部署 + 真人对局 | AOT 差异、真网络、跨机、发布验收 |

能用内环回答的问题不进外环；**内环绿不等于可发布**。

## 2. DevHUD（F1）

`DevHUD` **自创建**：`[RuntimeInitializeOnLoadMethod(AfterSceneLoad)]` 建 `[DevHUD]` 并 `DontDestroyOnLoad`，场景不挂组件，**不得移入 `Editor/`**。UI Toolkit 渲染（`sortingOrder=10000`，不可用回退 IMGUI）；0.25 s 节流；位置/折叠持久化，首次运行按 `DevStartupConfig.DevHudDefaultExpanded` 初始化。

| 段 | 内容 |
|---|---|
| **错误** | `Log.ErrorCount` > 0 时的红色计数 |
| **联机诊断** | 相位 / RTT / 丢包 + 和解次数 + 回滚/输入领先/快照年龄；60 s sparkline；无对局隐藏 |
| **性能** | FPS / p50 / p95 / p99 / 最差 / 长帧；GC、Draw/Batches、HUD 自耗时 |
| **Stats** | 按模块分段（容器 + 场景组件合并去重），未登记默认隐藏 |
| **Log Recent / DiagTrace / 日志 sink** | 最近 N 条日志；`total=N` + 最近 8 条诊断；`written/dropped` |

性能口径：240 帧环形窗（≈4 s@60fps），**长帧阈值 100 ms**；p95>16.6 ms 黄、p99>33 ms 红。段开关是 `DevHUD` 的 public 字段（`showPerf`/`showNetDiag`/`statToggles` 等），GM「联机诊断」页直接改；`DiagTrace` 与日志 sink 段无开关，无数据即隐藏。

**联机诊断读口**：`BattleDiagnostics`（`Assets/LiteGame/Adapters/Dev/Debug/Diagnostics/BattleDiagnostics.cs`）是静态登记口——对局上下文是流程私有件，HUD 与 GM 页都够不到，故 `Attach/Detach` 在 `BattleViewRig` 装配/拆卸时登记注销；`Take(ctx)` 出快照，`DescribeCurrent()` 无对局返回 `null`、消费方整段隐藏；无样本时 RTT 显示 `无样本`、丢包 `—`（占位不撒谎）。本件只登记、只读、只拼文本。

## 3. 运行期控制台（F3）与常用面板（F2）

### 3.1 F3 开发控制台

`DebugConsole`（`Assets/LiteGame/Adapters/Dev/Projection/DebugConsole.cs`）：F3 开关、Esc 关闭；打开时注册 `debug.console` 输入拦截（角色不动）；底部面板（`sortingOrder=10100`），最近 **200 行**。动作经 `DebugKernel`：命令走 `CommandCenter`、开关走 `TestModeOptions`、请求桥走 `TestModeRuntime`。

| 命令 | 作用 |
|---|---|
| `help` / `commands` / `run <命令名>` | 列命令、执行发现的 GM 命令（仅无参） |
| `audit [n]` / `options` / `option <Id> <on|off>` | 审计环（最近 **32 条**）/ 开关清单与唯一写口 |
| `tune [list] [scope]` / `tune <id> [value]` / `tune reset|resetall` | 调试参数 |
| `stats` / `log [n]` / `diag [n]` / `battle` / `request <enter|exit|teleport>` | 读数与一次性请求桥 |
| `weak none|lan|mobile|lossy` / `net drop|reconnect|auto` / `hud stats` | 弱网、会话与断线、模块 Stats 白名单 |

已知边界：带参命令标「需专面板」并拒绝；无 `ThemeStyleSheet`（自绘）；全屏产品页会盖住底部面板；发现命令依赖反射，IL2CPP 未实测。

### 3.2 F2 常用面板与弱网注入

`DebugPanel`：F2 开/关，打开时注册 `debug.panel` 输入拦截；顶部右侧（`sortingOrder=10200`）。内容 = 本地测试模式进入/退出/传送 + `TestModeOptions` 的 `Group.Live` 开关 + 快捷调参（`RuntimeVisible=true` 且非 `Product` 的子集）+ 联机会话动作（强制断线/重连、抑制自动重连）；不展示也不写 `Startup` 项。

弱网只对真 KCP 形态生效：`weak` 切 `none/lan/mobile/lossy`，`tune` 调 `net.latency/jitter/loss/dup/reorder`，HUD 显示注入行与 240 样本曲线；可靠信令不丢、不重、不乱序。抑制自动重连后断线停在 `SuspectedLost`，用「强制重连」恢复。

## 4. 编辑器 GM 页

### 4.1 宿主与契约

Hub 唯一入口 `LiteGame/工具链`（`LiteGameToolboxWindow.cs`），清单驱动：页/动作由 `scripts/gate/toolchain.json` 声明，`EditorToolCatalog` 装配，handler 在 `EditorToolHandlers.cs` 注册。壳只做三件事：切页调 `OnShow/OnHide`、**仅 Play 中且仅活动页**按 0.5 s 调 `Poll()`、选中记忆写 `EditorPrefs`（`LiteGame.Toolchain.*`）。页件契约 `IGmPage`（`Title/OnShow/OnHide/Draw/Poll`）；读数经 `GmEditorResolve.ResolveFromContainer<T>()`（走 `GameEntry.TakeContainer()`，未装配按空态），写只经 `TestModeOptions` / `TestModeRuntime` / 命令中心。

### 4.2 七页

`debug.test-mode` 本地测试模式 · `debug.tunables` 调试参数 · `debug.commands` 命令与审计 · `debug.scene` 场景操作 · `debug.config-diagnostics` 配置诊断 · `debug.local-chain` 本地联测 · `debug.net-diag` 联机诊断。除本地联测（外部平面，编辑态即 1 s 自刷新）外都要求 Play。另有两个工具挂在调试分类：`logs.query`（日志检索 CLI）与 `debug.devhud`（面板说明页）。

### 4.3 本地测试模式页

三个一次性请求桥（`RequestX` → `TakeX` 读即清）：`RequestEnter` → `ProcedureMain` 进 Room-Test；`RequestExit` → 主菜单与对局两流程各持一次 Take；`RequestTeleport` → `ProcedureBattle.SendQueued(TeleportToAimCommand)`（进审计环、可撤销）。

页内区块：进入/退出/传送；`Live` 现场开关；`Startup` 只读回显 + `bot=N`；**云端测试房（sandbox）**——选地图 →「创建并进入云端测试房」→ 房号回填 → 免死/无限弹药下发 `POST /gm/rules`（真 KCP 必须用这块，现场开关只改本进程预测）；bot 重置/无限生命；爆头区「导出 `HeadBake.g.cs`」（**对局中导出会 domain reload 中断对局**）。

### 4.4 开关矩阵（`TestModeOptions.All`，9 项）

| Id | 分组 | 默认 | 收口 |
|---|---|---|---|
| `NoDeath` | Startup | 开 | 规则实例（Hp 保底 1、不写 Kill/Death） |
| `InfiniteAmmo` | Live | 关 | `Set` 内写当前活动局 `MatchRules.InfiniteAmmo` |
| `LaserSight` / `DamageNumbers` | Live | 开 | 表现面 |
| `AutoHeadshot` / `DrawHeadshotDebug` | Live | 关 | 替换输入源 / 画身位与爆头柱 |
| `TeleportEnabled` / `BotFrozen` / `BotInfiniteHp` | Startup·Startup·Live | 开 / 关 / 关 | T 键门闩 / 权威侧回写 bot 位置 / 宿主钩子每帧回满 |

**写点唯一**：面板勾选、运行时快照、`DevStartupConfig` 初值都经 `TestModeOptions.Get/Set`；新增开关 = 表里加一行 + 运行时字段，面板零改动。`BotCount` 是 int、不进表，总席位 = 1 + 本值。

### 4.5 调试参数与其余页

调试参数页按 `IDebugTunableProvider` 自动渲染（`Id/Group/Label/Kind/Scope/Default/Min/Max/Get/Set/Reset`；发现面 = `DebugKernel.Tunables`）。默认值由 provider 提供、`Reset` 回源值；写口直调 setter，只在本机运行时、不落盘、不进摘要，定型值经导出进 `*.g.cs`。

- **命令与审计**：`DebugKernel.Commands` 发现清单（`[GM]` 标 `GmOnly`），`TryExecute` 只执行无参命令；审计环 32 条。
- **场景操作 / 配置诊断**：加载卸载经 `SendAsync`（Play + `AssetService.Initialized`）；配置诊断给状态行、`cfg.Tables` 表查询与产物预检。
- **联机诊断**：DevHUD 的编辑器投影，读数同源。

## 5. 启动配置与运行态旋钮

`DevStartupConfig`（Boot 场景、与 `GameEntry` 同 GameObject）：`DirectToTraining`、本地测试模式启动项（`NoDeath`/`InfiniteAmmo`/`LaserSight`/`DamageNumbers`/`AutoHeadshot`/`DrawHeadshotDebug`/`TeleportEnabled`/`BotFrozen`/`BotCount`，进房时快照）、`DevHudDefaultExpanded`（出厂四段：错误/联机诊断/性能/模块 Stats）。未挂时套 `TestModeRuntime.ApplyDefaults`。`DebugRuntimeTuner`：`SyncEnabled`/`WorldTimeScale`/`WorldPaused`（`SyncEnabled=false` 时停止每帧覆写）、`UiPaused`、`StrictMode`；未挂时时钟旋钮不生效，GM 页显式 Warning。

## 6. 本地测试模式的真实边界

本地测试模式（Room-Test）**恒为本地服形态**：客户端预测与权威 Sim **同进程、同实例、同规则对象**，现场开关即时生效。`LocalServerTransport` 列出的「假」部分：**无 Socket**、**无票据验签**（token 只做非空）、**单房间**、**自动补位**、**代房主开局**。弱网、断线重连真实性、多房间隔离必须在真服务器验。真 KCP 下现场开关**只改本进程预测**，权威侧只认 `/gm/rules` 的 `gm_flags`；云端测试房（隐藏房）**不产结算**，客户端仍收 `MatchEnded`，结算页按「无结果」展示。

## 7. 云端 GM（运维端点）

与编辑器 GM 页不是一回事：后者在编辑器 + 预测面，前者是**房间服进程内的写面 HTTP 端点**（`http://10.8.0.1:9101/gm/*`，详见 [12](12-云侧部署与联机测试.md)）。门禁：仅 POST、`X-GM-Key` 恒定时间比对、body ≤ 4096 B、密钥 `LITENET_GM_KEY` 为空则不启用、`gm_bind` 不得为通配地址。动作 `rooms/diag-list/diag-fetch/start/abort/kick/rules/settle-flush`，契约源 `gm-contract.json`；`rules` 只对隐藏测试房生效。审计行走裸 `Console.WriteLine`（`[GM]` 前缀），未过 `HostLog`，是登记在案的偏差。

## 8. 日志与诊断面

### 8.1 `Log` 与结构化 JSONL

`Log`：`Info/Warning/Error/Fatal(message, tag)` + 两个 `Exception` 重载；环缓冲 **32 条**；编辑器/开发包 `Info` 起、release `Warning` 起；`ErrorCount` 统计 Error 与 Fatal；`LogTag` 是封闭词表（`None` + **33 个标签**），漏臂编译告警 + 穷尽守卫测试。

结构化日志（dev 三宏内由 `StructuredLogInstaller` 安装，release 不装）：`persistentDataPath/logs/log-<session>-<yyyyMMdd-HHmmss>-p<n>.jsonl`，一行一个 JSON（`ts/lvl/tag/sid/mid/f/p/msg`）；调用线程只入队（容量 **1024**，满则丢最旧并计数），后台线程落盘；单文件 **8 MB** 轮转、保留 **8 个**。检索：`python scripts/logs/query.py <文件或目录> [--match/--player/--tag/--level/--frame-min/--frame-max/--contains/--since/--limit/--json/--stats/--all]`。

### 8.2 服务端 `HostLog`、Ops 行、`/metrics`

`HostLog.Info/Warn/Error(area, message)` 只管宿主逻辑输出（缺省 Console）。**Ops 周期行**缺省 **5 s 一行、每房一行**（`host_tuning.ops_interval_ms`，1 s–600 s），格式单源 `Ops.Format`：

| 段 | 字段 | 看什么 |
|---|---|---|
| 房间 / 快照 | `steps sessions players` / `snap: sent full bytes drop` | `steps` 应随墙钟涨；`full` 涨快 = 有人 ack 落后；`drop>0` = 快照被撑爆 |
| 输入 | `in: pkts acc drop(dup/range/stale/ack/btn)` | **`acc` 不涨 = 输入链断**；`range/stale` 暴涨 = 帧号窗口错位 |
| 和解 / 回溯 / 背压 | `reconcile: reports` / `lagcomp: degr` / `bp: throttled outRej` | `reports` 涨 = 反复分叉；`degr` 高 = 回溯走退化；`throttled` 涨 = 有人跟不上 |
| 比赛 / 边缘 / 循环 | `match: … obx(ok/dup/rej/fail)` / `edge: … tktBad` / `loop: … pumpFail` | `rej` 涨 = Outbox 满；**`pumpFail>0` = 权威帧体在抛且已被吸收** |

`/metrics` 只认 GET（其余 404）：房间服 `metrics_port`（云上 9100）**32 项 `roomserver_*`**，Meta **9 项 `meta_*`**；不含高基数字段与房间内瞬时量（归 Ops 行）；房间服侧启动失败告警降级。

### 8.3 `DiagTrace`（两端同形同键）

`Assets/LiteNet/Core/Diagnostics/DiagTrace.cs`：`DiagEvent{Seq, TickMs, Stage, Code, Key, Detail}`，容量 **64 条**；Stage 5 个（`Build/Content/Txn/Session/Room`），Code 8 个（`JoinAttempt`、`JoinRejected*`、`JoinNoAckDisconnected`、`ActivationFailed/Recovered`）；关联键 `JoinKey(roomId, playerId, buildHash)`（空值写 `-`），**不记凭据**。发送点 4 处（`RoomClient` 两个 Join 事件、`ServerHost` 两处拒绝）；读面 HUD 段、F3 `diag [n]`、`DebugKernel.RecentDiag`。

## 9. 确定性与回放

### 9.1 分层跑法

分层跑法：L0 `l0-dep-scan.py`；L1 `test.py --suite L1 --profile PullRequest`（含纪律扫描/表守卫/BuildHash 守卫）；L2 `l2-unity-gate.py`；L3 `test.py --suite L3 --profile PullRequest`；Doc `test.py --suite Doc`。

### 9.2 对账三件

对账三件：**IEEE 基线对账**（Unity 与 .NET 同一份样本逐位比较，不等 = 浮点路径分叉；Hub 质量门禁 / CI `RunCli`，一致 exit 0）；**`SimWorldDiff`**（把「checksum 不符」翻成「哪个槽位哪个字段变成什么」，不做容差；已有实现但**生产零调用**）；**`SimReplayRunner`**（`SimRunRecord` 跨运行时重放、给首个分歧帧；**零调用**）。纪律扫描菜单 `Tools/纪律扫描`，规则与作用域在 `ScanTargets.cs`，CI 入口 `DisciplineScanMenu.RunCli`（违规 exit 1）。

复现口径：单帧直构 `RoomRuntime`/`SimStep`；单局用 L3 假传输 `FakeRoomTransport`；固定种子靠模板 `seed`（非 0 固定、0 由 Tick 派生）。

### 9.3 房间记录、重放与现场包

房间服 `diagnostics` 启用后，房间**终态静默后**落盘 `room-<roomId>-<matchId>-<utc>.json.gz`（身份、有序命令、逐帧 checksum、`HostLog` 尾与最近 mismatch）；目录须绝对路径，不配即零行为变化。

```powershell
dotnet run --project Server/ReplayTool -- replay <record.json.gz> [--json] [--defaults]
```

默认加载真实表并复算 `fixedConfigDigest`；身份三项（`buildHash`/`fixedConfigDigest`/`mapDigest`）任一不符即拒放；退出码 `0` 一致、`2` 首分歧、`3` 身份或格式不符、`4` IO、`5` 截断。客户端现场包（checksum mismatch 或 `StartGame.ConfigHash` 不符）落在 `persistentDataPath/diagnostics/diag-<时间戳>-<reason>-<uuid8>`：`manifest.json`（buildHash/configDigest/matchId/frame/localEntityId/reconcileCount/平台/版本）、`log-recent.txt`、`player-log-tail.txt`；同局最多 **3 份**、间隔 ≥ **30 s**、预算 2 MB，本地 only、失败只 `Log.Warning`；HUD F7 同信封（`hud-snapshot`）。

## 10. 症状 → 分层 → 处置

判断顺序：**先确认哪一段断，再看具体原因**。

| 症状 | 先看 | 处置 |
|---|---|---|
| 登录失败 / 大厅看不到房 | Meta `/live`、`meta.url`；房间是否注册 | 没隧道/没起 Meta/Mongo；隐藏测试房不进大厅 |
| 签票 `409` / `403` / `503` | `buildHash`；测试房口令；实例容量 | 漏跑 `gen-build-hash.py`；`LITEGAME_GM_ROOM_KEY` 为空；心跳超时或房满 |
| Join 无 Ack / 连上就断 | `JoinNoAckDisconnected`、`rejects/tktBad`；信封 PSK | 准入链拒绝（拒因不回明文）；握手形状不符即断无回执 |
| 进局但角色不动 | Ops `in: acc`、`drop(range/stale/btn)` | AimPoint 全零/帧号越窗/seq 违纪/按键白名单 |
| 打完没有战绩 / 结算一直重试 | 是否云端测试房；Ops `obx(fail/rej)` | 测试房不产结算；Meta 不可达或凭据不匹配 |
| `steps` 不涨 / L1 报 MSB3027 | Ops `loop: pumpFail`；是否有活服进程 | 帧体异常被吸收（查 `LastPumpError`）；先停服再编 |

## 11. 调试面红线与已知不足

1. 判定路径禁读任何静态可变值（含 `#if UNITY_EDITOR` 内）；GM 开关一律显式注入规则实例。
2. **开关写点唯一**：新增开关 = `TestModeOptions.All` 加一行 + 运行时字段，不许在面板里直写判定。
3. **投影面零业务逻辑**：DevHUD / GM 页只读 + 调写口，不持规则、不写运行态；审计环只收命令化动作。
4. **覆写面不落盘、不进摘要、复位回导出值**；成型值经导出进 `*.g.cs`。
5. **调试件随三宏剥离**，release 零残留；`DevHUD` 不得移入 `Editor/`；临时诊断带 `[Diag]` + 摘除批次号。
6. UI 调试面默认只读，写回仅编辑器属性级 patch；写动作只经 `DebugKernel`。
