# 说明（解释层）

> **定位**：回答"这是什么、怎么跑、数据怎么流、代码在哪、怎么部署/排障"。只解释现状，不裁决目标架构、不记施工批次。
> **权威边界**：目标架构归 [设计文档](../设计文档/README.md)；批次证据归 [施工进度](../施工进度/README.md)；关口与剩余面归 [待办总览](../待办总览.md)；必须遵守的硬规则归 [规范](../规范/README.md)。
> **编号规则**：一章一文件，两位数连续递增（01–16），不留跳号；插入新章时整段重排。生成物 `工具索引.md` 固定名、不占编号。
