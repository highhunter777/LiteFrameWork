## 1. 四条硬约束

UI 不是"一个 UIManager"，而是**运行时 + 绑定生成 + 工具链 + 页面逻辑**四段流水线。四段共同服务的约束（违反由扫描器、校验规则或运行时抛错兜住）：

1. **视觉单一来源**：可见结构只能来自 `Assets/LiteGame/Modules/UI/Content/{Screens,Widgets}` 与 `Assets/LiteGame/Modules/Battle/Content/Hud` 的 prefab，运行时不得 `new GameObject`/`AddComponent` 拼界面。`RuntimeVisualRule` 扫 `UIValidator.SourceScanDirs`（`Packages/com.litegame.framework/Runtime`、`Assets/LiteGame/App`、`Assets/LiteGame/Modules/Battle` 等）。
2. **单写者**：产品页面开关只经 `UINavigationController`；`UIService.ShowAsync` 只留给工具/测试。
3. **逻辑可热更**：页面逻辑是 C#（`Page_<Name>Logic`，prefab 根挂组件），随 `LiteGame.Modules.UI` 等 hot 程序集经 HybridCLR `code/` 段热更；运行时不再解释脚本，也没有脚本环境重建。
4. **制作可分工**：美术管 prefab/命名/暴露，工程管表行/绑定/接线，以**页面契约**交接。

## 2. 运行时：一个壳 + 协作件

`UIService`（`Packages/com.litegame.framework/Runtime/Services/UI/UIService.cs`）只做**开关管线编排**（校验 → 取/建实例 → 转场 → 落池 → 重算遮盖/模态），其余由协作件各管一件：`UIFormStore`/`UIFormCacheEvictor`/`UIFormStats` 管实例、租约、LRU 记账与淘汰选谁（表只给候选集，只淘汰池中非 `Resident`）；`UIFormLogicBinder` 管逻辑解析/注入；`UILayerGroupFactory`/`UIStack` 管运行时根与层级组（索引即 `PageDefinition.Layer`）；`UICoverageResolver` 管遮盖推导（以"仍逻辑打开的最高全屏"为界，更低组全遮，逐界面最小迁移并联动焦点）；`UIModalStack` 管模态、顶模态、射线遮蔽与 Back 目标（从仍打开页面推导，只依赖 `IUIFormQuery`）；`UITransitionRunner` 管转场（不注册 `ITickable`，壳在 Tick 帧末转发）；`UIFocusCoordinator`/`UIBindIndex` 管焦点与名字到控件索引（`Get` 未命中直接抛）。

层级固定为 `UIService.GroupNames = Bottom / Window / Top / System`（索引 0/1/2/3）。**没有独立的 Modal/Loading 层**：模态是"页面属性 + 栈推导"，Toast/Loading/错误重试统一落 `System` 层并由统一排序器分配 `order`——反馈面不得自建 Canvas 或私有 `sortingOrder`。

## 3. 生命周期、缓存与关闭原因

```text
Loading → Active ⇄ Covered / Paused → Closing → Recycled → Disposed
```

- 只有 `Active` 转发 `OnUpdate`；`Covered` 由更高层全屏批量推导，`Paused` 是手动暂停；非法迁移在 `UIForm` 当场抛。`Recycled` 可复用且**不重跑 `OnInit`**，`Disposed` 是终态；Tick 走快照迭代（`_tickSnapshot`），回调里开关界面安全。
- 关闭原因 `CloseReason` 六值：`User / Back / Replace / ScopeExit / Reload / Shutdown`；系统关闭（后三个）跳过"未保存拦截"与离场动画，`User`/`Back` 可被出栈拦截。
- 缓存预算 `UIService.DefaultCacheBudget = 16`（`Resident` 也计入，只是不参与淘汰）；`UICacheStrategy` 三值：`Lru`（默认）/ `Resident`（关闭入池不淘汰）/ `DestroyOnClose`（关即销毁、不进池）。
- 策略链路：`UIPageManifest.json` 的 `cacheStrategy` → `gen-ui-page.py` → `UIPageCatalog.g.cs` → 运行时（`UIService` 关闭路径按 `DestroyOnClose` 销毁，`UIFormStore` 淘汰候选过滤 `Resident`）。当前 12 个登记页全部 `Lru`。

## 4. 导航单写者

`UINavigationController`（与 `UIService` 同目录）串行排队执行 Go/Back：

| 参数 | 值 | 语义 |
|---|---|---|
| `DefaultQueueCapacity` | 8 | 排队中操作上限（不含正在执行） |
| `DefaultOpenTimeoutSeconds` | 10 | 排队等待上限；`<=0` 不超时 |
| `UITransitionRunner.DefaultMaxDuration` | 2s | 转场兜底，超时广播 `Completed=false` |
| 转场待办队列 | 1 | 同帧 last-wins；目标即当前 Incoming 则忽略，再来的丢弃计数 |

- **队列满在创建/入栈/OnShow 之前拒绝**（`UIOpenException(Rejected)`，不留半成品）；**排队期取消**＝标记放弃、出队跳过；**执行期取消**贯穿 `ShowAsync`，半成品由其回滚。
- `UIOpenFailure`：`Canceled / LoadFailed / InitFailed / Busy / Rejected / Timeout`（同界面在途且数据不同＝`Busy`，不静默覆盖）。读数：`Executed`/`RejectedByCapacity`/`TimedOut`/`CancelledWhileQueued`。
- `GoAsync` 保留旧页（新页覆盖其上），`ReplaceAsync` 显式关闭当前记录（旧页收 `Replace`）。Back 链：**最顶模态优先**，其次最高非空层栈顶（原因 `Back`，可被出栈拦截）；`BackInterceptor` 返回 true＝本次 Back 已消费（如 Loading 阻断）。平台返回统一口径：`Focus.PlatformBack` 挂 `nav.BackAsync`（`UISegment`）。

## 5. 绑定：一条运行期索引

- prefab 挂 `BindNode`、`BindName` 非空；`BindIndexBuilder` 实例化后扫全树登记，空名跳过（只参与代码生成），重名抛。当前 UI Content 下 prefab 共 144 个 `BindName`。
- `UIBindIndex.Get<T>` 未命中抛 `KeyNotFoundException`、类型不符抛 `InvalidOperationException`，不返回 null。
- **单一驱动 + 文本单写者**：页面逻辑只走命令式受控 API；不存在运行时数据绑定驱动。同一节点不得同时有静态 `LTextKeyRef` 与动态 `SetTextKey`（`ui.contract.text-double-write`）。按钮绑定是替换式（重绑先移除旧监听），池化复用安全；页面逻辑在 `OnHide` 走 `UnbindAll` 解绑全部按钮。
- **生成类路径当前无生产页面**：`BindRoot`+`BindNode` → `BindGenerator` → `Xxx.cs`/`Xxx.Designer.cs`，但无页面挂 `BindRoot`，`UIBindManifest.json`（绑定面指纹）未生成；无 `BindRoot` 时不伪造 hash。生成文件禁手改，主类可写 partial。

## 6. 页面逻辑层

### 6.1 载体与解析

页面逻辑＝prefab 根上的 `IUIFormLogic` 组件，类型为 `Page_<Name>Logic`，住 `Assets/LiteGame/Modules/UI/Pages/Screens/<域>/`：
`PageLogicBase` 提供 `Ctx`（`IPageContext`）与端口便捷口（`Nav`/`Meta`/`Maps`/`Room`/`Settings`）、受控 API 基类（`UIBindBase` 派生），生命周期七回调 `OnInit/OnShow/OnUpdate/OnPause/OnCover/OnReveal/OnHide`；异常由 `UIForm.SafeCall` 隔离（单页降级）。
解析单源＝`UIPageLogicScanner`：按页名递归找 `Page_<Name>Logic.cs`，并把名字型首参调用点/事件接线投影给契约对账；`ui.page-logic` 规则校验"有逻辑件 ⇒ prefab 根必须挂实现 `IUIFormLogic` 的组件"（重复实现报错）。模板页不要求逻辑件。

### 6.2 预载与放行

`ProcedurePreload`（`Assets/LiteGame/Modules/Procedure/SubModules/StagesSubModule/ProcedurePreload.cs`）在配置装载后：装载配置表 → 放行时登记设置页为模态（`PageIds.Page_Settings`，表驱动反查）→ `Request(Main)`。没有脚本预载、环境初始化或注册表填充步骤；失败/取消都先 `LaunchLoading.End()`。

### 6.3 数据面与页面服务

- 页面对外数据走强类型 `IUIData`：`ResultPageData`/`SettingsPageData`/`RoomPageData` 等由 `PageFlow` 或页面自身构造，不经 table/dictionary。
- 页面服务经 `IPageContext` 注入：`Meta`（`IMetaSession`）、`Room`（`IRoomView`）、`Maps`（`IMapCatalog`）、`Nav`（`UINavigationController`）、`Settings`（`ISettingsPagePort`）；端口由组合根（`AppComposition.BindPageServices`/`BindProductSettings`）产出，UI 段只经工厂延迟取件。`Meta`/`Room`/`Settings` 允许为 null（未配置部署/未进房/未装配），页面按"能力缺失显性拒绝"处理。快速进入/选房/建房/离房经 `IMetaSession` 转 `IRoomFlow`，页面不直接触阶段机；`Room` 仍是 JoinAck 后的只读投影与开局请求面。
- 设置页只经 `Ctx.Settings`（`ISettingsPagePort`，28 个原语成员：15 读 + 13 写/动作，写即生效、无 `Apply`）读写；端口住 `Modules/UI/Abstractions`，生产实现 `ProductSettingsAdapter` 住 `App/PageServices`（组合根在 `ProductSettings` 实例登记之后包端口，页面上下文用 `Func` 惰性取）。UI 域不引 `LiteGame.Modules.Settings`。空端口（未装配）时 `OnShow` 早退：12 个设置控件禁用、页签仍可切、关闭可用，读写一律 `?.` 不抛。

### 6.4 生命周期与解绑

`PageLogicBase.OnHide` 先跑页面收尾再 `UnbindAll`（等价旧适配器的解绑纪律）；`CloseSelf` 走 UI 服务统一关闭。页面不持有需要手工释放的脚本引用。

### 6.5 热更

页面逻辑随 hot 程序集发布：`LiteGame.Modules.UI` 在 HybridCLR hot 清单内，`code/` 候选段经 `HotUpdateLoader` 唯一装载点换入；编辑期结构性改动走域名重载/编辑器重编译，不再有"改脚本存盘即生效"的运行期通道。

### 6.6 页面流

`PageFlow`（`Assets/LiteGame/Modules/Procedure/Flow/PageFlow.cs`）只接流程与 UI 之间的接缝，页面跳转由 C# 页面经 `Ctx.Nav` 驱动（仍走导航单写者）。`Landing` 三值 `Login`（正式）/`Lobby`（本地服务器、开发）/`None`（直入训练场、工作台）；`OpenLanding` 只在首进 Main 开一次页，账号重入走 `ShowLogin`——它同步推进恢复代次，使旧房间清理/错误反馈的晚到导航失效。开局关房间页、结束开结算页、对局中开设置页（导航数据 `battleExit` 门控"退出对局"）；房间正常离场/失败先完成清理，再由流程统一回大厅或错误确认。房间页与设置页只表达离房意图，不提前 `Replace` 大厅；恢复完成前入场仍被操作句柄阻断。

## 7. 工具链

### 7.1 目录与入口

`Assets/LiteGame/Editor/UITools/`（108 个 `.cs`）按职责分十四目录（`Workbench`、`Compose`、`Binding`、`Contract`、`Contracts`、`Page`、`Preview`、`Validation`、`Widgets`、`Text`、`Naming`、`Reference`、`UIApi`、`Templates`）；清单与生成物为 `UIPageManifest.json`、`UIWidgetManifest.json`、`Contracts/<Page>.contract.json`（12 份）、`UIRuleExceptions.json`、`UIStyleTokens.json`、`UIDeviceProfiles.json`。

16 个 UI 类工具 id（`python scripts/toolchain.py open <id>`）：`ui.workbench`（唯一制作入口）、`ui.page-scaffold`、`ui.page-register`、`ui.contract`、`ui.contract-diff`、`ui.page-manifest`、`ui.widget-manifest`、`ui.validate`、`ui.binding-hash-all`、`ui.binding-hash-selected`、`ui.style.colors-refresh`/`colors-report`/`text-apply`/`text-report`/`tokens`、`ui.preview-matrix`。

### 7.2 五透视与 Lane

`UIWorkbenchPerspectives` 是单源（窗口与夹具共用）：页面 10（`page.list`/`page.metadata`/`page.scaffold`/`page.register`）、控件库 20（`widgets.insert`/`widgets.properties`）、绑定 30（`binding.edit`/`binding.generate`/`binding.hash`）、契约 40（`contract.generate`/`contract.diff`）、校验 50（`validate.narrow`/`validate.full`）。

`UILanePolicy` 是"Lane × 动作"门控单源（表驱动，窗口里不得散落 `if (lane == …)`）；Lane 只是 UX 分层与默认动作集，不是权限系统。词表 `Art`/`Technical`/`Engineering`，一个 prefab 同一时间一个 Owner。全部允许 `OpenPage`/`EditBinding`/`GenerateContract`/`Validate`/`Preview`；`EditMetadata` 限美术/工程（TA 只读）；`InsertWidget` 限美术/TA；`DiffContract` 限 TA/工程；`Scaffold` 限美术；`Register`/`GenerateBinding` 限工程。

### 7.3 起页与登记

**起页（美术）**：输入页面名 `Page_<Semantic>`（根名与文件名同文）+ 视觉基线（`Tmp_BaselineA`/`Tmp_BaselineB`/`Tmp_ListScreen`/空白 `Tmp_Page`）。产物：`Assets/LiteGame/Modules/UI/Content/Screens/Page_<Semantic>.prefab`（从基线**复制**为自包含 prefab，不是 Variant）、`UIPageManifest` 草稿条目（`owner` 默认 `art.ui`、`status=Draft`）；**不写**表、不生成逻辑件、不生成绑定类。根契约幂等补齐 `Canvas`+`CanvasScaler`（1920×1080，Match 0.5）+`GraphicRaycaster`+`CanvasGroup`；`SafeAreaReceiver` 挂在现有拉伸 `Cot_*` 容器（无则由工具新建）。交接前须生成草稿契约（查 `sourceHash`/`controls[]`/`text[]`/`templates[]`），草稿布局改动后必须重生成（`ContractDriftRule` 判 Error），无草稿契约时登记被拒。

**登记（工程）**：输入页面名、`id`（窗口给"最小空闲 ≥16"建议值，不复用 201–206）、`layer`（0–3）、`full_screen`、缓存策略；契约门槛＝`Contracts/<Page>.contract.json` 存在、`formId=0`、`prefabGuid` 与当前 prefab 一致。步骤与失败面 `UIPageRegisterFailure`（`Validate / Contract / WriteTable / Codegen / Manifest / ContractRefresh`）：① 预检（查重、非法名/保留 id/layer 越界）→ 失败零产物；② 写表前备份 → `Luban/Data/#uiform.xlsx` 追加 `id/prefab/layer/full_screen` 行；③ `codegen.luban` → `codegen.build-hash`；④ 清单 `Draft → Registered` + 写 `formId`/缓存策略；⑤ 契约按真实 `formId` 重生成。逻辑件由工程按 `Pages/Screens/<域>/Page_<Name>Logic.cs` 新建并挂到 prefab 根（`ui.page-logic` 对账）。回滚：表写失败按备份回滚并复核行不存在；Luban/BuildHash 失败回滚表行并重跑 Luban（清单仍 Draft）；清单保存失败不回滚表；契约刷新失败提示重跑 `ui.contract`。

### 7.4 契约、校验与预览

- 契约＝prefab 对外 API 快照；契约 diff 视为 UI API 变更，破坏性变更需双方评审，**不手改契约**。`UIPageManifest` 五态 `Draft / InReview / Registered / Wired / Frozen`，`UIPageStatusRules` 是迁移表唯一实现源。
- `UIValidator` 是**唯一校验核心**，三入口共用（菜单、CLI `RunCli`、EditMode）；规则按 `IUIRule` 端口注册，当前 **23 条规则、10 个规则族**（结构、命名/绑定、契约、样式、文本、布局/适配、资源、性能、行为、渲染/适配）。各族缺口写在 `UIValidator.Families`，未落地子项显式标注、不显示为通过；例外走 `UIRuleExceptions.json`。
- 预览：工作台「预览」→ `UIPagePreview` 打开专用预览场景进 Play，页面由 `UIPreviewDriver` 直接实例化，**不跑 Boot/页面数据**；保存该 prefab 资产即热重载，退出 Play 回到原场景，预览中隐藏 DevHUD。参数经 `EditorPrefs`/`SessionState` 键 `LiteGame.UiPreview.*` 传递（设备档、宽高、四边 inset、locale、字体缩放）；安全区由 `PreviewSafeAreaStrategy` 注入页面内 `SafeAreaReceiver`；设备档清单 `UIDeviceProfiles.json`，语言档含伪本地化（`PseudoLocale`）。**是布局档**：按钮回调、列表数据、语言服务行为不在这一档验证。

## 8. 现状清点

页面轻提示的调用链是 `UIBindIndex.ShowToast → UIForm → FeedbackService.ShowToast`。`UISegment` 给 `UIService` 注入回调，`UIBindBase` 在 OnInit 建立页面索引时绑定所属表单；首次调用不依赖场景预放 Toast，承载由反馈服务懒打开，计时仍由 `ToastTicker` 消费 UIClock。


`Assets/LiteGame/Modules/UI/Content/Screens` 14 个 prefab = 7 个产品页（`Page_Login/Lobby/Room/Result/Settings/Records/ButtonDemo`）+ 6 个模板 + 1 个测试载体。生成目录 `UIPageCatalog.g.cs`（源头 `#uiform` + `UIPageManifest` + `Contracts`，重生成 `python scripts/codegen/toolbox.py ui-page`）：产品页 11–17（设置页 15 为 Layer 1，其余 Layer 0 全屏；设置页在预载放行时登记为模态）；模板 201–206（`Tmp_Dialog` 占 201 Layer 3 与 206 Layer 1 两行，其余为 Loading/Toast/两个基线）。12 个登记页全部 `status=Registered`、`cacheStrategy=Lru`、有契约；目录按 formId 排序（13 行）——读目录时不要假设"一页一行"。

- `Tmp_UITestPage` 是 UI 栈夹具：**不登记** `tbuiform`、不产出 `PageIds` 常量。
- 控件模板 `Assets/LiteGame/Modules/UI/Content/Widgets` 30 个 prefab；HUD 为 `Assets/LiteGame/Modules/Battle/Content/Hud/Hud_Battle.prefab`（`UIHud` 收集组单件打包）。生产接线集中在 `ProgressBar`/`HpBar`/`Countdown`/`Toast`/`UIBubble`/`FlyTextPool`/`VirtualList`/`UIDialog`/`LoadingMask`；`AvatarFrame`/`GuideHighlight`/`StarRating`/`Stepper`/`BottomNav`/`TabGroup`/`SafeAreaReceiver`/`SimpleListView` 等只有模板与测试，不能宣称接入业务。
- **红点模板**：`Tmp_RedDot` 保留 `_Dot` 的布局、颜色与图片，根组件使用通用 `UIWidget`；模板只提供可复用视觉，不包含规则登记、树传播或节点订阅。

**边界**：预览场景/预览驱动/脚手架模板/深检面/调试面板不得进收集组或构建，`UITools` 与工作台只在编辑器程序集；契约、清单、`UIPageCatalog.g.cs`、`PageIds.g.cs`、`UIApiManifest.g.cs` 由工具生成，禁手改；"能点/能操作"的结论必须走真实操作路径（可点性自检 → 模拟指针/按键 → 副作用断言），不以直调 API 冒充。

## 9. 排障与核对

Console 标签：`[UI]`＝UI 服务/导航；`[Patch]`/`[Content]`＝内容侧（见 [09](09-内容热更与资源管线.md)）；工作台日志前缀 `[ui/workbench]`。

| 现象 | 原因/处置 |
|---|---|
| 工作台显示"未绑定目标" / 页面下拉为空 | 从页面选择器选页或在 Prefab Stage 选中 prefab；刷新；检查 `#uiform.xlsx` 可读与 `python -c "import openpyxl"` |
| 登记被拒（契约缺失 / guid 不符） | 先跑 `ui.contract` 生成或刷新（`formId=0`、prefabGuid 与当前 prefab 一致） |
| "表已写入但清单失败" / "契约未刷新" | 前者重跑 `ui.page-manifest` 且不要重复登记；后者重跑 `ui.contract`（`ContractDriftRule` 会一直报红） |
| 逻辑件存在但页面无反应 | 跑 `ui.validate` 看 `ui.page-logic`：prefab 根是否挂实现 `IUIFormLogic` 的组件；逻辑件是否重名 |
| 绑定未命中 / 点了没反应 | 先核对 `BindName` 与节点类型（`KeyNotFoundException` 即索引无该名）；再看可点性（遮挡、`interactable`、`blocksRaycasts`）与回调是否被 `OnHide` 解绑 |
| 页面复用后状态残留 / 真机安全区不对 | 前者查 `OnShow` 是否重推数据、异步是否有代次判据；后者用设备档预览 + 真机包，检查 `SafeAreaReceiver` 是否在内容容器 |

Unity 侧操作（打开 prefab、改场景、跑测试）一律走 unity-pipeline CLI，见 [15-工具链手册](15-工具链手册.md)。
