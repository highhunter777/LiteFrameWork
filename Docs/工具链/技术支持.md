# 工具链清单（技术支持）

> **定位**：技术支持/排障查询——全项目**有哪些工具、怎么跑、产出什么、忘跑什么症状**。说明·导览层，不裁决设计（工具形态权威：[生成器工具箱专项设计](../设计文档/架构/生成器工具箱专项设计.md)、[烘焙工具箱专项设计](../设计文档/游戏玩法/烘焙工具箱专项设计.md)；红线必跑表权威：[修改指南 §2.3](../修改指南.md)）。

> **统一入口**：`python scripts/toolchain.py`（`list / check / docs / open / run / generate / verify / build / doctor`）；**全量工具表**见[工具索引](工具索引.md)（由清单生成，勿手改）。编辑器内入口为 `LiteGame/工具链`。

## 2. 生成器工具箱（`scripts/codegen/`——全 Python，2026-10-11 迁移）

**统一入口**：`python scripts/codegen/toolbox.py`（无参列索引）；单脚本直调等价；共享单源 `_codegen.py`（根推导/输出三档/失败契约：一行 `[codegen/<tool>] FAILED` + exit 1）。

| 工具 | 命令 | 产物 | 重跑时机 | 忘跑症状 |
|---|---|---|---|---|
| build-hash | `toolbox.py build-hash` | `Assets/LiteNet/Protocol/BuildHash.g.cs` | 改 `LiteSim/Core/{Scripts,Systems}`、`LiteNet/{Proto,Protocol,Transport/Security}`、玩法表后（★红线） | 两端 hash 不等 → **Join 被拒进房** |
| build-hash --check | `toolbox.py build-hash --check` | 复算比对（exit 0/1） | 出包前（`build-player.py` 门禁步强制；开发期不校验） | stale 包出厂 |
| proto | `toolbox.py proto --protoc <protoc.exe>` | `Proto/Generated/Battle.cs`（入库勿手改） | 改 `.proto` 后 | 编译失败（无静默面） |
| luban | `toolbox.py luban`（= `Luban/gen.bat`） | GameData/Generated+Config、Lua/Cfg、LuaKeys.g.cs | 改表源/表结构后 | 表与代码漂移（L1 表守卫红） |
| sync-code | `toolbox.py sync-code` | `EntitySlot.Sync.g.cs`（入库勿手改） | `[StateLayer]` 字段/分型表结构变化后 | **静默分叉**（漏字段不报编译错） |
| refresh-hash | `toolbox.py refresh-hash [--skip-server-build] [--skip-unity-recompile]` | 新常量 + 双端对账 | 改 Sim/协议/表后的"一键全链" | 漏重建/漏重编译 → Join 超时 |

工具箱外登记（不收编）：xLua 适配生成（`Tools/XLuaGenerate.exe` vendored）、Sim 三角表（`SimTrigTableGenerator`，Unity 菜单——与运行时常量单源约束）、片源清单（`AgentScripts/BuildClipManifestAssets`）——理由见生成器工具箱专项设计 §5。

## 3. 烘焙工具箱（`Assets/LiteGame/Editor/Baking/`——Hub 入口 `LiteGame/工具链` → 烘焙工具箱）

**前提**：本地 `Player(Rifle).prefab` 在位（**不入版本管理**，缺包从派发渠道还原）。产物 emit 统一 `BakeTargets.WriteGenerated`（固定头/LF/write-if-changed——值不变的重烘零文件触碰）。

## 7. 排障速查（症状 → 工具）

| 症状 | 先查 | 处理 |
|---|---|---|
| Join 被拒/握手失败 | `toolbox.py build-hash --check` | stale → `build-hash` 重生成 + `refresh-hash` 全链（漏 RoomServer 重建/Unity 重编译同样拒进房） |
| 改了表但行为没变 | luban 产物时间戳 | `toolbox.py luban` + Unity 导入（`refresh-hash` 编排可代跑） |
| checksum 红/和解假和解 | sync-code 产物 vs `[StateLayer]` 标注 | `toolbox.py sync-code` + `build-hash` |
| 爆头/枪位/身位手感漂 | prefab 是否被美术动过 | 烘焙工具箱对应页重烘（write-if-changed，值不变零触碰） |
| L2 全绿但行为不对 | 新鲜度守卫（[05-验证与门禁 §3](../项目说明/05-验证与门禁.md)） | 外部改码后强制 Refresh+编译收敛再跑（旧程序集假绿） |
| 出包被 --check 拦 | buildHash stale | `toolbox.py build-hash` 后再出包 |
| 克隆后缺 prefab/资产 | `.gitignore` 白名单裁决 | 派发渠道还原（烘焙工具箱前提） |
