# 规范 01 · 文档体系与写作

> **定位**：回答"这条内容该写进哪一层、文件叫什么、索引怎么登记、怎么自检"。违规由 `doc-lint` 拦。
> **权威边界**：本规范只裁文档形态与纪律；领域契约归 [设计文档](../设计文档/README.md)，批次证据归 [施工进度](../施工进度/README.md)。
> **来源**：合并自旧 `项目说明/06`（§2 文档权威层级）、`设计文档/README` §3/§5、`doc-authoring` skill（旧路径已删，映射见 [规范索引](README.md)）。
> **关联**：[02 代码与修改规范](02-代码与修改规范.md) · [07 审计与债登记](07-审计与债登记.md) · [说明索引](../说明/README.md)

## 1. 权威层级（谁压谁）

1. **当前实现事实**：代码、版本化配置、可复现测试。
2. **设计文档**：目标架构、契约与验收；总设计裁跨域边界，领域总设计裁本领域契约。
3. **规范**（本目录）：必须遵守的硬规则与流程；违规应被工具或门禁发现。
4. **说明**（[说明/](../说明/README.md)）：解释层，只答"是什么/怎么跑/在哪"；与设计冲突以设计为准，与代码冲突以代码为准。
5. **施工进度**：批次证据（实际怎样）；**待办总览**：关口与剩余面。
6. **归档记录**：仅追溯，不参与当前裁决。

> 冲突处理顺序：代码事实 → 设计文档 → 规范 → 说明 → 归档。文档与代码不一致时**以代码为准并顺手修文档**。

## 2. 落点决策（写之前 30 秒）

| 你要写的是 | 去哪 | 判据 |
|---|---|---|
| 目标架构 / 契约 / 验收标准 | `设计文档/<域>/` | 裁决"应该怎样"，不记完成状态 |
| 必须遵守、且应能被门禁发现的规则 | `规范/` | 违规可被 `doc-lint`/纪律扫描/评审拒收 |
| 解释"是什么、怎么跑、在哪、怎么排障" | `说明/` | 读者目的是理解或操作，不是遵守 |
| 这批做了什么、证据是什么 | `施工进度/<线>线.md` 追加一章 | 记"实际怎样"，可验证 |
| 存量质量债登记 | `审计/`（按类型一文件） | file:line + 状态 |
| 被取代 / 已吸收的旧稿 | `归档记录/<date>/` + README | 不再参与裁决 |

**两者同时需要 → 写两份并互相链接，绝不混写。**

## 3. 命名与元数据

- 章节文件：`NN-<主题>.md`（两位数、连续无跳号，**D9 把守**）；目录内 `README.md` 是索引；生成物用固定名（如 `工具索引.md`）不占编号。
- 设计文档类型后缀限定：`总设计 / 专项设计 / 层级设计 / 分层设计 / 策略选型 / 备选方案 / 规范 / 参考 / 演进路线图`；**禁止裸「设计」**，禁止「最终版/新版/具体方案」等不可治理后缀（**D5 把守**）。
- 每份文档必须带元数据头：定位、权威边界、来源/关联；设计文档另需版本、日期、冲突裁决。
- 文件名与正文用中文；代码标识符按 [04 术语与用词](04-术语与用词.md) 的大小写规约。

## 4. 两条硬纪律

**纪律一：设计与进度分离**
- 设计文档/规范/说明禁止写「已实施 / 已交付 / 批A 完成 / 某日期交付」这类流水；只写现行形态。
- 状态由 `施工进度` 承担；表内嵌状态由 **D1/D6** 提醒。
- 后批修正前批：在**后批章内**写「修正前批某结论」，不回改前章——前章是当时事实。

**纪律二：索引零孤儿**
- 新增文件必须同批补进该目录 `README.md` 索引；`设计文档/`、`施工进度/` 的孤儿由 **D3** 拦。
- 改名/移动/合并：同一批内改完全部引用；链接与 `#锚` 由 **D4** 拦。
- 跨文档只引用唯一权威，不复制第二份（复制即未来分叉）。

## 5. 链接、锚与归档

- 相对链接按目录深度写；**锚**支持 `<a id="x"></a>` 与标题 slug 两种；改标题等于让所有指向旧 slug 的链接失效，改标题当批搜全仓。
- **不保留重定向壳**：旧路径退役时，把映射写进目录 README 的「旧路径映射」表，全仓入链同批改指新章（2026-10-29 起执行）。
- 归档：移入 `Docs/归档记录/<date>/`，该目录 README 写明「文件 → 退役原因 → 现行权威」；`Docs/README` 归档节登记一行。

## 6. 自检（改完必跑）

```powershell
python scripts/gate/test.py --suite Doc      # doc-lint + 工具索引新鲜度
python scripts/gate/doc-lint.py              # 或直跑
```

| 规则 | 拦什么 |
|---|---|
| D1/D6 | 设计文档内嵌施工状态（提醒，人工复核） |
| D2 | 审计表裸「，待提交）」 |
| D3 | 设计文档/施工进度未入索引（孤儿） |
| D4 | 相对链接或 `#锚` 失效 |
| D5 | 不可治理文件名后缀 / 设计文档裸「设计」 |
| D7 | `Docs/` 根目录白名单外文件 |
| D9 | `说明/`、`规范/` 章节编号跳号或丢前缀 |
