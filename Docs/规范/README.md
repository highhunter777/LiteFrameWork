# 规范（规范层）

> **定位**：必须遵守且应能被工具/门禁发现的硬规则与流程。违规由门禁拦或由评审拒收，不靠自觉。
> **权威边界**：目标架构与契约归 [设计文档](../设计文档/README.md)；批次证据归 [施工进度](../施工进度/README.md)；本目录只裁"怎么做才算合规"。
> **编号规则**：一章一文件，两位数连续递增（01–08），不留跳号。
