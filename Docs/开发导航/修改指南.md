# 修改指南：我想改 X，去哪改、改完跑什么

> 查表方式：先找"我想改…"，**改动文件**给出精确路径；**改完必跑**给验证命令（标注★的表示"不跑必出事"的红线联动）。
> 通用验证基线（白天代码批）：Unity recompile 0 错误 + `scripts/test.ps1 -Lane L1 -Profile PullRequest`；L2（EditMode/PlayMode）留夜间流水线。Unity 交互一律走 unity-pipeline CLI（`UNITY-GUIDE.md`）。
