## 3. 程序集对照（asmdef = csproj 双轨）

FFA 对局规则入口：`LiteSim/Scripts/Rules/MatchRules.cs` 与 `LiteSim/Systems/{ScoreSystem,RespawnSystem,MatchSystem}.cs`；`RoomRuntime` 装配/裁决，`RoomOutput.MatchResultSummary` 冻结结果，`ServerHost` 发送 `MatchEnded`，`SettlementOutbox` 保存逐玩家成绩。规则参数来自 `Config/roomserver.json` 房间模板，快照字段同时覆盖 checksum/差分/协议重建。验收证据见[对局规则闭环](../施工进度/玩法规则与开房线.md#ch1-对局规则闭环)。

> 全量引用图（双端宿主 + 测试 + 编辑器 + 外部依赖标注）→ [程序集引用图](程序集引用图.md)；本节为自研主线速览。

**自研主线**（asmdef 引用即依赖方向，无环）：

```
LiteFramework.Runtime（单程序集，物理根 Assets/LiteFramework/Runtime/）
  ├─ Core/（纯机制：DI/Scope/Event/Command/Fsm/Pool/Clock/IO/Logging/Threading/Operations/Errors/Util/Module/Diagnostics——零引擎零第三方；dotnet 双轨 = LiteFramework.Core.csproj）
  ├─ Modules/<服务>/（Hosting+Recovery、Identity、Content+Abstractions、Config+Abstractions、Animation、Localization、Settings、Scene+Abstractions、Camera、UI、Input、Audio、Entity、Battle、Diagnostics——接口由模块自持 Abstractions/）
  ├─ Adapters/<第三方>/（Unity、InputSystem、Cinemachine、Newtonsoft、YooAsset、XLua、Luban——实现对应模块 Abstractions；装配在组合根）
  ├─ → LiteBattle.Abstractions（对局/开发端口——只引 LiteSim.Core）
  ├─ → LiteSim.Core（BuildHash 源集）/ LiteNet / LiteCodeGen.Runtime
  └─ LiteFramework.Editor（Assets/LiteFramework/Editor：UI 绑定生成器——仅编辑器）
LiteSim.Core（零依赖；Core/Scripts 六段 Kernel/World/Config/Map/Pipeline/Rules + Systems 九系统）
  └─► RoomServer.Runtime（服务端内核，只引 LiteSim.Core，noEngineReferences）
         └─► RoomServer.Application.Runtime（+LiteNet +Google.Protobuf vendor）
LiteNet → LiteSim.Core
LiteView → LiteFramework.Runtime + LiteBattle.Abstractions + LiteSim.Core（不得引 LiteGame.*）
LiteCodeGen.Runtime（BindRoot/BindNode）
LiteGame.* 产品侧（物理根 Assets/LiteGame/）：
    App（流程/装配/Meta/Room）→ Presentation（对局表现域 LiteGame.Presentation）
    + LuaBridge（Lua 桥）＋ ShareResource（UI/FX/字体资产）＋ Lua（页面脚本）
    + Dev（开发装配层：DevHUD/控制台/调试面板/本地服——唯一可引服务端程序集，defineConstraints 三宏）
    + Editor（LiteGame.Editor / LiteGame.Editor.Core / LiteGame.Editor.UiTools 三件，仅编辑器）
```

**双轨规则**：`Assets/{LiteFramework,LiteSim,LiteNet,LiteTesting,RoomServer}` 下 csproj 与 asmdef 编译**同一份源码**（dotnet 侧供 `Tests.slnx`/宿主/CI，Unity 侧供编辑器与 Player）；csproj 是手写文件在 gitignore 白名单里；产物重定向 `.dotnet/`，**绝不许在 Assets 下落 bin/obj**（Unity 会当插件导入，CS1704）。

**离线开发形态**（F3 开发控制台 `request enter` 本地测试模式）：`ProcedureMatch.CreateTransport` 只经 `ILocalTransportFactory` 端口取实现——`LiteGame.Dev` 的 `DevLocalTransportFactory`（`RuntimeInitializeOnLoadMethod` 装订进 `LocalTransportRegistry`）产 `LocalServerTransport`，进程内跑真 `RoomRuntime`（自动补位满员开局）；每局规则由 `MatchRulesSeeder.Seed` 先播种、作为入参传入。其余路径（本地全链/云端）恒真 KCP。
