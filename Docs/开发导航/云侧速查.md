# 云侧速查卡（命令级，一页）

> 只放"照着敲"的命令；机制与判据见 [11-联机测试流程](../项目说明/11-联机测试流程.md)、[10-Windows 云主机部署](../项目说明/10-Windows云主机部署.md)。
> **值都在机器私有文件里**：主机/账号/密钥 → `LocalNotes/cloud-host.md`（gitignore）；测试者 `.conf` → `Dist/out/`。

---

## 0. 入口

| 用途 | 命令 |
|---|---|
| SSH 别名（**隧道优先**） | `litegame-cloud-tunnel`（`HostName 10.8.0.1`）——公网 22 关闭，本机出口 IP 变了也不用改安全组；配置见 10 手册 §4.1 |
| SSH 别名（公网，备用） | `litegame-cloud`（需安全组临时放行 22） |
| 连通自检 | `ssh litegame-cloud-tunnel "hostname"`（或 `Test-NetConnection 10.8.0.1 -Port 22`） |
| 云上常驻对象 | 任务计划 `LiteGame-Meta` / `LiteGame-Room`；路径 `C:\litegame\{meta,room,mongo,wg}` |

> 发布/运维脚本（`deploy-room.ps1` / `gm.ps1` / `wg-peer.ps1`）**自动选路**：`10.8.0.1:22` 可达即走隧道，否则回退公网并打印原因；可用 `-SshHost` 或环境变量 `LITEGAME_SSH_HOST` 强制指定（见 `scripts/deploy/_ssh-host.ps1`）。

## 1. 服务端发布 / 重启

```powershell
# 全量：publish → 打包（room + 玩法表）→ 停服 → 上传 → 解压 → 起服 → 回读 buildHash/表摘要
pwsh -NoProfile -File scripts/deploy/deploy-room.ps1

# 只上传现有产物（重试/网络抖动后）
pwsh -NoProfile -File scripts/deploy/deploy-room.ps1 -SkipPublish

# 连 deploy/roomserver.windows.json 一起传（模板/端口/心跳改动）
pwsh -NoProfile -File scripts/deploy/deploy-room.ps1 -SkipPublish -WithConfig

# 只换二进制、不同步玩法表（一般别用：会触发 StartGame「玩法数据身份不符」拒局）
pwsh -NoProfile -File scripts/deploy/deploy-room.ps1 -SkipPublish -SkipTables
```

> 判据：`task=Running` + `buildHash=…`（与客户端包内常量同值）+ `[Tables] 玩法数据身份基摘要:0x…`（与客户端日志「本地基摘要」同值）。
> 顺序红线：**先停服再解压**（脚本已保证）；改 C# 必须重新 publish，只重启任务无效。
> **改表必同步**：`Map/tbmap.bytes` 等判定面表变了却不传，客户端整局被拒（`StartGame.ConfigHash` 不符）——脚本默认已带上，除非显式 `-SkipTables`。

## 2. 房间模板（不是地图）

```jsonc
// deploy/roomserver.windows.json → rooms
"standard": { "match_duration_frames": 10800, "kill_limit": 20, ... }   // 20 杀 / 180 s，会结算
"sandbox":  { "match_duration_frames": 0,     "kill_limit": 0,  ... }   // 不限时 / 无击杀上限，不结算
"default_template": "sandbox"   // 切回 "standard" 才能验结算
```

| 字段 | 0 的含义 | 校验 |
|---|---|---|
| `match_duration_frames` | 不限时 | ≥ 0 |
| `kill_limit` | 不按击杀结束 | ≥ 0 |
| `respawn_delay_frames` | — | **必须 ≥ 1** |
| `spawn_protection_frames` | 无出生保护 | ≥ 0（开火即清零，不能当免死） |

## 3. GM 动作（运维端点）

```powershell
pwsh -NoProfile -File scripts/deploy/gm.ps1 -Action rooms                  # 谁在房 / phase / 席位
pwsh -NoProfile -File scripts/deploy/gm.ps1 -Action start  -Room <房号>     # 强制开局（需有 owner）
pwsh -NoProfile -File scripts/deploy/gm.ps1 -Action abort  -Room <房号>     # 运维终止（走结算路径）
pwsh -NoProfile -File scripts/deploy/gm.ps1 -Action kick   -Room <房号> -Player 1
pwsh -NoProfile -File scripts/deploy/gm.ps1 -Action settle-flush            # 立刻回灌 Outbox
# 测试房 GM（只对带模板建、不进大厅的房生效）：1 = 免死 / 2 = 无限弹药 / 0 = 关闭
pwsh -NoProfile -File scripts/deploy/gm.ps1 -Action rules -Room <房号> -Flags 3
pwsh -NoProfile -File scripts/deploy/gm.ps1 -Action rules -Room <房号> -NoDeath -InfiniteAmmo
```

- 端点只在隧道内：`http://10.8.0.1:9101/gm/*`，仅 POST + 头 `X-GM-Key`；密钥 = 本机用户环境变量 `LITEGAME_GM_KEY`（缺失回退 `LocalNotes/cloud-host.md`）。
- **编辑器内开关**：`deploy.args` 或命令行加 `-room.template=sandbox`、`-room.gmkey=<口令>`、`-gm.key=<GM 密钥>`（`-gm.url` 缺省由 `meta.url` 推导 `:9101`）→ **GM 面板 → 测试模式 → 联机测试房（云端 GM）** 点「免死 / 无限弹药」；房号留空 = 服务端取唯一在册测试房。
- 脚本自动起/关 SSH 隧道；**本机端口用 19101，别用 9101**（Windows 排除区间 9014-9113）。
- 手拼 curl 必须带 body（无 `Content-Length` → `411`）。

## 4. 测试者接入

```powershell
# ① 开隧道（云上生成密钥 + 追加 peer + 重装服务 → Dist/out/<名字>.conf）
pwsh -NoProfile -File scripts/deploy/wg-peer.ps1 -Name alice
pwsh -NoProfile -File scripts/deploy/wg-peer.ps1 -Name alice -DryRun     # 只生成，不改云上
pwsh -NoProfile -File scripts/deploy/wg-peer.ps1 -Name bob -Ip 10.8.0.9  # 指定隧道内地址

# ② 组包：推荐一份无 conf 基包只发一次；每人只发自己的 conf（不能共用）
pwsh -NoProfile -File Dist/New-Package.ps1 -Tester LiteGame-base -Base -Zip

# ②b 批量出包：叠加包（kit+conf，配基包）或全量包；省略 -Testers 则扫 Dist/out/*.conf
pwsh -NoProfile -File Dist/New-Packages.ps1 -Testers alice,bob -Overlay -Zip -Force
pwsh -NoProfile -File Dist/New-Packages.ps1 -Testers alice,bob -Zip -Force

# ③ 发 Dist/out/LiteGame-base.zip 一次 + 每人 Dist/out/<名字>.conf
# 玩家：解压基包 → 放自己那份 conf（同目录唯一）→ 解除锁定 → 双击「加入联机环境.cmd」→ 双击游戏
```

- 一人一份 `.conf`（内含私钥）；换机/换公网 IP 全部作废，只需重生成 `Endpoint` + 服务端 `PublicKey` 两处，**游戏包不用换**。
- 换网络不用重加白（隧道；公网只开 `51820/udp`）。
- 服务端目前只有 add（移除 peer 需改 `C:\litegame\wg\wg0.conf` 后重装隧道服务）。

## 5. 观测 / 排障

```powershell
# 房间服日志（[GM] 审计 / 结算 / Lobby 注册）
ssh litegame-cloud-tunnel powershell -NoProfile -Command "Get-Content C:\litegame\room\out.log -Tail 30"

# 指标（本机隧道转发；端口避开 9100/9101）
ssh -N -L 19100:10.8.0.1:9100 litegame-cloud-tunnel
# 另开终端： curl.exe -s http://127.0.0.1:19100/metrics
```

| 症状 | 先查 |
|---|---|
| 签票 `409 version-mismatch` | 两端 `buildHash`；改共享源是否跑了 `gen-build-hash.py` |
| 开局即拒 | 表摘要；`Luban/gen.bat` 后是否重建产物 + 重打包 |
| 登录 `Insecure connection not allowed` | 包是否用当前 profile 出的（构建期烙定） |
| 同机两客户端同账号 | 各给不同 `-device.id` |
| 大厅看不到对方房 | 列表 1 s 自轮询 + 房间心跳 1 s；仍建议先建房再登录 |
| 端点/模板没变 | 是否只重启了任务、没上传配置；改 C# 是否没重新 publish |
| `ssh` 超时但 `ping` 通 | 出口 IP 变了（安全组 `/32`）或 `sshd` 停 → 控制台 |

## 6. 红线（贴屏保用）

1. 私钥 / `deploy/.env` / 测试者 `.conf` / `LITENET_GM_KEY` **不入库、不回显、不截图**。
2. 封闭测试环境不得公开宣传，**不得作为"可发布"判据**。
3. 云上应用一律任务计划托管；**禁 SSH 会话里 `Start-Process` 起常驻进程**（随会话回收）。
4. 云上脚本保持**纯 ASCII**（PS 5.1 经 SSH 按 GBK 误解 UTF-8 中文 → 静默失败/解析报错）。
