# 框架流程说明手册（精简版）

> 面向日常开发者，说明“运行时怎么走”；架构决策见《自研框架设计方案》，施工记录见归档目录。

## 1. 启动流程

```text
GameEntry
  → 创建根容器/日志/时钟/资源壳
  → ProcedureLaunch 注册服务并 Seal
  → ProcedurePreload 加载配置、Lua、表注册项
  → ProcedureMain 启动主界面和内容入口
  → Match/Battle 创建 BattleContext
```

原则：组件 Awake 只注册，不解析；Preload 完成前不允许查表、不允许执行玩法；失败进入可见错误流程。

## 2. 配置和资源

1. `ConfigService` 从 `AssetService` 获取 Luban binary，构建 `Tables`。
2. `ConfigService` 回填 `CombatConfig`，并校验关键表和 buildHash。
3. Lua 文件在启动阶段预载，loader 只读启动缓存，不在运行期偷偷 IO。
4. 场景、Prefab、UI、VFX 通过 YooAsset/AssetService 统一加载。

## 3. 典型流程

### 3.1 UI

`UIService.Open → UIForm 生命周期 → Lua OnInit/OnShow → Bridge/UI API → OnHide → SubscriptionBag 注销 → 回池`。

UI 逻辑只更新 ViewModel；高频数据由 C# 批量推送或脏位刷新。

### 3.2 战斗

`Lobby/Match → Join(buildHash) → StartGame → 创建 BattleContext → PlayerController 采集意图 → FrameDriver 60Hz → Sim/快照 → SimView/HUD`。

离开战斗时流程销毁 BattleContext，解绑网络、停止 FrameDriver、回收实体/VFX；不把战斗状态留在全局容器。

### 3.3 社交和库存

`Bridge.inventory/chat/guild → HTTPS 命令 → 服务端校验/事务 → WebSocket 推送 ViewModel`。

UI 不直接修改库存、聊天记录、公会成员或权限。

## 4. 时间和异步

- Sim 判定只用固定逻辑帧；表现使用 `WorldClock/UIClock`。
- 业务异步统一返回 UniTask，必须可取消；网络连接和资源加载都由流程持有取消令牌。
- 不在 Lua 或 MonoBehaviour 中启动无法回收的协程/定时器。

## 5. 错误和重载

- 配置缺失、表校验失败、协议/buildHash 不一致：fail-fast，禁止静默回退。
- Lua 内容异常：捕获并记录上下文，保留主流程可恢复；UI 关闭时注销回调。
- 编辑器重载：停止 Lua/表现层 → 清 Bridge 缓存 → 重填注册表 → 重建 LuaEnv；不触碰服务器权威态。

## 6. 日常红线

- 不裸用 `Debug.Log`、`Resources.Load`、`INetworkService`、`Transform` 作为玩法真相。
- 不在 Sim 中引用 Unity/Lua/框架；不在 View/UI 回写 Sim。
- 不把玩家库存、奖励、聊天、公会状态塞入战斗快照。
