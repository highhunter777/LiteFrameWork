13. [框架先行建设与业务接入专项设计](设计文档/architecture/框架先行建设与业务接入专项设计.md)：先建范围、五个施工包与验证样例、正式业务准入，以及和 G0～G6 的衔接。
14. [Meta 服务专项设计](设计文档/architecture/Meta服务专项设计.md)：Auth/Lobby/Profile 模块化单体、宿主选型、票据与签名、存储与结算 Outbox 幂等、测试矩阵；框架期只建接缝，主体归 G3。
15. [性能工程专项设计](设计文档/quality/性能工程专项设计.md)：Sim/网络/宿主侧性能预算（最坏帧 23 逻辑帧当量推导）、BenchmarkDotNet/埋点/DevHUD 三层度量、热点清单与 P0～P3 门禁路线；草案，预算数值待基线回填。
