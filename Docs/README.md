# Docs 阅读入口

## 当前主线

1. 先看《待办总览》：当前基线、优先级和验收闸门。
2. 做玩法系统看《六大系统具体方案》。
3. 做战斗联机看《状态同步实施方案》；做非战斗服务看《服务端架构设计》。
4. 做框架看《自研框架设计方案》《框架流程说明手册》《框架实施手册》。
5. 做 Demo、角色、动作和数值分别看《联机Demo设计》《角色状态与动作实现设计》《动作与特效设计》《玩法数值解耦审查与Luban表设计》。
6. 测试门禁看《测试开发方案》《CI门禁（L1-L2）》。

## 归档

详细施工记录、阶段审查和后置设计位于 `Docs/Archive/2026-09-20/`。归档文档只用于追溯，不作为当前实现依据；冲突时以代码、测试和根目录主线文档为准。
