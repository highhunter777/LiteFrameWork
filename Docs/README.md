## 目录结构

```
Docs/
├─ README.md            本页：目录总入口
├─ 待办总览.md           进度与优先级权威（G0～G6 关口）
├─ 修改指南.md           动代码前必读：§1 红线 / §2 修改规范 / §3 领域查询表
├─ 设计文档/             目标架构与专项设计（权威：应该怎样）
├─ 施工进度/             一条线一卷的实施证据（权威：实际怎样）
├─ 项目说明/             说明导览层（是什么、怎么跑、怎么流）
├─ 技术总结/             通读卷：按章解释架构与机制（11 章 + 索引）
├─ 开发导航/             代码地图与"改 X 去哪改"
├─ 工具链/               工具形态与 CLI 操作（技术支持 / Unity 操作规范 / Pipeline 补丁）
├─ 环境/                 环境复原与机器差异事实（环境恢复 / 非作者机记录）
├─ 审计/                 两份质量登记表（存量债，改文件前必查）
└─ 归档记录/<date>/      被取代的历史稿（仅追溯）
```

> **根目录只放三份**：入口（README）、进度权威（待办总览）、动手指南（修改指南）。其余按职能入子目录——这是 2026-10-18 的分层裁决。
