# LiteFramework 项目技术总结

> **版本**：1.0（2026-10-22）
> **定位**：面向"要完整读懂这个项目"的读者，按主题分章解释**它是什么、为什么这样造、关键机制怎么运转、边界在哪里**。本卷是解释层，不是裁决层。
> **不做的事**：不定义目标架构（归 [设计文档](../设计文档/README.md)）、不登记批次证据（归 [施工进度](../施工进度/README.md)）、不维护关口清单（归 [待办总览](../待办总览.md)）、不替代代码地图（归 [开发导航](../开发导航/README.md)）。
> **冲突裁决**：事实以**工作区代码**为准（本卷写作时点 2026-10-22，`main` 分支含在途批次）；目标架构以设计文档的总设计为准；本卷与代码不一致时改本卷。

一句话概括：这是一个**用确定性 Sim + 服务器权威状态同步做联机射击**，并把"框架能力"（生命周期、作用域、内容事务、UI、热更、门禁）压在**同一条真实业务链**上验证的工程。

## 技术要点（先看这五条）

1. **一份判定源码，三处编译**：`LiteSim.Core` 被客户端、服务端宿主、dotnet 测试共同编译（`RoomServer.Runtime` 另由服务端宿主与测试共编，客户端仅开发档 `DevLocalServer` 引用）；BuildHash 握手保证两端判定代码一致。
2. **确定性是设计出来的**：60Hz 定长帧、硬编码系统顺序、自研 software sqrt、整数随机、版本化槽位、全量/公共双 checksum——每一环都有守卫测试。
3. **权威 + 预测 + 回滚**：服务端权威步进与回溯补偿；客户端预测只保留"瞄准"等连续位，命中/死亡只认权威；快照用全量/增量双锚点和解。
4. **框架能力有真实消费者**：内容租约与代次、热更激活事务、UI 导航单写者、Scope 级联释放、多房宿主与排空，都不是"接口存在"，而是跑在对局链上。
5. **规范门禁化**：13 条纪律扫描、5 层验证、4 类生成器、文档 lint——把"注释里的约定"变成可执行的红绿。

## 口径与时效

1. **基线**：2026-10-22 工作区。`git status` 显示 162 项改动、79 个未跟踪文件，含三条在途批次：`debug-kernel-projections`（调试内核与三投影）、`tps-shoulder-camera`（越肩相机/瞄准）、UI 工具链重构（`Editor/UiTools` 新结构）。凡涉及这些区域的章节，按**工作区代码**描述，并在文中标注"在途"。
2. **数字**：用例数、门禁数、文档数随批次变化，本卷**不固化易变计数**，只给结构量与常量（帧率、容量、超时、版本号），并注明口径。代码规模统计口径＝手写 `.cs`，排除 `Vendor/`、`Generated/`、`*.g.cs`、`obj/`、`bin/`、Unity/dotnet 测试工程。
3. **文档滞后**：仓库文档量大且更新频繁，个别条目可能落后于代码。本卷对"文档说已交付、代码却无生产调用点"的情况按代码判，并在第十一章集中列出易误判项。
4. **状态词**：本卷使用的"已交付/已接线/未接线/目标"是**工程事实描述**，不是验收裁决；验收以施工进度卷的证据与门禁结果为准。

## 术语速查

| 术语 | 在本项目中的含义 |
|---|---|
| **Sim** | `Assets/LiteSim/Core` 的确定性战斗模拟：定长逻辑帧 + 纯 C# 系统步进，客户端与服务端共编同一份源码 |
| **逻辑帧 / 渲染帧** | 逻辑帧固定步长推进判定；渲染帧按显示器刷新驱动表现，二者由 `FrameDriver` 解耦 |
| **快照（Snapshot）** | 服务端按 30Hz 下发的权威状态切片，可全量或差分；客户端据此和解与插值 |
| **AOI** | 兴趣域过滤：按玩家位置裁剪快照实体集合，降低带宽 |
| **回溯补偿** | 服务端按客户端"看到的过去帧"重跑射击判定，避免高延迟下"打中却不判中" |
| **Scope / 租约** | 五层作用域树（Root/Account/Match/Scene/UI）；资源以租约归还，作用域关闭即级联释放 |
| **双轨** | 同一份源码既被 Unity asmdef 编译，也被 dotnet csproj 编译（供测试/服务端/CI） |
| **BuildHash** | 共享源集的 SHA-256 摘要（16 位十六进制），Join 握手校验两端判定代码一致 |
| **候选 / 激活事务** | 热更的待发布内容包；下载校验后经原子事务切换，失败可回滚 |
| **单写者** | 某类状态只允许一个组件写入（导航、UI 开关、时钟暂停），避免多入口竞争 |
| **开发三宏** | `UNITY_EDITOR \|\| DEVELOPMENT_BUILD \|\| LITEFRAMEWORK_DEBUG`，调试代码的编译边界 |
