> 用途：本仓库保留**自研框架代码、vendored 第三方包、预制品与文档**。
> 自 **2026-09-21 C0-① 起**：依赖声明（manifest/lock）与在用的第三方包（YooAsset、Luban unity wrapper）已随库分发——干净环境**按本指南一条命令校验还原**，不再需要从个人目录复制任何依赖。
> 依据：《商业级通用客户端框架总设计》§14.1、§19 C0。

## 1. 还原步骤

```powershell
git clone <repo>
cd <repo>
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/restore-check.ps1
```

- **退出码 0**：环境就绪，直接用 Unity 2022.3.55f1c1 打开工程，等包解析完成后跑 `scripts/l2-unity-gate.ps1` 验证。
- **退出码 1**：按 `[MISS]` 清单逐项补齐（见下表）后重跑，不允许带缺件继续。

工具链版本以 `scripts/toolchain.json`（机器可读）为准；Unity / .NET / Python 版本不符也会被校验器拦下。
