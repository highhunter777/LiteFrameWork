# VFX 服务实施指导（M11 表现层）

> 依据：**《动作与特效设计》§2**（特效 = 服务（机制）+ 内容表：§2.1 定位判据 / §2.2 API 草案 / §2.3 三条边界 / §2.4 基础预算与降级 / §2.5 升级判据 / §2.6 验收）；《状态同步实施方案》§6.2（`silenceUntilFrame` 防重播住 View）；《联机Demo美术资源清单》§0-4/§0-6（**特效不携带判定** / **命名即引用** `fx_`）与 §4 特效清单（P1 六件）；《自研框架设计方案》§8.1 四模式判据。
> 定位：**表现层服务**（不是系统）——无玩法状态、不参与判定、不改 Sim；**服务不调用其他服务**（音效由编排方分别调）。
> 归属落位：**`Assets/LiteSim/View/Vfx/`（`LiteSim.View` 程序集）**——与相机服务同层（表现层专属：跟 Sim 实体挂点/跟随），**不进 `LiteFramework`**（框架只放契约）、**不进 LiteGame 壳**（声音壳是通用壳件，VFX 是表现层件）。
> 工期：**1 天**；预算 ~600 行（含测试 ~200）。

## 1. 前置决策（开工前定案）

| # | 决策 | 结论 | 理由 |
| --- | --- | --- | --- |
| 1 | **归属与接口落位** | `IVFXService` + `VfxHandle` + `VfxService` 放 **`LiteSim.View`**；**不进框架、不进 LiteGame 壳** | 有 Sim 实体挂点语义（表现层专属）；相机服务同层先例 |
| 2 | **句柄语义** | `VfxHandle` = `int`（**单调递增、永不复用**，0 = 无效）；`Stop(handle)` 对已回收句柄**幂等**（静默 no-op） | 照 `AudioService` 既有形态；避免 ABA（旧句柄误杀新特效） |
| 3 | **名 → 地址解析** | **命名即引用**：`Play("fx_hit_default", …)` → 解析为 **`Assets/FX/fx_hit_default.prefab`**（2026-09-19 改，原定 `Assets/LiteGame/Art/Effects/`）的 YooAsset 地址；**本里程碑不做 Luban 表** | 服务只需"名字 → 资源"；"哪个动作播哪个特效"属表现轨/动作表（C3 之后）内容侧——**不为能用先造表** |
| 4 | **加载与池化** | YooAsset 异步加载 + **prefab 句柄缓存**（同 prefab 只加载一次）+ **按 prefab 分桶的实例池**；常用特效可选预热 | 复用既有资源服务与池化纪律；池命中率进统计 |
| 5 | **跟随语义** | `follow=true` → `SetParent(attach, false)`（随宿主移动/销毁）；`follow=false` → 挂"世界特效容器"（点位特效，播完即收） | 两种语义覆盖 P1 六件（枪口/拖尾跟随；命中火花/AOE 圈世界） |
| 6 | **时长与自动回收** | **不依赖粒子回调**：播放时算 `max(各 ParticleSystem.main.duration + startLifetime)`（或 prefab 上配置/美术标注）→ 到点 `Stop` + 归还池 | 回调会因 `ParticleSystem` 被禁用/对象失活而漏触发；定时回收是唯一可靠路径 |
| 7 | **预算（同屏上限）** | `maxActive`（默认 **64**，低端 **32**）；超限按配置二选一：**最旧先回收**（默认）/ **拒绝播放 + 日志** | 设计 §2.4 原文；"最旧先回收"保新特效可见（战斗反馈优先） |
| 8 | **低端降级** | `GameSettings.Quality` → **类别白/黑名单（跳过非关键类别）+ `maxActive` 缩放**；**粒子数上限留后续** | 运行时改 `ParticleSystem.main.maxParticles` 成本高且行为不直观；"类别跳过"可控可验 |
| 9 | **挂点清理（"谁挂谁清"）** | `StopAll(attach)` 由**宿主回收点**调用：`SimView` 的实体视图归还池时 + UI/表现件销毁时 | 与 `SubscriptionBag` 同一纪律：**短命宿主清理自己名下的一切**；不靠 GC/不靠帧扫描 |
| 10 | **加载在途 × 宿主已回收（竞态）** | 句柄带 `pending` 标记：加载回调里若句柄**已取消**（`StopAll` 或 `Stop` 已发生）→ **不实例化，直接归还资源句柄** | 同 `EntityService` 的"加载在途收到 Hide → 竞态表"先例；否则"迟到的特效"会挂在已回收宿主上永久残留 |
| 11 | **静默期不在服务内** | `silenceUntilFrame` 属 **View 观察层**；服务**不知道**静默这回事 | 设计 §2.3-3；服务保持无状态可并行 |
| 12 | **红线：特效不携带判定** | 特效**只读**表现数据；**AOE 圈的视觉半径必须来自表**（与判定半径同源），**不得由美术/代码另给** | 《美术清单》§0-4；"表现与判定同一真相"是联机 demo 的信任基础 |
| 13 | **不做的** | 跨特效优先级/抢占/同槽位互斥（设计 §2.5 留位不建，出现真实需求再加 `VfxPolicy`）· UI 动效（`UiFx`）· 音效（声音壳）· 对象池跨场景常驻管理 | 设计既定边界 |

### 2.1 API（照设计 §2.2，仅补必要细节）

```csharp
public readonly struct VfxHandle { public readonly int Id; public bool IsValid => Id != 0; }

public interface IVFXService : IModuleStats
{
    VfxHandle Play(string name, Transform attach, bool follow, float scale = 1f);
    void Stop(VfxHandle handle);          // 幂等
    void StopAll(Transform attach);       // 宿主回收点调用（"谁挂谁清"）
}
```

### 2.2 内部结构（~6 件）

| 件 | 职责 |
| --- | --- |
| `VfxInstance` | 实例 + 所属 prefab 桶 + 句柄 + 挂点 + 到期时刻（`Time.realtimeSinceStartup` 或世界时钟——**决策：世界时钟**，时停即冻结） |
| `VfxPool` | `prefab → 空闲实例栈`；`Acquire/Release`；预热带 |
| `VfxHandleTable` | 句柄 → 实例 + `pending` 标记（决策 2/10） |
| `VfxBudget` | `maxActive` / 类别白名单 / 超限策略（决策 7/8） |
| `VfxTicker` | 每帧（`ITickable` 或由 `SimView` 驱动）扫描到期项 → 回收 |
| 统计 | 活跃数 / 池命中 / 池增长 / 拒绝数 / 加载中（`IModuleStats`，DevHUD 可见） |

### 2.3 接缝（谁调它）

| 调用方 | 场景 | 说明 |
| --- | --- | --- |
| `SimView` 观察层 | 命中 / 暴击 / 死亡（帧事件 + 状态差分） | **在静默门外**调用（`silenceUntilFrame` 由观察层判断） |
| `SimView` 开火即时反馈 | 本地开火（0 延迟） | 纯表现，不等 Sim |
| `SimView` 实体视图回收 | `StopAll(view.transform)` | 决策 9；实体死亡/出 AOI/场景切换 |
| UI / 表现件销毁 | `StopAll(owner.transform)` | 同上（若挂载） |

## 3. 测试与自测策略

| 用例 | 断言 |
| --- | --- |
| API 跑通 | `Play` → 活跃 +1、实例非空、挂点正确；`Stop` → 实例归还池、活跃 -1 |
| **句柄语义** | 已回收句柄 `Stop` 幂等不抛；句柄单调递增（旧句柄不会命中新实例） |
| **池化生效** | 同 prefab 重复 `Play/Stop` N 次 → **实例总数不增长**（池命中率 = N-1） |
| 超限策略 | `maxActive=2`：第 3 个按配置（默认回收最旧）→ 活跃恒 ≤2；拒绝模式 → 计数 + 日志 |
| 低端降级 | 档位切低 → 黑名单类别不播、`maxActive` 缩小（用例直接断言预算参数与跳过行为） |
| `StopAll(attach)` | 挂点下多个特效一次清空；其它挂点的实例不受影响 |
| **竞态（决策 10）** | 模拟"加载在途宿主已回收" → 加载完成后**无实例残留**、活跃数不变 |
| 自动回收 | 到时长上限 → 自动归还（不依赖粒子回调；用短时长测试 prefab） |
| Play 冒烟（人工） | P1 六件肉眼：枪口火光/弹道拖尾/命中火花/血雾/AOE 圈/护盾球（+ 冲刺残影） |
| 联机静默（M11 联调用例） | 回滚重放期观察层不调 `Play` → 无重播（**验的是观察层**，服务侧无静默概念——决策 11） |

## 4. 完成判定（对账设计 §2.6）

- [ ] 服务 API 跑通：播放 / 跟随 / 停止 / **宿主回收清理**（挂载特效随宿主回收清零）
- [ ] 基础预算生效：超上限行为符合配置；画质档切换改变预算（记录 Profiler 实测）
- [ ] 池化生效：同 prefab 重复播放无新增实例（活跃数 / 池命中率入 `IModuleStats`）
- [ ] 联机：特效由观察触发、回滚期间不重播（`silenceUntilFrame` 用例在 View 侧通过）

- [ ] L1 全绿 · L2（EditMode 用例）全绿 · 纪律 0 违规（R8/R10 等）

## 6. 决策记录

| # | 决策 | 备注 |
| --- | --- | --- |
| ① | **服务不进框架也不进 LiteGame 壳**，落 `LiteSim.View` | 表现层专属（挂点/跟随语义） |
| ② | 句柄**单调递增永不复用**、`Stop` 幂等 | 照 `AudioService`；防 ABA |
| ③ | **名 → 地址直连**（命名即引用），**不做表** | 表属动作/表现轨内容侧，本里程碑无需求 |
| ④ | 回收**靠定时**不靠粒子回调 | 回调会被禁用/失活漏掉 |
| ⑤ | 超限默认**最旧先回收** | 战斗反馈优先 |
| ⑥ | 低端降级 = **类别跳过 + 上限缩放**（粒子数上限留后续） | 可控可验 |
| ⑦ | **加载在途 × 宿主回收** = 句柄取消标记 → 迟到实例直接归还 | 同 `EntityService` 竞态表先例 |
| ⑧ | 静默期**不在服务内** | 服务无状态可并行 |

## 7. 边界与风险

- **不越界**：不做优先级/抢占/互斥（§2.5 留位）· 不碰 UI 动效与音效 · 不参与判定 · 不写 Sim
- **风险 1：视觉半径与判定半径不一致**（AOE 圈最典型）——玩家会按视觉判断走位，不一致即"被看不见的东西打死"。对策：半径**从表取**（决策 12）+ 联调时用调试线框叠加核对
- **风险 2：特效残留**——宿主回收路径漏调 `StopAll` → 视觉垃圾 + 预算被占满（新特效全被"最旧回收"掉，看起来像"特效不播"）。对策：`StopAll` 接进 `SimView` 视图归还路径（**唯一入口**）+ 用例覆盖 + `IModuleStats` 活跃数异常时可见
- **风险 3：池膨胀**——长尾 prefab 各留实例 → 内存增长。对策：池上限（每桶上限 + 超限销毁）+ 统计可见
- **风险 4：低端机降级效果未实测**——决策 8 的档位映射需真机验证（M12 机型适配时补），本里程碑只验"参数生效"
- **风险 5：加载抖动**——首次播放某特效有异步加载延迟（表现为"第一次开火没火花"）。对策：启动预热常用集（P1 六件）+ 预热清单入配置
