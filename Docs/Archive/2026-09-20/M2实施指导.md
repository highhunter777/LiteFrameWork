## 1. gen.bat 双输出 + 注册表三件套

**gen.bat 两遍**（bat 内注释只写 ASCII——UTF-8 中文注释在 GBK 控制台乱码破坏解析，实施教训）：
① `-c cs-bin -d bin`：代码→`GameData/Generated`，数据→`LiteGame/RawFile/Config`
② `-d lua`：→`LiteGame/Lua/cfg`（M3 消费）

**三件套**（`Data/` 下，`read_schema_from_file=true`）：
- `#cfg.uiform.xlsx`：Id/Lua路径/Prefab/层级/全屏（Lua路径必填，M3 填充期校验）
- `#cfg.contententry.xlsx`：Id/Name/Entry
- `#cfg.strategy.xlsx`：Id/Name/Lua路径（空 = C# 默认实现）
- 表注册进 `__tables__.xlsx`（output 列实际被 Luban 默认命名覆盖——产物为 `cfg_tbuiform.bytes` 等，loader 键以 `Tables.cs` 为准）

**产物核对**（已跑通）：`Tables.cs` 含 `Tbitem/Tbuiform/Tbcontententry/Tbstrategy` 四表；`Tables` 构造签名 `Func<string, ByteBuf>`（同步）。

## 2. AssetService（`LiteGame/Scripts/Runtime/Resource/`，静态门面豁免）

- **重写而非照搬**试验件：namespace LiteGame、Log → LiteFramework.Log、回调 → UniTask（经 `UniTaskAssetExtensions.AsUniTask`：YooAsset `AsyncOperationBase` 失败转 `InvalidOperationException`）
- `InitAsync`（EditorSimulateMode，幂等）：`YooAssets.Initialize` → `CreatePackage` → `EditorSimulateBuildInvoker.Build(VirtualAssetBundle)` → `InitializePackageAsync` → `RequestPackageVersionAsync` → `LoadPackageManifestAsync`（YooAsset 3.0.x 清单加载独立于初始化——试验件 YooAssetComponent 是 API 参考）
- RawFile **实际实现走 TextAsset**（`.bytes`/`.txt` 以 PackDirectory 打包）：YooAsset 3.0.5 模拟清单单一 BuildBundleType，VirtualAssetBundle 下 RawFileObject 恒加载失败（ABH 路径实测，见实施记录）；`LoadRawFileBytesAsync/TextAsync` API 名不变。收集器 `PackRawFile` 路线与混合包方案待 M6 定。
- 取消语义：YooAsset 操作不支持中途取消——ct 在操作边界检查；等待中不可取消
- location 契约：资源完整路径（手册坑①）
- `internal static Package`：仅供 SceneService 等同程序集薄壳，业务禁止
- **静态门面豁免名单（现行，登记于 2026-09-10）**：① `Log` ② `ReferencePool` ③ `FileSys`（框架 Core 三位，设计方案 §1.1 封闭名单）④ **`AssetService`（业务侧，方案 A"沿用 AssetService 静态门面"结论落地）**——名单到此为止；新增静态门面必须先改本节登记，不接受默认放行。

## 3. IConfigService（`Resource/ConfigService.cs`，DI 单例）

- 构造收 `Func<string, CancellationToken, UniTask<byte[]>>` 字节委托（装配点绑定 `AssetService.LoadRawFileBytesAsync`）——服务不感知资源方案（"松"）
- `TableDataFiles` 显式登记表数据文件清单：逐文件预取 → 缺文件报错带 location（"删 bytes 报错明确"的实现位）；**新增 Luban 表时此清单加一行**（将来随 Bridge 生成器自动产出）
- Luban `Tables` 构造是同步签名——异步预取全部 bytes 后同步建表，loader 查预取缓存
- 失败 fail-fast（损坏/缺失不静默）——与存档"损坏不炸启动"相反：**配置缺失必须炸**（二分口径的另一侧）
- 旧件已删：`GameData/ConfigLoader.cs`、`StreamingAssets/Config/`

## 5. Bridge.Data 骨架 + SceneService + link.xml

- **`Bridge/Bridge.Data.cs`**：`Bridge.Bind(Func<Tables>)` 装配期绑定（Launch 调，不碰容器）+ `Data.GetItem(int)`（按行缓存字典——C# 行对象已被 Luban 缓存，字典为 M3 LuaTable 转换缓存预留同构位）+ `Data.GetUIForm(int)`。M3：ToLuaTable 转换 + 生成器产出
- **`Shell/SceneService.cs`**（DI 单例）：**两种加载方式**——单场景 `LoadSingleAsync/UnloadSingleAsync`（切换语义，先卸后载）与叠加 `LoadAdditiveAsync/UnloadAdditiveAsync`（并发多场景；同 location 重复加载 = Warning + no-op，卸载未加载 = no-op）。单场景切换后叠加登记一律清理（Unity Single 语义销毁全部旧场景，句柄只 Dispose 不再 Unload）。`Progress`/`SingleSceneName`/`AdditiveCount`/`AdditiveLocations`/`IsLoaded` 只读暴露；句柄由本类持有不外泄；**切换决策归 Procedure，业务禁止裸调 AssetService.LoadSceneAsync**；叠加场景的 AudioListener/Camera 冲突由场景制作者处理；进度回调等 M5 消费方出现再加。**场景收集**：`BundleCollectorSetting` 加 LiteGameScenes 组（Assets/Scenes → PackDirectory）；`Test.unity` 已进 EditorBuildSettings 供叠加实测。
- **叠加加载的重复引导隐患与守卫**（实测发现）：场景实例若含 `GameEntry`，叠加加载会因 `DontDestroyOnLoad + Awake` 二次引导并覆盖静态 `s_container`/静态设施（表现为"面板读到的服务与加载用的服务不是同一实例"）。已在 `GameEntry.Awake` 加守卫：`s_container != null` → Warning + 销毁重复件（`_active` 标志使 Start/Update 不参与首个引导之外的动作）。**纪律：除启动场景外，任何场景都不得挂 GameEntry**——守卫是兜底，不是许可。
- **`Assets/LiteGame/link.xml`**：Luban.Runtime / Luban.Tables / LiteFramework 三程序集 `preserve="all"`

## 6.5 玩法层决策：挂载回收契约与队友单机边界（2026-09-10 定）

### ① 挂载型对象回收契约 = **谁挂谁清**

Buff / 装备 / 光环 / 定时器等挂载物，**由挂载方负责摘除与回收**；宿主（角色、队友实体）只维护一个**生命周期容器**，回收时逆序执行容器内已登记的注销委托（与 `SubscriptionBag` 同款语义）。

- **挂 = 交出注销委托**：挂载方必须提供 `Action` 注销；宿主不遍历别人的挂载、不做"帮别人清理"的兜底
- **宿主回收后容器必须为空**——执行完仍非空 = 有人挂了却不注销，Debug 告警（设计方案 §163"漏了不报错、只表现为缓慢内存增长"的隐患由此可见）
- 与 §7.3"返回注销委托"红线同源；该容器即 **M4 实体壳的"生命周期容器"**——**M4 之前业务层按同一契约自建**，不做两套
- 关闭挂账：设计方案 §163"角色回池时谁清 Buff"由此定案

### ② 队友系统只用于**单机部分**（不进 Sim）

- 不进 `SimWorldState`：不做确定性、不进固定容量槽位数组、不参与快照与 checksum（"id 不用引用 / 槽位数组"是联机纪律，单机队友**不受此约束**）
- 内部**可用引用与 `List<Teammate>`**；AI/行为使用可取消 UniTask，禁止 C# 原生 Unity 协程
- **跨边界红线（必须守）**：队友一旦与 Sim 侧实体（联机战斗对象）交互，一律走 **id**，由玩法层做 id ↔ 引用转换；**禁止把 Sim 实体引用存进单机队友结构**——否则污染确定性，M7 接入时无处可查
- 时间原语待 M4 调度器/序列执行（业务禁止裸调 UniTask 时间原语，纪律不变）
- 编队/好感度持久化走 `FileSys`；内容热更走 Lua（M3+）
