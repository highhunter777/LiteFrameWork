## 1. 前置决策（开工前定案）

### 1a. 渲染栈（定案 2026-09-13）
UGUI + TextMeshPro——manifest 既定依赖，无悬念。DOTween 只做转场/表现（M5 红线提前生效：判定不碰 DOTween）。

### 1b. 绑定双路径范围（定案）
路径 A（标记即数据，主路径）**全量交付**：`BindNode` 补显式 `BindName` 字段 + `BindIndexBuilder` 运行期读标记建索引。路径 B 交 `UIBindBase` 双模式索引基类 + 一个最小示例走通 Designer 字段登记即验收；BindCodeGen 生成器侧只做"生成路径与 UI 程序集对齐"的小改（ScriptsFolder 默认值指向 LiteGame），**不扩功能**。

### 1c. SafeArea（定案）
`ISafeAreaStrategy` 接口 + 默认实现（SafeAreaReceiver 驱动 CanvasScaler 偏移）随 UI 壳交付；`Screen.safeArea` 为唯一事实源，横竖屏/分屏自动跟随；DevHUD 豁免（仅电脑测试，已定）。

### 1d. 薄壳三件全进 M4（定案，手册 §六步骤 6）
实体壳（池化 + 生命周期容器 + 加载竞态表）与声音壳（组 + 代理轮转）按手册最小形态交付，**均不转发 Lua**。

### 1e. 时序执行三决策（M4 开工第一步复核定案，本规划建议默认）
①驱动源 = 双时钟分轨：逻辑时序挂 `IWorldClock`、表现时序挂 `IUIClock`（Timescale=0 冻结语义由时钟层给，执行器不自读 Time）；②序列等待模型 = **回调注册**，不用协程（协程对象生命周期与暂停/恢复语义冲突）；③调度器到期判定 = 逻辑帧累积。定死并记录后 M5 直接消费。

### 1f. 资产与收集（定案）
新增收集组 `LiteGameUI`（CollectPath: `Assets/UI`，**PackSeparately**——单界面单包体支撑热更粒度），收集器 tag `ui`；`Assets/UI/UIMain.prefab` 建灰盒骨架（全屏页 + 一个 Button + TMPro 文本 + BindRoot/BindNode 标记 + SafeAreaReceiver），**含占位美术**（2026-09-13 定案）：UGUI 内置 Sprite + 纯色块 + 默认字体，不引入外部素材；tbuiform 行 prefab 列 `UI/UIMain.prefab` 与收集后 location 对齐。

### 1g. Bridge.ui 门面 API（定案最小集——§4.7"M4 定 UI 壳 API 前定死"的落点）
`Show(id)` / `Close(id)` / `IsOpen(id)`——id 为 TbUIForm 行主键；**Lua 不触碰 GameObject / prefab 名字**（受控 API 面 §4.6）。`Bridge.content` 保持骨架。

### 1h. 七态映射（定案）
C# `UIFormState`：Loading→OnInit→Active⇄Covered/Paused→Closing→Recycled（GF UIManager 同款）；`IUIFormLogic` 七回调 = OnInit / OnShow / OnUpdate / OnPause / OnCover / OnReveal / OnHide（手册 §六步骤 3 回调名表为准）。

### 2.7 实体壳（手册步骤 6）
- 池化 GameObject + 生命周期容器 + **加载竞态表**（异步加载中收到 Hide → 记入集合，加载完成立即回收——GF EntitiesToReleaseOnLoad 同款）；不转发 Lua

### 2.8 声音壳（手册步骤 6）
- 组 + 代理模型：一组 N 个代理轮转（并发通道，同组音效可叠加）、组音量/静音、同优先级不被替换；播放入口收口（业务禁裸 AudioSource）

### 2.9 时序执行（手册步骤 7，M5 前就绪）
- 调度器：动作点/定时注册、到期触发、可取消；序列执行器：有序步骤表推进（剧情与技能共用）
- 三决策按 §1e 建议默认复核定死；**业务禁止裸调 UniTask 时间原语**（M5 红线提前生效）

### 2.10 控件库（M4c 批次，2026-09-13 定案：**预建大而全**，推翻"按需生长"）

**定位**：壳机制层的可复用组件资产；Lua 经数据口子/受控 API 消费、不碰内部实现（设计方案 §1.3 归属纪律不变）。**绑定工具只是加速开发**（BindNode/索引免查找接线），控件不依赖绑定标记亦可代码使用——两者正交。依赖：M4a（基座/绑定索引/UiFx 原语）；与 M4b 无依赖可并行。
