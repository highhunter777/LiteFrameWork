# 历史施工文档归档

这里保存 2026-09-20 之前的详细施工记录、阶段性审查和已被新方案覆盖的设计稿。

## 使用规则

- 日常开发以 `Docs` 根目录的主线文档为准。
- 本目录只作追溯、审计和恢复，不作为当前实现依据。
- 若归档文档与主线文档冲突，以主线文档、代码和测试为准。
- 需要恢复某份历史文档时，直接从本目录复制回 `Docs`，不要覆盖同名主线文档前先做差异审查。

## 归档内容

- `M0–M4、M7–M11`：阶段施工记录和实施日志。
- `编辑器/UI/样式/资源/VFX/动效`：细节规划，当前主线只保留边界和验收。
- `状态机`：历史施工图，当前语义收口到框架与角色主线文档。
- `模组系统`、`联机 Demo 美术资源清单`：后置或内容生产资料。
