# 历史施工文档归档

这里保存 2026-09-20 之前的详细施工记录、阶段性审查和已被新方案覆盖的设计稿。

## 使用规则

- 日常开发以 `Docs/README.md` 索引的现行文档和 `Docs/design/` 下的权威设计为准。
- 本目录只作追溯、审计和恢复，不作为当前实现依据。
- 若归档文档与主线文档冲突，以主线文档、代码和测试为准。
- 需要恢复某份历史设计时，先做差异审查，再按领域放回 `Docs/design/` 的对应目录；执行手册类文档才放回 `Docs` 根目录，且不得直接覆盖同名现行文档。

## 归档内容

- `M0–M4、M7–M11`：阶段施工记录和实施日志。
- `编辑器/UI/样式/资源/VFX/动效`：历史细节规划；现行承接见下节，旧结论不覆盖当前总设计。
- `状态机`：历史施工图，当前语义收口到框架与角色主线文档。
- `模组系统`、`联机 Demo 美术资源清单`：后置或内容生产资料。

## 2026-09-21 UI 现行承接

本目录的 `UI性能优化规划`、`UI扩展能力设计`、`UI资源热更缺口收口`、`UI控件库Prefab落地规划`、`样式编辑器设计` 和 `编辑器设计规划` 保持历史归档，不作为施工入口。有效内容由 [UI框架总设计](../../design/client/ui/UI框架总设计.md) 及制作规范、Lua API 参考、编辑器工具专项承接；当前范围和冲突以总设计为准。

随后形成的 UI 运行时专项和演进路线图也已被总设计吸收，见 [2026-09-21 归档映射](../2026-09-21/README.md)。技能 Timeline 编辑/导出细节转归 [动作与特效专项设计](../../design/gameplay/动作与特效专项设计.md) 第 5 节；UI 动效的作用域、取消和复位以 UI 总设计为准。
