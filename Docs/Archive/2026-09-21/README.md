# 2026-09-21 客户端与服务端设计归档

本目录保存被《商业级通用客户端框架总设计》和《商业级通用服务端框架总设计》取代的旧总设计文档。

## 使用规则

- 当前客户端目标架构、运行闭环、重构顺序、测试补足和发布门槛以 `Docs/design/architecture/商业级通用客户端框架总设计.md` 为准。
- 当前服务端目标架构、重构顺序、安全红线和上线门槛以 `Docs/design/architecture/商业级通用服务端框架总设计.md` 为准。
- 本目录内容仅用于历史追溯和设计差异审计，不作为当前实施依据。
- 若归档文档与主线文档冲突，以主线总设计为准；当前实现事实仍以代码和可复现测试为准。

## 归档内容

- `服务端架构设计.md`：原 Meta/RoomServer 精简拓扑，已由新总设计完整吸收并扩展。
- `自研框架设计方案.md`：原客户端框架边界和分层精简稿，已由客户端新总设计吸收并重定优先级。
- `框架流程说明手册.md`：原启动、资源、UI 和战斗流程精简稿，已由客户端新总设计的生命周期与完整流程取代。
- `框架实施手册.md`：原 M0～M16 里程碑精简稿，客户端部分由 C0～C5、服务端部分由 R0～R4 取代。
