## 使用规则

- 客户端跨域架构、资源所有权与发布门槛以 [商业级通用客户端框架总设计](../../design/architecture/商业级通用客户端框架总设计.md) 为准。
- 服务端目标与上线门槛以 [商业级通用服务端框架总设计](../../design/architecture/商业级通用服务端框架总设计.md) 为准。
- UI 当前契约、缺陷核查、重构与验收以 [UI框架总设计](../../design/client/ui/UI框架总设计.md) 为准；制作规范、Lua API 与工具专项由该文索引。
- 本目录只供追溯、恢复和差异审计，不作为当前实施依据；历史“已交付/全绿”不能替代当前代码与测试。
- 原稿保持归档前内容，不修订其中失效的相对路径、章节引用或结论。查看现行来源请使用本索引。
