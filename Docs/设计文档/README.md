# 设计文档中心

本目录保存仍然有效的目标架构、专项设计、规范、参考和路线图。执行命令、环境恢复、本地补丁与历史稿不放在这里。

## 1. 权威层级

发生冲突时按以下顺序处理：

1. **当前实现事实**：以代码、版本化配置和可复现测试为准。
2. **总设计**：裁决目标架构、重构顺序和商业验收门槛；架构总设计负责跨域边界，领域总设计在该边界内裁决本领域契约。UI 的唯一领域入口为《UI 系统总设计》，实施阶段并入该文，不另维护 UI 路线图。
3. **专项设计/策略选型**：定义单一领域的协议、状态、数据流和实现约束，不得违反总设计。
4. **规范**：定义制作与提交硬规则，违规必须由工具或门禁发现。
5. **参考**：描述 API、映射和使用方式；与代码不一致时修正文档或代码契约。
6. **路线图**：记录目标路线、依赖与退出条件，不作为“已经实现”的证据；完成状态归 `Docs/施工进度/`。
7. **Archive**：仅用于历史追溯，不参与当前设计裁决。

## 2. 目录职责

| 目录 | 职责 |
| --- | --- |
| `架构/` | 客户端、服务端跨域总设计，框架先行/业务准入与商业验收门槛 |
| `gameplay/` | 游戏业务、联机演示、角色、动作、特效和玩法数值 |

| `客户端/UI/` | UI 框架总设计（含运行时与路线）、制作规范、Lua API、编辑器工具 |
| `quality/` | 跨客户端、服务端和纯 C# 的测试开发框架与性能工程（预算/度量/门禁） |

## 3. 命名规范

| 类型 | 命名格式 | 使用条件 |
| --- | --- | --- |
| 总设计 | `<领域>总设计.md` | 跨多个模块，能够裁决边界和优先级 |
| 专项设计 | `<能力>专项设计.md` | 单一领域的完整运行设计 |
| 层级设计 | `<对象>层级设计.md` | 单个资产/单件的节点树、命名与暴露定稿（只裁"长什么样"） |
| 分层设计 | `<对象>分层设计.md` | 一项能力的分层形态与逐层契约（如 GM/调试四层） |
| 策略选型 | `<主题>策略选型.md` | 比较候选并冻结当前选择 |
| 备选方案 | `<能力>备选方案.md` | 当前不实施、满足触发条件后再启动 |
| 规范 | `<对象>规范.md` | 必须遵守并应进入自动校验的规则 |
| 参考 | `<对象>参考.md` | API、字段、映射或使用查询表 |
| 路线图 | `<领域>演进路线图.md` | 目标路线、依赖、退出条件与当前进度状况 |

文件名禁止使用“最终版”“新版”“具体方案”“精简版”“V2最新版”等不可治理后缀，**也禁止裸 `设计` 后缀**（无法判定属于上表哪一类）；版本、状态和日期写入文档元数据，不写进文件名。

> 归类自问一句「它裁决什么」：只需一句话限定的形态 → **层级/分层设计**；要跑起来才算完整 → **专项设计**；只在查表时被引用 → **参考**。

## 5. 维护规则

- **新增/修改/移动/合并/归档设计文档时按 `doc-authoring` skill 走**（落点决策 → 命名与元数据 → 索引登记 → `--lane Doc` 自检）。
- 总设计必须写明状态、版本、适用范围、Current/Target 和冲突裁决规则。
- 专项设计必须写明 Owner、依赖、输入输出、失败语义、容量或性能预算和对应测试层级。
- 设计改名或移动时必须在同一变更中更新 `Docs/README.md`、本索引和全部现行引用（**链接与 `#锚` 都由 doc-lint D4 把守**）。
- 已被完整吸收的文档移动到 `Docs/归档记录/<date>/`，归档索引写明替代文档。
- 不复制第二份相同设计；跨文档只引用唯一权威来源。
- 设计文档只保留最新设计与必要的当前进度状况：不录施工记录、批次流水与设计迁移过程；施工证据与批次状态归 `Docs/施工进度/`（**内嵌状态由 doc-lint D1/D6 提醒**）。
- 目标能力不得描述为当前能力；路线图中的完成状态必须能由代码、测试或发布产物证明。
- 文件名禁止不可治理后缀（`最终版`/`新版`/`具体方案`/`精简版`/`V2最新版` 等，**D5 把守**）；**本目录下每份文档必须被 §4 索引引用**（**D3 把守**——孤儿文档即违规）。

> **门禁**：`python scripts/gate/test.py --lane Doc`（或 `python scripts/gate/doc-lint.py`）——D1/D6 状态混入（提醒）、D2 审计表裸待提交、D3 索引孤儿、D4 链接与锚失效、D5 文件名后缀，全部为违规级。
