## 1. 定位

五件编辑器工具分两族：**prefab 采样族**（身位圆柱/枪口偏移/持枪偏移/爆头带调带——共享 `Player(Rifle).prefab` + `Rifle_Controller.controller` 与参考姿态 AimIdle t=0）与**片段采样族**（根位移——共享 `RootMotionBakeConfig.asset` 逐动作登记）。产出编译期同值的烘焙常量：四件 Sim 常量（进 BuildHash 源集，双端同值）+ 一件表现常量（持枪偏移，不进源集）。2026-10-10 前四个独立菜单、两种形态、三套失败口径、路径字面量复制 4×3 份——统一为**一个工具箱窗口 + 一份共享单源 + 一种执行形态**；v1.1 统一**产物形态**（全部 `.g.cs`、同一 emit 原语）；v1.2 收编根位移（原第五个独立菜单、第四份 emit、`LogError` 口径）。

代码落点：`Assets/LiteGame/Editor/Baking/`（程序集不变，仍 `LiteGame.Editor`）。

| 文件 | 职责 |
|---|---|
| `BakeTargets.cs` | **共享单源**：目标资产路径/参考片段/各产物输出路径（两族分节）+ `FindDeep` + `LoadReferenceClip` + `PrefabEditScope`（Load→Unload 编辑域收口）+ **`WriteGenerated`（统一产物 emit：固定头/LF/write-if-changed/ImportAsset）** |
| `BakingToolbox.cs` | 统一窗口：五页（身位圆柱/枪口偏移/持枪偏移/爆头带调带/根位移），每页＝前提说明 → 执行 → 报告区 |
| `BodyCylinderBaker.cs` / `MuzzleOffsetBaker.cs` / `WeaponGripBaker.cs` / `RootMotionBaker.cs`（含 `RootMotionBakeConfigAsset`） | 一键烘焙器：静态 `All()` 返回报告；产物体各自由 `BuildBody` 生成，写盘只走 `WriteGenerated` |
| `HeadHitLineTuner.cs` | 交互调带器：可寄宿工具件（`Activate/Deactivate/DrawGUI`，Scene 绘制+滑杆），由工具箱「爆头带」页承载；`Export` 同时被 GM 面板复用 |

## 2. 统一形态（红线）

| 面 | 统一后 | 原状态（已消灭） |
|---|---|---|
| 入口 | **唯一菜单 `LiteGame/烘焙工具箱`**（run_script 仍可直调各类 `All()`/`HeadHitLineTuner.Export`） | 四个独立菜单各自为政 |
| 执行面 | 静态 `All() → string` 多行报告；**预期失败返回 `ABORT …` 报告，不抛异常** | 抛 `InvalidOperationException` / 返回 ABORT 字符串 / 对话框三套并存 |
| 失败兜底 | 工具箱 `Run()` 内 try/catch 转报告（防御层；工具本体不应再抛） | 异常直接冒泡 |
| 常量 | 路径/片段/输出路径**只存在于 `BakeTargets`**；工具与生成文件头注释一律引用常量 | `"Assets/Prefab/Player(Rifle).prefab"` ×4、controller 路径 ×3、AimIdle ×3 散落 |
| 产物 emit | **只走 `BakeTargets.WriteGenerated`**：固定头（生成器名+工具箱入口+勿手改）→ 工具语义行 → 代码体；LF、UTF-8 无 BOM、**write-if-changed**（同字节不动文件——重烘不触碰源集，防 hash 噪声） | 三份 `BuildText` 手拼头注释 + 裸 `File.WriteAllText`（无条件改写）+ 一条 SO `Configure/SetDirty/SaveAssets` 资产链 |
| 原语 | `FindDeep` 一份；`PrefabEditScope` 统一 Load/Unload 纪律；`LoadReferenceClip` 一份 | `FindDeep` 两份逐字复制；try/finally 三份手写 |
| 报告留痕 | 工具箱执行即 `Debug.Log("[BakingToolbox] …")`，报告区同步显示 | 部分工具只弹窗不落日志 |

**工具内注释"菜单 LiteGame/烘焙XX"字样已随生成器更新**；已检入的生成文件（`HeadBake.g.cs`/`MuzzleBake.g.cs`/`BodyBake.g.cs` 头部）在下一次重烘时自然更新为工具箱口径（生成文件勿手改）。

## 4. 工具清单

| 工具（页） | 输入 | 校验 | 输出 | 重跑时机 | 消费点 |
|---|---|---|---|---|---|
| 身位圆柱 | prefab 的 **CharacterController**（美术可调、可视、唯一） | `center.y == height/2`（圆柱底=脚底），不满足 ABORT | `BodyBake.g.cs`（Radius/Height） | 美术调 CC 后 | `CombatConfig.BodyRadius`（移动去穿插）+ `HitscanHeight`（站姿高/头带比例基底）+ 视图 CC；服务端命中柱同值；`BodyBakeEditModeTests` 卡"改 CC 忘重烘" |
| 枪口偏移 | prefab 的 `Weapon_Rifle/Muzzle` 锚点 @ AimIdle t=0 | 锚点/片段缺失 ABORT | `MuzzleBake.g.cs`（Forward/Right/Height，相对 prefab 根，视觉 +Z→Sim 前） | 美术调锚点/换枪/换参考姿态后 | `CombatConfig.MuzzleOrigin` 三常量——**进 `CombatConfigDigest`**（联机身份） |
| 持枪偏移 | AimIdle t=0 下「`add_weapon_r` 相对持枪手 RightHand」局部变换（采样后须 `Physics.SyncTransforms()`，否则读到旧世界矩阵——历史实测 1 米量级错值） | 非 humanoid/缺骨 ABORT | `GripBake.g.cs`（FollowPath/WeaponPath/LocalPos/LocalEuler/TorsoWeight=1 常量，落 LiteView 不进 BuildHash 源集） | 换绑定骨/换枪后 | 换弹期枪位姿态覆写 `WeaponGripConstraint`（**为什么跟随右手而非躯干**：`add_weapon_r` 与右手世界位全同（差 0.6mm）、右手是枪挂点父级；跟躯干会在拉栓（右手位移 21cm）时脱节——"枪没对上手"）；观感幅度走 GM 面板「持枪幅度」滑杆（`GripTuning` dev 覆写，不落盘——同爆头带口径；v1.1 起原 SO 资产面板途径退役） |
| 爆头带调带 | Scene 视图拖带（黄球竖调下沿、滑杆调爆头柱半径），AimIdle 参考姿态 + 模型锚点对照线（颈/面顶/帽顶/发冠顶） | 比例/半径各自钳制区间 | `HeadBake.g.cs`（Ratio/Radius，R 格式逐位往返） | 视觉调带裁决后（编辑器拖带或 GM 面板实机滑杆——两模式共用同一 `Export`） | `CombatConfig.HeadHitLine = HitscanHeight × Ratio`、`HeadshotRadius`（爆头判据）；对局内预调走 `HeadHitLineDevOverride`/`HeadshotRadiusDevOverride`（开发三宏，release 剥离、不落盘不进 digest） |
| 根位移（片段采样族） | `RootMotionBakeConfig.asset` 逐动作登记（ActionId/MotionVersion/片段/三策略）；人形 RootT 曲线 60Hz 帧间差分 | NaN/Inf、单 tick 超 2m、重复 ActionId fail-fast；Y 位移记峰值警告（不进权威位移） | `RootMotionData.g.cs`（`RootMotionCatalog.Entries` + `BakedContentDigest`，毫米量化 R 定序） | 改片段/导入设置/配置登记后（同配置重烘逐字节一致） | 《联机动画与根位移专项设计》§3 的 Sim 动作位移执行层（**消费批未接线**——产物 digest 准入两端校验随该批） |

## 5. 标准工作流

1. **前提**：`Player(Rifle).prefab` 本地在位（不入 VCS——缺包从派发渠道还原）；缺 prefab 时各页给出警告与 ABORT 报告。
2. **调/烘**：打开 `LiteGame/烘焙工具箱` → 对应页执行；交互页（爆头带）在 Scene 视图拖带后点导出。
3. **收尾**（★ 均为修改指南红线联动）：
   - 烘出 `.g.cs` 命中 **BuildHash 源集**（`LiteSim/Core/Scripts` 三件）→ 出包前 `--check` 门禁复算（开发期不重跑，2026-10-07 起口径）；`GripBake.g.cs` 落 LiteView **不在源集**，表现值变化不踢握手；
   - `WriteGenerated` write-if-changed：值未变的重烘不动文件、零 hash 噪声；
   - 产物常量进 digest 的（枪口三常量）→ 联机身份变化，联机手测复核；
   - 身位几何变化 → SimChecksum 基线重录（L1 会指出）。
4. **实机复核**：F9 测试模式 + GM 面板（爆头带可视化滑杆 / 身位可视化）。

## 6. 扩展约定（新增第五件烘焙工具）

0. **两族归属**：prefab 采样族（来源=PrefabPath+Controller）与片段采样族（来源=配置资产逐动作登记）并存；未来场景采样族（地图烘焙）落点同页。产物 emit 红线：`.g.cs` 产物**必走 `WriteGenerated`**；非 `.g.cs` 产物（如地图批的 Luban JSON）按各自通道（暂存/发布纪律），报告面仍走 `All()→ABORT`。
1. 落 `Baking/`，命名 `<对象>Baker`；目标/输出常量进 `BakeTargets`，禁私有复制。
2. 执行面：静态 `All() → string`，预期失败返回 `ABORT …`，不抛异常；采样 prefab 走 `PrefabEditScope`；**写盘只走 `BakeTargets.WriteGenerated`**（禁私有 `BuildText` 头注释拼接与裸 `File.WriteAllText`）。
3. 工具箱加一页（`Tabs` + `DrawXxxPage`：前提说明 → 执行 → 报告）；交互型工具照 `HeadHitLineTuner` 的寄宿件形态（`Activate/Deactivate/DrawGUI`）。
4. 本专项设计 §4 清单加一行；施工进度记录批次证据。
