# 角色状态与动作专项设计

> 状态：现行专项设计
> 版本：1.2
> 更新日期：2026-10-01
> 适用范围：角色 Sim 状态、输入控制、网络映射和表现状态
> 维护责任：角色与表现

## 1. 三层边界

| 层 | 职责 | 禁止 |
|---|---|---|
| Sim | 移动、朝向、动作阶段、状态效果、战斗判定 | Unity/Lua/框架引用 |
| 控制器/网络 | 采集设备意图、帧对齐、输入校验、发送 | 直接改 Transform 或权威状态 |
| View | 镜像、动画、特效、音效、相机、HUD | 回写 Sim 判定 |

## 2. 状态模型

- `ActionState`：`ActionId/StartFrame/Phase/SourceId`，阶段为 `None/Windup/Active/Recovery`。
- 每实体一个主动作槽；技能、冲刺、交互、死亡/复活可进入；移动、瞄准、连发射击不进入。
- **瞄准态**（右键举枪）：**权威公开状态**——`EntitySlot.Flags` 的 `Aiming` 位（该位集随公共快照/差分/checksum 下发，远端可见），不进主动作槽；链路口径、限速与朝向规则见 §7。
- `StatusSlot`：固定数量的 `EffectId/EndFrame/Param`；眩晕、护盾、无敌等限时状态住 Sim。
- 仲裁优先级：死亡 → 状态压制 → 主动作 → 移动/瞄准 → 表现过渡。

## 3. 输入三件

1. `IIntentSource`：键鼠和触屏输出相同的 Move/Aim/Buttons。
2. 上下文门：UI/菜单打开时输出零战斗意图。
3. 帧边界门：渲染帧只刷新待用意图，逻辑帧消费一次；追帧不产生额外输入。

服务器重新绑定 EntityId，并校验移动/瞄准向量、帧号、按钮白名单、动作频率和 `action_seq`。

## 4. 动作和武器的协作

- 连发 Fire 每帧由 `WeaponSystem` 处理，不占主动作槽。
- Reload/Switch 若有前后摇，使用 `category=reload/equip` 的 ActionState 参与仲裁。
- `ActionSlots.TryOccupy/Release` 统一处理冲刺、技能、交互和换弹冲突；同帧按优先级和 EntityId 决定。

## 5. View 驱动

角色动画的 Profile、CharacterAnimationDriver、播放器与后端按[动画模块专项设计](../client/animation/动画模块专项设计.md)实施。本文负责角色事实与输入边界；播放时钟、打断结果、资源和池化契约由动画专项维护。

- Animator 参数只由 Sim 快照/事件推导，单向写入；值不变不重复写。
- 本地相机跟预测位置，和解期间跟表现位置；远端插值。
- 开火枪口反馈可立即播；命中、受击、死亡和技能结果只由权威事件触发。
- `silenceUntilFrame` 防回滚重放重复特效、音效和震屏。

## 6. 验收

- UI 打开时角色不动；追帧输入次数准确；非法按钮被拒绝。
- 动作前摇/判定/后摇、状态持续、回滚重放两端一致。
- 本地移动无明显延迟，远端不抖，和解不重复播事件。

## 7. 瞄准态（右键）口径

瞄准是**权威状态**而非纯表现（它改变移速/动画/相机），且是**公开状态**：任一段缺席要么表现为"客户端按了没效果"（白名单/预测清零），要么表现为"远端永远不举枪"（没落 Sim 状态）。逐段落点如下：

| 段 | 落点 | 要点 |
|---|---|---|
| 输入资产 | `Player.inputactions` 的 `GamePlay/Aim`（Button 型，绑 `<Mouse>/rightButton`） | — |
| 设备源 | 输入三件第 1 件（`NewInputIntentSource.Sample`） | `Aim.IsPressed()` 拼进 `Buttons`；**连续意图**，不带 `action_seq` |
| 输入面 | `SimInputFrame.ButtonAim`（位 9，**不进**离散意图位集） | 位定义见[业务总设计 §3.2](游戏业务系统总设计.md#32-输入位和边沿) |
| 预测/回放 | `SimInputFrame.PredictedButtons` + `RollbackSim.PrepareNext` | 预测帧只保留**连续意图位**（开火/离散位不进预测）——否则本地举枪会在缺真实输入的帧闪断；新增连续位只改这个常量，不在回滚代码里散写位 |
| 服务器准入 | `InputGate.AllowedButtons` | 白名单加位；未登记位会让**整条输入**被丢弃（客户端正常、服务器判非法） |
| Sim 状态 | `EntityFlags.Aiming`（`EntitySlot.Flags` 位 0），由 `InputSystem` 每帧从输入位覆写 | **输入位与实体标志位是两个位空间**（各自命名常量，值可相同）；`Flags` 已在 checksum / 公共快照 / 差分器 / `SlotDelta.flags` 内 ⇒ **协议零改动**、远端可见 |
| **限速** | `CombatConfig.AimMoveSpeed` = `MoveSpeed × AimMoveSpeedFactor(0.5)`，由 `InputSystem` 应用到移动速度——**条件：瞄准中 ∨ 开火态** | 0.5 = 乘 2 的幂（**位级精确**、不引舍入）；= 2.5 m/s 恰为视图 Walk 档上界 ⇒ 瞄准/开火移动只需一套 `AimWalk_*`，不需要 AimJog。值进 `CombatConfigDigest`（联机身份） |
| 开火窗 | `EntitySlot.FireStanceFrames`（帧计数、**公共面**——随 SlotDelta / 公共快照 / 公共 checksum 下发；客户端预测/回滚重放必须能从快照重建窗，否则重放丢限速/朝向会出现窗内逐快照纠偏） | 自 `ShootingSystem` 开火判定点置满窗、`InputSystem` 逐帧递减；窗长单源 `CombatConfig.FireStanceFrames`（**实时调参项**）；**事件刷新＝重置满窗**（上限即窗长）；**不变式：窗长 ≥ 开火片段播放时长**（装配期校验）；进 digest；View 窗长同源派生——**限速时间＝开火态时间＝射击窗**。瞄准帧（`ButtonAim` 在场）同样置满同一窗。**离开开火态即取消**（自然窗尽；打断态落地时建立点清窗） |
| **朝向派生** | `InputSystem` 的 `Yaw` | **射击语境（瞄准 ∨ 开火帧 ∨ 开火驻留窗内）且准星向量有效** → 朝准星（即时跟枪，**点射间隙帧不回摆**）并**武装离场转向**（`EntitySlot.FaceExitTurning`，私有面）；否则有移动 → 朝移动方向——**武装态按 `CombatConfig.FaceTurnRadPerSec`（12 rad/s）逐帧过渡**（窗尽回转不瞬切），到位解除恢复即时跟向；都没有 → **保持上一帧**（不拿零向量退化，且回放/重放可重建；准星零向量同样不派生） |
| 表现读取 | `SimView.IsAiming(slotIndex)` | 本地取预测态（**按实体 Id 解析槽位**，不能把带版本的 Id 当下标）、远端取最新权威快照的位（离散位"取新不取插值"；槽位已死/首快照未到 → false） |
| **准心（HUD 第一件）** | `BattleCrosshairDriver`（App/Presentation）+ 场景 `/Battle HUD`（训练场；构建器生成） | 纯 View、**零网络面**：位置=鼠标屏幕点（腰射时即瞄准落点——瞄准链 = 鼠标点 → 相机射线 → 地面交点，无散布下严格同位）、形态=`SimView.IsAiming`（预测态）切 Hip/Ads 两组、上下文门被拦/本地未建 → 藏准心还系统光标。画布**无 GraphicRaycaster**（永不拦输入）。鼠标位读数自设备源适配器（`NewInputIntentSource.MouseScreenPosition`——InputSystem 只在 R12 边界内）。**瞄准参照原点 = 逻辑枪口**（`BattleContext.LocalMuzzlePosition`——`ProcedureBattle` 逐帧喂给采样；瞄准向量 = 枪口 → 准心地面点 ⇒ **子弹过准心正上方**，消除枪口出射与本体锚点的平行差；原点由 Sim 预测态派生，与权威枪口同式不读视图 Transform）。**不做**（2026-10-02 裁决"仅形态切换、最小可用"）：散布张开（随 G2 数值表化）、命中标记（随帧事件批）、ADS 锁屏心（须瞄准相机同轴——**未接相机前 ADS 准心跟鼠标**） |
| **瞄准激光（世界空间第一件，2026-10-05 已交付；同日修订口径：激光器装在武器上）** | `BattleLaserDriver`（App/Presentation）+ `Assets/FX/fx_lazer_sight.prefab`（KriptoFX Lazer 的 fx 归置副本——LineRenderer 纯视觉资产）+ `LaserSightPolicy`（武器支持位） | 纯 View、**零网络面**。**挂载与方向（修订）**：束实例挂在武器挂载点 `Weapon_Rifle/Muzzle` 本地空间（useWorldSpace=false，随枪姿态/动画自动跟转，美术转锚点即调向）；截停判定走 `SimRaycast` 单源——**遇玩家/障碍截停不穿透**（同批起权威子弹同样被障碍截停，见[业务总设计 §1 射击行](游戏业务系统总设计.md)）。隐藏门：本地未对齐/输入被拦/死亡/未装备/策略不支持/**无挂载点（灰盒）**。**仅本地玩家显示**；支持位按 `WeaponDefId` 集合（`LaserSightPolicy`，默认 {0}=演示步枪），**测试模式直通任何武器**；tb_weapon（G2-P1）落地后迁列只动策略类。**行为语义（双模式）**：语境外（待机/移动）沿枪管出射（枪口朝下自然扎地、不追鼠标）；**射击语境（瞄准 ∨ 开火窗）内端点收敛到开火射线终点**（"激光器归零"——束起点仍枪口，端点=子弹停点 ⇒ 激光点落在准心线上，根治与准心的原点/姿态偏移；瞄准向量无效时回枪管模式）。**开火射线出射点 = 逻辑枪口**（本体+朝向系常量偏移 `MuzzleOffsetForward/Right/Height`，进 digest，表化随 tb_weapon——激光收敛端点与 `ShootingSystem` 同源，见[业务总设计 §1 射击行](游戏业务系统总设计.md)） |
| 动画 | 驱动层以[层次动画机设计](../client/animation/层次动画机设计.md)为权威：战斗根 `FireIdle/FireWalk/AimIdle/AimWalk`、移动根 `Idle/Moving` | 瞄准/开火全走 **FullBody** 通道；**权重由 Driver 给**，经 `UpdateBlendWeights` **就地调参**（不换句柄/不重建节点/不产生终态）；唯一迟滞在"瞄准静止 ↔ 瞄准移动"（进 0.6 / 出 0.3 m/s） |
| 相机 | `ICameraService.SetAiming`（语义态端口）+ `CinemachineCameraService`（适配）+ `ProcedureBattle`（喂态） | **2026-10-02 瞄准相机批已接线，同日改持续预放置形态（用户裁决"根据玩家当前位置旋转直接放好"）**：瞄准机的 Follow/LookAt 在**绑定主相机时即接线**（不等右键）+ `StandbyUpdate=Always` 全程跟着玩家——**接管瞬间瞄准机已在正确位姿**，切换只剩优先级翻转（`SetAiming` 唯一写的字段：主 vcam 优先级+1/还原）与 FOV 混合，无陈旧位姿甩动。跟随目标与主相机**同源**（同一焦点——**AimPoint 方案废弃**）；主相机解析**排除**瞄准机；缺瞄准机 no-op + `LastAimResolveReason`。**焦点带旋转**：`Follow` 增传朝向（视觉前沿 +Z 同款旋转），`TrackedObjectOffset` 变**角色系**（X=右肩、Z=前方）。ADS 构图（训练场）：观感 Inspector 调；brain 混合 0.25s（Test.unity）。**腰射开火驻留窗相机冻结（2026-10-06 用户裁决"腰射驻留窗停止主相机旋转，窗后才可以旋转"）——两半条链**：相机旋转有**两个驱动源**（训练场 rig 实况：`/Player Camera` 挂 `CinemachineInputProvider`、`cm` 为 `OrbitalTransposer+HardLookAt`——**鼠标直驱轨道旋转**＋**焦点朝向→heading 跟随**）：①**鼠标半条链**——`ICameraService.SetOrbitInputEnabled(bool)`（新语义，与 `SetAiming` 同款"语义态进端口、接管方式归实现"）：`ProcedureBattle.OnUpdate` 每帧喂 `!SimView.IsLocalFireStance`（窗内关主 vcam 的 `CinemachineInputProvider`——鼠标 delta 不再喂轨道轴；窗尽恢复。变化沿生效、幂等；无输入组件的适配器/替身如实 no-op）；②**朝向半条链**——`SimView.UpdateCamera` 窗内冻结喂给 `Follow` 的朝向（进窗帧锁存表现 Yaw；窗尽恢复跟 Yaw，vcam 阻尼平滑回归）。两半都只作用**主相机**；ADS 段瞄准机接管（瞄准机输入门不受本语义管辖——ADS 保持鼠标控制）。**锁存时机＝进窗帧**（表现 Yaw 含当帧衰减＝开火瞬间实际朝向） |
| 散布/后坐 | `ShootingSystem` + 玩法表 | 瞄准降低散布（腰射反之） |

**开火链路（帧事件路径）**：开火是**一次性动作**（与瞄准的连续状态不同），归[动画模块专项设计](../client/animation/动画模块专项设计.md)§8 的帧事件接缝——Sim 侧产出、表现侧消费。逐段落点：

| 段 | 落点 | 要点 |
|---|---|---|
| 判定与产出 | `ShootingSystem`（输入带 `ButtonFire` 位 → hitscan → `Events.Write(Fire, shooter.Id, …)`） | 事件在**每个逻辑帧 Step 后立即消费并清空**；`Pos` = 射线原点（枪口表现的锚点）；开火态置窗与 Fire 事件**同点**写入 |
| 交付 | `SimView.OnFrameEvents`（接 `RollbackSim.OnFrameEvents`，**逻辑帧边界**） | **静默门**：回滚重放/和解段事件一律丢弃并计数——§8"本地即时反馈与权威确认不能各播一次"的结构性保证 |
| 主体寻址 | `SimView.TryGetSlot(entityId)` | 事件主体是 Id（跨对象复用代次稳定），视图/播放器按槽位寻址；未解析 → **丢弃事件**（不猜、不补播） |
| 动画消费 | `CharacterLocomotionDriver.OnFrameEvent`（实现 `IFrameEventAnimationConsumer`；**构造自订阅** `SimView.EventSink`、`Dispose` 摘下） | 事件按锁存**路由**进战斗根对应态（站定 → `FireIdle`、移动 → `FireWalk`），走 **FullBody** 通道——**映射即层次动画机的转换条件**，无独立决策表；**已在播则不重提**（连发合并），播完后仍在开火 → 重起一轮 |

**开火链路边界**：`EntityFlags.Firing`（Sim 侧连续"开火中"状态位）**不采用**——开火只走帧事件路径（本地预测经静默门去重即可），无消费者前不引入新的 checksum/快照状态位。
