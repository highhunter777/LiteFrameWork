## 1. 目标

写一个 Unity Editor 工具（`SimMapBaker`），把 `Assets/Scenes/TrainingGround.unity` 里**判定用碰撞代理几何 + 出生点**烘焙成 **Luban `.bytes` 地图数据**，供**服务端权威 Sim 与客户端预测**共用同一份 `SimMapData`（移动碰撞 + 射击遮挡）。

一句话：**判定地图从"硬编码 C# 常量"升级为"可烘焙、可数据驱动、两端单源"的 Luban 表。**

## 4. 架构与数据流

```
Assets/Scenes/TrainingGround.unity
  └─ MapCollision（根）+ 子 Box/Sphere 代理 + spawn_00.. 标记        [经 Unity Pipeline 制作]
        │  [Editor 菜单] SimMapBaker: 采集→校验(fail-fast)→排序→毫米量化→写 JSON+digest
        ▼
Luban/Data/tbmap.json            （机器生成、可 diff、确定性）
        │  Luban/gen.bat (Pass1: -c cs-bin -d bin)
        ▼
Assets/GameData/Config/tbmap.bytes        ← 进 buildHash DATA_TARGETS
Assets/GameData/Generated/{tbmap,map,mapobstacle,mapspawn}.cs
        │
   ┌────┴──────── 客户端装配 ────────┐        └──────── 服务端装配 ────────┐
   │ ConfigService.TableDataFiles+tbmap │        │ 读 cfg.Tables（同 .bytes）    │
   │ → MapTableProjection.Project(row) ◄── 同一 .bytes + 同一份投影源码 ──► 同 │
   │ → SimMapBuilder.Build → SimMapData  │        │ → MapNumbers → RoomConfig.Map │
   │ → ProcedureBattle 传 BattleContext  │        │ → RoomRuntime.Map = config.Map ??… │
   ▼                                    ▼
RollbackSim(_map) / SimView        SimStep.Step(AuthSim, Map, …)
        └─ MovementSystem 去穿插 + ShootingSystem LOS（SimRaycast，已实现）─┘
```

**不变量**：两端从同一 `tbmap.bytes`，经**同一份** `MapTableProjection` 投影出 `SimMapData`；`content_digest` 两端复算比对，防投影漂移。

## 5. Luban 表设计

- **单表 `TbMap`（一图一行）+ 嵌套 bean 列表**（不拆多表、不用联合键）：

| 类型 | 字段 |
|---|---|
| bean `MapObstacle` | `kind:int(0圆/1盒)`、`x:float`、`y:float`(底)、`z:float`、`radius:float`、`half_x:float`、`half_z:float`、`height:float` |
| bean `MapSpawn` | `x:float`、`y:float`、`z:float` |
| 行 `Map`（表 `TbMap`） | `map_id:int`、`name:string`、`content_digest:string`、`ground_y:float`、`half_width:float`、`half_depth:float`、`obstacles:list<MapObstacle>`、`spawns:list<MapSpawn>` |

- **数据源 = Luban JSON**（`Luban/Data/tbmap.json`）：文本可 diff、嵌套数组天然、确定性由 baker 掌握。本工程 Luban 按扩展名自动选 loader，**无需改 `luban.conf`**；在 `Data/__tables__.xlsx` 的 input 列填 `tbmap.json`，在 `Data/__beans__.xlsx` 加上述 bean，该表 `read_schema_from_file=false`（JSON 无表头）。
- **注意**：`gen.bat` Pass4 会 `git checkout` 恢复 `Assets/GameData/Generated/Luban.Tables.asmdef`——新增表不影响该步。

**`tbmap.json` 形态（示例）**
```json
[
  {
    "map_id": 1, "name": "training_ground", "content_digest": "<16hex>",
    "ground_y": 0.0, "half_width": 100.0, "half_depth": 100.0,
    "obstacles": [
      {"kind":1,"x":0.0,"y":0.0,"z":-69.0,"radius":0.0,"half_x":70.0,"half_z":1.0,"height":20.0}
    ],
    "spawns": [ {"x":-15.0,"y":0.0,"z":-15.0} ]
  }
]
```

## 6. 关键组件与契约

```csharp
// S0：Assets/LiteSim/Core/Scripts（零依赖，两端共编）
public static class SimMapBuilder {
  public static SimMapData Build(float groundY, float halfWidth, float halfDepth,
      SimObstacle[] obstacles, int obstacleCount, SimVector3[] spawns, int spawnCount); // 定长填充 + 越界/NaN fail-fast
}
public static class SimMapDigest {
  public static string CanonicalText(SimMapData map);  // InvariantCulture 固定字段序 + '\n'
  public static string Compute(SimMapData map);        // SHA-256 前 16 hex（同 RootMotion/CombatConfigDigest）
}

// 共享投影：Assets/GameData/Map/MapTableProjection.cs（新 asmdef Luban.Map；两端共编同一物理文件）
public static class MapTableProjection {
  public static SimMapData Project(cfg.map row);              // kind 0→Circle/1→Box；其余 fail-fast
  public static SimMapData Project(cfg.Tables tables, int mapId);
  // 校验：数量 ≤ 上限、全 finite、Compute(map) == row.content_digest（不等→抛）
}

// 服务端：Server/RoomServer/MapNumbers.cs（仿 CombatNumbers）
public static class MapNumbers {
  public static SimMapData LoadFromRepo(int mapId);
  public static SimMapData LoadTableBytes(string configDir, int mapId);
}
```

**烘焙器规则**（`Assets/LiteSim/Core/Editor/SimMapBaker.cs`，菜单 `LiteSim/地图/烘焙 tbmap.json`）：
- 采集根 `MapCollision`（缺失 fail-fast）；`BoxCollider→Box`、`SphereCollider→Circle`、`CapsuleCollider` 按方向定形；**`MeshCollider → 默认 fail**（策略可切 ReportOnly）
- 旋转仅接受 yaw∈{0,90,180,270}（90/270 交换 HalfX/HalfZ）；pitch/roll≠0 或非均匀缩放 → fail
- 出生点：前缀 `spawn_`，按名 Ordinal 排序定 index；0 个 → fail；>16 → fail
- 确定性：固定 key 排序 + 毫米量化（`Round(v*1000, AwayFromZero)/1000`）+ `InvariantCulture` + LF → **重复烘焙逐字节一致**
- 超上限：面积降序取前 256 + **报告丢弃清单**（禁止静默截断）
- 产出：写 JSON（含 `content_digest`）；**不手写 `.bytes`**

## 7. 装配注入

- **服务端**：`RoomConfig` 加 `SimMapData Map`；`RoomRuntime.Map = config.Map ?? SimMapData.StandardBattleMap()`（默认回退保测试/单机形态，`RoomRuntime(config)` 单参签名不变）；`MapNumbers` 在宿主/装配层装载；`Program`/`ServerHost`/`LocalServerTransport` 注入。**Runtime 仍零 IO。**
- **客户端**：`ConfigService.TableDataFiles += "tbmap"` + `BuildMap(mapId)`；`ProcedureBattle` 装配期 `new BattleContext(…, map)`；`RollbackSim`/`SimView`/`BattleLaserDriver` 自动跟随。
- **保留** `StandardBattleMap()` 原样（回退/测试夹具；现有 `MovementCollisionTests` 依赖其 5 障碍断言）。

## 9. 验证

- **L1**（`dotnet test Tests/Tests.slnx`）：地图合法性（数量/出生点不落障碍内/全 finite）；双跑逐位一致 + digest 相等；`tbmap.bytes` 投影 == 期望快照且两端两条路径 digest 相等；**LOS 验收**（真实地图：墙后打不中只写 Fire、空旷命中）；新 `.bytes` 自动进 buildHash 闭包，出包前 `--check` 复算覆盖。
- **L2**（`scripts/gate/l2-unity-gate.ps1`）：随机采样点 Sim 判定 == 场景 `MapCollision` 代理物理命中（守「视觉能穿、判定挡住」）；baker 幂等；baker fail-fast（含 MeshCollider/旋转盒/NaN → 报错不产半成品）。
- **收尾**：`Luban/gen.bat` → `scripts/codegen/refresh-hash.ps1`（重生成 hash + 重编服务端 + 触发 Unity 重编 + 两端对账）→ `scripts/gate/l2-unity-gate.ps1`。

## 11. 风险

- **最高：工作区 34 个未提交改动（含 LOS）** → 实施前先对齐分支，**勿重写** `SimRaycast`/`ShootingSystem`/`SimStep`/`BattleContext`。

- **确定性回归** → 量化 + InvariantCulture + 固定排序 + digest 守卫；改 Sim/表后必跑 hash 生成器。
- **Runtime 纯净** → 地图只在装配层 IO 装载后注入。
