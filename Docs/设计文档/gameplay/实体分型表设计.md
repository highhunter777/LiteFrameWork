# 实体分型表设计

> 状态：现行专项设计
> 版本：1.0
> 更新日期：2026-10-01
> 适用范围：Sim Core 实体数据面（分型表）
> 维护责任：Sim 架构

- 权威层级：本文是实体数据面**新权威设计**；与《服务端总设计》§7 RoomRuntime 纯化、`ItemConfig`/`MovementConfig` 静态装载衔接。
- 结论先行：**脊柱不动、分型表平行展开、不上 ECS**——ECS 的组合性收益用"同槽位索引的平行数组"取得；结构变更/快照重写/确定性重证的成本不付。

> 当前进度：kind 位与三分型表已接入 `SimWorldState`（CopyTo/Checksum/Despawn 三面）；系统消费面（ItemSystem/ProjectileSystem/ZoneSystem）与 `CustomData` blob 退役尚未开始（见[施工进度](../../施工进度/实体分型与配置归拢.md)）。

---

## 1. 数据面形状

脊柱（`EntitySlot` 数组 + alive bitmap + Id/代次）**不动**——快照/回滚/SlotDelta/Checksum 基线全部保持有效。新增"每型一张定容平行表"：

```csharp
// SimWorldState 内新增（全部定容、零分配、槽位索引即键）：
public ItemState[]     Items;      // 道具：类型/数量/归属/存在标记
public ProjectileState[] Projectiles; // 投掷物：速度/引信/主人/命中标记（手雷/闪光等）
public ZoneState[]     Zones;      // 区域效果：EMP/雷达/毒圈——半径/剩余时间/归属
```

- **型别掩码**：`EntityFlags` 增设 kind 位（`KindItem/KindProjectile/KindZone`——输入位与实体标志位是两个位空间的既有纪律照旧）。Flags 上的 kind 位即"该槽位持有哪张分型表数据"的迷你 archetype mask。
- **结构 = 槽位占用**：没有 ECS 的结构变更机制——分型表行跟槽位同生共死（`Spawn` 置 kind 位、`CleanupSystem` 清行），迭代序 = 槽位升序（与输入升序排序同源，确定性免费）。
- **CustomData blob 退役**：`SimWorldState.CustomData` 由 typed 分型表吸收——需要跨端恢复的正式状态一律进定型表。

## 2. 快照/增量/校验扩展面（关键的三个"必须"）

分型表要进**全部三个确定性面**，缺一即隐形分叉：

1. **CopyTo/SimWorldStateSnapshot**：分型表整段拷贝（定容数组 memcpy 级）。
2. **SlotDelta/增量协议**：每型一列（或一型一 delta 分组）——公共面只增字段号的既有纪律（SlotDelta 家族）照旧扩号；私有面不进协议的照旧。
3. **SimChecksum/ComputePublicChecksum**：公共可重建面纳入分型表公共字段；私有面照 P0 口径（线上 checksum=公共面）。

`CombatConfigDigest` 不动（分型表是状态面，不是配置面）。

## 3. 系统落位（单一职责顺带变好）

| 新系统 | 独占读写 | 上游 | 语义 |
| --- | --- | --- | --- |
| `ItemSystem` | Items[] | tbitemconfig（刷新间隔/最大存在数/拾取半径/携带上限/使用时长） | 刷新/拾取判定/使用计时 |
| `ProjectileSystem` | Projectiles[] | tbitemconfig（投掷物速度/手雷伤害/半径/衰减） | 推进/引信/命中结算 |
| `ZoneSystem` | Zones[] | tbitemconfig（EMP/雷达半径与持续时间） | 区域生效/衰减 |

SimStep 顺序插位（§3.3 固定顺序的延伸，无自动扫描）：`Input → Movement → Shooting → Item → Projectile → Zone → FlushCommands → Cleanup`（投掷物/区域在射击后、命令结算前——命中产伤害命令进当帧缓冲）。系统集合编译期确定的纪律照旧。

## 4. 配置与状态的连接

`ItemConfig` 静态面就是这三张表的数据源——**不新建配置面**；拾取/使用/效果数值全部按行读表。钩爪/传送走 `MovementConfig`，触发属输入位面（离散意图位），本设计不扩输入位。

## 5. 系统消费与验收

系统消费面（ItemSystem / ProjectileSystem / ZoneSystem）按 G2 切片排期接入，`CustomData` blob 随 typed 表落地退役。验收基线：结构 CopyTo 一致、增量往返、checksum 纳入（公共/私有两口径）、房间链路不回归。
