## 0. 视角前提（TPS 越肩，已定）

| # | 裁决 | 含义 |
|---|---|---|
| V1 | **第三人称越肩自由视角** | 相机位于角色后上方（越肩），鼠标驱动相机 **yaw 360° / pitch ±80°**；指针在对局中锁定、光标隐藏；鼠标不直接移动角色朝向，只改变视线 |
| V2 | **准心钉屏幕中心** | 准心恒在屏幕中心（加后坐冲量偏移）；"屏幕光标位"语义不存在——瞄准解算走**屏心射线**，眼见即所打 |
| V3 | **相机跟位置不跟朝向** | 相机跟随本地玩家的表现位置（预测/和解后的位置），**不**把角色朝向写进相机旋转；角色转身不带动构图 |
| V4 | **瞄准单口径 AimPoint** | 上行只有"瞄准目标点"三个分量；方向、朝向、弹道方向全部由两端从该点派生——协议里不存在第二套瞄准表示 |
| V5 | **判定与镜头解耦** | 客户端只上报点；服务器用同一套几何（圆柱 + 障碍）重算命中/爆头。镜头怎么摆不改变判定 |

**为什么坚持屏心**：越肩视角下"看到的"与"打得中的"必须同源。若准心跟鼠标屏幕位、相机又能自由旋转，准心与屏心射线分离，玩家会持续遇到"准心在人身上、子弹从旁边过"的视差；屏心 + AimPoint 把瞄准收敛成一条单向链（§1）。

## 1. 现行链路（单口径、单向无环）

```text
鼠标位移 → 相机服务累进 yaw/pitch（pitch 限位 ±80°）
  → 屏心射线（viewport 0.5, 0.5）
  → SimRaycast 实体圆柱（本地预测世界，跳过自己）──命中──► P = 交点（带高度）
  → 未命中 → 地面 y=0 平面 ─────────────────────────────► P = 地面点
  → 超程/无交 → 按射程截断（不产生"无点"帧）
  ⇒ AimPoint（唯一瞄准表示，3 float 上行）

服务器 / 客户端预测同式派生：
  Yaw（射击语境）= Atan2(P − 本体XZ)；水平距 < ε 不派生（保持上帧）
  弹道 d = normalize(P − MuzzleOrigin(Pos, Yaw))；|P − muzzle| < ε ⇒ 无效开火（只写 Fire，无命中）
  命中 = SimRaycast 实体三维圆柱 + 障碍 2.5D 折算取近（§4）
  爆头 = 准心点高度落头部带（归属校验后，§4）

表现同源：
  准心 = 屏幕中心（+ 后坐冲量偏移；零网络面）
  激光 = 枪管前向被 SimRaycast 截停点（纯视觉，不读 AimPoint/准心）
  相机 = TPS 跟随（yaw/pitch 由本地输入驱动，§6）
```

**单向无环不变式**：P 由"屏心射线 ∩ 世界"产生，**不读 Yaw** ⇒ `P → Yaw → 枪口 → d` 是单向链，不存在 `Yaw → 枪口 → 瞄准向量 → Yaw` 的正反馈（历史"原地摆头"缺陷的结构性根除）。

**像素 → 角度**：鼠标 delta 由相机服务按灵敏度换算成 yaw/pitch 增量；pitch 钳在 ±80°（常量见 §6），yaw 环绕。视角**不上行**——服务器只认 AimPoint。

## 2. 瞄准单口径：AimPoint

- **零值约定**：`(0,0,0)` = 无点（`ShootingSystem` 的 `hasPoint` 判据）。相机未就绪/数值边缘才可能无点，此时沿用上次有效点。
- **采集侧不产方向**：`NewInputIntentSource` 只解算并缓存 AimPoint；不存在方向缓存与方向长度闸。
- **AI / 沙盒 / 测试**：直接构造 AimPoint（目标位置 + 期望高度），不构造方向。
- **朝向派生**：`InputSystem` 在**射击语境**（瞄准 ∨ 开火帧 ∨ 开火驻留窗内）且 AimPoint 有效时 `Yaw = Atan2(P.Z − Pos.Z, P.X − Pos.X)`；水平距本体 < ε 或零值 ⇒ 不派生（保持上帧）。语境外朝移动方向；语境解除后按 `FaceTurnRadPerSec`（12 rad/s）平滑转回，不瞬切。
- **射程截断**：屏心射线无地面交（瞄天）或交点超出射程时，取"距射手恰为射程"的球面交点——保证任何合法开火帧都有闸内有效点，不因"无点"丢整帧输入。
- **预测同式**：客户端预测世界用同一函数解算 AimPoint；服务器不信任该点，只把它当"意图方向"，用它重算几何。

## 3. 协议与输入面

| 面 | 口径 |
|---|---|
| `battle.proto` `InputFrame` | 只保留 `aim_point_x/y/z = 11/12/13`；旧的瞄准方向字段已删并 **reserved 4/5/10**（保号不重用） |
| `SimInputFrame` | 只留 `AimPointX/Y/Z`（输入面不进 `SimChecksum`，改输入面不重录 checksum 基线） |
| `InputPacker` | 只映射 AimPoint 三点 |
| `InputGate` | AimPoint 有限性闸 + 距离闸（≤ `HitscanRange × 1.1`）；开火帧判 AimPoint 非零；不做方向长度闸 |
| `LagCompensator` | 回溯补判/退化路径只拷 AimPoint；补判输入带 `ButtonFireFlag` 跳武器资源门（权威帧已消费） |
| `ShootingSystem` | 主路"枪口 → P"；无方向回退分支（零点 = 无效开火，只写 Fire/开火窗） |
| 客户端采集 | 屏心 `ViewportPointToRay(0.5, 0.5)`；先实体圆柱、再地面、最后射程截断 |

## 4. 判定链（数学不变，锚点单源）

- **命中谁**：子弹射线 `muzzle → P` 经 `SimRaycast`——实体三维圆柱最近者 + 障碍 2.5D 折算（`RaycastObstacles3D`）取近；**障碍更近即截停**（子弹不穿墙，只出着墙反馈）；与障碍并列时实体优先。
- **爆头判谁**：判定高度 = **AimPoint.Y**（"准心指哪按哪判"），不是子弹近弧交点高度。**归属校验**：准心点水平距命中目标 ≤ `HitscanRadius` 才用 `P.Y`，否则回退子弹交点高度。
- **双柱判定几何**：实体命中形状 = 竖直堆叠的两根圆柱——身体柱 `[0, HeadHitLine) × HitscanRadius(0.45)`（普通命中）＋ 爆头柱 `[HeadHitLine, HitscanHeight] × HeadshotRadius(0.15)`（Crit）。分界线 `HeadHitLine = HitscanHeight × HeadBake.Ratio`（当前导出值 `Ratio = 0.805` ⇒ 1.8 × 0.805 = **1.449 m**，随重烘自动缩放）。**命中爆头柱即 Crit**，无事后水平闸；上段 `[HeadshotRadius, HitscanRadius)` 的环状空隙按裁决不可命中。爆头伤害 `dmg <<= 1`（×2）。
- **散布**：表值 = 瞄准态最大偏转角；腰射 = 表值 × `HipSpreadFactor`(4)。偏转几何单源 `SimSpread`（以瞄准方向为轴的正交基锥偏转），每弹丸独立消费 RngState；多弹丸（霰弹）逐弹丸求交与结算。
- **伤害**：`baseDamage + rng(−DamageSpread, +DamageSpread+1)`，爆头在命中判定处 `<<1`；每发/每弹丸独立。
- **事件**：爆头发 `FrameEventKind.Crit`、普通发 `Hit`、着墙发 `ObstacleHit`；帧内瞬态，不进 checksum/快照。
- **回溯契约**：`ShootingSystem` 不改时序；只读输入、写 Cmds/Events/RngState/开火窗；回溯用静态地图 + 历史帧位；回调方还原 RngState。回溯窗口 16 帧（≈267 ms）。
- **确定性**：全部走 `SimMath`；RngState 仅真实命中/散布消费。
- **身位双半径**：命中柱 0.45 m 是**判定宽容裁决常量**（覆盖战斗姿态肢体/站姿，放过枪尖与长发）；物理半径 0.32 m 是**烘焙值**（prefab CharacterController，供移动去穿插/视图 CC）——两者解耦。
- **逻辑枪口 = 烘焙值**（`MuzzleBake`：prefab `Weapon_Rifle/Muzzle` 锚点 @ AimIdle t=0）。服务器无模型/动画，动画枪口不可重建；静态烘焙常量保留权威、确定、可回溯。三常量进 `CombatConfigDigest`。
- **接触容差**：命中圆闸的垂距含 `SimRaycast.TouchEpsilon`（1e-5 m）——AimPoint 是屏心射线与同一圆柱的交点、落在表面上，无容差时擦边会被 float32 舍入随机判成"超半径"。

## 5. 表现同源

| 件 | 口径 |
|---|---|
| **准心**（`BattleCrosshairDriver`） | 位置 = **屏幕中心** + 后坐冲量偏移（上跳回弹）；形态 = 腰射/ADS 双组；随有效散布角张开（按武器表 `static_max_scale`），连发逐发临时张开、停火指数回正。零网络面，不读快照 |
| **瞄准（ADS）** | 右键举枪：切瞄准机位（优先级 + FOV 混合）、散布收窄到表值、移动限速 `AimMoveSpeed`；`AimHoldGate` 滞回防抖；`SetAimPoint` 让瞄准机按准心距离做近距后撤 |
| **激光**（`BattleLaserDriver`） | **单模式**：端点恒沿枪口挂载点世界前向（含俯仰）被 `SimRaycast` 截停（实体/障碍/射程取近）；不追准心、不读 AimPoint。仅本地玩家可见，纯表现，**不入玩法** |
| **伤害数字** | 普通/爆头两档（聚合键含爆头档，各并各的）；飘字锚定受击点世界位，不随实体移动 |
| **命中特效/音效** | 本地造成的 Hit/Crit → 受击点特效（爆头放大）、着墙 → 障碍命中点特效；开火/命中/死亡走统一反馈分发 |
| **角色姿态** | 射击语境下上半身按相机 pitch 俯仰（`AimPitchPosture`，钳 −50°~+60°），根级枪骨同步镜像；语境外停写。**枪口对齐**（`WeaponAimConstraint`）：仅本地/瞄准或开火窗，把**胸腔与根级枪骨作为同一刚体**补转（手是 Chest 子骨，随枪一起转，握持关系不变），使 `Muzzle` 前向指向准心世界点；单帧修正上限 ADS **20°** / 腰射 **45°**（腰射 FireIdle 更低）；超出上限说明动画姿态/枪口锚点本身错，不硬掰 |

## 6. 相机（TPS）

- **状态归属**：yaw/pitch 由相机服务自持（`ICameraService.AddLookDelta` 累进）；yaw 环绕、pitch 钳 **±80°**。视角增量是**纯视图侧**读数，不进意图三件、不进协议、不上行。
- **构图**：相机在角色后上方，按"恒定臂长俯仰弧"跟随（`TpsCameraMath.PitchArm`）——pitch 越大相机抬得越高、角色在画面中的位移由 `pitchFollow` 决定（默认 0.4，PUBG 量级漂移）；枢轴高度 1.6 m、最低高度 0.4 m，参数在场景 `TpsCameraRigTuning` 单源，代码不写第二份档位常量。
- **左右肩**：`Q` 切换（初档；纯视图侧，不进意图/协议）；相机服务镜像场景 `FollowOffset.x`（宽度仍归场景单源），ADS 同步换肩；每局从右肩起步。
- **跟随**：只跟表现位置（预测/和解衰减后），`Follow(target, facing)` **不把朝向写进相机旋转**——角色转身不带动构图。
- **ADS**：`SetAiming(true/false)` 语义口，切换瞄准机位（优先级提升 + FOV 混合）；`SetAimPoint` 供瞄准机做近距后撤；松开恢复。相机 yaw/pitch 不因 ADS 重置。
- **重置**：复活/重开局/传送后 `Reset()`，下一次 `Follow` 直接落位，不从上一次位置阻尼飞过去。
- **指针锁定**：对局中锁定并隐藏光标（`PointerLockService` 是 Cursor 唯一写者）；模态/死亡/离场解锁还光标。
- **移动输入**：WASD 按**相机 yaw** 旋转到世界系（屏幕前后左右 = 世界方向），相机转、移动方向跟着转；Sim 输入契约仍是世界空间向量，服务器零改动。

## 7. FireStanceFrames（纯玩法）

开火/瞄准驻留窗（表值 60 帧 @60Hz）：窗内移动限速 `AimMoveSpeed`（2.5 m/s）、朝向保持朝准星；窗尽按 `FaceTurnRadPerSec` 转回移动方向。窗是**判定输入**（进全量 checksum），**不驱动相机**——相机自由旋转与开火态无关。
