## 1. Current 与边界

- **Current**：`FrameEventKind` 产出 `Fire/Hit/Crit/Death`（`Explosion` 预留）；`SimView` 静默门 + `EventSink` 已就位（回滚重放/和解段丢弃一次性副作用）；动画消费者接 `Fire`（`CharacterLocomotionDriver` 构造自订阅）。**命中分发骨架与伤害数字**（[施工记录](../../施工进度/角色表现与动画线.md#ch1-客户端表现基础)）；**枪口火光 + 敌人命中特效**（[施工记录](../../施工进度/战斗与武器线.md#ch5-战斗特效接线)）：`BattleMuzzleFlashDriver`（Fire → 武器挂点跟随 `fx_muzzle_flash`）/ `BattleImpactFxDriver`（本地 Caused 的 Hit/Crit → 受击点世界位 `fx_impact_enemy`，爆头放大）；`VfxService.PlayAt` 世界位播放与挂点归零补齐。**观感与样式（批C）**：逐档材质（黑描边 + 软影 + 按档光晕）×4 + 顶点渐变（顶亮底暗）+ 底件 Bold——DNP 观感技法炼化，**未归置 DNP 资产**（技法自研：TMP 原生 full SDF 描边/软影/光晕 + `colorGradient` 四角）。批D（ObstacleHit）：枚举＋产出点（障碍截停写 `ObstacleHit` 帧事件，Pos=障碍命中点）＋着墙消费（`fx_impact_wall` 世界位）；**远端开火火光**（公共开火面 `MatchStateDelta.recent_fires`——最近开火窗口 → `BattleRemoteMuzzleFlashDriver` 落远端枪口挂点）。余项：表面分流（待地图表面标记）、贴花朝向对齐、着墙音效（无素材）。
- **范围**：命中分发器（表现层事件路由）＋伤害数字系统（纯件＋驱动＋样式面）。
- **边界**：命中判定归 `LiteSim`（`SimRaycast` 单源）；特效/音效本体归 `VfxService`/`AudioService`（选择逻辑经分发器，服务契约归《动作与特效专项设计》）；动画迁移细节归动画专项。伤害数字属高频事件——**永不过 Lua**（归档《UI性能优化规划》事件过桥硬规则）。表现层只读 Sim 事件，禁回写。

## 2. 事件源与数据（零 Sim 改动起步）

`FrameEvent { Kind, EntityId=主体, OtherId=对象, Value=数值, Pos=位置 }`——伤害数字所需字段当前已齐备：

| Kind | 产出 | 释义（主体/对象/数值/位置） | 消费现状 |
|---|---|---|---|
| Hit | `ShootingSystem` | 命中目标/射手/伤害量/命中点 | **已接**（`BattleDamageNumberDriver`、`BattleImpactFxDriver`、`AutoHeadshotRig`——均为 `IHitFeedbackConsumer`） |
| Death | `ShootingSystem` | 死者/击杀者/—/死亡位置 | 未接（受击/死亡动画归动画批） |
| Fire | `ShootingSystem` | 开火者/0/—/射线原点 | 已接（枪口火光/开火动画；**远端开火火光**＝公共开火面 `recent_fires` → `BattleRemoteMuzzleFlashDriver`） |
| Crit | `ShootingSystem`（`headshot ? Crit : Hit`） | 暴击目标/射手/伤害量/命中点 | **已产出并接入**（伤害数字亮红爆头档＋`BattleImpactFxDriver` 放大 1.35） |
| ObstacleHit | `ShootingSystem` | 开火者/0/—/障碍命中点（子弹被截停处） | **已接**（`BattleImpactFxDriver` 着墙档——`fx_impact_wall` 世界位；表面分流待地图表面标记） |

- **静默门**：`SimView.OnFrameEvents` 在回滚重放/和解段丢弃事件（"一次命中只响一次"是结构性保证）——伤害数字**不自行防重**，实现者不得在消费者内再加去重。
- 命中点 `Pos` 为 Sim 空间，消费侧经 Sim→世界换算（与 `SimView` 同式）。

## 4. 分层契约

### 4.1 命中分发器 `HitFeedbackDispatcher`（App/Presentation；装配 `ProcedureBattle`）

> **实施修订（批A 落地时）**：分发器为 `EventSink` 的**并列订阅者**（多播——`SimView` 既有编排方接线契约"具体表现（VFX/音效/飘字）由编排方接线"），**不做动画缝收编**——`CharacterLocomotionDriver` 的"构造即自订阅"是被帧事件开火全链 EditMode 用例锁死的既有契约，收编无功能增益、纯破坏面。契约类型（`HitFeedbackContext`/`IHitFeedbackConsumer`/`HitLocalRole`）落 `LiteView`（与 Sim 事件同域）；`HitLocalRole` 独立零引擎文件（L1 源链接前提——`HitFeedback.cs` 含 `Vector3` 不入 L1）。

- **并列订阅** `SimView.EventSink`（构造挂上、Dispose 摘下）；逻辑帧边界批量转发（静默门之后）。
- 事件前解析进上下文 `HitFeedbackContext`：`kind / 槽位（实体 Id 解析，失败=-1）/ 对方槽位 / 命中点世界位 / 数值 / 本地角色（造成/承受/旁观）`——一次解析、集中消费。
- 消费者面（表现扩展点）：`IHitFeedbackConsumer` 注册（**注册序转发**）——伤害数字为首个消费者；命中特效/音效/受击死亡动画随各自批注册，注册面即扩展点（框架件零改动）。
- 分发器不持业务状态、不做消费者裁决（本地过滤在伤害数字消费者内做——特效/音效对旁观事件同样可见，过滤不是分发器职责）。

### 4.2 伤害数字核心纯件（`Assets/LiteView/DamageNumbers/`，**文件零引擎引用** → L1 经源链接直测，`InputService` 先例）

- **聚合器**：同 **(目标, 角色, 爆头档)** 合并窗口（窗口内命中累加＋重置淡出——连击合并语义，即 DNP `CombinationSettings` 的自研对应物）。**爆头档进合并键**（用户裁决）：爆头只并爆头、普通只并普通，两档各成一条互不合并；**旧"暴击粘滞"已废除**（打头再打身体不得把普通那发染红）。窗口/初速/淡出等**表现参数落纯件常量或样式档位**，**禁入 `CombatConfig`**（BuildHash/digest 源集，表现参数不得搅联机身份）。
- **轨道数学**：初速/推挤/插值/淡出/按值缩放/抖动 → 每渲染帧输出 `(pos, alpha, scale)`；参数表驱动、可确定性测试。**双钟口径**：升浮/抖动/出场缩放用**出场钟**（合并不重置，数字不跳回起点），淡出用**最后活动钟**（合并即重置，连击驻留）。**当前导出常量**：`HoverHeight=0.25`、`RiseSpeed=1.8`、`RiseDecel=1.2`、`FadeStart=0.55`、`FadeEnd=1.10`、`MergeWindow=0.45`、`PopSeconds=0.09`、`PushDistance=0.28`、`AnchorFollowSpeed=14`（锚点追随速度 m/s——合并时锚点目标改最新受击点，恒速靠近；见 §4.3）、`CritShake=0.22s/0.06m/46Hz`。推挤用**种子黄金角散布**（同种子同散布，合并条目保持原种子 ⇒ 运动不漂）。
- **样式解析 `IDamageNumberStyleResolver`**：值/暴击/承受 → 档位（**渐变双端色**/字号/格式化/缩放/**材质档键**）；**初版常量表实现**，样式编辑器批（《UI编辑器工具专项设计》§3）落地后换 token 来源——**接口不变，消费者零改动**。**当前四档**（顶色→底色 / 字号）：造成白 `(1,1,1)→(0.84,0.87,0.94)`/5f、**造成爆头亮红** `(1,0.36,0.24)→(0.88,0.05,0.04)`/6.5f、承受暗砖红 `(0.95,0.30,0.24)→(0.62,0.10,0.08)`/5f、承受爆头深红 `(0.78,0.16,0.12)→(0.45,0.02,0.02)`/6.5f（批C 口径：**顶亮底暗**——光源在上、同色系明度差，DNP Gold 同向；顶亮度单调 白>亮红>暗砖>深红）；按值分带缩放 **≥100→1.20／≥50→1.12／≥20→1.05**（与角色档正交）。**已知取舍**：红被"爆头"与"承受"两档共用，敌我不再靠颜色单独区分（改亮暗＋字号＋抖动＋光晕材质）；若要完全解耦需把承受档迁到另一色相——须单独裁决。
- **材质档键 `DamageNumberTier`**（批C 新增，纯件零引擎）：(角色, 爆头档) 四档枚举——**调色板查表键**（`DamageNumberMaterialSet`，装配点整组注入；"档位→外观"仍单源在解析器，材质只是档位的机械映射）。
- **格式化**：**`KThreshold = 10000`**——小于阈值走原位数；≥ 阈值走 K 简写：**整千不带小数**（`20K`）、带余保留一位小数（`12.3K`），`InvariantCulture`（跨区域设置小数点一致）。

### 4.3 渲染驱动 `BattleDamageNumberDriver`（App/Presentation；`BattleLaserDriver` 同款纪律：sealed/IDisposable/只读）

- 首版渲染件＝**池化世界空间 TMP**（`ObjectPool<GameObject>`——**不是** `GameObjectPool`）；静态文本不逐帧 layout。**淡出与颜色走每帧写顶点色**（不取网格、不调 `UpdateVertexData`）——与 §5「升级1：TMP 网格提取 + 顶点色淡出」是两种不同实现，当前首版即前者。**批C 起**：颜色写 **`colorGradient` 四角**（顶/底各一对，含 alpha——渐变与淡出同一写入口）；平色写 `tmp.color`（顶色）为**诚实兜底**（底件未开顶点渐变时仍平色 + alpha 淡出）。已核 `TMP_SDF.shader`：顶点色 alpha 乘到最终输出，描边/软影/光晕随淡出**不残留**。
- **逐档材质（批C）**：`DamageNumberMaterialSet` 调色板按 `DamageNumberTier` 取材质（描边/软影/光晕；`_FaceColor` 保持白——面部颜色只走顶点渐变）；条目**出场时**按档赋 `fontSharedMaterial`（档含爆头键 ⇒ 条目内恒定，合并不换）；调色板 `null` = 不碰材质（测试/降级形态，底件默认材质即造成档）。装配点四档材质任缺 → **整组不注入**（警告，不做部分档位混合观感）。
  - **billboard 朝向**：底件 `fx_damage_number.prefab` 只有 Transform+MeshRenderer+TextMeshPro（**无 `TMP_Billboard`**、初始旋转 identity），故朝向**必须由驱动每帧写**。取 **`−toCam`** 使 TMP 的 −Z 正面朝相机（传 `+toCam` 会镜像文字）；up 取世界上方向（跟相机俯仰会侧翻）。
  - **相机来源经 `cameraOf` 注入**（对局渲染相机/Cinemachine brain 的 OutputCamera）；null 时回落 `Camera.main` 且 `camScale` 恒 1、不跟随朝向（诚实退化）。相机距离缩放三常量：参考距离 **22 m**、钳制 **[0.6, 1.4]**。
- **时钟**：合并窗与寿命走注入的 **`IWorldClock`**（世界钟——VfxService 同款纪律，变速/暂停语义内建）；**禁累加渲染帧 delta**——实测编辑器背景态 `Time.unscaledDeltaTime` 整体通胀数倍（unscaledTime 跑 2.6~3.5 倍墙钟），累加会把淡出窗压扁；世界钟恒 1:1。
- 锚定：**受击点**（命中事件世界位＝弹道命中部位；用户裁决"飘字应该在受击部位飘"）——不随实体移动，实体 despawn/视图回收无影响（不悬挂、不瞬移）。**合并锚口径（用户裁决 2026-10-11"合并时挪到最新受击点"）**：连击合并时锚点**目标**改为最新一发的受击点，锚点以**恒速**（`AnchorFollowSpeed`）逐帧靠近——平滑滑行、不瞬跳（步长夹 [0, 0.1s]，首帧/时钟回拨不吃负步长）；起条目时目标=当场受击点（无位移）。
- 预算：同屏上限常量（起始 24）；超限淘汰最旧并**记日志不静默丢**（UiFx 先例）。
- 相机距离缩放：驱动读**注入的对局渲染相机**（`cameraOf`；null 时回落 `Camera.main`）换算——参考距离 22 m、钳制 [0.6, 1.4]（§4.3）。

### 4.4 样式面

- 颜色/字号/渐变档位唯一来源＝`IDamageNumberStyleResolver`；样式编辑器落地前为常量表、后换 token（§4.2）。**材质档**（描边/软影/光晕）为纯件枚举键 `DamageNumberTier` → 资产映射（`DamageNumberMaterialSet`）。
- **批C 落地口径（2026-10-11）**：**未归置 DNP 资产**——字体沿用 LiberationSans（刻实 DNP demo 同源底字；Apache 许可、资产可入库）；描边/软影/光晕用 **TMP full SDF 原生材质**（`TextMeshPro/Distance Field` 的 OUTLINE_ON + UNDERLAY_ON + GLOW_ON；Mobile 版无 GLOW 不用），`Sprite Overlay.shader`（`ZTest Always`——HUD 叠加口，世界空间飘字走正常深度）仍**不直用**；底件 `enableVertexGradient=true` + `fontStyle=Bold`（TMP faux bold——LiberationSans 无独立 Bold 字面）。
- **资产与单源**：四档材质 `Assets/ShareResource/FX/fx_damage_number_{caused,caused_crit,received,received_crit}.mat`（YooAsset「FX」组目录收集，随底件同组）＋底件 `fx_damage_number.prefab` 均由 `AgentScripts/BuildDamageNumberAssets.cs` 构建/刷新（幂等；参数单源在 builder；经 pipeline `run_script` 执行——资产禁直改）。**平台坑登记**：Unity 材质的序列化属性表在资产创建时随 shader 固化——脚本切 shader 后 full-shader 专属属性（Glow 系）**静默写不进**（本批实踩）；builder 处置 = 换 shader 即**删资产重建** + 参数写回**自校验**（读回不符即抛）。
- 运行时取件：`BattleViewAssets.AcquireDamageNumberMaterialsAsync` 按路径四件成组取（任缺整组不注入 + 警告；缺件静默降级口径同底件/激光/音效）。

## 5. 渲染件三级升级路径（留作扩展，不预建）

| 级 | 形态 | 触发判据 |
|---|---|---|
| 首版 | 池化世界空间 TMP 直渲（批B 形态） | 默认——8 人对局＋同屏预算下 Profiler 无压力即止 |
| 升级1 | **TMP 网格提取**：`ForceMeshUpdate → textInfo.meshInfo → 裸 Mesh + MeshRenderer + 顶点色淡出`（DNP 同款技巧，§6） | Profile 证据：TMP 对象/layout 开销或 GC 显著 |
| 升级2 | **真合批**：自研 MeshBuilder＋数字图集（0-9/+/%），N 个活跃数字拼单 Mesh 单材质 **1 draw call**（超越 DNP——DNP 无跨数字合批） | Profile 证据：draw call/SetPass 成瓶颈（100+ 同屏需求） |

架构保证：驱动只消费轨道数学输出 `(pos, alpha, scale)`——渲染件是**可替换实现**，升级不动纯件/分发器/样式面。

## 6. DNP 技巧炼化口径（读码实证 2026-10-06，`DamageNumber.cs`/`DNPUpdater.cs`）

- **弃用裁决不变**：运行时不引入、不拷源码（DNP 是 MonoBehaviour＋Inspector Settings 形态，硬搬破坏驱动/纯件结构）。
- **可炼技巧**（Unity 公开 API 标准用法，非 DNP 专利）：

| 技巧 | 源码事实 | 炼化落点 |
|---|---|---|
| TMP 作"文本→网格"后端 | `textMeshPro.ForceMeshUpdate → textInfo.meshInfo → CopyMeshInfo` 裸 Mesh，随即停用 TMP | 升级1 |
| 顶点色驱动淡出 | DNP 走 `mesh.GetColors` 逐顶点 alpha（升级1 的裸 Mesh 路线）；**本项目首版更简——直接每帧写 `tmp.color`（TMP 顶点色属性），不取网格** | 首版已用（零 DNP 代码）；升级1/2 时若改裸 Mesh 再落到 `GetColors` 口径 |
| **顶点渐变面部** | DNP 样式资产走 TMP `enableVertexGradient` 四角（Gold = 白→暗金） | **批C 已用**（顶→底四角，驱动逐帧写入含 alpha——见 §4.3） |
| **描边/软影/光晕材质** | DNP 每样式一个 TMP 字体资产 + 材质（OUTLINE_ON/UNDERLAY_ON/GLOW_ON，full SDF shader） | **批C 已用**（自研四档材质，未拷其资产；见 §4.4） |
| 双渲染器交叉淡入 | `meshFilterA/B` 同 mesh 双材质，淡入完关 B | 仅描边/发光双层需要——批C 评估**不需要**（TMP 单材质三层特性已足） |
| 共享 tick 向量 | `DNPUpdater` 80Hz 分桶＋billboard 向量一帧一算全数字共享 | 驱动 Tick 内共享相机基向量 |
| 连击合并语义 | `CombinationSettings`（逻辑合并，非渲染合批） | §4.2 聚合器 |

- **纠偏记录**：DNP **无跨数字渲染合批**——每数字独立 `MeshRenderer` 独立 draw call（淡入期双渲染器＝2 个）；其 "Combination"＝逻辑合并。真合批是本项目升级2 的超越点。

## 7. 批次与验收

## 8. 总验收口径

- 功能对齐 DNP §4.4 清单（**碰撞项除外**——俯视角垂直上浮＋合并窗口已消解叠字，不复刻 2D 物理碰撞）。
- 口径生效：本地造成/承受过滤＋承受染红；世界空间；一次命中一次飘字（静默门结构性回归）；despawn 不悬挂；预算超限有日志。
- 观感定档以 DNP demo 对照为准（差距是调参时间，不是能力差距——§5 首版止步判据由 Profiler 说话）。**批C 已落 DNP 观感技法**（描边/软影/光晕/渐变/Bold）；逐项精调（描边厚度/光晕强度/渐变深浅）以用户实机试玩为准——参数单源在 builder（材质）与解析器常量（渐变），不动结构即可对表。
