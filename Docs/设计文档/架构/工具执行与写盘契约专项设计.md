# 工具执行与写盘契约专项设计

> **版本**：0.1（2026-10-21）
> **定位**：裁决开发工具一次性动作的执行请求、结果报告、写盘追踪、dry-run 与回滚契约；覆盖生成物与文件写盘，资产写盘留 L2-C。
> **不做的事**：不重写工具业务算法；不统一 IMGUI/Odin 或交互式窗口；不把 GM 页/窗口改成 one-shot 动作；不改 Sim/协议/BuildHash 语义。
> **冲突裁决**：入口/清单/CLI 形态以[开发工具链平台专项设计](开发工具链平台专项设计.md)为准；生成物语义以[生成器工具箱专项设计](生成器工具箱专项设计.md)、[烘焙工具箱专项设计](../游戏玩法/烘焙工具箱专项设计.md)为准；本文件只裁决执行与写盘这一层。
> **关联**：[开发工具链平台专项设计](开发工具链平台专项设计.md)、[开发工具链平台分层设计](开发工具链平台分层设计.md)（L2-C/D 与 L3 的总体分层/批次）、[修改指南](../../修改指南.md)、[技术支持](../../工具链/技术支持.md)。

## 1. 定位

L2 解决的是执行结果不可信与写盘可能越界/覆盖：

- 动作执行前可预览（dry-run），不写盘；
- 执行中所有写入经过 `ToolWriteScope`，可追踪、可校验、可回滚；
- 执行后统一 `ToolResult`（状态/摘要/详情/修复提示/变更集）；
- 清单声明 `outputs/safety`，Hub/CLI/文档共用。

**边界**：只覆盖 `action` 类一次性动作与生成文件写盘。`window`/`page` 是交互面，保留自己的 UI 与生命周期；GM 页与绑定/编排/回写窗口不在本契约内，后续若要接只接结果摘要。

## 2. 核心类型

```text
ToolRequest
  ToolId, DryRun, AllowedOutputs[], Actor(Hub/CLI/Test), ProjectRoot

ToolResult
  Status(Ok|Warning|Aborted|Failed)
  Summary, Details, FixHint
  Changes: ToolChange[]
  DryRun, Duration
  Undo: Func<ToolResult>?   // 仅实际写入且可回滚时非空

ToolChange
  Path, Kind(Created|Updated)
  BeforeHash, AfterHash, Written

ToolWriteScope
  ProjectRoot, AllowedOutputs[]
  DryRun, Changes[]
  WriteText(path, content, kind) -> Unchanged|Planned|Written
  Undo() -> ToolResult
```

### 2.1 状态语义

| 状态 | 含义 | UI |
|---|---|---|
| `Ok` | 执行成功（允许零变更） | 绿色摘要 |
| `Warning` | 成功但有需要人看的信息（未保存场景、截断、提示） | 黄色摘要 + 详情 |
| `Aborted` | 预期失败（前提缺失/校验失败），带 `FixHint` | 红色摘要 + 修复提示 |
| `Failed` | 程序员错误/未预期异常 | 红色 + 异常摘要，不吞栈 |

预期失败不再以裸字符串 `ABORT` 直接进文本框；legacy 工具通过 `FromLegacy` 适配，识别 `ABORT` 前缀。

### 2.2 写盘规则（ToolWriteScope）

1. 只允许写 `ProjectRoot` 下的路径；`..` 逃逸直接拒绝。
2. 只允许写清单 `outputs` 声明的路径；支持精确文件与以 `/` 结尾的目录前缀；未声明写入直接失败。
3. 生成文本 UTF-8 无 BOM、内容原样写入；生成器负责固定头/LF。
4. `write-if-changed`：内容逐字节相同 → `Unchanged`，不触碰文件。
5. `DryRun`：只记录 `ToolChange(Written=false)`，不创建目录、不写文件。
6. 实际写入前快照旧字节；`Undo` 逆序恢复：新建文件删除，更新文件回写旧字节。
7. 资产写入（Prefab/Scene/Material）**不在本契约**；L2-C 再引入 Unity Undo/AssetDatabase 语义，当前 `undo` 可声明 `none`。

## 3. 清单 v3

新增可选字段：

```jsonc
{
  "schemaVersion": 3,
  "tools": [
    {
      "id": "baking.body",
      "kind": "action",
      "outputs": [
        { "path": "Assets/LiteSim/Core/Scripts/BodyBake.g.cs", "kind": "generated" }
      ],
      "safety": {
        "dryRun": "supported",   // supported | unsupported
        "undo": "file",          // file | asset | none
        "confirmation": "none"   // none | required
      }
    }
  ]
}
```

- `outputs[].path`：仓库相对路径或目录前缀（以 `/` 结尾）；`kind` 为 `generated/source/data/asset`。
- `safety.dryRun=supported`：Hub 显示预览开关；CLI `run --dry-run` 只对声明 supported 的工具开放（L2-D）。
- `safety.undo=file`：写盘 scope 可回滚文件；`asset` 留给 L2-C；`none` 不显示回滚。
- 未声明 `safety` 的工具按 `dryRun=unsupported/undo=none/confirmation=required` 处理（保守）。

## 4. Hub 动作页

- 支持 dry-run 的动作显示“仅预览（不写盘）”开关；按钮文案“预览变更/执行”。
- 结果区显示状态、摘要、详情、变更列表（路径/新建或更新/是否写入/前后 hash）。
- 预览结果有变更时显示“应用变更”（关闭 dry-run 再执行）；实际写入后若结果带 Undo 显示“回滚上次写入”。
- 不支持 dry-run 的动作保持原行为；写资产/发布类仍按 `writes`/`destructive` 确认。

## 5. 迁移范围（L2-B）

| 工具 | 写盘点 | 目标 |
|---|---|---|
| 身位/枪口/持枪/根位移烘焙 | `BakeTargets.WriteGenerated` | `ToolWriteScope`、dry-run、write-if-changed、文件 Undo；新增 Hub action 入口 |
| 地图烘焙 | `BakeTargets.WriteArtifact`（`Luban/Data/Map/`） | 同上；outputs 用目录前缀 |
| SimTrig 查表 | `SimTrigTableGenerator` 无条件 `File.WriteAllText` | Hub action 走 scope；`Generate()` 自身改 write-if-changed |
| BindGenerator | 主文件 `WriteIfChanged` 覆盖 | 主文件只创建不覆盖；Designer 保持 write-if-changed；拒绝写入共享源集目录 |

**不迁移**：HeadHitLineTuner 交互调带（保留工具内导出）；UI 样式/写回/绑定 hash（L2-C）；GM 页；CLI 脚本内部写盘（L2-D 只做清单/参数层）。

## 6. 测试

- `ToolWriteScopeEditModeTests`：dry-run 零写盘、allowlist 拒绝、`..` 拒绝、write-if-changed、Undo 恢复/删除。
- `EditorToolCatalogEditModeTests`：清单 v3、outputs/safety、迁移动作的 dry-run 声明、handler 1:1、菜单路径守卫。
- 烘焙动作：在现有 `SimMapBakerEditModeTests`/BodyBake 对账基础上，验证 scope 的变更集与幂等；不触碰真实 prefab 的场景用合成根。
- `BindGenerator`：主文件存在时不覆盖；共享源集目录拒绝。
- CLI/Python：schema v3、outputs/safety 校验、生成索引含安全列。
- 回归：L1、Doc、Unity 编译、定向 EditMode；全量 L2 夜间。

## 7. 非目标与顺序

- L2-A：契约壳 + manifest v3 + Hub 动作页 dry-run/undo + 测试。
- L2-B：烘焙/SimTrig/BindGenerator 写盘安全（本文件 §5）。
- L2-C：资产写盘（UI 样式/写回/内容样例）引入 Unity Undo/预览。
- L2-D：CLI `run --dry-run`、参数 schema、`refresh_hash` 严格失败。
