## 0. 契约摘要

| 项 | 内容 |
| --- | --- |
| 输入 | 云主机（+Mongo 副本集）、测试者 IP 名单、PSK/ticket 密钥（Secret 注入）、表数据（与客户端同源 `.bytes`） |
| 输出 | 封闭测试环境：一键游客 → 进房 → FFA 对局（规则闭环）→ 结果落库可查 → 重启不丢不重 |
| 失败语义 | 缺密钥拒启（信封/票据 fail-closed 已有）；白名单外不可达（网络面）；结算失败进 Outbox 重试，不阻塞对局 |
| 测试层级 | 批A：L1 + 本机 L3 闭环保真；批C：本机 Unity 验收；端到端手工验收（§6） |
| 预算 | 单云主机 + 单 Mongo（副本集形态）；容量不做承诺（≠R4/G5 验收） |

## 1. 范围与裁决

- **用户裁决（2026-10-08）**：网络形态 **B（公网 + IP 白名单封闭测试）**；登录形态 **游客一键**；范围含**房间服闭环**（身份→对局→结算→查询→重启恢复全链）。
- **红线口径**：本部署属**封闭测试例外**——白名单仅测试者可达，非公开暴露；**部署门禁（IL2CPP 真机核证、密钥轮换/批2 随 R4）延续不变**，本环境不得作为"可发布"判据，不得对外宣传/开放（§7）。
- **不做**：大厅/Lobby、账号密码体系、库存/Loadout、Android 真机、真云 CDN、R4 运维套件（OTel/灰度/实例注册/多实例调度）。

## 6. 端到端验收（封闭测试达成定义）

1. 白名单外**连不上**（UDP 与 HTTPS 均不可达）
2. 一键游客 → 拿访问令牌 → 分配后拿 Join Ticket → 进房成功；无票/错票/过期被拒
3. 打完一整局（击杀上限或帧时限）→ MatchEnded 可靠到达客户端
4. 结果在 Meta **可查**（按账号）；同一结果重复提交 100 次只落一条（幂等）
5. 杀 RoomServer 重启 → Outbox 待提交**重放**：不丢、不重
6. 重启窗口 Mongo 不可用 → 提交重试；Mongo 恢复后收敛
7. 停机 → 走完**排空 5 步**（Linux 容器形态为容器 stop/SIGTERM；Windows 原生形态为停止计划任务，等价判据同「信号→排空→退出」）

## 7. 红线与边界（必须遵守）

- **不得公开**：白名单 = 测试名单管理，不是公网运营；不发布地址、不开放注册、不做宣发。
- **门禁未闭合**：IL2CPP 真机核证、密钥轮换（批2 随 R4）仍挂账——本环境只能作为封闭测试，不能作为可发布判据。
- 数据最小化：游客随机账号，不采集个人数据；测试期日志与控制台按最小必要保留。
- 本专项 ≠ R4/G5：容量、长稳（24h）、灰度回滚等验收不做承诺。
