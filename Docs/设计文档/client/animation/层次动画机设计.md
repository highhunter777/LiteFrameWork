# 层次动画机设计

> 状态：现行设计。角色动画**驱动层**的权威定义——单机双根层次状态机（战斗根四态 FireIdle/FireWalk/AimIdle/AimWalk ＋ 移动根 Idle/Moving）已落地；后续消费者态（换弹/受击/死亡/回避）待接入
> 更新日期：2026-10-01
> 设计归属：驱动层设计以本文为权威；通道/Profile/Backend 契约仍以《动画模块专项设计》为准，《角色状态与动作专项设计》§7 定义瞄准/开火口径
> 前置阅读：[动画模块专项设计](动画模块专项设计.md)、[角色状态与动作专项设计](../../gameplay/角色状态与动作专项设计.md)（§7 瞄准/开火口径）

## 0. 设计动机

角色动画的形态裁决若以散布在驱动器里的布尔规则集实现（瞄准合成、迟滞锁存、移动门控、起跑终止叠加、驻留计时各写各的），每条单看都对，合起来却是一个**没有名字的隐式状态机**：规则之间靠时序与顺序耦合，加一个语义要在多处同步。本设计把它升成显式层次状态机，用框架现成的 `HierarchicalStageMachine`（LiteFramework/Fsm，UnityLib 同步件）承载，不新造轮子。

登记面随之收敛为两处：`CharacterAnimationIds`（Profile 登记用的 id 常量）与 `AnimationProfile`。"帧事件 → 语义/通道"不再是独立决策表，即状态机的转换条件。

## 1. 分层（上层战斗层 / 下层移动层）——互斥覆盖，单机双根

```
Combat（复合态，根①）               ← 战斗层（上层）：决定"正在干什么"——激活即覆盖移动层
 ├── FireIdle（开火·静止：站姿射击片段按事件重播 / 播完持 AimIdle 循环）
 ├── FireWalk（开火·移动：AimWalk 四向循环——限速走路档）
 ├── AimIdle（瞄准·静止）
 ├── AimWalk（瞄准·移动：4 向 strafe + 步频倍率）
 ├── Reloading（随消费者接入再启用）
 └── Hit / Death / Evade（后续消费者接入时启用）
Locomotion（复合态，根②）            ← 移动层（下层）：默认移动——战斗根不活动时主导
 ├── Idle（速度≈0）
 └── Moving（速度轴 1D 混合 {Idle,Walk,Run}）
```

- **单机双根，互斥覆盖**：每槽**一台** `HierarchicalStageMachine`、两棵根树。在战斗根任一态上=覆盖中（移动根整体不活动）；退回移动根=覆盖解除。框架多根=互斥平级根：单活动路径、跨根迁移=全退全进（LCA=0）——正是"覆盖/解除"的语义。**双根成立的前提**：任何时刻只有一层驱动身体（半身叠加不参与生产）。
- **战斗层不可被移动层打断**：退根**唯一条件 = 窗尽 ∧ !IsAiming**（瞄准在场即充值窗，故瞄准系与开火系同一条退根路）。**移动事实（速度/锁存）永不触发退根**——只驱动战斗根内的 idle↔walk 轴（FireIdle↔FireWalk、AimIdle↔AimWalk）与退根时的叶选择。打断只来自战斗层家族自身（换弹/受击/死亡/回避——权威事件），不是移动层。
- **覆盖的机制面=通道接管**：战斗动作全走 **FullBody 通道**（无 Mask 整身覆盖）。**各根自管本根通道**：移动根 OnLeave 收 Locomotion 通道（停 MoveBlend 句柄）、战斗根 OnEnter 播 FullBody；反向同构（战斗根 OnLeave 收 FullBody、移动根 OnEnter 重提交 MoveBlend 按当前速度权重）。HSM 事务序（LCA 下先深→浅退出、再浅→深进入）**结构性保证先停旧通道再开新通道**——同帧无两层写身体，单一写入责任成立。
- **战斗根状态 → 通道映射**（全部 FullBody）：
  - `FireIdle` → `AimIdle_Shoot`（2× 速——Fire 事件**按重播**：在播吞/已完重起；**播完窗内持 `AimIdle` 循环**——窗内保持 clip；停步进态同持站姿）
  - `FireWalk` → `AimMoveBlend`（4 向混合**循环** + 倍率；**不播站姿射击**——无移动射击资产，反馈枪口特效）
  - `AimIdle` → `AimIdle` 单片段循环；`AimWalk` → `AimMoveBlend`（4 向 + 播放倍率 1×..2× 钳制——限速下恒≈1）
  - 后续消费者态：`Reloading`→`Reload`、`Hit/Death/Evade`→`Hit1/Die1/Evade`
- **移动根状态 → 通道映射**：`Idle`/`Moving` 同形态 `MoveBlend`（Locomotion 通道，权重就地连续；态界只服务诊断直读与转换表，跨越不重提交）。
- **半身机构（UpperBody 通道）**：**保留不拆**（后端分层混合/AvatarMask/能力位与契约用例零改动），当前生产消费者为 0——未来需要半身叠加时按消费者重新启用。
- **Profile 仍是绑定单源**：HSM 只持有**状态 ID**，不持有片段名——`AnimationProfile` 的 id→binding/loop/speed 登记面保留。枚举 `CharacterAnimationIds` 仅作 Profile 登记用的 id 常量。当前登记通道：Fire/AimIdle/AimMoveBlend → FullBody，MoveBlend → Locomotion，Reload 留 UpperBody。

## 2. 状态事实与转换（谁驱动状态机）

**输入事实**（每渲染帧采集，沿用驱动器来源，零新数据面；**单机单上下文**）：
- `IsAiming`（SimView.IsAiming，Sim 权威）
- `Speed` / `MoveDir` / `Rotation`（视图帧间位移与朝向）
- **`IsMoving` 锁存**——迟滞公式单源在 `LocomotionBlendMath`（进 0.6 / 出 0.3 m/s）；**原始速度的纯函数**，由驱动器每帧算并喂入——战斗根 idle↔walk 轴（两族共用）与退根叶选择**同吃这一个锁存**，机内无迟滞散字段
- 帧事件（Fire——经 SimView.EventSink 静默门，§8 接缝纪律不变）
- 片段完成终态（backend Tick 返回的 done mask）

**开火窗（战斗根复合态持有，Sim 权威 + View 同源镜像）**：**开火态＝FireIdle/FireWalk 状态族所在的射击窗语境**——自开火判定起、最后一次开火后窗长内的整段。窗长**单源** `CombatConfig.FireStanceFrames`（当前 `= 60`，即 1s @60Hz；**用户实时调参项**，改窗长只动这一处）；窗与开火动画时长**解耦**——开火动画（≈0.48s）小于窗，**不变式：窗长 ≥ 开火片段播放时长**，否则事件后窗先于 clip 尽会截断在播射击片段（装配期校验）。窗长影响模拟行为 ⇒ 进 `CombatConfigDigest`（联机身份）。Sim 侧 `EntitySlot.FireStanceFrames`（帧计数）在 `ShootingSystem` 开火判定点置窗（与 `FrameEventKind.Fire` 事件**同点**⇒ 两层窗同触发同长度），`InputSystem` 每逻辑帧统一递减（整数计数 ⇒ 确定性；缺席/空输入帧与死亡实体照常推进），瞄准帧（`ButtonAim` 在场）同样置满同一字段；**事件刷新＝重置到满窗**（上限即窗长，不累加）。该字段经**公共快照 SlotDelta（字段 19）与公共 checksum** 同步（回滚基线可重建窗）。View 侧 `FireHoldSeconds = FireStanceFrames / TickRate` 派生——**改窗长只动一处**。

**窗内保持 clip**：Fire 状态族持续整窗、**窗内永远有 clip 在播**——
- `FireIdle`：Fire 事件 → 播一轮 `AimIdle_Shoot`（2×，在播吞/已完重起）；**clip 播完 ∧ 窗在 → 态内切 `AimIdle` 循环**（不迁移——"开火动画播完进入 aim 动画循环播放"）；新事件 → 重播射击片段 + 窗重置满窗。
- `FireWalk`：`AimMoveBlend` 四向循环（同窗规则——"firewalk 也一样"）；新事件只续窗（不播站姿 clip，反馈枪口特效）。
- **窗尽＝保持 clip 的终点**：根单点裁决转移——Fire 状态的通道所有权终止、移交次态：**同形态次态就地续播**（AimIdle/AimWalk 的循环与 Fire 态持的是同一 clip——续播保相位，不重提交不闪动）；**异形态由次态提交替换**（移动根 MoveBlend 提交替换、淡出收尾；Death 等打断态同理）。离场不做无条件 Stop。
- **离开开火态即取消限速**（`InputSystem`：瞄准 ∨ 开火态 → `AimMoveSpeed` 走路档——**限速时间＝开火态时间＝射击窗**）：自然结束＝窗尽，被打断＝打断态落地时在其建立点清窗（死亡不特判——输入已丢弃、窗自然衰减；换弹/回避接入时**两端同步**补清窗纪律）。

**退根/降级裁决单点**：窗递减与退根/降级目标选择**收在战斗根复合态 OnUpdate 单点**——窗尽时按 `IsAiming × 锁存` 选目标：IsAiming → Fire* 降级 Aim 叶（AimIdle/AimWalk，同形态续播保相位），否则 → 移动根叶（Idle/Moving）。叶只发**层内** idle↔walk 轴请求，且**先判语境解除**（根已挂退根请求时叶放弃一切层内请求——防 last-wins 覆盖与一帧闪现）。

**转换表**（加粗行=退根路）：

| 根 | 从 | 到 | 条件 | 说明 |
| --- | --- | --- | --- | --- |
| 战斗 | AimIdle | AimWalk | 锁存置位 | 迟滞进入（进 0.6 m/s） |
| 战斗 | AimWalk | AimIdle | 锁存清零 | 迟滞退出（出 0.3 m/s） |
| 战斗 | FireIdle | FireWalk | 起跑（锁存置位）→ **停在播射击 clip**、窗不清 | 起跑不退态，保持射击语境 |
| 战斗 | FireWalk | FireIdle | 停步（锁存清零、窗在）→ 持 AimIdle 循环、不重播 | 停步回落持枪站姿 |
| 战斗 | AimIdle | FireIdle | Fire 事件 → 播一轮 clip（2×）、置窗 | 首发提交 |
| 战斗 | AimWalk | FireWalk | Fire 事件 → 置窗（**同形态就地续播**、不重提交） | 开火语境覆盖瞄准态 |

| **战斗** | **Fire\*** | **移动根叶** | **窗尽 ∧ !IsAiming** → 保持 clip 由 MoveBlend 提交替换淡出 → 按锁存选 Idle/Moving | **退根路** |
| **战斗** | **Aim\*** | **移动根叶** | **窗尽 ∧ !IsAiming**（ADS 解除后窗尾护持完毕）→ 按锁存选叶 | **退根路** |
| 移动 | Idle ↔ Moving | — | 锁存置位 / 清零（同形态就地调权重、跨越不重提交） | 移动根内轴 |

| 战斗 | 任意 | Death/Hit/Evade/Reloading | 各权威触发（死亡/受击事件等）——**打断**：Sim 侧建立点清窗、在播收口 | 后续消费者态 |

- **提交门控结构化**：fire 事件按锁存**路由**进 FireIdle/FireWalk，站姿 clip 只存在于 FireIdle；移动开火的反馈由枪口特效承担（`AimWalk_Shoot` 家族缺资产）。
- **迟滞口径**：锁存=驱动器算的输入事实，公式单源；机内无散字段。
- **事件路径**（逻辑帧边界，Tick 之外）：Fire 事件路由——Fire* 态内走合并口（续窗/吞/重起）；Aim*/移动根叶 → Request(Fire 叶按锁存)。迁移在下次机.Tick 的 Advance 应用，不入队跨帧。
- **喂序**：测速 → 算锁存 → 喂上下文 → 机.Tick（根→叶 OnUpdate，事务帧末应用）→ 播放器 Tick。

## 3. 不动的东西（明确边界）

- `AnimatorAnimationBackend` / `AnimationLayerGraph` / `ChannelNode` / `ChannelBlendAdvance` / 遮罩机构 / `UpperBodyMaskFactory` 排除面——**引擎机构零改动**（UpperBody 通道当前零消费者，机构与契约用例保留）。
- `AnimationProfile`/`AnimationDefinition`/Blend 数学（`LocomotionBlendMath`）——绑定与权重数学不动（只改登记的通道列）。
- 通道语义（Locomotion/UpperBody/FullBody）与淡化时长、截断策略、节点稳定用例。
- `IFrameEventAnimationConsumer` 接缝与 §8 静默门、合并规则——只换消费者内部实现。
- `[Anim][diag]` 诊断面升级为 HSM 状态直读（单机 `Current` 活动路径——"Combat/FireWalk"、"Locomotion/Moving"），IModuleStats 聚合照旧。

## 4. 状态机载体与后续消费者态

- **载体＝框架 `HierarchicalStageMachine`**（LiteFramework/Fsm）：平机=退化形态，两者已有对拍用例，复用该测试基建。状态机的**提交序列必须与既有手工规则等价**——同输入序列 → 提交序列一致，作为行为对拍的 oracle。事务式（一帧一事务）：全部转换为单跳 Request（跨根全退全进=覆盖切换）。
- **后续消费者态**（Reloading / Hit / Death / Evade）：全部 FullBody、同战斗根；进入即打断开火态（Sim 建立点清窗），同根内 Request（last-wins，优先级路由随其设计定稿）。按"不预建无消费者"纪律等 G2 落地。

## 5. 风险与对策

- **HSM 是事务式（一帧一事务）**：全部转换为单跳 Request（跨根全退全进=覆盖切换）；FireIdle 连发重起走态内合并口（不迁移、不触发 LCA）；退根/降级由根单点裁决，叶先判语境——无 last-wins 竞速。
- **战斗层不可被打断的边界**：移动事实只在层内用——FireWalk 中窗尽 ∧ 仍在移动 → 退根选 Moving 叶，保持 clip 由 MoveBlend 替换、限速同帧解除；反向（移动中开火）随时可进战斗根——**单向可进、退出只走战斗层自己的条件**，正是"上层覆盖下层"的语义。
- **窗长独立常量的结构属性**：开火动画（≈0.48s）小于窗——**播完由 aim 系循环填满窗口**（窗内保持 clip），这正是"窗与动画解耦"的落点；单发点射后走路档与持枪语境持续整窗；**不变式：窗长 ≥ 开火片段播放时长**（资产改长/倍率改值 ⇒ 常量必须跟改，装配期校验）；改窗长只动 `CombatConfig.FireStanceFrames` 一处。
- **窗尽移交不闪动**：Fire* 持的 aim 循环与 Aim 叶是**同一 clip**——窗尽转移走"同 ID 在播即续播"（保相位、零淡化、零重提交）；异形态（移动根/打断态）由次态提交替换（后端淡出收尾）。对拍用例钉死"窗尽无 Interrupted、无句柄重建"。
- **跨根切换频率**：ADS/开火窗每次翻转=全退全进+Stop/重提交 Locomotion——与既有"瞄准形态切换"同频同本（有界尾部/节点稳定用例已覆盖）；切换接缝的淡化观感归真机手测。
- **站定开火的视觉等价假设**：`AimIdle_Shoot` 整身播与"AimIdle 基础+上半身叠加"预期近等价（同包瞄准姿态族）；真机验收归手测，不等价再议腰射专用片段。
- **同形态跨越不重提交**：Idle↔Moving 同 `MoveBlend`、AimIdle↔AimWalk 同瞄准语境内、**AimWalk↔FireWalk 同 `AimMoveBlend`（跨态同形态——进开火族就地续播）**——跨越只走 `UpdateBlendWeights` 就地调权重（重提交会刷 `Interrupted` + 淡化接缝），对拍用例钉死。
- **确定性边界**：HSM 全在 View 侧、不碰 Sim 事实；唯一例外是**开火窗的 Sim 侧镜像**（`EntitySlot.FireStanceFrames`）——由开火/瞄准输入派生、回放可重建，进公共 checksum 与 SlotDelta，联机一致性由 digest 守卫；View 侧动画仍被静默门挡在门外（不播双份）。
- **步频倍率缩放恒≈1**：窗内与瞄准中均被限到走路档 ⇒ `speed/AimMoveSpeed ≈ 1`——倍率缩放成为恒等路径；机制保留，确认无第二用途后可退役。
