# 上云测试页面层级设计

> 状态：设计稿（2026-10-10）——层级图先行；prefab 搭建与 MetaClient 接线归客户端入口批（需 Unity 环境）
> 范围：封闭测试五页——登录（Login）/ 大厅（Lobby）/ 房间（Room）/ 结算（Result）/ 设置（Settings）
> 上位：[上云测试专项设计](../architecture/上云测试专项设计.md)（批C 客户端入口）；[UI制作规范](UI制作规范.md) §9（命名）；[UI框架总设计](UI框架总设计.md)（壳/导航）
> 命名依据：§9 业务命名——`Page_`/`Cot_`/`Bg_`/`Txt_`/`Image_`/`Icon_`/`Clone_`；控件段按出处（模板实例 → 模板段 `Slider_*`/`Toggle_*`/…；裸 UGUI → 控件段 `Button_*`）
> 本地化依据：总设计 §9——文案键 `UI.<页面>.<语义>`/`Common.<语义>`（源表 `#text.xlsx`；页面段 = 页名去 `Page_`）；文案走 `SetTextKey`、数据走 `SetText`；语言切换经绑定索引自动重刷

## 0. 总则

- **命名**：五页均为新页，自出生按 §9 执行（无存量迁移）；根 `Page_<语义>`，与 prefab 文件名同文。
- **结构**：页面根 = Canvas + CanvasGroup（嵌套统一根 Canvas 时继承缩放）；`Bg_*` 全屏出血；内容/交互一律入 `Cot_SafeArea`；层级尽量浅。
- **暴露**：运行时读写的节点设 `BindName`（与节点名同文）——**文案节点同样暴露**（`SetTextKey` 需寻址）；本文 `◄暴露` 标交互/动态面，纯装饰（`Bg_*`/`Cot_*`/`Image_*`/`Icon_*`）不设。列表条目内部**不暴露**——行数据经条目回调上报。
- **本地化（多语言）**：文案一律经 `SetTextKey`/`SetTextKeyPlural` 写入（受控 API；Lua `SetTextKey`/`SetTextKeyArgs`/`SetTextKeyPlural`，参数 ≤4）——**不裸 `SetText`**，否则语言切换不刷新；动态数据（数值/账号/地址/时间）走 `SetText`（数据不是文案，同节点两种语义不混用）。key 见 §8（源表 `#text.xlsx`；缺 key 开发期显 `[key]`）。简便约定：数值拼接统一“标签 {0}”式单节点（避复数陷阱），跨页复用 `Common.*`/`UI.Result.*`；语言切换由 `BindLocale`+`OnLocaleChanged` 自动重刷（不重跑 OnShow；装配点未注入语言服务时 `SetTextKey` 抛）。本批五页不挂 `LTextLabel`（打字机=叙事专用）；字体族/fallback 走统一配置。
- **系统面不内嵌**：Loading / Toast / 错误弹窗 = 系统反馈面（tbuiform 2xx），确认弹窗走 DialogService；页面层级中不出现其节点。
- **模板**：控件来自 `Assets/UI/Widgets` 模板的实例/变体（`Tmp_` 更名随模板批次）；条目模板 `Clone_<语义>` 保持在列表变体内、非激活、子树不设 `BindName`。
- 战斗（对局 HUD）不在本次五页范围。

## 1. 页面关系

```
Page_Login ──登录成功(替换)──▶ Page_Lobby ──进房(分配/选择)──▶ Page_Room ──开局──▶ [对局]
Page_Lobby ◀──返回── Page_Result（结算）◀──MatchEnded───────────────┘
登录/大厅/结算 ──设置入口──▶ Page_Settings（全屏叠加，Back 关闭）
```

- 打开由导航单写者执行；登录成功/进房用替换（返回栈不残留）；设置以叠加打开。

## 2. Page_Login（登录页）

职责：游客一键登录（`POST /auth/guest` 拿访问令牌）；失败页内重试；设置与版本入口。

```
Page_Login
├─ Bg_Login                  全屏底（出血）
└─ Cot_SafeArea
   ├─ Txt_Title              标题（游戏名/测试环境标识）
   ├─ Txt_Status             登录状态/错误原因                     ◄暴露
   ├─ Button_GuestLogin      一键游客登录（失败即重试）             ◄暴露
   └─ Cot_Footer
      ├─ Txt_Version         版本/buildHash
      └─ Button_Settings     设置入口                              ◄暴露
```

| 暴露节点 | 事件/写面 | 接线（待建） |
| --- | --- | --- |
| `Button_GuestLogin` | `OnButton` | MetaClient `/auth/guest` → 成功替换 `Page_Lobby` |
| `Txt_Status` | `SetTextKey`（`UI.Login.Connecting`/`UI.Login.Failed`） | 登录/网络失败原因（系统 Toast 兜底） |
| `Button_Settings` | `OnButton` | 打开 `Page_Settings` |

## 3. Page_Room（房间页）

职责：进房后的等待/信息页——房号与状态、玩家列表、离开；开局由对局规则触发切换。

```
Page_Room
├─ Bg_Room
└─ Cot_SafeArea
   ├─ Txt_RoomId             房号/地图/模式                        ◄暴露
   ├─ Cot_Players
   │  └─ SimpleList_Players  玩家列表（Tmp_SimpleList 变体）        ◄暴露
   │     └─ Clone_PlayerItem 条目（变体内·非激活）
   │        ├─ Txt_PlayerName
   │        └─ Txt_PlayerState
   ├─ Txt_State              等待人数（如“等待玩家 2/6”；连接异常同点）◄暴露
   └─ Button_Leave           离开房间                              ◄暴露
```

备注：Join/席位/快照走现有链路；被拒/超时 → 系统弹窗；离开 = 断开 + 返回大厅。裁决：开局文案 = 等待人数。

## 7. 动效/音效接线注记

依据：《UI效果系统专项设计》§5.1 `UiEffectBinder`（声明式作者面）与 §7 通道适配——规则不在此复制，只列五页的具体接线。

| 页 | 节点 | 效果 | 通道/方式 | 现状 |
| --- | --- | --- | --- | --- |
| 全页 | 页面出现（可选） | 面板滑入 | `Slide`（或转场策略现有） | ✅ 可做 |
| Login | `Button_GuestLogin`、`Button_Settings` | 按压动效（Pulse） | `UiEffectBinder`（动画通道）或 Lua `Pulse` shim | ✅ 可做 |
| Login | 全页按钮 | 点击音 | 音效键 `Ui.Click` → AudioService(Ui) | ⏳ 挂账 E2 |
| Login | `Bg_Login`（可选） | 背景装饰（帧动画/粒子自播） | `Tmp_AnimatedImage` 变体 / 粒子子件直挂 | ✅ 直挂（复位/时钟注意） |
| Lobby | `Button_QuickEnter`、`Button_Records` | 点击音 | 音效键 `Ui.Click` | ⏳ 挂账 E2 |
| Room | `Txt_State` 变更（可选） | 闪烁提醒 | `UiEffectBinder`（Flash，Manual）或 Lua `Flash` shim | ✅ 可做 |
| Room | `Button_Leave` | 点击音 | 音效键 `Ui.Click` | ⏳ 挂账 E2 |
| Result | `Txt_KillCount`、`Txt_Score` | 数字滚动 | `UiEffectBinder`（CountUp） | ◐ UiFx 可用；Lua 面待补 |
| Result | `Button_BackLobby` | 点击音 | 音效键 `Ui.Click` | ⏳ 挂账 E2 |
| Settings | `Toggle_Sound`、`Dropdown_Quality`（可选） | 切换音 | 音效键（细分随 E2 登记） | ⏳ 挂账 E2 |
| Settings | `Button_Close` | 点击音 | 音效键 `Ui.Click` | ⏳ 挂账 E2 |

三条约定（与制作规范 §5 / 效果系统同源，此处只记口径）：

1. **装饰自播可直挂**：粒子/帧动画装饰直接挂 prefab 子件（`Tmp_AnimatedImage` 变体或粒子）——**循环装饰不走 `UiEffectBinder`**；池化复用回基线、引擎时钟（不受 UIClock 暂停）两点验收留意。
2. **事件驱动走入口**：动效一律经 `UiEffectBinder`（`Trigger=Click/OnShow/Manual`）或 UiFx 受控面——禁第二套 tween（`UIWidget.pressFx` 已是同源先例）。
3. **音效禁直挂、语义键登记**：页面/控件不得挂 AudioSource；统一语义键（起步 `Ui.Click`，细分随 E2 音效登记）→ AudioService(Ui)；**现状无 UI 音效接入面**（底座在、消费端缺席，见效果系统 §2），未接通时显性可观测、不静默。

挂账：音效通道（`AudioEffectChannel` + 语义键登记）归效果系统 **E2**；五页为其"真实页面消费者闭环"首批载体（§5.1）。
