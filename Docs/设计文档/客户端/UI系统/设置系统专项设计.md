## 1. 定位

### 1.1 它回答什么

| 问题 | 本文的答案 |
| --- | --- |
| 玩家偏好有哪些项？ | §3 设置项总表：分组 + 字段 + 存储键 + 值域 + 默认值，单一清单 |
| 值存哪、什么时候落盘？ | `GameSettings` 具名字段 + `SettingService` 脏标记三处纪律（§5） |
| 改了什么时候生效、谁负责？ | 每个分组一个"生效器"，构造即应用、改值即应用、顺序固定（§4） |
| Lua 页面怎么读写？ | `Bridge.settings` 平铺旧项 + `graphics`/`display`/`control`/`general` 子表（§6） |
| 面板怎么摆、页签怎么切？ | 左分类导航 + 右面板互斥显隐，页签控件走 `TabGroup`（§7） |
| 桌面与移动差在哪？ | 能力矩阵（§4.6）：显示类桌面专属，其余两端；页面按能力查询隐藏行，不写平台分支 |

### 1.2 与相邻设计的分工

| 相邻面 | 边界 |
| --- | --- |
| `SettingService` / `Setting<T>` | 机制件：字符串字典 + 类型转换 + 脏标记；不知道有哪些项。本文只增字段，不改机制 |
| `GameSettings` | 设置项清单与键/默认值的**唯一单源**（业务层件）；本文所有项都落在这里 |
| `ProductSettings` | Lua 门面 + 值域收敛 + 生效编排；本文把它从"音量+画质"扩成"四组编排" |
| `AudioService` | 分组音量语义不变；"音效"开关仍是 Effect 组门 |
| `QualitySettings` / URP 资产 | 画质档位的真实数值；本文只定义"档位 ↔ UI 档"映射与覆盖语义 |
| `IInputService` / `NewInputIntentSource` | 意图三件与设备源；本文只在设备源资产上做**绑定覆盖**（P2），不改意图契约 |
| `LookTuning`（开发三宏） | GM 实时调参面；优先级高于产品设置，发布形态剥离（§4.4） |
| `LocalizationService` | 语言切换仍走 `Bridge.text.SetLocale`；本文只把它归位到"常规"页 |
| GM / 调试面 | 不改任何判定与数值面；设置项不进 BuildHash 源集（§8.4） |

## 2. 现状与缺口

### 2.1 现状（现行形态）

| 面 | 现状 |
| --- | --- |
| 数据 | `GameSettings` 五项：`volume`（0..1，默认 0.8）、`quality`（0..3，默认 2）、`lang`、`fullscreen`、`sfx` |
| 生效 | `ProductSettings` 构造即应用音量与画质；改值即应用；落盘在设置页 `OnHide`/`Close` 与退出钩子 |
| 页面 | 单列四项（音量滑条 / 音效开关 / 画质下拉 / 语言下拉）+ 只读（账号、服务器、版本）+ 对局中"退出对局"钮 |
| 画质 | UI 三档（低/中/高）↔ 平台档位按名匹配，缺档钳位；三套 URP 资产 `URP-Performant/Balanced/HighFidelity` |

### 2.2 缺口

| # | 缺口 | 后果 |
| --- | --- | --- |
| G1 | `fullscreen` 只存不生效（全仓无消费者） | 死设置项；玩家改了也没用 |
| G2 | 无显示设置：显示模式、分辨率、帧率上限、垂直同步 | 桌面端只能吃 PlayerSettings 默认（1024×768、无边框全屏） |
| G3 | 图形只有整体档位，无渲染缩放/抗锯齿/阴影覆盖 | 中低端机只能在"整体降档"与"忍着卡"之间二选一 |
| G4 | 无控制设置：视角灵敏度、开镜灵敏度、Y 轴反转 | 手感只能改代码常量（`BattleLookController`）或开 GM 调参 |
| G5 | 无按键重绑 | 键位写死在 `Player.inputactions`；`Q` 肩换甚至写死在设备源里 |
| G6 | 页面单列，项数已到 8；再加三组将超过一屏 | 信息密度不可维护，需要分组导航 |
| G7 | Lua 侧静态文案仍走 `SetTextKey`（规范要求静态文案走 `LTextKeyRef`） | 双写者风险；本批新增控件按新口径落地时会出现两套写法并存 |

### 2.3 本设计的裁决

- **分组**：五个页签——音频 / 图形 / 显示 / 控制 / 常规（§7）。
- **图形**：档位预设 + 三项覆盖（渲染缩放、抗锯齿、阴影距离档），覆盖走"影子管线资产"（§4.2）。
- **显示**：显示模式、分辨率、帧率上限、垂直同步，桌面专属；移动端只保留帧率（§4.3/§4.6）。
- **控制**：视角灵敏度、开镜灵敏度、Y 轴反转（本期）；按键重绑列为 P2（§4.5）。
- **删除** `fullscreen`（从未生效，无产品语义），由 `displayMode` 取代，不做迁移（§5.2）。

## 3. 设置项模型

### 3.1 分组与页签

| 页签 | 语义 | 项数 |
| --- | --- | --- |
| 音频 Audio | 输出音量与音效开关 | 2 |
| 图形 Graphics | 画质预设 + 渲染覆盖 | 4 |
| 显示 Display | 窗口形态与刷新（桌面） | 4 |
| 控制 Control | 视角手感（+ P2 键位） | 3（+1 P2） |
| 常规 General | 语言、页签记忆（2 项设置）+ 账号/服务器只读 + 恢复默认 | 2（+2 只读行） |

分组依据是**生效面**（谁把值写进引擎），不是"像不像同一类"：同一生效器的项放同页，改一项的设置页刷新路径才一致。

### 3.2 设置项总表（单源）

字段名即在 `GameSettings` 中的具名 `Setting<T>`；"默认"列是构造参数，也是"恢复默认"的来源。

| # | 组 | 显示名键 | 字段 | 存储键 | 类型 | 值域 | 默认 | 生效器 | 平台 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 1 | 音频 | `UI.Settings.Volume` | `MasterVolume` | `volume` | float | 0..1 | 0.8 | Audio | 全 |
| 2 | 音频 | `UI.Settings.Sound` | `SoundEnabled` | `sfx` | bool | — | true | Audio | 全 |
| 3 | 图形 | `UI.Settings.Quality` | `Quality` | `quality` | int | 0..2（存储钳 0..3） | 2 | Graphics | 全 |
| 4 | 图形 | `UI.Settings.RenderScale` | `RenderScale` | `renderScale` | int | −1 / 70 / 85 / 100（−1＝跟随预设） | −1 | Graphics | 全 |
| 5 | 图形 | `UI.Settings.AntiAliasing` | `AntiAliasing` | `aa` | int | −1 / 0 / 2 / 4（−1＝跟随预设） | −1 | Graphics | 全 |
| 6 | 图形 | `UI.Settings.Shadow` | `ShadowQuality` | `shadow` | int | −1 / 0 / 1 / 2（低/中/高） | −1 | Graphics | 全 |
| 7 | 显示 | `UI.Settings.DisplayMode` | `DisplayMode` | `displayMode` | int | 0 独占全屏 / 1 无边框 / 2 窗口 | 1 | Display | 桌面 |
| 8 | 显示 | `UI.Settings.Resolution` | `Resolution` | `resolution` | string | `"1920x1080"` / `""`（未指定→窗口用默认尺寸） | `""` | Display | 桌面·仅窗口模式可改 |
| 9 | 显示 | `UI.Settings.FrameRate` | `FrameRate` | `frameRate` | int | 0（无限制）/ 30 / 60 / 90 / 120 / 144 | 桌面 0、移动 60 | Display | 全 |
| 10 | 显示 | `UI.Settings.VSync` | `VSync` | `vsync` | int | −1 / 0 / 1（−1＝跟随档位） | −1 | Display | 桌面 |
| 11 | 控制 | `UI.Settings.LookSensitivity` | `LookSensitivity` | `lookSens` | float | 0.2..3.0（倍率） | 1.0 | Control | 全 |
| 12 | 控制 | `UI.Settings.AdsSensitivity` | `AdsSensitivity` | `adsSens` | float | 0.5..1.5（倍率，叠在机制收敛比 0.6 之上） | 1.0 | Control | 全 |
| 13 | 控制 | `UI.Settings.InvertLookY` | `InvertLookY` | `invertY` | bool | — | false | Control | 全 |
| 14 | 控制 | `UI.Settings.Bindings` | `Bindings` | `bindings` | string | JSON 覆盖串 / `""` | `""` | InputBindings | 桌面（P2） |
| 15 | 常规 | `UI.Settings.Language` | `Language` | `lang` | string | `zh-CN` / `en` | `zh-CN` | Localization | 全 |
| 16 | 常规 | —（无标签） | `LastTab` | `settingsTab` | int | 0..4 | 0 | 页面自身 | 全 |

- **15 项之外不加**：新增设置项＝在 `GameSettings` 加一个字段 + 本文表加一行；机制零改动（`Setting<T>` 已承载键/默认/钳制）。
- **`LastTab` 也入表**：它是玩家偏好，必须随存档跨会话；但它不产生任何引擎副作用，生效器写"页面自身"。
- **值域即契约**：越界值在 `Setting<T>` 的 clamp 里死掉；UI 只暴露表内枚举，不提供自由输入。

### 3.3 默认值与常量的归属

| 常量 | 归属 | 理由 |
| --- | --- | --- |
| 帧率档默认（桌面 0 / 移动 60） | `FrameRateOptions.DefaultFor(bool isMobile)`（Settings 模块内常量类） | 与 `AppLifetime` 现有 `MobileTargetFrameRate/DesktopTargetFrameRate` 同源；`AppLifetime.ResolveTargetFrameRate` 改为委托它，现有用例继续钉 |
| 渲染缩放档（70/85/100） | `GraphicsOptions`（Settings 模块内常量类） | Lua 选项表要与它对齐（§9.1 选项对齐用例） |
| 抗锯齿档（0/2/4） | 同上 | 同上 |
| 阴影档（距离/级联数） | 同上：低 25m/1 级、中 50m/2 级、高 80m/4 级 | 阴影数值是表现参数，不进 `CombatConfig`（BuildHash 源集） |
| 灵敏度基线与 ADS 比值 | 沿用 `BattleLookController.LookSensitivityRadPerPixel`（0.0025）/`AdsLookSensitivityScale`（0.6） | 机制初档常量单源；产品设置只提供倍率，不复制数值 |

## 4. 生效面

### 4.1 生效纪律（四组共用）

| # | 纪律 | 落地 |
| --- | --- | --- |
| E1 | **单一写者** | 每个设置项恰有一个生效器；页面与 Lun 只经门面，不直接调 `Screen`/`QualitySettings` |
| E2 | **构造即应用** | `ProductSettings` 构造时全量应用一次（启动按存档生效），顺序固定（E4） |
| E3 | **改值即应用** | `Set*` 先写 `GameSettings`（标脏），再调对应生效器；不攒批、不等关闭 |
| E4 | **顺序固定** | 画质档 → 图形覆盖 → 垂直同步 → 分辨率 → 显示模式 → 帧率上限（后项依赖前项，见 §4.2/§4.3） |
| E5 | **幂等** | 同值重复应用必须零副作用（避免页签来回切换时反复重建管线/窗口） |
| E6 | **失败降级** | 平台不支持/参数非法：`Log.Warning` + 保持原值，不抛、不炸装配 |
| E7 | **落盘时机不变** | 仍走 `SettingService` 脏标记三处纪律（设置页 `OnHide`/`Close`、`OnApplicationPause(true)`、退出钩子） |

### 4.2 图形生效器

**档位（预设）**：`QualitySettings.SetQualityLevel(target, applyExpensiveChanges: true)`，UI 三档 ↔ 平台档位按名匹配、缺档按序号钳位（现行逻辑不变）。

**覆盖（渲染缩放 / 抗锯齿 / 阴影）**：走"影子管线资产"。

| 项 | 规则 |
| --- | --- |
| 触发 | 三项全为"跟随预设"时**不克隆**（零开销，与现状等价） |
| 克隆 | `Object.Instantiate(QualitySettings.renderPipeline ?? GraphicsSettings.currentRenderPipeline)`，只改标量后 `QualitySettings.renderPipeline = clone` |
| 可改字段 | 只允许 URP 公开 setter：`renderScale`、`msaaSampleCount`、`shadowDistance`、`shadowCascadeCount`（URP 14.0.11 已核：阴影开关 `supportsMainLightShadows`、阴影贴图分辨率 `mainLightShadowmapResolution`、软阴影 `supportsSoftShadows`、附加光模式 `additionalLightsRenderingMode` 均为 `internal set`，**不在覆盖面**；`supportsHDR` 虽是公开 setter，但见下条不暴露） |
| 管线切换 | `QualitySettings.renderPipeline` 是引擎级"当前质量档的管线覆盖"（Unity 2022.2+），URP 不需要感知它；赋值后是否真正切管线属阶段 B 的验证项（R1） |
| 缓存 | 键 =（档位, 缩放, 抗锯齿, 阴影）；命中复用，未命中重建并销毁旧副本 |
| 还原 | 三项全回"跟随预设" → `QualitySettings.renderPipeline = null` + 销毁副本 |
| 换档 | 画质档变化后**重跑**覆盖（覆盖是叠在新档之上的结果，不是绝对配置） |
| Editor 安全 | 副本是运行时对象，永不写盘（不触 `AssetDatabase`，不违反"Unity 序列化资产禁直改"） |
| 释放 | 模块关闭/应用退出时销毁副本，避免内存与管线句柄残留 |
| 存放 | `Assets/LiteFramework/Runtime/Adapters/Urp/`（适配器）；URP 引用只加在 `LiteFramework.Runtime.asmdef`，并登记纪律扫描 R12 边界（§8.4） |
| 生效器位置 | 三个生效器住 `Assets/LiteFramework/Runtime/Adapters/Unity/Settings/`——`Modules/Settings/**` 被 `LiteFramework.Async.csproj`（L1 纯项目）glob，带 UnityEngine 的件进去会编译失败 |

**为什么不是"运行时直接改资产"**：在编辑器里跑 Play 会就地修改已导入的 URP 资产（标脏、可能被保存），是"直改 Unity 序列化资产"的变体；克隆方案把写面限制在运行时对象上，代价是一次性 `Instantiate` 与一次管线切换。

**为什么覆盖项只有三个**：三个覆盖都对应"性能可感知、观感代价可控"的开关。阴影开关与阴影贴图分辨率虽是更直观的档，但 URP 把它们设成 `internal set`——用反射去改等于把表现档位绑在包实现细节上，下一次 URP 升级即断，所以阴影档只走"距离 + 级联数"两个公开标量。HDR 有公开 setter 却**刻意不做玩家开关**：它改变色调映射与后期观感，属美术口径，玩家可见的"画质"不该由玩家自己改成另一套观感。三档预设已经承载"整体降档"，覆盖只解决"某项特别吃性能"的个例。

### 4.3 显示生效器

| 项 | 规则 |
| --- | --- |
| 分辨率表 | `Screen.resolutions` 按（宽, 高）去重，取支持的最大刷新率，宽高降序；表为空或只有一项（部分平台/远程桌面）时该行隐藏 |
| 分辨率语义 | **只在窗口模式可编辑**：独占全屏/无边框由显示器分辨率决定，行置灰并显示"跟随显示器"；窗口模式下 `""` 取默认窗口尺寸（常量 1280×720），否则按 `"WxH"` |
| 应用顺序 | 分辨率 → 显示模式 → 垂直同步 → 帧率：窗口模式用 `Screen.SetResolution(w, h, Windowed)` 一次提交；全屏/无边框走 `Screen.fullScreenMode`（尺寸由显示器决定，不传分辨率） |
| 显示模式 | 0 `FullScreenMode.ExclusiveFullScreen`、1 `FullScreenMode.FullScreenWindow`、2 `FullScreenMode.Windowed` |
| 帧率 | `Application.targetFrameRate = effectiveVSync > 0 ? -1 : (cap == 0 ? -1 : cap)`（垂直同步开时上限由刷新率决定，改帧率上限无效） |
| 垂直同步 | `effectiveVSync = VSync == -1 ? 档位值 : VSync`；`QualitySettings.vSyncCount = effectiveVSync`（三档资产的 `vSyncCount` 为 0/1/1） |
| 分辨率匹配失败 | 存档里的 `"WxH"` 不在当前显示器列表 → 按"未指定"应用（窗口用默认尺寸）并 `Log.Warning`（换显示器是合法场景，不报错） |
| Editor | 运行时判 `Application.isEditor`：不改窗口（Game 视图不受 `Screen.SetResolution` 影响），只应用帧率与垂直同步；**不写 `#if UNITY_EDITOR`**（R5 要求三宏并集，运行时判断更省事） |
| 移动端 | 只应用帧率；显示模式/分辨率/垂直同步不进 UI（§4.6） |
| 对局中 | 显示模式与分辨率**页面置灰**（窗口重建会卡顿，战斗中被拖帧＝体验事故）；帧率与画质不受限 |

**PlayerSettings 联动建议**：`defaultScreenWidth/Height` 现为 1024×768，与 1920×1080 参考分辨率不符；建议改为 1920×1080（工程设置改动走 unity-pipeline，不在本设计的代码面内）。

### 4.4 控制生效器（视角）

**端口**（App 层实例，只读）：

```text
ILookPreferences
  float SensitivityMultiplier { get; }   // 0.2..3.0
  float AdsScale { get; }                // 0.3..1.0
  bool InvertY { get; }
  event Action Changed;                  // 设置页改值后触发（对局中即时生效）
```

- 实现 `LookPreferences`（`Modules/Presentation/Battle/Look/`）：读 `GameSettings`，`Set` 时触发 `Changed`。
- 注入链：`ContainerModule` 构造 → `ProcedureBattle` 构造参数 → `BattleViewRig` 构造参数 → `BattleLookController`。
- 计算：`effective = LookSensitivityRadPerPixel × SensitivityMultiplier`；ADS 期再乘 `AdsScale`；`InvertY` 对 y 增量取反。
- 优先级：**GM 覆写（开发三宏）> 产品设置 > 机制常量**。`LookTuning` 仍优先（实机定档工具），发布形态随宏剥离。
- 为什么不用静态读口：R13/红线 6 禁新增 public static 可变状态；设置值经实例端口随装配链下传，`Changed` 事件替代轮询。

### 4.5 按键绑定（P2，目标形态）

| 面 | 设计 |
| --- | --- |
| 资产所有权 | `PlayerInputActions` 由 `InputModule` 创建一次，注入设备源与绑定服务（**单一资产实例**；现状是设备源自建，重绑拿不到同一份） |

## 5. 存储与迁移

### 5.1 存储形态

- 文件：`settings.json`（`SettingService` 单文件字典），键值全是字符串，可读可调试。
- 新增键天然兼容：缺键＝默认值，无需版本迁移脚本（`SettingService` 契约①）。
- 落盘仍是脏标记协议：`Set` 只标脏；设置页 `OnHide`/`Close`、`OnApplicationPause(true)`、退出钩子调 `SaveIfDirty`。

### 5.2 删除 `fullscreen`

- 该键**从未被消费**（全仓只有定义，无生效面），不承载任何产品语义。
- 处理：删 `GameSettings.Fullscreen`；不写迁移、不读旧值。旧档里残留的 `fullscreen` 键成为无害死键（`SettingService` 只读已知键）。
- 反向约束：**不许**再把"UI 开关"当存档迁移手段——迁移只在值有语义时才做。

### 5.3 值域收敛点

| 层 | 责任 |
| --- | --- |
| `Setting<T>` clamp | 第一道：越界写入即钳制（音量 0..1、灵敏度 0.2..3.0 等） |
| 生效器 | 第二道：档位映射（如 `displayMode` 非法 → 回 1）、分辨率匹配失败 → 未指定（窗口默认尺寸） |
| 门面 | 第三道：枚举型值先查允许集，非法值静默忽略 + 开发期 Warning |

## 6. Lua 门面（`Bridge.settings`）

### 6.1 形状

旧项**平铺保持兼容**（页面与既有测试不破），新三组用子表（可读、与生效器 1:1、便于后续加项）：

```text
Bridge.settings
  Volume() / SetVolume(v)                  -- 既有
  SoundEnabled() / SetSoundEnabled(on)     -- 既有
  Quality() / SetQuality(tier)             -- 既有，0..2
  Save()                                   -- 既有
  ResetDefaults()                          -- 新增：全部回默认并应用（不含会话态）

  .graphics
    RenderScale() / SetRenderScale(v)      -- -1 跟随 / 70 / 85 / 100
    AntiAliasing() / SetAntiAliasing(v)    -- -1 跟随 / 0 / 2 / 4
    Shadow() / SetShadow(v)                -- -1 跟随 / 0 低 / 1 中 / 2 高

  .display
    Mode() / SetMode(v)                    -- 0 独占全屏 / 1 无边框 / 2 窗口
    SupportsMode() -> bool
    ResolutionCount() / ResolutionLabel(i) -- i: 0..Count-1；标签 "1920 × 1080"
    ResolutionIndex() / SetResolutionIndex(i)  -- i = -1 未指定（窗口默认尺寸）
    SupportsResolution() -> bool
    FrameRateOptionCount() / FrameRateOption(i)  -- 平台可用帧率档（值）
    FrameRate() / SetFrameRate(v)
    VSync() / SetVSync(v)                  -- -1 跟随 / 0 关 / 1 开
    SupportsVSync() -> bool

  .control
    LookSensitivity() / SetLookSensitivity(v)     -- 0.2..3.0
    AdsSensitivity() / SetAdsSensitivity(v)      -- 0.5..1.5（倍率）
    InvertLookY() / SetInvertLookY(on)
    -- P2
    BindingCount() / BindingLabel(i) / BindingKey(i)
    BeginRebind(i, cb) / CancelRebind() / ResetBindings()
    SupportsRebind() -> bool

  .general
    LastTab() / SetLastTab(i)              -- 0..4，页面记忆
```

### 6.2 语义约束

| # | 约束 |
| --- | --- |
| A1 | 所有 `Set*` 即时生效并标脏；不提供"只存不生效"的变体 |
| A2 | `Set*` 返回 void；非法值静默忽略（保 UX 不炸），开发期 `Log.Warning` |
| A3 | 动态枚举（分辨率、帧率档）**数量与取值由 C# 给**，Lua 不硬编码平台差异 |
| A4 | 固定枚举（渲染缩放/抗锯齿/阴影/显示模式）Lua 侧持有"值 + 文案键"常量表，C# 侧持有允许值集；两侧由用例钉住对齐（§9.1） |
| A5 | 语言不进 `settings`：仍走 `Bridge.text.SetLocale`（避免两套语言写口） |
| A6 | 门面**不判对局态**：对局中禁用显示类是页面职责（门面保持无流程耦合） |

### 6.3 页面与门面的调用约定

- 打开：`OnShow` 一次性读全部初值 → 写控件 → 只登记回调；不在拖动过程中反复读设置。
- 关闭：`OnHide`/`Close` 调 `Bridge.settings.Save()`（"设置界面关闭"纪律点，与现状一致）。
- 语言切换：`Bridge.text.SetLocale` 后**重设全部分类的下拉选项文本**（下拉项文本是引擎组件，不随 LText 自动刷新——现行代码只刷了画质，扩展后必须刷全部，这是本节最容易漏的一条）。

**实测坑（必须在本设计里解决，否则施工会写错文件）**：`gen-ui-page.py` 与 `gen-ui-api.py` 的默认输出仍指向已不存在的 `Assets/LiteClient/...`，与现役产物（`Assets/LiteFramework/Runtime/Modules/UI/Generated`、`.../UI/Bind/Generated`）不一致，`--check` 必然 FAIL。该问题已登记在[全项目数据流 §18 P1 #20](../../../说明/17-全项目数据流.md)（只登记了 page 脚本，api 脚本同型未登记）。落地前先修两处 `DEFAULT_OUTPUT`/`OUT_*` 并纳入门禁复跑，否则"重生成"是假动作。

## 13. 词汇

| 词 | 含义 |
| --- | --- |
| 生效器（Applier） | 把某个设置项的值写进引擎/服务的那一小块代码；一门一组 |
| 影子管线资产 | 运行时从当前档 URP 资产克隆出来、只承载覆盖参数的副本；不落盘 |
| 预设（Preset） | 画质三档对应的 `QualitySettings` 档位 + URP 资产组合 |
| 覆盖（Override） | 叠在预设之上的单项调整（缩放/抗锯齿/阴影）；`-1` 表示不覆盖 |
| 能力（Capability） | 当前平台是否支持某类设置；页面据此隐藏行，而不是写平台分支 |
