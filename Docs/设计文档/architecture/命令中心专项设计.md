## 1. 定位与分工

命令中心是框架级**机制件**：类型化"意图请求"的注册-执行-结果链路。与相邻机制的分工（本专项的边界即这张表）：

| 机制 | 分工边界 |
| --- | --- |
| `EventCenter`（事件） | **事件 = 已发生的事实**：广播、无结果、发布即移交。**命令 = 有意图的请求**：单处理器、可拒绝、有结果；执行成功后由执行方发事件（命令→事实的单向流，CQRS 轻量版）——命令中心不发布事件，执行方自己发 |
| `RoomCommand`（服务端） | 服务端权威循环的**网络命令输入**。客户端命令中心只管**本地意图**（GM 操作、本地流程动作）：不做权威判定、不发网络——需要服务端权威的操作走既有网络协议，命令中心在协议层之下不做转发 |
| `DebugTuner` 连续旋钮 | 时间缩放滑条/暂停开关这类**连续状态直调**保持现状（不是命令）；命令中心面向**离散动作**（重置时钟、切换本地服、跳流程、给道具……）——GM 面板是 GM 命令的第一消费端（发现 + 执行），旋钮不强行命令化 |
| `Procedure`/状态机 | 流程切换有状态机守卫，不是命令；命令可以**请求**流程动作（执行方调状态机），中心不碰流程 |
| `SubscriptionBag`/`ClientScope` | 命令注册的生命周期挂点（`Register` 返回 `IDisposable`，Scope 可登记） |

红线：**命令类型唯一处理器**（同类型重复注册 = 契约违反，注册时 fail-fast）；客户端本地语义（无权威、无网络）；主线程 only；零引擎依赖（`Core/Command`，与 Pool/Event 同层）。

## 2. 核心契约

```csharp
public interface ICommand { }                          // 标记接口（类型即命令；零字段命令合法）

public interface ICommandHandler<in TCommand> where TCommand : ICommand
{
    CommandResult Execute(TCommand command);           // 同步；可拒绝（返回失败结果而非抛）
}

public readonly struct CommandResult
{
    public bool Ok;                                    // 校验/执行失败 = false + Reason/Detail
    public CommandReject Reason;                       // None/GmBlocked/HandlerRejected/...
    public string Detail;
}

public sealed class CommandOptions
{
    public bool GmOnly;                                // 权限门（§3）
    public string Description;                         // GM 面板发现面用（§5）
}

public interface ICommandCenter
{
    IDisposable Register<TCommand>(ICommandHandler<TCommand> handler, CommandOptions options = null) where TCommand : ICommand;
    CommandResult Send<TCommand>(TCommand command) where TCommand : ICommand;   // 同步执行
    bool HasHandler<TCommand>() where TCommand : ICommand;
}
```

- **执行序**：`Send` = 权限门（§3）→ 处理器 `Execute`。**无处理器 = 编程错误**，`Send` 直接抛 `InvalidOperationException`（fail-fast，同 `_active.ContainsKey` 先例；GM 面板从注册清单发现命令，不会踩到）；`GmBlocked` 是**运行态拒绝**，返回失败结果不抛（release 的正常路径）。
- **处理器异常**：`Execute` 抛异常 = 处理器作者代码缺陷——记 `Log.Error` + 审计留痕，返回 `Failed` 结果（不炸调用方；同事件订阅者隔离口径）。
- **命令对象生命周期归调用方**：`Send` 同步返回后调用方可复用/池化（走 `ReferencePool` 与否是发送方的事——中心不知道 `IReference`，与事件通道同纪律）。
- **重复注册**：抛 `InvalidOperationException`（唯一性是契约；替换先注销返回的 `IDisposable`）。

## 3. 权限门（GM 命令三宏分流）

- `options.GmOnly = true` 的命令：**三宏并集之外（release）`Send` 一律 `CommandReject.GmBlocked`**（不执行、不抛、计数）——GM 能力物理上进不了发布版；三宏内（编辑器/开发构建）放行。
- 非 GmOnly 命令不受门影响（业务命令 release 正常执行）。
- `StrictMode` 不参与权限门（一个是"没人听告警"、一个是"能力隔离"，两回事）。

## 4. 高级执行形态（排队/异步/拦截器/撤销重做）

地基完整性优先于"当前无调用方"——四种执行形态全部入契约：

- **排队执行** `SendQueued<TCommand>(TCommand cmd, int delayFrames = 0)`：入队，`Tick` 驱动到期按入队序执行（**fire-and-forget**——无返回结果，失败走审计与日志；命令对象实现 `IReference` 则执行完由中心回收，即移交语义）。有界队列 `MaxQueued`（默认 256）+ 溢出丢弃计数。`SendQueued` 命令同样过权限门与拦截器链。
- **异步处理器** `IAsyncCommandHandler<in TCommand>`（`ValueTask<CommandResult> ExecuteAsync(TCommand, CancellationToken)`）+ `SendAsync<TCommand>`——`RegisterAsync<T>` 单独注册（同步/异步注册互斥，类型错配 = 编程错误 fail-fast）。Core 零第三方依赖，用 `ValueTask` 不引 UniTask。
- **拦截器管线** `RegisterInterceptor(ICommandInterceptor)`（登记序）：执行序 = 权限门 → 拦截器链（任一拒绝即终止，`InterceptorRejected`）→ 处理器。定位：频率限制、审计、GM 防滥用。
- **撤销/重做**（opt-in 能力件）：`RegisterUndoable<T>`（`IUndoableCommandHandler<T> : ICommandHandler<T>` 追加 `Undo(TCommand)`）——`Send` 成功的 undoable 命令进历史栈（容量 64），`Undo()`/`Redo()`/`CanUndo`/`CanRedo`；**仅同步 `Send` 进栈**（排队/异步命令无回滚点）；重做 = 重新 `Execute`。约束：客户端本地语义（§1），业务命令自行声明可撤销性。

## 5. 明确不做（非目标登记）

- **网络转发**：§1 边界——协议层职责（`RoomCommand`）。
- **值类型命令/跨线程**：同事件中心 §3.7 的架构不变量。

## 6. 统计、审计与发现面

- **统计**（`IModuleStats`）：`Registered`（当前注册数）/`Sent`/`GmBlocked`/`Failed`（处理器返回失败与异常合计）。
- **审计环**：最近 32 条（预分配环形，无分配）——命令类型/时序/Ok/Reason；无条件记录（release 排障同样需要"刚才发了什么命令"），**读取面** `GetAuditLog()` Debug 三宏（与 HUD 同生命周期）。
- **发现面**：`GetRegisteredInfos()` Debug 三宏——`CommandInfo`（命令类型/`GmOnly`/`Description`/注册时序），GM 面板据此列出可用命令，不硬编码命令清单。

## 6. 与 GM 面板的关系

`DebugTuner` 现状 = 公有字段旋钮 + `Inject` 直调服务（连续状态直调，保持）；命令中心交付后，**离散调试动作**（重置时钟、切本地服、重载 Lua、测试钩子）以 GM 命令注册，面板经发现面列出并执行——旋钮不强行命令化，两形态并存。首批示范迁移（1 个命令）验证消费端闭环，其余迁移归 Debug/开发面消费批。

## 7. 验收口径

- **L1 直测**（`CommandCenterTests`，机制件零直测不允许）：注册/Send 成功路径、处理器返回失败、处理器异常隔离（返回 Failed 不炸调用方）、无处理器 fail-fast、重复注册抛、权限门两态（GmOnly 在三宏外拒绝且计数、三宏内执行）、审计环容量与内容、统计口径、Register 返回的 IDisposable 注销后 Send 转 NoHandler。批3 追加：排队到期序与有界溢出、SendAsync 同步/异步注册互斥、拦截器拒绝短路、撤销/重做栈（含不可撤销命令跳过）。
- **行为等价**：`DebugTuner` 现有旋钮零改动仍正确（示范迁移命令不影响旋钮）。
- 门禁：L1 全量 + Unity 编译；EditMode 随编辑器窗口期。
